=== 许可证开始 ===

VIM 许可证

I)  分发未修改的 Vim 副本没有任何限制，但它们必须包含此许可证文本。
    你也可以分发未修改的 Vim 部分，同样不受限制，但它们必须包含此许可证
    文本。你还可以包含从未修改的 Vim 源代码编译的可执行文件，加上你自己的
    使用示例和 Vim 脚本。

II) 当满足以下四个条件时，允许分发修改 (或扩展) 版本的 Vim，包括可执行
    文件和/或源代码:
    1) 此许可证文本必须不加修改地包含在内。
    2) 修改的 Vim 必须以以下五种方式之一分发:
       a) 如果你自己对 Vim 进行了修改，你必须在分发中清楚地描述如何联系你。
	  当维护者以任何方式要求你提供分发的修改 Vim 的副本时，你必须免费向
	  维护者提供你的修改，包括源代码。维护者保留将你的修改包含在 Vim
	  官方版本中的权利。维护者如何处理你的修改以及以何种许可证分发是
	  可以协商的。如果没有进行协商，则此许可证或更高版本也适用于你的
	  修改。当前的维护者列在此处:
	      https://github.com/orgs/vim/people
	  如果有变更将在适当的地方公布 (最可能是 vim.sf.net、www.vim.org
	  和/或 comp.editors)。当完全无法联系维护者时，发送修改的义务终止。
	  一旦维护者确认收到你的修改，就不需要再次发送。
       b) 如果你收到了按 a) 所述分发的修改 Vim，你可以按 I) 所述进一步
	  分发未修改的版本。如果你做了额外的修改，a) 下的文本适用于这些
	  修改。
       c) 在你分发的修改 Vim 的每个副本中提供所有修改，包括源代码。这可以
	  以上下文差异的形式完成。你可以选择对新添加的代码使用什么许可证。
	  修改及其许可证不得限制他人对 Vim 官方版本进行自己的修改。
       d) 当你有一个包含 c) 所述修改的修改 Vim 时，如果满足以下三个条件，
	  你可以在没有修改源代码的情况下分发:
	  - 适用于修改的许可证允许你免费且不受限制地将修改分发给 Vim 维护者，
	    并允许 Vim 维护者免费且不受限制地将修改包含在 Vim 官方版本中。
	  - 你在最后分发相应修改 Vim 后至少保留修改三年。当维护者或你分发
	    修改 Vim 的对象在此期间内以任何方式要求修改时，你必须向他提供。
	  - 你在分发中清楚地描述如何联系你。此联系信息在最后分发相应修改 Vim
	    后至少三年内或尽可能长的时间内必须保持有效。
       e) 当 GNU 通用公共许可证 (GPL) 适用于修改时，你可以在 GNU GPL
	  版本 2 或任何更高版本下分发修改的 Vim。
    3) 必须添加一条消息，至少在 ":version" 命令的输出和介绍屏幕中，使得
       修改 Vim 的用户能够看到它已被修改。当按 2)e) 所述分发时，只有在
       不与修改所使用的许可证冲突的情况下才需要添加消息。
    4) 2)a) 和 2)d) 所要求的联系信息不得被删除或更改，除非本人可以进行
       更正。

III) 如果你分发修改版本的 Vim，我们鼓励你使用 Vim 许可证来处理你的修改，
     并将它们 (包括源代码) 提供给维护者。首选方式是通过电子邮件或将文件
     上传到服务器并通过电子邮件发送 URL。如果修改数量很少 (例如修改的
     Makefile)，通过电子邮件发送上下文差异即可。电子邮件地址为
     <maintainer@vim.org>

IV)  不允许从 Vim 源代码的分发、其部分或修改版本中删除此许可证。你可以
     选择将此许可证用于以前的 Vim 发行版，以代替它们附带的许可证。

=== 许可证结束 ===

注意:

- 如果你对 Vim 感到满意，请通过阅读本文件的其余部分来表达，并考虑帮助
  乌干达有需要的儿童。

- 如果你想支持 Vim 的进一步开发，考虑成为 |sponsor|。捐款最终都会送往
  乌干达。

- 根据 Richard Stallman 的说法，Vim 许可证与 GNU GPL 兼容。自他检查以来
  做了一些小的更改，但这应该没有区别。

- 如果你将 Vim 与使用 GNU GPL 的库链接，这会将进一步的分发限制为 GNU GPL。
  即使你实际上没有更改 Vim 中的任何内容。

- 一旦包含了使用 GNU GPL 的更改，这会强制所有后续更改也必须在 GNU GPL 或
  兼容许可证下进行。

Kibaale 儿童中心		*kcc* *Kibaale*  *charity*

Kibaale 儿童中心 (KCC) 位于 Kibaale，乌干达南部靠近坦桑尼亚的一个小镇，
在东非。该地区被称为 Rakai 区。人口主要是农民。虽然人们很穷，但通常有
足够的食物。但这个地区比世界上任何其他地方都更严重地遭受艾滋病的影响。
有人说它就是从那里开始的。估计在过去 10 到 30% 的乌干达人感染了 HIV。
因为父母去世，有很多孤儿。在这个区域，35万人口中约有 60,000 名儿童
失去了一个或两个父母。虽然艾滋病现在基本得到控制，但问题仍在继续。

这些儿童需要大量帮助。KCC 努力为有需要的人提供食物、医疗和教育。食物和
医疗帮助他们现在保持健康，教育使他们将来能够照顾自己。KCC 基于基督教基础
运作，但向任何宗教的儿童提供帮助。

解决这个地区问题的关键是教育。在 Idi Amin 总统和随后的内战期间，教育
被忽视了。现在政府再次稳定，儿童和父母必须学会如何照顾自己以及如何避免
感染。也有帮助生病和饥饿的人，但主要目标是防止人们生病并教他们如何种植
健康的食物。

大多数孤儿生活在大家庭中。一个叔叔或姐姐在照顾他们。因为这些家庭很大
而收入很低 (如果有的话)，一个孩子能得到健康的食物就算幸运了。衣服、
医疗和上学超出了他们的能力范围。为了帮助这些有需要的儿童，建立了一个
资助计划。一个孩子可以被经济资助。每月几美元，KCC 确保孩子获得必需品、
保持健康、上学，KCC 还处理孩子和支持它的家庭需要做的其他一切。

除了直接帮助儿童外，还需要改善儿童成长的环境。KCC 帮助学校改进教学方法。
中心有一所示范学校，提供教师培训。培训卫生工作者，开展卫生教育，鼓励
家庭建造合适的厕所。我帮助建立了一个水泥板生产基地。这些用于建造好的
厕所。它们以低于成本价出售。

项目中有一个诊所，为儿童及其家庭提供医疗帮助。自 2020 年以来增加了
产科病房，提供 24/7 服务。需要时提供到医院的交通。进行免疫接种计划，
在疫情爆发时提供帮助 (麻疹和霍乱一直是问题)。

1994 年夏天到 1995 年夏天，Bram 在中心度过了整整一年，作为志愿者工作。
Bram 帮助扩建了中心并在水和卫生领域工作。Bram 了解到 KCC 提供的帮助
确实有效。当 Bram 回到荷兰时，他想继续支持 KCC。为此他一直在筹集资金
并组织资助计划。

你怎么知道钱会被正确使用？首先，你有 Bram 作为 Vim 作者的个人保证，
他亲自认识在中心工作的人。此外，中心曾被 World Vision、Save the Children
Fund 共同赞助和检查，现在在 Pacific Academy Outreach Society 的监督下。
Bram 从 1993 年开始多次访问中心。访问报告已在 ICCF 网站上分享 (可能
不再可用)。

如有任何进一步的问题，请发送电子邮件: info@kuwasha.net。
