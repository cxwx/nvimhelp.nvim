• *$NVIM_LISTEN_ADDRESS*
  • 已弃用的用途：
    • 设置服务器名称（使用 |--listen| 或 |serverstart()| 代替）
    • 获取服务器名称（使用 |v:servername| 代替）
    • 检测父 Nvim（使用 |$NVIM| 代替）
  • 如果给出了 --listen 则被忽略。
  • 在启动时取消设置（在 |v:servername| 初始化之后）。可以通过 "env" 选项
    显式提供给 |terminal| 和 |jobstart()|。示例：>vim
	call jobstart(['foo'], { 'env': { 'NVIM_LISTEN_ADDRESS': v:servername  } })
