可视模式				*Visual* *Visual-mode* *visual-mode*

可视模式是一种灵活且简单的方式来选择一段文本以供操作符使用。它是选择文本块的
唯一方式。

此内容在用户手册的 |04.4| 节中有介绍。

                                      输入 |gO| 查看目录。

==============================================================================
1. 使用可视模式					*visual-use*

使用可视模式由三个部分组成：
1. 用 "v"、"V" 或 CTRL-V 标记文本的起始位置。
   光标下的字符将作为起始位置。
2. 移动到文本的末尾。
   从可视模式开始处到光标下字符（含）之间的文本会被高亮显示。
3. 输入一个操作符命令。
   高亮显示的字符将被执行该操作。

|hl-Visual| 组决定了可视选区的高亮方式。
'virtualedit' 选项可以用来允许将光标定位到没有实际字符的位置。

高亮的文本通常包括光标下的字符。但是，当 'selection' 选项设置为 "exclusive" 且
光标在可视区域之后时，光标下的字符不会被包含。

使用 "v" 时，起始位置之前和结束位置之后的文本不会被高亮显示。但是，所有大写和
非字母的操作符（除了 "~" 和 "U"）都会在整行上操作。参见下面的操作符列表。

							*visual-block*
使用 CTRL-V（块状可视模式）时，高亮的文本将是起始位置和光标之间的矩形区域。
但是，某些操作符仍然在整行上操作（参见下面的列表）。更改和替换操作符会删除高亮
的文本，然后从左上角位置开始插入。

2. 进入和退出可视模式				*visual-start*

						*v* *charwise-visual*
[count]v		按字符启动可视模式。
			使用 [count] 时，选择与上次可视操作相同数量的字符
			或行，但在当前光标位置，乘以 [count]。
			当上次可视操作是块状操作时，块的宽度和高度都会
			乘以 [count]。
			当没有上次可视操作时，选择 [count] 个字符。这就
			像将光标向右移动 N * [count] 个字符。当
			'selection' 不是 "exclusive" 时少一个。

						*V* *linewise-visual*
[count]V		按行启动可视模式。
			使用 [count] 时，选择与上次可视操作相同数量的行，
			但在当前光标位置，乘以 [count]。当没有上次可视
			操作时，选择 [count] 行。

						*CTRL-V* *blockwise-visual*
[count]CTRL-V		按块启动可视模式。

如果你在可视模式下按 <Esc>、点击鼠标左键或使用任何跳转到其他缓冲区的命令，
高亮显示将停止且不影响任何文本。同样，在字符可视模式下按 "v"、在块状可视模式
下按 "CTRL-V" 或在行可视模式下按 "V" 也会停止可视模式。如果按 CTRL-Z，高亮
将停止且编辑器被挂起或启动一个新的 shell |CTRL-Z|。

	      输入后的新模式：			*v_v* *v_CTRL-V* *v_V*
旧模式		     "v"	      "CTRL-V"		     "V"	~

普通		    可视	   块状可视		  行可视
可视		    普通	   块状可视		  行可视
块状可视	    可视	   普通			  行可视
行可视		    可视	   块状可视		  普通

						*gv* *v_gv* *reselect-Visual*
gv			用与上次相同的区域和模式启动可视模式。
			在可视模式中，当前可视区域和上次可视区域会互换。
			在可视模式中使用 "p" 或 "P" 后，被放置的文本将
			被选中。

								*gn* *v_gn*
gn			向前搜索上次使用的搜索模式，就像用 `n` 一样，
			并启动可视模式来选择匹配项。如果光标在匹配项上，
			则可视选择该匹配项。如果有操作符等待中，则对
			匹配项执行操作。例如，"dgn" 删除下一个匹配项
			的文本。如果可视模式已激活，则将选区扩展到下
			一个匹配项的末尾。
			'wrapscan' 生效。
			注意：与 `n` 不同，搜索方向不取决于上次搜索
			命令。

								*gN* *v_gN*
gN			类似 |gn|，但向后搜索，就像用 `N` 一样。

							*<LeftMouse>*
<LeftMouse>		设置当前光标位置。如果可视模式处于激活状态，则
			停止可视模式。仅当 'mouse' 选项包含 'n' 或 'a'
			时有效。如果位置距屏幕最后一行在 'so' 行以内，
			文本会向上滚动。如果位置距屏幕第一行在 'so' 行
			以内，文本会向下滚动。

							*<RightMouse>*
<RightMouse>		如果可视模式未激活，则启动可视模式。从光标位置到
			点击位置之间的文本会被高亮显示。如果可视模式已经
			激活，则将高亮文本的起始端或结束端（取较近者）
			移动到点击位置。仅当 'mouse' 选项包含 'n' 或
			'a' 时有效。

			注意：当 'mousemodel' 设置为 "popup" 时，
			需要使用 <S-LeftMouse> 代替 <RightMouse>。

							*<LeftRelease>*
<LeftRelease>		此操作类似 <LeftMouse>，但仅在与 <LeftMouse> 不在
			同一位置时生效。在较旧版本的 xterm 中，除非能
			访问运行 xterm 的显示器（通过 DISPLAY 环境变量
			或 -display 参数），否则在释放按钮之前看不到
			选中的区域。仅当 'mouse' 选项包含 'n' 或 'a'
			时有效。

如果可视模式未激活，且 "v"、"V" 或 CTRL-V 前面带有计数，则会使用上次高亮区域
的大小作为起始。然后你可以移动高亮区域的末端并执行操作符命令。旧区域的类型
（字符、行或块状）会被使用。
- 行可视模式：行数乘以计数。
- 块状可视模式：行数和列数乘以计数。
- 单行内的普通可视模式：字符数乘以计数。
- 多行的普通可视模式：行数乘以计数，最后一行使用与上次高亮区域最后一行相同
  的字符数。
文本的起始位置是光标位置。如果 "$" 命令被用作扩展高亮文本的最后命令之一，
则区域将扩展到最长行的最右列。

如果你想高亮与上次完全相同的区域，可以使用 "gv" |gv| |v_gv|。

							*v_<Esc>*
<Esc>			在可视模式中：停止可视模式。
						*v_META* *v_ALT*
		如果组合键没有映射，ALT (|META|) 可能像 <Esc> 一样起作用。
		例如，如果 <A-x> 没有可视模式映射，<A-x> 就像 <Esc>x 一样
		起作用。

							*v_CTRL-C*
CTRL-C			在可视模式中：停止可视模式。当插入模式待处理时
			（模式消息显示 "-- (insert) VISUAL --"），也会
			被停止。
			在 MS-Windows 上，你可能需要按 CTRL-Break。

==============================================================================
3. 改变可视区域					*visual-change*

							*v_o*
o			转到高亮文本的另一端：当前光标位置变为高亮文本
			的起始位置，光标移动到高亮文本的另一端。高亮
			区域保持不变。

							*v_O*
O			转到高亮文本的另一端。类似 "o"，但在块状可视
			模式中，光标移动到同一行的另一个角落。当角落
			所在的字符在屏幕上占据多个位置（例如 <Tab>）时，
			高亮文本可能会改变。

							*v_$*
在块状可视模式中使用 "$" 命令时，高亮文本的右端将由最长的高亮行决定。当使用
不是直接上下移动的移动命令时，此行为停止。

许多命令可以用来移动块的末端，但不能使用 Ex 命令、进行更改的命令或放弃文件
的命令。以 "."、"&"、CTRL-^、"Z"、CTRL-]、CTRL-T、CTRL-R、CTRL-I 和 CTRL-O
开头的命令会发出蜂鸣声且可视模式继续。

切换到同一缓冲区的另一个窗口时，该窗口中的光标位置会被调整，以便仍然选中
相同的可视区域。这在一个窗口中查看可视区域的起始、在另一个窗口中查看末端
时特别有用。然后你可以使用 <RightMouse>（或当 'mousemodel' 为 "popup" 时使用
<S-LeftMouse>）来拖动可视区域的任一端。

	r	修改 (4)					|v_r|
	s	修改						|v_s|
	C	修改 (2)(4)					|v_C|

(2): 不使用 CTRL-V 时作用于整行。

(4): 使用 CTRL-V 时仅作用于块。

注意 ":vmap" 命令可以用来专门在可视模式中映射按键。例如，如果你想让 "/" 命令
不扩展可视区域，而是取高亮文本并搜索它： >
	:vmap / y/<C-R>"<CR>
（在 <> 表示法 |<>| 中，输入时应按字面意思输入；你需要从 'cpoptions' 中移除
'B' 标志。）

如果你想使用 """ 命令指定寄存器名，请在输入操作符字符之前执行此操作：
"v{move-around}"xd"。

如果你想为命令指定计数，请在输入操作符字符之前执行此操作：
"v{move-around}3>"（将行右移 3 个缩进）。

							*{move-around}*
{move-around} 是任意序列的移动命令。注意它与 {motion} 的区别，后者只是一个
移动命令。

对可视区域进行操作的另一种方式是在模式中使用 |/\%V| 项。例如，要将可视区域中
所有的 '(' 替换为 '#'： >

	:'<,'>s/\%V(/#/g

注意在可视模式中按 ":" 时 "'<,'>" 会自动出现。

5. 块状操作符					*blockwise-operators*

提醒：使用 'virtualedit' 可以选择在行尾之后或 Tab 字符中间开始或结束的块。

块状可视插入						*v_b_I*
在块状选区中，I{string}<ESC> 会在块的每一行的块起始处插入 {string}，前提是
该行延伸到块中。因此较短的行不会被修改。TAB 会被拆分以保持可视列。仅适用于
向行中添加文本，不适用于删除。参见 |v_b_I_example|。

块状可视追加						*v_b_A*
在块状选区中，A{string}<ESC> 会在块的每一行的块末尾追加 {string}。当块的
右边界不齐时（由于不同的行长度），行为有所不同：

1. 块是用 <C-v>$ 创建的
    在这种情况下，字符串追加到每行的末尾。
2. 块是用 <C-v>{move-around} 创建的
    在这种情况下，字符串追加到每行块的末尾，并插入空白以填充到块末尾列。
参见 |v_b_A_example|。
注意："I" 和 "A" 对不延伸到选中块的行的行为不同。这是有意为之的，以便你可以
按你想要的方式操作。
仅适用于向行中添加文本，不适用于删除。

块状可视修改						*v_b_c*
块中所有选中的文本将被替换为相同的文本字符串。使用 "c" 时，选中的文本会被
删除并进入插入模式。然后你可以输入文本（不含换行符）。当你按 <Esc> 时，
相同的字符串会被插入到所有先前选中的行中。

块状可视修改						*v_b_C*
类似 "c"，但选区会扩展到所有行的行尾。

								*v_b_<*
块状可视移位						*v_b_>*
块按 'shiftwidth' 移位。块的右边界无关紧要。块的左边界决定了应用右移的起点，
填充会根据 'ts' 和 'et' 最优化地包含 TAB。块的左边界决定了左移的终点。
参见 |v_b_>_example|。
参见 |v_b_<_example|。

块状可视替换						*v_b_r*
高亮区域中的每个屏幕字符都被替换为相同的字符，即 TAB 会被拆分，虚拟空白
会被替换，保持屏幕布局。
参见 |v_b_r_example|。

6. 重复						*visual-repeat*

重复可视模式操作符时，操作符将应用于与上次相同数量的文本：
- 行可视模式：相同的行数。
- 块状可视模式：相同的行数和列数。
- 单行内的普通可视模式：相同的字符数。
- 多行的普通可视模式：相同的行数，最后一行与上次最后一行相同的字符数。
文本的起始位置是光标位置。如果 "$" 命令被用作扩展高亮文本的最后命令之一，
重复将应用到最长行的最右列。传给 `.` 命令的任何计数都不会被使用。

可视模式 |default-mappings| "@" 和 "Q" 在选区为行选区时会为所有选中的行
重复寄存器。详见 |v_@-default| 和 |v_Q-default|。例如，给定文本：

	123(hello)321
	456(world)654
	456(NOT THIS)654

寄存器 "x" 包含命令 `yi(VP`，可视选择前两行并输入 `@x` 产生：

	hello
	world
	456(NOT THIS)654

7. 示例						*visual-examples*

							*:visual_example*
目前 ":" 命令仅作用于整行。当你选择了行的一部分时，执行类似 ":!date" 的操作
会替换整行。如果你只想替换行的一部分，你需要为此创建一个映射。在未来的版本中
":" 可能能作用于部分行。

这里是一个示例，用 "date" 的输出替换选中的文本： >
	:vmap _a <Esc>`>a<CR><Esc>`<i<CR><Esc>!!date<CR>kgJgJ

（在 <> 表示法 |<>| 中，输入时应按字面意思输入；你需要从 'cpoptions' 中移除
'B' 标志）

这个操作的作用是：
<Esc>		停止可视模式
`>		转到可视区域的末尾
a<CR><Esc>	在可视区域之后断行
`<		跳转到可视区域的起始处
i<CR><Esc>	在可视区域之前断行
!!date<CR>	通过 date 过滤可视文本
kJJ		将各行重新连接在一起

							*visual-search*
这里是一个映射的想法，可以搜索选中的文本： >
	:vmap X y/<C-R>"<CR>

（在 <> 表示法 |<>| 中，输入时应按字面意思输入；你需要从 'cpoptions' 中移除
'B' 标志）

注意特殊字符（如 '.' 和 "*"）会引起问题。

8. 选择模式					*Select* *Select-mode*

选择模式看起来像可视模式，但接受的命令完全不同。它类似于 Microsoft Windows
中的选择模式。
当 'showmode' 选项开启时，最后一行会显示 "-- SELECT --"。

进入选择模式：
- 使用鼠标选择区域，且 'selectmode' 包含 "mouse"。
  'mouse' 也必须包含当前模式的标志。
- 使用不可打印的移动命令，同时按住 Shift 键，且 'selectmode' 包含 "key"。
  例如：<S-Left> 和 <S-End>。'keymodel' 也必须包含 "startsel"。
- 使用 "v"、"V" 或 CTRL-V 命令，且 'selectmode' 包含 "cmd"。
- 在普通模式中使用 "gh"、"gH" 或 "g_CTRL-H" 命令。
- 从可视模式，按 CTRL-G。			*v_CTRL-G*

选择模式中的命令：
- 可打印字符、<NL> 和 <CR> 会导致选区被删除，Vim 进入插入模式。输入的字符
  被插入。
- 不可打印的移动命令，同时按住 Shift 键，扩展选区。'keymodel' 必须包含
  "startsel"。
- 不可打印的移动命令，不按 Shift 键，停止选择模式。'keymodel' 必须包含
  "stopsel"。
- ESC 停止选择模式。
- CTRL-O 切换到可视模式，持续一个命令的时间。 *v_CTRL-O*
- CTRL-G 切换到可视模式。
- CTRL-R {register} 选择用于输入文本时删除文本所使用的寄存器。
								  *v_CTRL-R*
  除非你指定 "_"（黑洞）寄存器，否则无名寄存器也会被覆盖。

其他输入的字符按可视模式的方式处理。

在选择模式中使用操作符时，如果选区是行选区，选中的行会被操作，但方式类似
字符选区。例如，当整行被删除时，之后可以将其粘贴到行的中间。


选择模式中的映射和菜单。			*Select-mode-mapping*

当映射和菜单使用 |:vmap| 或 |:vmenu| 命令定义时，它们在可视模式和选择模式中
都有效。当它们在选择模式中使用时，Vim 会自动切换到可视模式，以便与可视模式中
相同的行为生效。如果你不想这样，请使用 |:xmap| 或 |:smap|。

一个特殊的边缘情况： >
	:vnoremap <C-K> <Esc>
这在可视模式中会结束可视模式，但在选择模式中不起作用，因为在执行映射的按键
后选择模式会被恢复。你需要使用： >
	:snoremap <C-K> <Esc>
<
用户期望可打印字符替换选中的区域。因此避免在选择模式中映射可打印字符。或者
在 |:map| 和 |:vmap| 之后使用 |:sunmap| 将其从选择模式中移除。

在映射或菜单完成后，选区会再次启用并进入选择模式，除非选中的区域被删除、
另一个缓冲区成为当前缓冲区或窗口布局被更改。

当输入的字符导致选区被删除并进入插入模式时，插入模式的映射会应用于该字符。
这可能会造成一些困惑，因为这意味着插入模式映射应用于在选择模式中输入的字符。
语言映射也同样适用。

							*gV* *v_gV*
gV			在选择模式映射或菜单完成后，避免自动重新选择可视
			区域。将此放在映射或菜单的末尾之前。至少应该在
			对选区的任何操作之后。

							*gh*
gh			启动字符选择模式。类似 "v"，但启动选择模式
			而非可视模式。
			助记："get highlighted"。

							*gH*
gH			启动行选择模式。类似 "V"，但启动选择模式
			而非可视模式。
			助记："get Highlighted"。

							*g_CTRL-H*
g CTRL-H		启动块选择模式。类似 CTRL-V，但启动选择模式
			而非可视模式。
			助记："get Highlighted"。
