*05.1*	vimrc 文件				*vimrc-intro*

你可能已经厌倦了输入那些经常使用的命令。要使 Vim 启动时就带有你喜欢的所有
选项设置和映射，你把它们写在所谓的 init.vim 文件中。Vim 在启动时执行这个
文件中的命令。

如果你已经有一个 init.vim 文件（例如，当你的系统管理员为你设置了一个），你
可以这样编辑它: >

	:edit $MYVIMRC

如果你还没有 vimrc 文件，参见 |init.vim| 了解在哪里创建 vimrc 文件。

这个文件始终被使用，推荐使用:

	~/.config/nvim/init.vim         (Unix 和 OSX) ~
	~/AppData/Local/nvim/init.vim   (Windows) ~

vimrc 文件可以包含所有你在冒号后输入的命令。最简单的是设置选项的命令。例如，
如果你想让 Vim 始终以 'ignorecase' 选项开启来启动，在 vimrc 文件中添加
这一行: >

	set ignorecase

要使这一新行生效，你需要退出 Vim 并重新启动。稍后你会学到如何不退出 Vim
就做到这一点。

本章只解释最基本的内容。关于如何编写 Vim 脚本文件的更多信息:
|usr_41.txt|。

*05.2*	vimrc 文件内容示例                          *vimrc_example.vim*

在第一章中解释了如何创建 vimrc 文件。 >

	:exe 'edit' stdpath('config').'/init.vim'

在本节中我们将解释可以在此文件中指定的各种命令。这会给你一些关于如何设置你
自己偏好的提示。不过不会解释所有内容。使用 ":help" 命令可以了解更多。
>
	set backup

这告诉 Vim 在覆盖文件时保留一个备份副本。备份文件的名称是原文件名加上 "~"。
参见 |07.4|
>
	set history=50
<
在历史记录中保留 50 个命令和 50 个搜索模式。如果你想记住更少或更多行，使用
其他数字。
>
	map Q gq

这定义了一个键映射。下一节会有更多内容。这将 "Q" 命令定义为用 "gq" 操作符
进行格式化。否则 "Q" 命令会重放上一次记录的寄存器。
>
	vnoremap _g y:exe "grep /" .. escape(@", '\\/') .. "/ *.c *.h"<CR>

这个映射复制可视选中的文本并在 C 文件中搜索它。这是一个复杂的映射。你可以
看到映射可以用来做相当复杂的事情。不过，它只是一系列像你手动输入一样执行的
命令。

							*vimrc-filetype*
>
	filetype plugin indent on

这启用了三个非常巧妙的机制:
1. 文件类型检测。
   每当你开始编辑一个文件，Vim 会尝试找出这是什么类型的文件。当你编辑
   "main.c" 时，Vim 会看到 ".c" 扩展名并识别这是一个 "c" 文件类型。当你编辑
   一个以 "#!/bin/sh" 开头的文件时，Vim 会识别它为 "sh" 文件类型。
   文件类型检测用于语法高亮和下面两项。
   参见 |filetypes|。

2. 使用文件类型插件文件
   许多不同的文件类型使用不同的选项来编辑。例如，当你编辑一个 "c" 文件时，
   设置 'cindent' 选项来自动缩进行是非常有用的。这些常用的选项设置包含在 Vim
   的文件类型插件中。你也可以添加自己的，参见 |write-filetype-plugin|。

3. 使用缩进文件
   当编辑程序时，一行的缩进通常可以自动计算。Vim 为许多文件类型提供了这些
   缩进规则。参见 |:filetype-indent-on| 和 'indentexpr'。


				*restore-cursor* *last-position-jump*  >vim
    augroup RestoreCursor
      autocmd!
      autocmd BufReadPre * autocmd FileType <buffer> ++once
        \ let s:line = line("'\"")
        \ | if s:line >= 1 && s:line <= line("$") && &filetype !~# 'commit'
        \      && index(['xxd', 'gitrebase'], &filetype) == -1
        \      && !&diff
        \ |   execute "normal! g`\""
        \ | endif
    augroup END

另一个自动命令。这次是在读取任何文件后使用的。后面那些复杂的内容检查 '"
标记是否已定义，如果是就跳转到那里。以下情况不会跳转:
 - 编辑提交或变基消息，它们很可能与上次不同,
 - 使用 xxd(1) 来过滤和编辑二进制文件，它会来回转换输入文件，使文件具有
   双重性质（参见 |using-xxd|），以及
 - Vim 处于 diff 模式

行开头的反斜杠用于将上一行的命令续行。这避免了一行变得太长。参见
|line-continuation|。这只在 Vim 脚本文件中有效，在命令行输入命令时无效。

>
	command DiffOrig vert new | set bt=nofile | r ++edit # | 0d_
		  \ | diffthis | wincmd p | diffthis

这添加了 ":DiffOrig" 命令。在修改过的缓冲区中使用它来查看与加载时文件的
差异。参见 |diff| 和 |:DiffOrig|。

>
	set nolangremap

防止 langmap 选项应用于映射产生的字符。如果设置（默认），这可能会破坏插件
（但它是向后兼容的）。参见 'langremap'。

*05.3*	简单映射

映射允许你将一组 Vim 命令绑定到一个键上。假设你需要用花括号包围某些单词。
换句话说，你需要把像 "amount" 这样的词改成 "{amount}"。使用 :map 命令，
你可以告诉 Vim F5 键来做这件事。命令如下: >

	:map <F5> i{<Esc>ea}<Esc>
<
	注意:
	输入这个命令时，你必须通过键入四个字符来输入 <F5>。类似地，<Esc> 不是
	按 <Esc> 键输入的，而是输入五个字符。阅读手册时请注意这个区别！

让我们分解一下:
    <F5>	F5 功能键。这是触发键，按下这个键时命令就会被执行。

    i{<Esc>	插入 { 字符。<Esc> 键结束插入模式。

    e		移到单词末尾。

    a}<Esc>	追加 } 到单词末尾。

执行 ":map" 命令后，你只需要将光标放在单词的第一个字符上并按 F5 就可以在
单词周围加上 {}。

在这个例子中，触发是一个键; 它可以是任何字符串。但是如果你使用一个现有的
Vim 命令，那个命令就不再可用了。你最好避免这样做。
   可以用于映射的一个键是反斜杠。由于你可能想定义多个映射，再加一个字符。
例如，你可以映射 "\p" 来在单词周围加括号，"\c" 来加花括号: >

	:map \p i(<Esc>ea)<Esc>
	:map \c i{<Esc>ea}<Esc>

你需要快速接连输入 \ 和 p，这样 Vim 才知道它们属于一起。

不带参数的 ":map" 命令列出你当前的映射。至少是普通模式的映射。关于映射的更多
内容在 |40.1| 节。

*05.4*	添加软件包					*add-package*

你可以使用 |:packadd| 按需启用软件包。这对于你只想偶尔启用的插件很有用。
要启用 `example_package`，使用以下命令: >
       packadd example_package

就这样！现在你可以找到这个插件的帮助: >
       :help example_package

这是有效的，因为当 `:packadd` 加载插件时，它也将软件包目录添加到了
'runtimepath' 中，这样就可以找到帮助文件。

软件包是一组你可以添加到 Vim 的文件。有两种软件包: 可选的和启动时自动加载的。

你可以在互联网上的各种地方找到软件包。它通常以归档文件或仓库的形式提供。
对于归档文件，你可以按照以下步骤:
	1. 创建软件包目录: >
		mkdir -p ~/.local/share/nvim/site/pack/fancy
<	   "fancy" 可以是你喜欢的任何名称。使用一个能描述该软件包的名称。
	2. 在该目录中解压归档文件。假设归档文件的顶层目录是 "start": >
		cd ~/.local/share/nvim/site/pack/fancy
		unzip /tmp/fancy.zip
<	   如果归档文件的布局不同，确保你最终得到这样的路径:
		~/.local/share/nvim/site/pack/fancy/start/fancytext/plugin/fancy.vim ~
	   这里 "fancytext" 是软件包的名称，它可以是任何其他名称。


------------------------------------------------------------------------------
添加 nohlsearch 软件包		*nohlsearch-install* *package-nohlsearch*
------------------------------------------------------------------------------

使用此命令加载插件: >
	packadd nohlsearch
<
在 'updatetime' 超时或进入 |Insert| 模式后自动执行 |:nohlsearch|。
因此假设默认的 updatetime，hlsearch 将在 4 秒空闲后被暂停/关闭。

要在插件加载后禁用其效果: >
	au! nohlsearch
<


关于软件包的更多信息可以在这里找到: |packages|。

*05.5*	添加插件					*add-plugin* *plugin*

Vim 的功能可以通过添加插件来扩展。插件只不过是一个在 Vim 启动时自动加载的
Vim 脚本文件。你只需将它放到插件目录中就可以非常容易地添加一个插件。

有两种类型的插件:

    全局插件: 用于所有类型的文件
  文件类型插件: 只用于特定类型的文件

全局插件先讨论，然后是文件类型插件 |add-filetype-plugin|。


全局插件						*standard-plugin*

当你启动 Vim 时，它会自动加载一些全局插件。你不需要为此做任何事情。它们添加了
大多数人都会用到的功能，但它们是作为 Vim 脚本而不是编译进 Vim 的。你可以在
帮助索引 |standard-plugin-list| 中找到它们的列表。另见 |load-plugins|。

							*add-global-plugin*
你可以添加一个全局插件来增加在你使用 Vim 时始终可用的功能。添加全局插件只需
两个步骤:
1. 获取插件的副本。
2. 将它放到正确的目录中。


获取全局插件

你在哪里可以找到插件？
- 一些是始终加载的，你可以在 $VIMRUNTIME/plugin 目录中看到它们。
- 一些随 Vim 附带。你可以在 $VIMRUNTIME/scripts 目录及其子目录和
  $VIM/vimfiles/pack/dist/opt/ 下找到它们。
- 从网上下载。https://www.vim.org 上有大量收集。
- 它们有时发布在 Vim 邮件列表上。
- 你可以自己写一个，参见 |write-plugin|。


使用全局插件

首先阅读插件本身中的文本以检查是否有特殊条件。然后将文件复制到你的插件目录:

	系统		插件目录 ~
	Unix		~/.local/share/nvim/site/plugin

Unix 的示例（假设你还没有插件目录）: >

	mkdir -p ~/.local/share/nvim/site/plugin
	cp /tmp/yourplugin.vim ~/.local/share/nvim/site/plugin

就是这样！现在你可以使用这个插件中定义的命令了。

你可以将插件放在 plugin/ 目录下的子目录中来更好地组织它们，而不是直接放在
plugin/ 目录中。例如，可以使用 "~/.local/share/nvim/site/plugin/perl/*.vim"
来存放所有你的 Perl 插件。


文件类型插件			*add-filetype-plugin* *ftplugins*

Vim 发行版附带了一组用于不同文件类型的插件，你可以用这个命令开始使用它们: >

	:filetype plugin on

就这样！参见 |vimrc-filetype|。

如果你缺少某个文件类型的插件，或者你找到了一个更好的，你可以添加它。添加
文件类型插件需要两个步骤:
1. 获取插件的副本。
2. 将它放到正确的目录中。


获取文件类型插件

你可以在与全局插件相同的地方找到它们。注意是否提到了文件类型，这样你就知道
该插件是全局的还是文件类型的。$VIMRUNTIME/scripts 中的脚本是全局的，文件类型
插件在 $VIMRUNTIME/ftplugin 中。


使用文件类型插件					*ftplugin-name*

你可以通过将文件类型插件放到正确的目录来添加它。该目录的名称与上面提到的
全局插件目录相同，但最后一部分是 "ftplugin"。假设你找到了一个用于 "stuff"
文件类型的插件，你在 Unix 上。那么你可以把这个文件移到 ftplugin 目录: >

	mkdir -p ~/.local/share/nvim/site/ftplugin
	mv thefile ~/.local/share/nvim/site/ftplugin/stuff.vim

如果该文件已存在，说明你已经有了一个 "stuff" 插件。你可能需要检查现有插件
是否与你要添加的冲突。如果没问题，你可以给新的取另一个名字: >

	mv thefile ~/.local/share/nvim/site/ftplugin/stuff_too.vim

下划线用来分隔文件类型名称和其余部分，其余部分可以是任何内容。如果你使用
"otherstuff.vim"，它将不会工作，因为它会被加载给 "otherstuff" 文件类型。

文件类型插件的通用名称是: >

	ftplugin/<filetype>.vim
	ftplugin/<filetype>_<name>.vim
	ftplugin/<filetype>/<name>.vim

这里 "<name>" 可以是你喜欢的任何名称。
Unix 上 "stuff" 文件类型的示例: >

	~/.local/share/nvim/site/ftplugin/stuff.vim
	~/.local/share/nvim/site/ftplugin/stuff_def.vim
	~/.local/share/nvim/site/ftplugin/stuff/header.vim

<filetype> 部分是该插件要用于的文件类型的名称。只有该文件类型的文件会使用
该插件的设置。插件文件的 <name> 部分无关紧要，你可以用它来为同一个文件类型
拥有多个插件。注意它必须以 ".vim" 或 ".lua" 结尾。


进一步阅读:
|filetype-plugins|	文件类型插件的文档以及如何避免映射引起问题的信息。
|load-plugins|		全局插件在启动时何时被加载。
|ftplugin-overrule|	覆盖全局插件的设置。
|write-plugin|		如何编写插件脚本。
|plugin-details|	关于使用插件的更多信息或当你的插件不工作时。
|new-filetype|		如何检测新的文件类型。

*05.6*	添加帮助文件		                   *add-local-help*

如果你幸运的话，你安装的插件附带了帮助文件。我们将解释如何安装帮助文件，以便
你可以轻松找到新插件的帮助。

假设有一个插件（"my-plugin"），它的帮助文件在一个非标准位置（通常它位于名为
`doc/` 的子文件夹中）。

首先，在 'runtimepath' 中的某个目录下创建一个 "doc" 目录: >

	:!mkdir -p ~/.local/share/nvim/site/doc

然后，将帮助文件复制到 "doc" 目录: >

	:!cp my-plugin/my-plugin-doc.txt ~/.local/share/nvim/site/doc

这是关键的一步，它允许你跳转到新帮助文件中的主题。使用 |:helptags| 命令
生成本地标签文件: >

	:helptags ~/.local/share/nvim/site/doc

当你执行以下命令时可以看到本地帮助文件的条目: >

	:help local-additions

本地帮助文件的标题行会自动添加到此部分。在那里你可以看到添加了哪些本地帮助
文件，并通过标签跳转到它们。

关于编写本地帮助文件，参见 |write-local-help|。

*05.7*	选项窗口

如果你在寻找一个能做你想要的事情的选项，你可以在这里的帮助文件中搜索:
|options|。另一种方法是使用这个命令: >

	:options

这会打开一个新窗口，其中包含选项列表和每个选项的一行说明。选项按主题分组。
将光标移到一个主题上并按 <Enter> 跳转到那里。再次按 <Enter> 跳回。或者使用
CTRL-O。

你可以更改选项的值。例如，移到 "displaying text" 主题。然后将光标向下移到
这一行:

	set wrap	nowrap ~

当你按 <Enter> 时，该行会变为:

	set nowrap	wrap ~

该选项现在已关闭。

就在这一行上面是 'wrap' 选项的简短描述。将光标向上移一行放在这一行上。现在
按 <Enter>，你就跳转到了 'wrap' 选项的完整帮助。

对于接受数值或字符串参数的选项，你可以编辑值。然后按 <Enter> 应用新值。例如，
将光标向上移几行到这一行:

	set so=0 ~

用 "$" 将光标定位在零上。用 "r5" 将它改成五。然后按 <Enter> 应用新值。当你
现在移动光标时会注意到文本在你到达窗口边界之前就开始滚动了。这就是
'scrolloff' 选项的作用，它指定了在开始滚动处与窗口边界之间的偏移量。

*05.8*	常用选项

选项的数量非常多。大多数你几乎不会使用。这里将提到一些比较有用的。不要忘记
你可以用 ":help" 命令找到这些选项的更多帮助，选项名前后要加单引号。例如: >

	:help 'wrap'

如果你搞乱了选项值，你可以在选项名后面加一个 & 号将它恢复为默认值。例如: >

	:set iskeyword&


不折行

Vim 通常会折行显示长行，以便你能看到所有文本。有时候让文本延续到窗口右边更好。
这时你需要左右滚动文本来查看长行的全部内容。用这个命令关闭折行: >

	:set nowrap

Vim 会在你移到未显示的文本时自动滚动。要看到十个字符的上下文，这样做: >

	:set sidescroll=10

这不会改变文件中的文本，只是改变显示方式。


折行移动命令

大多数移动命令会在行首和行尾停止移动。你可以用 'whichwrap' 选项来改变这个。
下面将它设为默认值: >

	:set whichwrap=b,s

这允许 <BS> 键在行的第一个位置时将光标移到上一行的末尾。<Space> 键则从行尾
移到下一行的开头。

要允许光标键 <Left> 和 <Right> 也折行，使用这个命令: >

	:set whichwrap=b,s,<,>

这仍然只对普通模式有效。要让 <Left> 和 <Right> 在插入模式中也这样做: >

	:set whichwrap=b,s,<,>,[,]

还有一些其他的标志可以添加，参见 'whichwrap'。


查看制表符

当文件中有制表符时，你看不到它们在哪里。要使它们可见: >

	:set list

现在每个制表符显示为 ^I。每一行末尾会显示一个 $，这样你可以发现那些可能被
忽视的尾部空格。
   缺点是当文件中有很多制表符时看起来很丑。如果你有彩色终端或使用 GUI，Vim
可以将空格和制表符显示为高亮字符。使用 'listchars' 选项: >

	:set listchars=tab:>-,trail:-

现在每个制表符显示为 ">---"（或多或少的 "-"），尾部空格显示为 "-"。看起来好
多了，不是吗？


关键字

'iskeyword' 选项指定哪些字符可以出现在单词中: >

	:set iskeyword
<	  iskeyword=@,48-57,_,192-255 ~

"@" 代表所有字母字符。"48-57" 代表 ASCII 字符 48 到 57，即数字 0 到 9。
"192-255" 是可打印的拉丁字符。
   有时你想在关键字中包含连字符，这样 "w" 等命令就会将 "upper-case" 视为一个
单词。你可以这样做: >

	:set iskeyword+=-
	:set iskeyword
<	  iskeyword=@,48-57,_,192-255,- ~

如果你查看新值，你会发现 Vim 自动为你添加了一个逗号。
   要删除一个字符使用 "-="。例如，要删除下划线: >

	:set iskeyword-=_
	:set iskeyword
<	  iskeyword=@,48-57,192-255,- ~

这次逗号被自动删除了。


消息区域的空间

当 Vim 启动时，底部有一行用于显示消息。当消息很长时，它要么被截断，你只能看到
一部分; 要么文本滚动，你需要按 <Enter> 继续。
   你可以将 'cmdheight' 选项设为用于消息的行数。例如: >

	:set cmdheight=3

这意味着编辑文本的空间减少了，所以这是一个折中。
