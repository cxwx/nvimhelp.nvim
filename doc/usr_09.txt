					使用 GUI


Vim 在普通终端中工作，而 gVim 有图形用户界面 (GUI)。它能做同样的事情，
甚至更多。GUI 提供菜单、工具栏、滚动条和其他项目。本章介绍 GUI 提供的这些
额外功能。

*09.1*	GUI 的各部分

你可能在桌面上有一个启动 gvim 的图标。否则，以下命令之一应该可以: >

	gvim file.txt
	vim -g file.txt

如果不行，说明你没有带 GUI 支持的 Vim 版本。你需要先安装一个。
   Vim 会打开一个窗口并在其中显示 "file.txt"。窗口的外观取决于 Vim 的版本。
它应该类似于下面的图示（在 ASCII 中能显示的范围内！）。

	+----------------------------------------------------+
	| file.txt + (~/dir) - VIM			   X |	<- 窗口标题
	+----------------------------------------------------+
	| File	Edit  Tools  Syntax  Buffers  Window  Help   |	<- 菜单栏
	+----------------------------------------------------+
	| aaa  bbb  ccc  ddd  eee  fff	ggg  hhh  iii  jjj   |	<- 工具栏
	| aaa  bbb  ccc  ddd  eee  fff	ggg  hhh  iii  jjj   |
	+----------------------------------------------------+
	| file text					 | ^ |
	| ~						 | # |
	| ~						 | # |	<- 滚动条
	| ~						 | # |
	| ~						 | # |
	| ~						 | # |
	|						 | V |
	+----------------------------------------------------+

最大的空间被文件文本占据。这以与终端中相同的方式显示文件。可能使用一些不同的
颜色和另一种字体。


窗口标题

最上面是窗口标题。这是由你的窗口系统绘制的。Vim 会设置标题来显示当前文件的
名称。首先是文件名。然后是一些特殊字符和文件目录（在括号中）。这些特殊字符
可能出现:

	• -	文件不可修改（例如帮助文件）
	• +	文件包含更改
	• =	文件是只读的
	• =+	文件是只读的，但仍然包含更改

如果什么都没显示，你有一个普通的、未更改的文件。


菜单栏

你知道菜单是怎么工作的，对吧？Vim 有通常的项目，还有一些额外的。浏览它们
来了解你可以用它们做什么。一个相关的子菜单是 Edit/Global Settings。你会找到
这些条目:

	Toggle Toolbar		使工具栏出现/消失
	Toggle Bottom Scrollbar	使滚动条在底部出现/消失
	Toggle Left Scrollbar	使滚动条在左边出现/消失
	Toggle Right Scrollbar	使滚动条在右边出现/消失


工具栏

工具栏包含最常用操作的图标。希望这些图标是不言自明的。有工具提示可以获得
额外的提示（将鼠标指针移到图标上不点击并停留一秒钟）。

"Edit/Global Settings/Toggle Toolbar" 菜单项可以用来使工具栏消失。如果你永远
不想要工具栏，在你的 vimrc 文件中使用这个命令: >

	:set guioptions-=T

这从 'guioptions' 选项中移除 'T' 标志。GUI 的其他部分也可以通过这个选项来
启用或禁用。参见相关帮助。


滚动条

默认情况下右边有一个滚动条。它做你期望的事情。当你分割窗口时，每个窗口都会
有自己的滚动条。
   你可以使用菜单项 Edit/Global Settings/Toggle Bottom Scrollbar 来显示水平
滚动条。这在 diff 模式中或当 'wrap' 选项已被重置时很有用（稍后会详细介绍）。

当有垂直分割的窗口时，只有右边的窗口会有滚动条。但是，当你将光标移到左边的
窗口时，滚动条会控制那个窗口。这需要一点时间来习惯。
   当你使用垂直分割的窗口时，考虑在左边添加一个滚动条。这可以通过菜单项或
'guioptions' 选项来完成:
>
	:set guioptions+=l

这将 'l' 标志添加到 'guioptions'。

*09.2*	使用鼠标

标准是美好的。在 Microsoft Windows 中，你可以用标准方式使用鼠标来选择文本。
X Window 系统也有一个使用鼠标的标准系统。不幸的是，这两个标准不一样。幸运的
是，你可以自定义 Vim。

以下命令使鼠标的行为更像 Microsoft Windows 的鼠标: >

	set selection=exclusive
	set selectmode=mouse,key
	set keymodel=startsel,stopsel

鼠标还可以进一步调整。如果你想改变鼠标的工作方式，检查以下选项:

	'mouse'			Vim 在哪种模式下使用鼠标
	'mousemodel'		鼠标点击有什么效果
	'mousetime'		双击的两次点击之间的时间
	'mousehide'		打字时隐藏鼠标
	'selectmode'		鼠标是启动可视模式还是选择模式

*09.3*	剪贴板

在 |04.7| 节中解释了剪贴板的基本用法。关于 X-windows 有一个重要的事情需要
解释: 实际上有两个地方可以在程序之间交换文本。MS-Windows 没有这个。

在 X-Windows 中有 "当前选择"。这是当前被高亮显示的文本。在 Vim 中这是可视
区域（假设你使用默认选项设置）。你可以将这个选择粘贴到另一个应用程序中而
不需要任何其他操作。
   例如，在这段文本中用鼠标选择几个词。Vim 会切换到可视模式并高亮文本。现在
启动另一个 gvim，不带文件名参数，这样它显示一个空窗口。点击鼠标中键。选中的
文本将被插入。

"当前选择" 只在另一段文本被选择之前有效。在另一个 gvim 中粘贴后，现在在那个
窗口中选择一些字符。你会注意到之前在另一个 gvim 窗口中选择的词显示方式不同
了。这意味着它不再是当前选择了。

你不需要用鼠标选择文本，使用可视模式的键盘命令同样有效。


真正的剪贴板

现在说说可以交换文本的另一个地方。我们称之为 "真正的剪贴板"，以避免混淆。
通常 "当前选择" 和 "真正的剪贴板" 都被称为剪贴板，你必须习惯这一点。
   要将文本放到真正的剪贴板上，在你运行的一个 gvim 中选择一些不同的词。然后
使用 Edit/Copy 菜单项。现在文本已被复制到真正的剪贴板。你看不到这个，除非你
有一个显示剪贴板内容的应用程序（例如 KDE 的 Klipper）。
   现在选择另一个 gvim，将光标定位到某处并使用 Edit/Paste 菜单。你会看到来自
真正剪贴板的文本被插入了。


两者兼用

这种同时使用 "当前选择" 和 "真正的剪贴板" 的方式可能听起来有点令人困惑。但它
非常有用。让我们用一个例子来说明。使用一个带有文本文件的 gvim 并执行以下操作:

-  在可视模式中选择两个词。
-  使用 Edit/Copy 菜单将这些词放到剪贴板上。
-  在可视模式中选择另一个词。
-  使用 Edit/Paste 菜单项。效果是那个被选中的单词被剪贴板中的两个词替换了。
-  将鼠标指针移到其他地方并点击中键。你会看到你刚才用剪贴板覆盖的词被
   插入到了这里。

如果你小心地使用 "当前选择" 和 "真正的剪贴板"，你可以用它们完成很多有用的
编辑。


使用键盘

如果你不喜欢使用鼠标，你可以用两个寄存器来访问当前选择和真正的剪贴板。"*
寄存器用于当前选择。
   要使文本成为当前选择，使用可视模式。例如，要选择一整行只需按 "V"。
   要在光标前插入当前选择: >

	"*P

注意大写的 "P"。小写的 "p" 将文本放在光标之后。

"+ 寄存器用于真正的剪贴板。例如，要从光标位置到行末复制文本到剪贴板: >

	"+y$

记住，"y" 是 yank（复制），这是 Vim 的复制命令。
   要在光标前插入真正剪贴板的内容: >

	"+P

它和当前选择一样，但使用加号 (+) 寄存器而不是星号 "*" 寄存器。

*09.4*	选择模式

现在说一个在 MS-Windows 上比在 X-Windows 上更常用的东西。但两者都可以做到。
你已经知道可视模式了。选择模式与可视模式类似，因为它也用于选择文本。但有一个
明显的区别: 当输入文本时，选中的文本被删除，输入的文本替换它。

要开始使用选择模式，你必须先启用它（对于 MS-Windows 它可能已经启用了，但你
还是可以这样做）: >

	:set selectmode+=mouse

现在用鼠标选择一些文本。它像可视模式一样被高亮。现在按一个字母。选中的文本
被删除，那个字母替换了它。你现在处于插入模式，因此可以继续输入。

由于输入普通文本会导致选中的文本被删除，你不能使用正常的移动命令 "hjkl"、
"w" 等。而要使用带 Shift 的功能键。<S-Left>（Shift 加光标左键）向左移动光标。
选中的文本像在可视模式中一样改变。其他带 Shift 的光标键也按你期望的方式工作。
<S-End> 和 <S-Home> 也可以。

你可以用 'selectmode' 选项来调整选择模式的工作方式。
