Vim 的从右到左显示模式				*rileft*


这些功能最初由 Avner Lottem 创建:
   E-mail: alottem@iil.intel.com
   Phone:  +972-4-8307322

------------------------------------------------------------------------------
简介

某些语言，如阿拉伯语、波斯语、希伯来语 (以及其他语言)，需要能够从右到左
显示文本。这些语言的文件按常规方式存储，从右到左的要求只是显示引擎的功能
(根据 Unicode 规范)。在从右到左方向的文件中，字符在屏幕上从右到左显示。

双向性 (或简称 bidi) 是 Unicode 为这些语言提供的完整解决方案。Bidi 使
用户能够在同一窗口中同时正确查看从右到左和从左到右的文本。由于简单性，
Vim 目前不提供 bidi，只是提供了一种功能性手段来显示/输入/使用从右到左
的语言。一种较旧的混合方案 (每个字符或字符组编码方向) 也不被支持，因为
这种支持超出了对现有编辑器的简单添加的范围 (Unicode 也不认可这种方式)。

由于许多开发代码的人不使用从右到左模式，此功能在某些情况下可能无法工作。
如果你能描述问题以及修复后应如何工作，请在 github 上创建 issue，
参见 |bug-report|。


------------------------------------------------------------------------------
亮点

o  编辑从左到右的文件与原始 Vim 中一样，没有变化。

o  在从右到左的窗口中查看和编辑文件。文件方向是按窗口设置的，因此可以
   同时在从右到左和从左到右模式下查看同一文件。(对于编辑同时包含从右到左
   和从左到右文本的混合文件很有用)。

o  与原始 Vim 兼容。几乎所有功能在从右到左模式下都能工作
   (参见下方的错误)。

o  从反向插入模式退回到文件中的正确位置 (如果可能的话)。

o  不需要具有从右到左功能的特殊终端。从右到左的变化完全独立于硬件。

o  许多语言使用并需要从右到左支持。只要包含所需的键盘映射和一些可能的
   微小代码更改，这些语言就可以很容易地得到支持。当前支持的一些语言包括
   - |l10n-arabic.txt| 和 |l10n-hebrew.txt|。


------------------------------------------------------------------------------
有趣的内容...

o  调用方式

   + 'rightleft' ('rl') 将窗口方向设置为从右到左。
   + 'delcombine' ('deco')，布尔值，如果编辑 UTF-8 编码的语言，允许删除
     叠加在前面字符上的组合字符 (某些语言需要此功能)。
   + 'rightleftcmd' ('rlc') 设置某些模式 (如搜索) 下的命令行也以从右到左
     方向使用。

o  反向输入					*ins-reverse*

   代替使用功能完整的 'rightleft' 选项，可以选择反向插入。当设置了
   'revins' (反向插入) 选项时，插入以反向方式进行。这可用于输入从右到左
   的文本。当插入字符时光标不移动，文本向右移动。<BS> 删除光标下的字符。
   CTRL-W 和 CTRL-U 也以相反的方向工作。<BS>、CTRL-W 和 CTRL-U 不会在
   插入开始或行尾停止，无论 'backspace' 选项如何设置。

   目前没有反向替换模式。

   如果设置了 'showmode' 选项，当反向插入模式激活时，状态行会显示
   "-- REVERSE INSERT --"。

o  在从右到左窗口中粘贴

   当用鼠标剪切文本并在从右到左窗口中粘贴时，文本会被反转，因为字符从
   剪切缓冲区中从左到右获取，而在文件中从右到左插入。为了避免这种情况，
   在粘贴之前切换 'revins'。


------------------------------------------------------------------------------
错误

o  在从右到左窗口中不能正确处理 CTRL-A 和 CTRL-X 命令 (加和减)。

o  不支持命令行上的反向插入和从右到左模式。但是，编辑器的功能不会减少，
   因为可以在命令行上从左到右输入映射、缩写和搜索。

o  从右到左模式下速度略慢，因为从右到左的移动是在 Vim 内部模拟的，
   不是由控制终端完成的。

o  当 'rightleft' 和 'revins' 都开启时: 'textwidth' 不工作。
   行根本不会换行；你只会得到一个很长的单行。

o  不支持完全的双向性 (bidi)。
