*pi_spec.txt*   Nvim

by Gustavo Niemeyer ~

这是一个用于处理 rpm spec 文件的文件类型插件。

目前，此 Vim 插件允许你轻松更新 RPM spec 文件中的 %changelog 部分。如果
该部分尚不存在，它甚至会为你创建一个。如果你今天已经插入了一个条目，它会
给你机会在今天的条目中添加一个新项目。如果你没有提供格式字符串
(|spec_chglog_format|)，它会询问你的电子邮件地址并自行构建格式字符串。

1. 如何使用		|spec-how-to-use-it|
2. 自定义		|spec-customizing|

==============================================================================
1. 如何使用				*spec-how-to-use-it*

spec_chglog 插件提供了如下映射:

	:map <buffer> <LocalLeader>c <Plug>SpecChangelog

这意味着你可以在 spec 文件中按你的 maplocalleader 键 (默认是 '\') 加 'c'
来运行此插件。如果你没有设置 |spec_chglog_format|，插件会询问你在此编辑
会话中使用的电子邮件地址。

每次运行此插件时，它会检查 changelog 中的最后一个条目是否是今天由你编写的。
如果条目匹配，它只会插入一个新的 changelog 项目，否则会创建一个新的
changelog 条目。如果你启用了 |spec_chglog_release_info|，它还会检查名称、
版本和发布版本是否匹配。此插件足够智能，会询问你是否应该更新软件包版本号
(如果你还没有这样做)。

------------------------------------------------------------------------------
设置映射					*spec-setting-a-map*

如你所知，你可以轻松设置映射来访问任何 Vim 命令 (或其他任何东西)。如果你
不喜欢默认的 <LocalLeader>c 映射，可以自行设置键。以下行展示了如何在 vimrc
文件中将插件映射到 <F5> 键:

	au FileType spec map <buffer> <F5> <Plug>SpecChangelog

注意: 插件会尊重你更改默认映射的意愿，不会设置默认映射。

此命令只会在 spec 文件缓冲区中添加映射。


==============================================================================
2. 自定义					*spec-customizing*

------------------------------------------------------------------------------
格式字符串				*spec_chglog_format*

你可以轻松自定义 spec 文件条目的外观。只需在 vimrc 文件中设置变量
"spec_chglog_format" 即可: >

	let spec_chglog_format = "%a %b %d %Y My Name <my@email.com>"

注意 "%a %b %d %Y" 是最常用的时间格式。如果你不提供格式字符串，当你第一次
运行 SpecChangelog 命令时，它会询问你的电子邮件地址并为你构建
|spec_chglog_format| 变量。这样，你只需提供一次电子邮件地址。

要了解可以使用哪些格式选项，请查看 strftime() 函数的手册页。

------------------------------------------------------------------------------
新项目的插入位置			*spec_chglog_prepend*

插件通常会在现有项目之后插入新的 %changelog 条目项目 (注意这不是条目本身)。
如果你设置了 spec_chglog_prepend 变量 >

	let spec_chglog_prepend = 1

它会在现有项目之前插入新项目。

------------------------------------------------------------------------------
插入发布信息				*spec_chglog_release_info*

如果你愿意，插件可以在每个 changelog 条目中自动插入发布信息。启用此功能的
一个好处是它可以控制自上次更改包以来是否已更新发布版本。如果你没有更新包
的版本或发布版本号，它会询问你是否应该为你更新包的发布版本号。要启用此功能，
只需在 vimrc 中插入以下代码: >

	let spec_chglog_release_info = 1

然后，你的 changelog 条目中的第一个项目会是类似这样的: >

	+ name-1.0-1cl

如果你不喜欢发布版本更新功能，也不想每次检测到旧版本时都回答 "No"，你可以
通过以下设置禁用它 >

	let spec_chglog_never_increase_release = 1


祝好运!!
