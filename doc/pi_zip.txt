2. 用法						*zip-usage* *zip-manual*

   当编辑 `*.zip` 文件时，此插件会处理显示内容页面。将光标移到所需的文件上，
   然后按 <return> 键来选择要编辑的文件。编辑后，也可以写入文件。目前，不能
   通过插件在 zip 归档中创建新文件。

   zip 插件尝试检测一些常见的路径遍历攻击模式，但可能无法捕获所有可能的
   情况。使用此插件处理不受信任的输入时请非常小心。

   命令~
								*zip-x*
   x : 当光标在列出的文件上时提取该文件

   选项~

							*g:zip_nomax*

   如果此变量存在且为真，打开时文件窗口不会被自动最大化。

							*g:zip_shq*
   不同的操作系统可能使用一个或多个 shell 来执行命令。Zip 会尝试猜测
   正确的引号机制以允许文件名中包含空格等字符；但是，如果它对你的设置
   猜错了引号，你可以使用 >
	g:zip_shq
<  默认在 Unix 下是单引号 (')，在 Windows 下是双引号 (")。如果你不想要
   引号，只需在 <.vimrc> 中将 g:zip_shq 设置为空字符串 (let g:zip_shq= "")。

							*g:zip_unzipcmd*
   使用此选项指定执行 "unzip" 功能的程序。浏览时使用。默认值: >
	let g:zip_unzipcmd= "unzip"
<
							*g:zip_zipcmd*
   使用此选项指定执行 "zip" 功能的程序。在写入 (更新) zip 文件中已有的
   文件时使用；默认值: >
	let g:zip_zipcmd= "zip"
<
							*g:zip_extractcmd*
   此选项指定用于从 zip 归档中提取文件的程序 (及所需的选项)。默认值: >
	let g:zip_extractcmd= g:zip_unzipcmd
<
							*g:zip_exec*
   出于安全原因，可以阻止 Vim 在打开缓冲区时自动运行可执行文件。此选项
   (默认值: "1") 设置为 "0" 时可以阻止执行 "unzip" 命令: >
	let g:zip_exec=0
<
   回退到 POWERSHELL CORE~

   此插件首先会尝试使用 (功能更强的) GNU zip/unzip 命令。如果这些命令
   不可用或失败，并且用户使用的是 PowerShell Core (即 'shell' 选项匹配
   "pwsh")，插件将回退到 PowerShell Core cmdlet。PowerShell Core cmdlet
   功能有限: 它们无法在 zip 归档的子目录中写入或提取文件。但优点是不需要
   单独安装 unzip 二进制文件。

   阻止加载~

   如果由于某种原因你不希望使用 vim 来检查 zip 文件，可以在 <.vimrc> 中
   设置以下两个变量来阻止 zip 插件加载: >

	let g:loaded_zipPlugin= 1
	let g:loaded_zip      = 1
<

3. 额外扩展名					*zip-extension*

   显然有许多归档工具会生成不使用 .zip 扩展名的 zip 文件 (.jar、.xpi 等)。
   要处理此类文件，在 <.vimrc> 文件中放置以下行: >

	au BufReadCmd *.jar,*.xpi call zip#Browse(expand("<amatch>"))
<
   只需扩展此行即可适应应被视为 zip 文件的其他扩展名。

   或者，可以在 .vimrc 中更改 *g:zipPlugin_ext*。目前 (截至 2025 年 10 月)
   其内容为: >

        let g:zipPlugin_ext='*.aar,*.apk,*.celzip,*.crtx,*.docm,*.docx,
       \ *.dotm,*.dotx,*.ear,*.epub,*.gcsx,*.glox,*.gqsx,*.ja,*.jar,*.kmz,
       \ *.odb,*.odc,*.odf,*.odg,*.odi,*.odm,*.odp,*.ods,*.odt,*.otc,*.otf,
       \ *.otg,*.oth,*.oti,*.otp,*.ots,*.ott,*.oxt,*.pkpass,*.potm,*.potx,
       \ *.ppam,*.ppsm,*.ppsx,*.pptm,*.pptx,*.sldx,*.thmx,*.vdw,*.war,*.whl,
       \ *.wsz, *.xap,*.xlam,*.xlsb,*.xlsm,*.xlsx,*.xltm,*.xltx,*.xpi,*.zip'
