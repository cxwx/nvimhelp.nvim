==============================================================================
帮助标签约定					*help-context*

获取特定帮助：可以通过给 |:help| 命令一个参数来直接跳转到你想要获取帮助的
内容。通过前缀来指定上下文： >

	  内容			前缀    示例
      普通模式命令		   :help x
      可视模式命令	  v_	   :help v_u
      插入模式命令	  i_	   :help i_<Esc>
      命令行命令	  :	   :help :quit
      命令行编辑	  c_	   :help c_<Del>
      Vim 命令参数	  -	   :help -r
      选项		  '	   :help 'textwidth'
      正则表达式	  /	   :help /[

参见 |help-summary| 了解更多上下文和解释。
参见 |notation| 了解帮助语法的解释。

搜索帮助

输入 ":help word"，然后按 CTRL-D 查看与 "word" 匹配的帮助条目。或者
使用 ":helpgrep word"。|:helpgrep|

表示法						*notation*

当使用语法高亮来阅读本文档时，非字面输入的文本通常用 Special 组高亮显示。
这些是 []、{} 和 <> 中的项目，以及 CTRL-X。

注意 Vim 在命令中使用所有可能的字符。有时 []、{} 和 <> 是你实际输入的一部分，
上下文应该能说明这一点。


- []            方括号中的字符是可选的。

                                                    *count* *[count]*
- [count]       可以在命令前面加一个可选数字，用于乘以或迭代命令。如果没有给出
                数字，则使用计数 1，除非另有说明。注意在本手册中 [count] 不在
                命令的描述中提及，而只在解释中。这样做是为了使命令更容易查找。
                如果 'showcmd' 选项开启，（部分）输入的计数显示在窗口底部。
                你可以使用 <Del> 来删除最后一位数字（|N<Del>|）。

                                                        *[quotex]*
- ["x]          可选的寄存器指定，文本可以存储在其中。参见 |registers|。
                x 是 'a' 到 'z' 或 'A' 到 'Z' 或 '"' 之间的单个字符，在某些
                情况下（使用 put 命令时）可以是 '0' 到 '9'、'%'、'#' 或其他。
                大写和小写字母指定同一个寄存器，但小写字母用于覆盖之前的寄存器
                内容，而大写字母用于追加到之前的寄存器内容。不使用 ""x" 或
                使用 """" 时，存储的文本放入未命名寄存器。

                                                        *{}*
- {}            花括号表示命令中必须出现但可以取多种不同值的部分。Vim 和 Vi
                之间的差异也用花括号表示（从上下文可以看出）。

                                                        *{char1-char2}*
- {char1-char2} 从 char1 到 char2 范围内的单个字符。例如：{a-z} 是小写字母。
                可以连接多个范围。例如，{a-zA-Z0-9} 是任何字母数字字符。

                                                *{motion}* *movement*
- {motion}      移动光标的命令。这些在 |motion.txt| 中解释。
                - 示例：
                  - `w`           到下一个单词的开头
                  - `b`           到当前单词的开头
                  - `4j`          向下四行
                  - `/The<CR>`    到下一个 "The" 出现的位置
                - 在 |operator| 命令后使用，用于移动到要操作的文本上。
                  - 如果移动包含计数而操作符也有计数，两个计数相乘。例如：
                    "2d3w" 删除六个单词。
                  - 移动可以是向后的，例如 "db" 删除到单词的开头。
                  - 移动也可以是鼠标点击。但不是每个终端都支持鼠标。
                  - ":omap" 命令可用于在操作符待定时映射字符。
                  - Ex 命令可用于移动光标。这可以用来调用执行复杂移动的函数。
                    移动始终是字符方式排他的，无论使用什么 ":" 命令。这意味着
                    不可能在不包含换行符的情况下包含行的最后一个字符（除非设置
                    了 'virtualedit'）。如果 Ex 命令在操作符开始位置之前修改了
                    文本或跳转到另一个缓冲区，结果是不可预测的。可以修改更后面
                    的文本。如果当前缓冲区没有被卸载，跳转到另一个缓冲区是可能
                    的。

                                                        *{Visual}*
- {Visual}      选中的文本区域。它以 "v"、"V" 或 CTRL-V 命令开始，然后可以
                使用任何光标移动命令来改变选中文本的末端。
                在 |operator| 命令之前使用，用于高亮显示要操作的文本。
                参见 |Visual-mode|。

                                                        *<character>*
- <character>   下表中的特殊字符，可以带修饰符，或者带修饰符的单个 ASCII
                字符。

                                                        *'character'*
- 'c'           单个 ASCII 字符。

                                                        *CTRL-{char}*
- CTRL-{char}   {char} 作为控制字符输入；即按住 CTRL 键的同时输入 {char}。
                {char} 的大小写被忽略；因此 CTRL-A 和 CTRL-a 是等价的。但在
                某些终端和环境中，使用 SHIFT 键会产生不同的代码（例如
                CTRL-SHIFT-a）；在这些环境中使用 SHIFT 键不会触发 CTRL-A 等
                命令。

                                                        *'option'*
- 'option'      可以设置值的选项或参数，用单引号括起来。参见 |options|。

                                                        *quotecommandquote*
- "command"     你可以输入的命令的引用，用双引号括起来。
- `command`     新式命令，用于与其他引用文本和字符串区分。

帮助命令					*online-help*

			*help* *<Help>* *:h* *:help* *<F1>* *i_<F1>* *i_<Help>*
<Help>		或
:h[elp]			打开一个窗口并以只读模式显示帮助文件。如果已经打开了一个
			帮助窗口，使用那个窗口。否则，如果当前窗口使用全屏宽度或
			至少 80 个字符宽，帮助窗口将出现在当前窗口的正上方。
			否则新窗口放在最顶部。
			'helplang' 选项用于选择语言，如果主帮助文件有多种语言
			可用。

			输入 |gO| 查看目录。

							*:help!*
:h[elp]!		以 DWIM（"Do What I Mean"，按我的意思做）方式从光标处的
			|WORD| 猜测帮助标签：使用各种启发式方法修剪标点，直到找到
			有效的帮助标签。

			例如，将光标移到这段代码中的任意位置，然后运行 `:help!`： >

				local v = vim.version.parse(vim.system({'foo'}):wait().stdout)
<
			然后与 `:exe 'help' expand('<cword>')` 比较。

						*{subject}* *E149* *E661*
:h[elp] {subject}	类似 ":help"，但额外跳转到标签 {subject}。
			例如：  >
				:help options

<			{subject} 可以包含通配符如 "*"、"?" 和 "[a-z]"：
			   :help z?	跳转到任何 "z" 命令的帮助
			   :help z.	跳转到 "z." 的帮助
			但当标签存在时，它被按字面意思理解：
			   :help :?	跳转到 ":?" 的帮助

			如果模式没有完全匹配，或者有多个匹配，将使用"最佳"匹配。
			使用一个复杂的算法来决定哪个匹配比另一个更好。在计算中
			考虑以下项目：
			- 大小写相同的匹配比大小写不同的匹配好得多。
			- 在非字母数字字符之后开始的匹配比在单词中间的匹配好。
			- 在标签开头或附近的匹配比更远处的匹配好。
			- 匹配的字母数字字符越多越好。
			- 匹配的长度越短越好。

			'helplang' 选项用于选择语言，如果 {subject} 有多种语言
			可用。
			要在特定语言中查找标签，追加 "@ab"，其中 "ab" 是两个字母
			的语言代码。参见 |help-translated|。

			注意你给出的 {subject} 越长，找到的匹配就越少。你可以
			通过使用命令行补全（在 ":help subject" 后输入 CTRL-D
			|c_CTRL-D|）来了解这一切是如何工作的。
			如果有多个匹配，你可以通过按 CTRL-D 列出它们。例如： >
				:help cont<Ctrl-D>

<			不用输入 ":help CTRL-V" 来搜索 CTRL-V 的帮助，你可以
			输入： >
				:help ^V
<			这也可以与其他字符一起使用，例如在插入模式中查找 CTRL-V
			的帮助： >
				:help i^V
<
			也可以先执行 ":help"，然后在帮助窗口中使用 ":tag {pattern}"。
			然后可以使用 ":tnext" 命令跳转到其他匹配，用 "tselect"
			列出匹配并选择一个。 >
				:help index
				:tselect /.*mode

<			当没有参数时，你将看到 "help" 的匹配，以避免列出所有可能
			的匹配（那会非常慢）。
			显示的匹配数量限制为 300。

			`:help` 命令后面可以跟 '|' 和另一个命令，但你不需要在
			帮助命令中转义 '|'。所以这两个都可以工作： >
				:help |
				:help k| only
<			注意 '|' 前面的空格被视为 ":help" 参数的一部分。
			你也可以使用 <NL> 或 <CR> 将帮助命令与后续命令分开。
			你需要先输入 CTRL-V 来插入 <NL> 或 <CR>。例如： >
				:help so<C-V><CR>only
<

:h[elp]! {subject}	类似 ":help"，但优先选择与当前文件具有相同
			|help-translated| 语言的标签。

			与 |:help!|（没有 {subject}）无关。

							*:helpc* *:helpclose*
:helpc[lose]		关闭一个帮助窗口，如果有的话。
			Vim 将尝试将窗口布局（包括光标位置）恢复到最初打开帮助
			窗口之前的相同布局。这可能会触发一些自动命令。

							*:helpg* *:helpgrep*
:helpg[rep] {pattern}[@xx]
			搜索所有帮助文本文件并生成 {pattern} 匹配的行的列表。
			跳转到第一个匹配。可选的 [@xx] 指定只查找 "xx" 语言的
			匹配。
			你可以用 |quickfix| 命令浏览匹配，例如 |:cnext| 跳转到
			下一个。或者使用 |:cwindow| 在快速修复窗口中获取匹配
			列表。
			{pattern} 用作 Vim 正则表达式 |pattern|。
			不使用 'ignorecase'，添加 "\c" 来忽略大小写。
			区分大小写搜索的示例： >
				:helpgrep Uganda
<			忽略大小写搜索的示例： >
				:helpgrep uganda\c
<			搜索法语帮助的示例： >
				:helpgrep backspace@fr
<			模式不支持跨行匹配，它必须在一行内匹配。你可以改用
			|:grep|，但那样你需要用复杂的方式获取帮助文件的列表。
			不能后跟其他命令，所有内容都被视为模式的一部分。但你可以
			在需要时使用 |:execute|。
			压缩的帮助文件不会被搜索（Fedora 会压缩帮助文件）。

							*:lh* *:lhelpgrep*
:lh[elpgrep] {pattern}[@xx]
			与 ":helpgrep" 相同，但使用位置列表而不是快速修复列表。
			如果帮助窗口已经打开，则使用该窗口的位置列表。否则打开
			一个新的帮助窗口并设置该窗口的位置列表。不会改变当前
			窗口的位置列表。

							*:exu* *:exusage*
:exu[sage]		显示 Ex 命令的帮助。添加此命令是为了模拟 Nvi 命令。

							*:viu* *:viusage*
:viu[sage]		显示普通模式命令的帮助。添加此命令是为了模拟 Nvi 命令。

当没有给 |:help| 参数时，将打开 'helpfile' 选项指定的文件。否则在 'runtimepath'
选项指定的目录中的所有 "doc/tags" 文件中搜索指定的标签。

如果你想在当前窗口打开帮助，参见这个技巧：
|help-curwin|。

帮助窗口的初始高度可以用 'helpheight' 选项设置（默认 20）。
						*help-buffer-options*
创建帮助缓冲区时，会设置几个本地选项以确保帮助文本按预期方式显示：
    'iskeyword'		几乎所有 ASCII 字符，除了 ' '、"*"、'"' 和 '|'
    'foldmethod'	"manual"
    'tabstop'		8
    'arabic'		off
    'binary'		off
    'buflisted'		off
    'cursorbind'	off
    'diff'		off
    'foldenable'	off
    'list'		off
    'modifiable'	off
    'number'		off
    'relativenumber'	off
    'rightleft'		off
    'scrollbind'	off
    'spell'		off

使用标签跳转到特定主题。这可以通过两种方式完成：
- 站在命令或选项名称上使用 "CTRL-]" 命令。这只在标签是关键字时有效。
  "<C-Leftmouse>" 和 "g<LeftMouse>" 的工作方式与 "CTRL-]" 相同。
- 使用 ":ta {subject}" 命令。这也适用于非关键字字符。

使用 CTRL-T 或 CTRL-O 跳回。
使用 ":q" 关闭帮助窗口。
使用 `g==` 执行当前的 Lua/Vimscript 代码块。

如果你要查找的项目有多个匹配，以下是跳转到每个匹配的方法：
1. 打开一个帮助窗口
2. 使用 ":tag" 命令，在标签前加斜杠。例如： >
	:tag /min
3. 使用 ":tnext" 跳转到下一个匹配的标签。

可以为插件和其他项目添加帮助文件。你不需要为此修改已分发的帮助文件。
参见 |add-local-help|。

要编写本地帮助文件，参见 |write-local-help|。

注意本地帮助文件的标题行会自动添加到 "help.txt" 帮助文件的 "LOCAL ADDITIONS"
部分 |local-additions|。这是在 Vim 中查看文件时完成的，文件本身不会被修改。
它是通过遍历所有帮助文件并获取每个文件的第一行来完成的。$VIMRUNTIME/doc 中的
文件被跳过。

					*:helpt* *:helptags*
			*E150* *E151* *E152* *E153* *E154* *E670* *E856*
:helpt[ags] [++t] {dir}
			为目录 {dir} 生成帮助标签文件。
			当 {dir} 为 ALL 时，将使用 'runtimepath' 中的所有 "doc"
			目录。

			该目录及其子目录中的所有 "*.txt" 和 "*.??x" 文件被扫描
			以查找星号之间的帮助标签定义。"*.??x" 文件用于翻译文档，
			它们生成 "tags-??" 文件，参见 |help-translated|。生成的
			标签文件是排序的。
			当有重复时会给出错误消息。
			已存在的标签文件会被静默覆盖。

			可选的 "++t" 参数强制添加 "help-tags" 标签。当 {dir}
			等于 $VIMRUNTIME/doc 时也会这样做。

			要重建运行时目录中的帮助标签（需要那里的写权限）： >
				:helptags $VIMRUNTIME/doc
<

翻译的帮助文件					*help-translated*

可以在原始英语帮助文件旁边添加翻译的帮助文件。Vim 将在 'runtimepath' 中的
"doc" 目录中搜索所有帮助。

目前可用的翻译有：
	中文   - 多位作者
	法语   - 由 David Blanchet 翻译
	意大利语 - 由 Antonio Colombo 翻译
	日语   - 多位作者
	波兰语 - 由 Mikolaj Machowski 翻译
	俄语   - 由 Vassily Ragosin 翻译
参见 Vim 网站查找它们：https://www.vim.org/translations.php

一套翻译帮助文件由以下文件组成：

	help.abx
	howto.abx
	...
	tags-ab

"ab" 是两个字母的语言代码。因此对于意大利语，名称是：

	help.itx
	howto.itx
	...
	tags-it

'helplang' 选项可以设置为首选语言。默认根据环境设置。Vim 会首先尝试在首选
语言中查找匹配的标签。找不到时使用英语。

要在特定语言中查找标签，在标签后追加 "@ab"，其中 "ab" 是两个字母的语言代码。
示例： >
	:he user-manual@it
	:he user-manual@en
第一个找到意大利语用户手册，即使 'helplang' 为空。
第二个找到英语用户手册，即使 'helplang' 设置为 "it"。

使用命令行补全 ":help" 命令时，"@en" 扩展名只在标签有多种语言时显示。当标签
只有英语时 "@en" 被省略。当第一个候选项有 "@ab" 扩展名且匹配 'helplang' 中的
第一种语言时 "@ab" 也被省略。

在非英语帮助文件中使用 |CTRL-]| 或 ":help!" 时，Vim 将尝试在同一语言中查找
标签。如果找不到，则使用 'helplang' 选择语言。

帮助文件必须使用 latin1 或 utf-8 编码。Vim 在第一行发现非 ASCII 字符时假定
编码为 utf-8。因此你必须翻译以 "For Vim version" 开头的标题。

同一目录中一种语言的帮助文件必须使用相同的编码。你可以为不同的语言使用不同的
编码，也可以为不同目录中相同语言的帮助文件使用不同的编码。

给翻译者的提示：
- 不要翻译标签。这使得使用 'helplang' 指定首选语言成为可能。你可以用你的
  语言添加新标签。
- 当你不翻译文件的某个部分时，使用 "tag@en" 表示法在英语版本中添加标签。
- 制作一个包含所有文件和标签文件的包供下载。用户可以将其放入一个 "doc" 目录
  中并开始使用它。向开发团队报告，以便他们可以在 www.vim.org 上添加链接。
- 使用 |:helptags| 命令生成标签文件。它将在指定的目录中找到所有语言。

编写帮助文件					*help-writing*

为了易于使用，插件的 Vim 帮助文件应该遵循标准 Vim 帮助文件的格式，除了第一行。
如果你正在编写新的帮助文件，最好复制一个已有的文件并将其用作模板。

帮助文件的第一行应该有以下格式： >

	*plugin_name.txt*	{插件的简短描述}

第一个字段是帮助标签，":help plugin_name" 将跳转到那里。行的其余部分，在一个
Tab 之后，用简短的方式描述插件的用途。这将出现在主帮助文件的 "LOCAL ADDITIONS"
部分。在那里检查它是否正确显示：|local-additions|。

如果你想添加版本号或最后修改日期，将其放在第二行，右对齐。

在帮助文件的底部，放置一个 Vim 模式行来设置 'textwidth' 和 'tabstop' 选项
以及 'filetype' 为 "help"。永远不要在这样的模式行中设置全局选项，那可能有
不想要的后果。


标签

要定义帮助标签，将名称放在星号之间（"*tag-name*"）。标签名称应该与所有 Vim
帮助标签名称不同，最好以 Vim 插件的名称开头。标签名称通常在行的右对齐处。

当引用已有的帮助标签并创建热链接时，将名称放在两个竖线之间（"|"），
例如 |help-writing|。

当在帮助文件中引用 Vim 选项时，将选项名称放在两个单引号之间，
例如 'statusline'

当引用任何其他技术术语或符号，如文件名或函数参数时，用反引号括起来，
例如 `~/.path/to/init.vim`。这将其渲染为"内联"代码（相对于"代码块"
|help-codeblock|）。


高亮显示

要定义列标题，在行尾使用波浪号字符，前面加一个空格。这将以不同的颜色高亮显示
列标题。例如

列标题 ~

要在帮助文件中分隔各节，在从第一列开始的行中放置一系列 '=' 字符。节分隔线
以不同方式高亮显示。

							      *help-codeblock*
要逐字引用一段 ex 命令块，在块之前的行尾放一个大于号（>）字符，在块之后的
一行的第一个非空白处放一个小于号（<）字符。从第 1 列开始的任何行也会在其前面
隐式地停止 ex 命令块。例如 >
	function Example_Func()
	  echo "Example"
	endfunction
<
要为代码块启用语法高亮，在大于号（>）字符后放一个语言名称注释（例如 "vim"）。
例如 >vim
	function Example_Func()
	  echo "Example"
	endfunction
<
						*help-notation*
在 Vim 帮助文件中，以下内容以不同方式高亮显示：
  - 以 <> 表示法表示的特殊键名如 <PageDown>，或控制字符如 CTRL-X
  - {花括号} 之间的任何内容，例如 {lhs} 和 {rhs}

"Note"、"Notes" 等类似词语会自动获得特殊的高亮显示。以下也是如此：
	Todo	待完成事项
	Error	错误内容

你可以在 $VIMRUNTIME/syntax/help.vim 中找到细节


文件类型补全					*ft-help-omni*

要在编写标签引用时获取帮助标签的补全，可以使用 |i_CTRL-X_CTRL-O| 命令。
