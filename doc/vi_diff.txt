Vim 和 Vi 之间的差异					*vi-differences*

                                      输入 |gO| 查看目录。

==============================================================================
1. 限制						*limits*

Vim 对可编辑的文件几乎没有限制。Vi 不能处理 <Nul> 字符和 128 以上的字符，
有行长度限制以及许多其他限制。

最大行长度	   2147483647 个字符
最大行数	   2147483647 行
最大文件大小	   2147483647 字节（2 GB），当长整型为 32 位时。
		   64 位长整型则大得多。也受 |swap-file| 可用磁盘空间限制。
							*E75*
文件路径长度	   Unix 和 Win32：1024 个字符，否则 256 个字符
		   （或系统支持的最大值）。
展开后的字符串选项长度
		   Unix 和 Win32：1024 个字符，否则 256 个字符
最大显示宽度	   Unix 和 Win32：1024 个字符，否则 255 个字符
映射左侧最大长度  50 个字符。
不同高亮类型数量：超过 30000
数字变量的范围：  -2147483648 到 2147483647（64 位系统可能更多）
		   另见：|v:numbermax|、|v:numbermin| 和 |v:numbersize|
标签文件中一行的最大长度：512 字节。
							*E1541*
|/\U| 和 |/\%U| 的最大值：2147483647（对于 32 位整数）。

撤销和寄存器中的文本信息保存在内存中，因此在进行（大量）更改时，可用的
（虚拟）内存量限制了撤销级别数和可以保存在寄存器中的文本。其他内容也保存
在内存中：命令行历史、快速修复模式的错误消息等。

==============================================================================
2. 最有趣的新增功能				*vim-additions*

对不同系统的支持。
	Vim 可以在以下系统上使用：
	- 现代 Unix 系统（BSD、Linux 等）
	- Windows（XP SP 2 或更高版本）
	- OS X

多级持久撤销。						|undo|
	'u' 在时间上后退，'CTRL-R' 向前前进。设置选项 'undolevels' 为要记住
	的更改数（默认 1000）。设置 'undolevels' 为 0 表示与 Vi 兼容的单级
	撤销。设置为 -1 表示完全不撤销。
	当缓冲区中的所有更改都已撤销时，缓冲区不再被视为已更改。你可以用
	:q 退出，无需 <!>。
	当撤销一些更改然后进行新的更改时，Vim 将在撤销树中创建一个分支。
	这意味着你可以回到文本的任何状态，不会有因更改而永久丢失文本的
	风险。|undo-tree|
	当设置 'undofile' 选项时，撤销信息存储在文件中。这意味着你可以退出
	Vim，在之前编辑过的文件上启动 Vim 并撤销退出 Vim 之前所做的更改。

图形用户界面 (GUI)。				|gui|
	包含对 GUI 的支持：菜单、鼠标、滚动条等。你可以定义自己的菜单。
	更好地支持 CTRL/SHIFT/ALT 键与特殊键和鼠标的组合。支持各种平台
	如 Win32。

多窗口和缓冲区。					|windows.txt|
	Vim 可以将屏幕分成多个窗口，每个窗口编辑不同的缓冲区或在不同
	位置编辑同一个缓冲区。缓冲区仍然可以被加载（和更改）但不在窗口
	中显示。这称为隐藏缓冲区。为此功能添加了许多命令和选项。
	Vim 还可以使用多个标签页，每个标签页有一个或多个窗口。可以使用
	标签标签行在这些页面之间快速切换。
	|tab-page|

语法高亮。					|:syntax|
	Vim 可以高亮关键字、模式和其他内容。这由许多 |:syntax| 命令定义，
	可以用于高亮大多数语言和文件类型。包含了许多用于高亮最常见语言的
	文件，如 C、C++、Java、Pascal、Makefile、shell 脚本等。可以使用
	|:highlight| 命令为普通终端、彩色终端和 GUI 定义高亮使用的颜色。
	一种方便的方式是使用 |:colorscheme| 命令。
	高亮的文本可以导出为 HTML。|convert-to-HTML|
	其他可以高亮的内容包括搜索字符串匹配 'hlsearch'、匹配括号
	|matchparen| 以及光标行和列 'cursorline' 'cursorcolumn'。

拼写检查。					|spell|
	当设置 'spell' 选项时，Vim 将高亮拼写错误。目前支持约 50 种语言，
	通过 'spelllang' 选项选择。在源代码中只检查注释和字符串的拼写。

折叠。						|folding|
	一系列行可以显示为一个"折叠"行。这允许快速概览文件和移动文本块。
	折叠可以手动创建、从文件语法创建、按缩进创建等。

差异模式。					|diff-mode|
	Vim 可以显示文件的两个版本并高亮差异。相同的文本部分被折叠起来。
	可以使用命令将文本从一个版本移动到另一个版本。

插件。						|add-plugin|
	可以通过将插件文件放在正确的目录中来扩展功能。这是开始使用其他人
	编写的 Vim 脚本的简单方式。插件可以用于所有类型的文件，或专门用于
	某种文件类型。
	包使这变得更加容易。|packages|

异步通信和定时器。				|job-control| |timer|
	Vim 可以在后台与其他进程交换消息。
	Vim 可以启动作业、与其通信并停止它。|job-control|
	定时器可以触发一次或重复触发并调用函数来执行任何工作。|timer|

重复一系列命令。					|q|
	"q{c}" 开始将输入的字符录制到命名寄存器 {c} 中。随后的 "q" 停止
	录制。寄存器可以用 "@{c}" 命令执行。这对重复复杂操作非常有用。

灵活的插入模式。					|ins-special-special|
	箭头键可以在插入模式中使用以在文件中移动。就撤销和重做而言，这会
	将插入分成两部分。

	CTRL-O 可以用于执行单个普通模式命令。这几乎等同于按 <Esc>、输入
	命令然后执行 |a|。

可视模式。					|Visual-mode|
	可视模式可以先高亮一段文本，然后给出命令对其执行操作。这是先给出
	操作符然后移动到要操作的文本末尾的一种（易于使用的）替代方案。
	|v| 和 |V| 用于启动可视模式。|v| 作用于字符，|V| 作用于行。
	移动光标以扩展可视区域。它在屏幕上以高亮显示。通过输入 "o"
	可以移动可视区域的另一端。可视区域可以受到操作符的影响：
		d	删除
		c	更改
		y	复制
		> 或 <	插入或删除缩进
		!	通过外部程序过滤
		=	通过 indent 过滤
		:	为可视行启动 |:| 命令。
		gq	将文本格式化为 'textwidth' 列
		J	合并行
		~	交换大小写
		u	转为小写
		U	转为大写

块操作符。					|visual-block|
	通过可视模式可以选择矩形文本块。使用 CTRL-V 启动可视模式。
	块可以被删除（"d"）、复制（"y"）或其大小写可以更改（"~"、"u" 和
	"U"）。删除或复制的块可以用 "p" 和 "P" 命令放入文本中。

帮助系统。					|:help|
	帮助在窗口中显示。可以使用常用命令来移动、搜索字符串等。标签可以
	用于在帮助文件中跳转，就像超文本链接一样。|:help| 命令接受参数
	以快速跳转到某个主题的信息。<F1> 是帮助系统的快速访问键。帮助
	索引文件的名称可以用 'helpfile' 选项设置。

命令行编辑和历史。				|cmdline-editing|
	你可以使用光标键在命令行的任何位置插入或删除。右/左光标键可以
	用于前进/后退一个字符。Shift+右/左光标键可以用于前进/后退一个
	单词。CTRL-B/CTRL-E 可以用于跳到命令行的开头/末尾。
	（Vi：只能修改行中的最后一个字符）
	（Vi：按 <Esc> 时命令行会被执行。这对大多数人来说是意外的；因此
	在 Vim 中做了更改。但当 <Esc> 是映射的一部分时，命令行会被执行。
	如果你在输入 <Esc> 时也想要 Vi 的行为，使用 ":cmap ^V<Esc>
	^V^M"）
							|cmdline-history|
	命令行会被记住。上/下光标键可以用于调出之前的命令行。'history'
	选项可以设置为要记住的行数。命令和搜索模式有单独的历史。

命令行补全。					|cmdline-completion|
	在输入命令行时（在屏幕底部行）可以输入 <Tab> 来补全
	   内容		示例		~
	- 命令		:e<Tab>
	- 标签		:ta scr<Tab>
	- 选项		:set sc<Tab>
	- 选项值	:set hf=<Tab>
	- 文件名	:e ve<Tab>
	- 等。

	如果有多个匹配，CTRL-N（下一个）和 CTRL-P（上一个）将遍历匹配。
	<Tab> 的工作方式类似于 CTRL-N，但会循环到第一个匹配。

	'wildchar' 选项可以设置为用于命令行补全的字符，默认为 <Tab>。
	在（不完整的）通配符后可以输入 CTRL-D；将列出所有匹配。CTRL-A
	将插入所有匹配。CTRL-L 将插入匹配的最长公共部分。

插入模式补全。					|ins-completion|
	在插入模式中，CTRL-N 和 CTRL-P 键可以用于补全出现在其他地方的
	单词。|i_CTRL-N|
	通过 CTRL-X 进入另一个模式，可以完成以下补全：
	|i_CTRL-X_CTRL-F|	文件名
	|i_CTRL-X_CTRL-K|	'dictionary' 文件中的单词
	|i_CTRL-X_CTRL-T|	'thesaurus' 文件中的单词
	|i_CTRL-X_CTRL-I|	包含文件中的单词
	|i_CTRL-X_CTRL-L|	整行
	|i_CTRL-X_CTRL-]|	标签文件中的单词
	|i_CTRL-X_CTRL-D|	定义或宏
	|i_CTRL-X_CTRL-O|	全能补全：针对文件类型的智能补全
	|i_CTRL-X_CTRL-R|	寄存器中的内容
	等。

长行支持。					'wrap' 'linebreak'
	如果 'wrap' 选项关闭，长行不会换行，只显示它们的一部分。当光标
	移动到未显示的部分时，屏幕将水平滚动。可以用 'sidescroll' 选项
	设置最小滚动列数。|zh| 和 |zl| 命令可以用于侧向滚动。
	或者，当设置 'linebreak' 选项时，长行在单词之间断开。这允许方便
	地编辑单行段落（例如当文本稍后被读入 DTP 程序时）。使用 |gk| 和
	|gj| 命令上下移动光标。

文本格式化。					|formatting|
	'textwidth' 选项可以用于自动限制行长度。这补充了 Vi 的
	'wrapmargin' 选项，后者不是很有用。|gq| 操作符可以用于格式化
	一段文本（例如，|gqap| 格式化当前段落）。文本对齐命令：
	|:center|、|:left| 和 |:right|。

扩展搜索模式。					|pattern|
	有许多额外的匹配项可以匹配各种文本项。示例：
	"\n" 可以在搜索模式中匹配换行符。
	"x\{2,4}" 匹配 "x" 2 到 4 次。
	"\s" 匹配空白字符。

目录、远程和归档浏览。				|netrw|
	Vim 可以浏览文件系统。只需编辑一个目录。使用常用命令在列表中
	移动并按 <Enter> 进入光标下的目录或文件。
	这也适用于通过 ftp、http、ssh 等访问的远程文件。
	也可以浏览 Zip 和 tar 归档。|tar| |zip|

编辑-编译-编辑加速。				|quickfix|
	|:make| 命令可以用于运行编译并跳转到第一个错误。编译器错误消息
	文件将被解析。Vim 跳转到第一个错误。

	错误文件中的每一行都被扫描以获取文件名、行号和错误消息。
	'errorformat' 选项可以设置为类似 scanf 的字符串列表以处理
	来自许多编译器的输出。

	|:cn| 命令可以用于跳转到下一个错误。
	|:cl| 列出所有错误消息。其他命令也可用。
	'makeef' 选项有错误消息文件的名称。
	'makeprg' 选项包含要用 |:make| 命令执行的程序名称。
	'shellpipe' 选项包含用于将编译器输出放入错误文件的字符串。

在文件中查找匹配。				|:vimgrep|
	Vim 可以在多个文件中搜索模式。这使用高级的 Vim 正则表达式模式，
	在所有系统上工作，也可以搜索压缩文件。

改进的程序缩进。					'cindent'
	当 'cindent' 选项开启时，每行的缩进会自动调整。C 语法基本上
	被识别。可以用 'cinoptions' 设置各种风格的缩进。可以用
	'cinkeys' 设置触发缩进的按键。

	注释可以自动格式化。'comments' 选项可以设置为开始和结束注释
	的字符。这对 C 代码效果最好，但也适用于电子邮件（行首的 ">"）
	和其他类型的文本。|=| 操作符可以用于重新缩进行。

	许多其他语言有缩进插件来支持自动缩进。|30.3|

在包含文件中搜索单词。				|include-search|
	|[i| 命令可以用于在当前文件和包含文件中搜索光标下单词的匹配。
	'include' 选项可以设置为描述包含文件命令的模式（默认为 C 程序）。
	|[I| 命令列出所有匹配，|[_CTRL-I| 命令跳转到匹配。
	|[d|、|[D| 和 |[_CTRL-D| 命令做同样的事，但只针对 'define'
	选项给出的模式匹配的行。

自动命令。					|autocommand|
	命令可以根据文件名在读取文件、写入文件、跳转到另一个缓冲区等
	时自动执行。这对为 C 程序、文档、纯文本、电子邮件等设置选项和
	映射很有用。这也使得编辑压缩文件成为可能。

脚本和表达式。					|expression|
	已添加命令以形成强大的脚本语言。
	|:if|		条件执行，例如可以用于根据 $TERM 的值设置选项。
	|:while|	重复多个命令。
	|:for|		遍历列表。
	|:echo|		打印表达式的结果。
	|:let|		给内部变量、选项等赋值。
			变量类型有 Number、String、List 和 Dictionary。
	|:execute|	执行由表达式组成的命令。
	|:try|		捕获异常。
	等等。参见 |eval|。
	支持调试和性能分析。|debug-scripts| |profile|
	如果这不够，还提供了 |Python| 的接口。

Viminfo。
	命令行历史、标记和寄存器可以存储在启动时读取的文件中。这可以
	用于在退出和重启 Vim 后重复搜索命令或命令行命令。也可以用
	|'0| 直接跳回到上次编辑停止的地方。'viminfo' 选项可以设置为
	选择要存储在 .viminfo 文件中的项目。默认情况下此功能关闭。

鼠标支持。					|mouse-using|
	GUI 版本、Unix 的 xterm、带 sysmouse 的 BSD、带 gpm 的 Linux
	和 Win32 中都支持鼠标。它可以用于定位光标、选择可视区域、
	粘贴寄存器等。

键名的使用。					|<>| |key-notation|
	特殊键现在都有名称，如 <Up>、<End> 等。
	此名称可以在映射中使用，使编辑映射变得容易。

编辑二进制文件。					|edit-binary|
	Vim 可以编辑二进制文件。你可以更改可执行文件中的几个字符而不
	损坏它。Vim 不会删除 NUL 字符（它们在内部表示为 <NL>）。
	|-b|		启动编辑二进制文件的命令行参数
	'binary'	由 |-b| 设置的选项。防止为文件最后一行添加 <EOL>。

多语言支持。					|multi-lang|
	可以编辑双字节或多字节编码的文件。有 UTF-8 支持以便能够同时
	编辑各种语言而无需切换字体。|UTF-8|
	消息和菜单有不同语言的版本。

光标超越行。
	当设置 'virtualedit' 选项时，光标可以在屏幕上任何地方移动，
	包括没有文本的地方。这对于轻松编辑表格和图形很有用。
