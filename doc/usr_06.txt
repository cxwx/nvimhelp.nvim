				  使用语法高亮


黑白文本很无聊。有了颜色你的文件就有了活力。这不仅看起来漂亮，还能加快你的
工作。改变不同类型文本使用的颜色。用你在屏幕上看到的颜色打印你的文本。

*06.1*	启用高亮

语法高亮默认是启用的。Nvim 会自动检测文件类型并加载正确的语法高亮。

==============================================================================
*06.2*	没有或错误的颜色？

你看不到颜色可能有多个原因:

- 你的终端不支持颜色。
	Vim 会使用粗体、斜体和下划线文本，但这看起来不太好。你可能会想换一个
	支持颜色的终端。

- 你的终端支持颜色，但 Vim 不知道。
	确保你的 $TERM 设置正确。例如，当使用支持颜色的 xterm 时: >

		setenv TERM xterm-color
<
	或者（取决于你的 shell）: >

		TERM=xterm-color; export TERM

<	终端名称必须与你使用的终端匹配。

- 文件类型未被识别。
	Vim 不认识所有文件类型，有时几乎不可能判断一个文件使用的是什么语言。
	试试这个命令: >

		:set filetype
<
	如果结果是 "filetype="，那问题确实是 Vim 不知道这是什么类型的文件。
	你可以手动设置类型: >

		:set filetype=fortran

<	要查看有哪些类型可用，请查看 $VIMRUNTIME/syntax 目录。对于 GUI 你
	可以使用 Syntax 菜单。设置文件类型也可以通过 |modeline| 来完成，这样
	每次编辑该文件时都会被高亮。例如，这一行可以用在 Makefile 中（放在文件
	的开头或末尾附近）: >

		# vim: syntax=make

<	你可能知道如何自己检测文件类型。通常可以使用文件扩展名（点号后面的
	部分）。
	参见 |new-filetype| 了解如何告诉 Vim 检测该文件类型。

- 你的文件类型没有高亮。
	你可以通过如上所述手动设置来尝试使用类似的文件类型。如果那还不够好，
	你可以编写自己的语法文件，参见 |mysyntaxfile|。


或者颜色可能是错误的:

- 彩色文本非常难以阅读。
	Vim 会猜测你使用的背景颜色。如果是黑色（或其他暗色），它会使用浅色
	文本。如果是白色（或其他亮色），它会使用深色文本。如果 Vim 猜错了，
	文本就会难以阅读。要解决这个问题，设置 'background' 选项。对于暗色
	背景: >

		:set background=dark

<	对于亮色背景: >

		:set background=light

<	确保你把这个放在 ":syntax enable" 命令之前，否则颜色已经被设置了。
	你可以在设置 'background' 之后执行 ":syntax reset" 让 Vim 重新设置
	默认颜色。

- 从下往上滚动时颜色不对。
	Vim 不会读取整个文件来解析文本。它从你正在查看的位置开始解析。这节省了
	大量时间，但有时颜色会出错。一个简单的修复方法是按 CTRL-L。或者向后
	滚动一些再向前。
	要真正修复，参见 |:syn-sync|。一些语法文件有办法使其向后查看更远，
	参见特定语法文件的帮助。例如，TeX 语法的 |ft-tex-syntax|。

*06.3*	不同的颜色				*:syn-default-override*

如果你不喜欢默认颜色，你可以选择另一个配色方案。在 GUI 中使用 Edit/Color
Scheme 菜单。你也可以输入命令: >

	:colorscheme evening

"evening" 是配色方案的名称。还有其他几个你可能想试试的。查看
$VIMRUNTIME/colors 目录。

当你找到了你喜欢的配色方案，将 ":colorscheme" 命令添加到你的 |init.vim|
文件中。

你也可以编写自己的配色方案。方法如下:

1. 选择一个接近的配色方案。将此文件复制到你自己的 Vim 目录。对于 Unix，这
   应该可行: >

	!mkdir -p ~/.config/nvim/colors
	!cp $VIMRUNTIME/colors/morning.vim ~/.config/nvim/colors/mine.vim
<
   这是从 Vim 中完成的，因为它知道 $VIMRUNTIME 的值。

2. 编辑配色方案文件。以下条目很有用:

	cterm		彩色终端中的属性
	ctermfg		彩色终端中的前景色
	ctermbg		彩色终端中的背景色
	gui		GUI 中的属性
	guifg		GUI 中的前景色
	guibg		GUI 中的背景色

   例如，要使注释变为绿色: >

	:highlight Comment ctermfg=green guifg=green
<
   可用于 "cterm" 和 "gui" 的属性有 "bold" 和 "underline"。如果你两个都想要，
   使用 "bold,underline"。详情参见 |:highlight| 命令。

3. 告诉 Vim 始终使用你的配色方案。在你的 |vimrc| 中加入这一行: >

	colorscheme mine

如果你想看看最常用的颜色组合长什么样，使用这个命令: >

	:runtime syntax/colortest.vim

你会看到各种颜色组合的文本。你可以检查哪些可读性好且看起来美观。

==============================================================================
*06.4*	有颜色还是没颜色

彩色显示文本需要很多资源。如果你发现显示太慢，你可能想暂时禁用语法高亮: >

	:syntax clear

编辑另一个文件（或同一个）时颜色会恢复。

如果你想完全停止高亮，使用: >

	:syntax off

这会完全禁用语法高亮并立即对所有缓冲区生效。参见 |:syntax-off| 了解更多
详情。

							*:syn-manual*
如果你只想对特定文件使用语法高亮，使用: >

	:syntax manual

这会启用语法高亮，但不会在开始编辑缓冲区时自动打开。要为当前缓冲区打开高亮，
设置 'syntax' 选项: >

	:set syntax=ON
<
