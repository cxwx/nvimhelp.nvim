1. 折叠方法					*fold-methods*

折叠方法可以通过 'foldmethod' 选项设置。

当将 'foldmethod' 设置为 "manual" 以外的值时，所有折叠被删除并创建
新的。切换到 "manual" 方法不会移除现有的折叠。这可以用来先自动定义
折叠，然后手动更改它们。

有六种方法来选择折叠：
	manual		手动定义折叠
	indent		更多缩进意味着更高的折叠级别
	expr		指定表达式来定义折叠
	syntax		由语法高亮定义折叠
	diff		未更改文本的折叠
	marker		由文本中的标记定义折叠


MANUAL						*fold-manual*

使用命令手动定义折叠区域。这也可以被解析文本以查找折叠的脚本使用。

折叠的级别仅由其嵌套定义。要增加某范围行的折叠级别，在其内部定义
一个具有相同行的折叠。

手动折叠在放弃文件时丢失。要保存折叠，使用 |:mkview| 命令。
视图可以稍后用 |:loadview| 恢复。


INDENT						*fold-indent*

折叠由行的缩进自动定义。

折叠级别由行的缩进除以 'shiftwidth' 计算（向下取整）。具有相同或
更高折叠级别的连续行形成一个折叠，其中具有更高级别的行形成嵌套
折叠。

折叠的嵌套受 'foldnestmax' 限制。

某些行被忽略并获得其上方或下方行的折叠级别（以较低者为准）。这些是
空行或空白行，以及以 'foldignore' 中字符开头的行。在检查 'foldignore'
中的字符之前跳过空白。对于 C 语言使用 "#" 来忽略预处理行。

当你想以其他方式忽略行时，使用 "expr" 方法。|indent()| 函数可以在
'foldexpr' 中使用来获取行的缩进。


EXPR						*fold-expr*

折叠由其折叠级别自动定义，类似于 "indent" 方法。'foldexpr' 选项的
值被评估以获取行的折叠级别。示例：
这将为所有以制表符开头的连续行创建折叠： >
	:set foldexpr=getline(v:lnum)[0]==\"\\t\"
这将把由空行分隔的段落做成折叠： >
	:set foldexpr=getline(v:lnum)=~'^\\s*$'&&getline(v:lnum+1)=~'\\S'?'<1':1
这做同样的事情： >
	:set foldexpr=getline(v:lnum-1)=~'^\\s*$'&&getline(v:lnum)=~'\\S'?'>1':1

注意必须使用反斜杠来转义 ":set" 以不同方式处理的字符（空格、反斜杠、
双引号等，参见 |option-backslash|）。

最高效的方式是调用不带参数的函数： >
	:set foldexpr=MyFoldLevel()
该函数必须使用 v:lnum。参见 |expr-option-function|。

以下是评估表达式的条件：

- 当前缓冲区和窗口设置为该行。
- 变量 "v:lnum" 设置为行号。

foldexpr 的结果决定折叠级别如下：
  值			含义 ~
  0			该行不在折叠中
  1, 2, ..		该行在此级别的折叠中
  -1			折叠级别未定义，使用此行前后行的折叠级别
			（以较低者为准）
  "="			使用前一行的折叠级别
  "a1", "a2", ..	在前一行的折叠级别上加一、二、..，
			结果用于当前行
  "s1", "s2", ..	从前一行的折叠级别减去一、二、..，
			结果用于下一行
  "<1", "<2", ..	此级别的折叠在此行结束
  ">1", ">2", ..	此级别的折叠在此行开始

结果值 "="、"s" 和 "a" 更昂贵，请参见 |fold-expr-slow|。

不需要用 ">1"（"<1"）标记折叠的开始（结束），当折叠级别比前一行
的折叠级别高（低）时，折叠也会开始（结束）。

表达式不能有副作用。缓冲区中的文本、光标位置、搜索模式、选项等
不能被更改。如果你小心的话，可以更改并恢复它们。

如果表达式有错误，或结果值不被识别，没有错误消息，折叠级别为零。
为了调试，可以将 'debug' 选项设置为 "msg"，错误消息就会可见。

如果 'foldexpr' 表达式以 s: 或 |<SID>| 开头，则会被替换为脚本
ID（|local-function|）。示例： >
		set foldexpr=s:MyFoldExpr()
		set foldexpr=<SID>SomeFoldExpr()
<
使用 "a1" 和 "s1" 的示例：对于多行 C 注释，包含 "/*" 的行
返回 "a1" 开始折叠，包含 "*/" 的行返回 "s1" 在该行之后结束
折叠： >
  if match(thisline, '/\*') >= 0
    return 'a1'
  elseif match(thisline, '\*/') >= 0
    return 's1'
  else
    return '='
  endif
但是，这对单行注释、字符串等不起作用。

|foldlevel()| 可用于计算相对于前一个折叠级别的折叠级别。但请注意
foldlevel() 在级别尚未确定时可能返回 -1。它返回行开始处的级别，
但折叠可能在该行中结束。

折叠可能没有正确更新。你可以使用 |zx| 或 |zX| 强制更新折叠。

最小化计算成本					*fold-expr-slow*

由于计算成本，此折叠方法可能使 Vim 反应迟钝，特别是当所有行的
折叠级别都必须初始计算时。之后，在每次更改后，Vim 将计算限制
在折叠级别受影响的那些行（并重用其他所有行的已知折叠级别）。

因此，折叠表达式应力求最小化计算给定行所需的依赖行数：例如，
尝试避免 "="、"a" 和 "s" 返回值，因为这些将需要评估前面行的
折叠级别，直到找到一个独立的折叠级别。

如果这证明困难，下一个最好的方法是将所有折叠级别缓存在缓冲区
本地变量（b:foldlevels）中，仅在 |b:changedtick| 时更新：
>vim
  func MyFoldFunc()
    if b:lasttick == b:changedtick
      return b:foldlevels[v:lnum - 1]
    endif
    let b:lasttick = b:changedtick
    let b:foldlevels = []
    " compute foldlevels ...
    return b:foldlevels[v:lnum - 1]
  enddef
  set foldexpr=s:MyFoldFunc()
<
上面的示例中，通过使用不带参数的函数（仍须使用 v:lnum）获得了
进一步加速。参见 |expr-option-function|。

SYNTAX						*fold-syntax*

折叠由具有 "fold" 参数的语法项定义。|:syn-fold|

折叠级别由折叠嵌套定义。折叠的嵌套受 'foldnestmax' 限制。

注意正确指定语法同步。如果做得不对，折叠可能与显示的高亮不同。
这在使用匹配多行的模式时特别相关。如有疑问，尝试使用暴力同步： >
	:syn sync fromstart


DIFF						*fold-diff*

折叠自动为不是更改一部分或接近更改的文本定义。

此方法仅在当前窗口设置了 'diff' 选项且正在显示更改时才能正常工作。
否则整个缓冲区将是一个大折叠。

'diffopt' 选项可用于指定上下文。即折叠与更改之间未包含在折叠中的
行数。例如，使用 8 行上下文： >
	:set diffopt=filler,context:8
默认上下文为六行。

当 'scrollbind' 也设置时，Vim 会尝试在其他差异窗口中保持相同的
折叠打开，以便显示相同的文本。


MARKER						*fold-marker*

文本中的标记告诉折叠的开始和结束位置。这允许你精确指定折叠。
这允许删除和放置折叠，而不会有包含错误行的风险。'foldtext' 选项
通常设置为使标记前的文本显示在折叠行中。这使得可以给折叠命名。

标记可以包含级别，也可以使用匹配对。包含级别更简单，你不必添加
结束标记，避免了不匹配标记对的问题。示例： >
	/* global variables {{{1 */
	int varA, varB;

	/* functions {{{1 */
	/* funcA() {{{2 */
	void funcA() {}

	/* funcB() {{{2 */
	void funcB() {}
<							*{{{* *}}}*
折叠从 "{{{" 标记开始。后面的数字指定折叠级别。发生什么取决于
当前折叠级别和标记给出的级别之间的差异：
1. 如果遇到相同折叠级别的标记，前一个折叠结束，另一个相同级别
   的折叠开始。
2. 如果找到更高折叠级别的标记，开始嵌套折叠。
3. 如果找到更低折叠级别的标记，直到并包括此级别的所有折叠结束，
   指定级别的折叠开始。

数字表示折叠级别。不能使用零（零级的标记被忽略）。你可以使用
带数字的 "}}}" 来表示结束的折叠级别。下一行的折叠级别将比指示
的级别少一。注意 Vim 不会回溯查找匹配标记的级别（那会花太多时间）。
示例： >

	{{{1
	fold level here is 1
	{{{3
	fold level here is 3
	}}}3
	fold level here is 2

你也可以使用匹配的 "{{{" 和 "}}}" 标记对来定义折叠。每个 "{{{"
增加折叠级别一，每个 "}}}" 减少折叠级别一。注意保持标记匹配！
示例： >

	{{{
	fold level here is 1
	{{{
	fold level here is 2
	}}}
	fold level here is 1

你可以混合使用带数字和不带数字的标记。对大折叠使用带编号的
标记，对函数内部的局部使用不带编号的标记是一种有用的方式。
例如，对文件的各部分如 "structure definitions"、"local variables"
和 "functions" 使用级别一的折叠。对每个定义和函数使用级别 2
标记。在函数内部使用不带编号的标记。当你在函数中做修改以
拆分折叠时，不必重新编号标记。

标记可以通过 'foldmarker' 选项设置。建议保持默认值 "{{{,}}}"，
以便文件可以在 Vim 用户之间交换。只在文件需要时才更改它
（例如，它包含来自另一个折叠编辑器的标记，或默认标记对文件
的语言造成了问题）。

							*fold-create-marker*
"zf" 可用于创建由标记定义的折叠。Vim 会为你插入标记。Vim 会
附加由 'foldmarker' 指定的开始和结束标记。标记附加到行尾。
如果 'commentstring' 不为空则使用它。
在以下情况下不能正常工作：
- 行已经包含带有级别号的标记。Vim 不知道该怎么办。
- 附近的折叠在其标记中使用了级别号，这会干扰。
- 行在注释内部，'commentstring' 不为空且嵌套注释不起作用。
  例如 C 语言：在注释中添加 `/* {{{ */` 会截断现有注释。
  要么将标记放在注释之前或之后，要么手动添加标记。
通常，当你已经有带级别号的标记时，让 Vim 创建标记不是个好主意。

							*fold-delete-marker*
"zd" 可用于删除由标记定义的折叠。Vim 会为你删除标记。Vim 会
在折叠的开始和结束搜索由 'foldmarker' 指定的开始和结束标记。
当标记周围的文本与 'commentstring' 匹配时，该文本也会被删除。
在以下情况下不能正常工作：
- 行包含多个标记且其中一个指定了级别。只移除第一个，不检查
  这是否会产生删除折叠的预期效果。
- 标记包含级别号且用于同时开始或结束多个折叠。

2. 折叠命令				*fold-commands* *E490*

所有折叠命令以 "z" 开始。提示："z" 从侧面看像一张折叠的纸。


创建和删除折叠 ~
							*zf* *E350*
zf{motion}  或
{Visual}zf	创建折叠的操作符。
		这只在 'foldmethod' 为 "manual" 或 "marker" 时有效。
		"manual" 方法下新折叠将被关闭。
		'foldenable' 将被设置。
		另见 |fold-create-marker|。

							*zF*
zF		为 [count] 行创建折叠。工作方式类似 "zf"。

:{range}fo[ld]						*:fold* *:fo*
		为 {range} 中的行创建折叠。工作方式类似 "zf"。

							*zd* *E351*
zd		删除光标处的一个折叠。当光标在折叠行上时，该折叠被
		删除。嵌套折叠上移一级。在可视模式下，所选区域中
		（部分）的所有折叠的一个级别被删除。
		小心：这很容易删除比你预期更多的折叠，且手动折叠
		没有撤销。
		这只在 'foldmethod' 为 "manual" 或 "marker" 时有效。
		另见 |fold-delete-marker|。

							*zD*
zD		递归删除光标处的折叠。在可视模式下，所选区域中
		（部分）的所有折叠和其中的所有嵌套折叠都被删除。
		这只在 'foldmethod' 为 "manual" 或 "marker" 时有效。
		另见 |fold-delete-marker|。

							*zE* *E352*
zE		消除窗口中的所有折叠。
		这只在 'foldmethod' 为 "manual" 或 "marker" 时有效。
		另见 |fold-delete-marker|。


打开和关闭折叠 ~

小于 'foldminlines' 的折叠总是像打开的一样显示。因此下面的命令
在小折叠上可能工作方式不同。

							*zo*
zo		打开光标下的一个折叠。当给出计数时，打开那么多深度
		的折叠。在可视模式下，为所选区域中的所有行打开一级
		折叠。

							*zO*
zO		递归打开光标下的所有折叠。不包含光标行的折叠不变。
		在可视模式下，打开所选区域中的所有折叠，包括只部分
		被选中的折叠。

							*zc*
zc		关闭光标下的一个折叠。当给出计数时，关闭那么多深度
		的折叠。在可视模式下，为所选区域中的所有行关闭一级
		折叠。
		'foldenable' 将被设置。

							*zC*
zC		递归关闭光标下的所有折叠。不包含光标行的折叠不变。
		在可视模式下，关闭所选区域中的所有折叠，包括只部分
		被选中的折叠。
		'foldenable' 将被设置。

							*za*
za		总结：切换光标下的折叠。
		在关闭的折叠上：打开它。当折叠嵌套时，你可能需要
		使用 "za" 多次。当给出计数时，打开那么多关闭的折叠。
		在打开的折叠上：关闭它并设置 'foldenable'。这只关闭
		一级，因为再次使用 "za" 会打开折叠。当给出计数时
		关闭那么多折叠（这与重复 "za" 那么多次不同）。

							*zA*
zA		在关闭的折叠上：递归打开它。
		在打开的折叠上：递归关闭它并设置 'foldenable'。

							*zv*
zv		查看光标行：打开刚好足够的折叠使光标所在行不被折叠。

							*zx*
zx		更新折叠：撤销手动打开和关闭的折叠：重新应用
		'foldlevel'，然后执行 "zv"：查看光标行。
		同时强制重新计算折叠。这在使用 'foldexpr' 且缓冲区
		的更改导致折叠未正确更新时很有用。

							*zX*
zX		撤销手动打开和关闭的折叠：重新应用 'foldlevel'。
		同样强制重新计算折叠，类似 |zx|。

							*zm*
zm		折叠更多：从 'foldlevel' 中减去 |v:count1|。如果
		'foldlevel' 已经是零则什么也不做。
		'foldenable' 将被设置。

							*zM*
zM		关闭所有折叠：将 'foldlevel' 设置为 0。
		'foldenable' 将被设置。

							*zr*
zr		减少折叠：向 'foldlevel' 添加 |v:count1|。

							*zR*
zR		打开所有折叠。这将 'foldlevel' 设置为最高折叠级别。

							*:foldo* *:foldopen*
:{range}foldo[pen][!]
		打开 {range} 中的折叠。添加 [!] 时打开所有折叠。
		用于查看 {range} 中的所有文本。不带 [!] 打开一级折叠。

							*:foldc* *:foldclose*
:{range}foldc[lose][!]
		关闭 {range} 中的折叠。添加 [!] 时关闭所有折叠。
		用于隐藏 {range} 中的所有文本。不带 [!] 关闭一级折叠。

							*zn*
zn		不折叠：重置 'foldenable'。所有折叠将打开。

							*zN*
zN		正常折叠：设置 'foldenable'。所有折叠将恢复到之前
		的状态。

							*zi*
zi		反转 'foldenable'。


在折叠间移动 ~
							*[z*
[z		移动到当前打开折叠的开始。如果已在开始位置，移动到
		包含它的折叠的开始。如果没有包含折叠，命令失败。
		使用计数时，重复命令 [count] 次。

							*]z*
]z		移动到当前打开折叠的结束。如果已在结束位置，移动到
		包含它的折叠的结束。如果没有包含折叠，命令失败。
		使用计数时，重复命令 [count] 次。

							*zj*
zj		向下移动到下一个折叠的开始。关闭的折叠计为一个折叠。
		使用计数时，重复命令 [count] 次。
		此命令可在 |operator| 之后使用。

							*zk*
zk		向上移动到前一个折叠的结束。关闭的折叠计为一个折叠。
		使用计数时，重复命令 [count] 次。
		此命令可在 |operator| 之后使用。


在折叠上执行命令 ~

:[range]foldd[oopen] {cmd}		*:foldd* *:folddo* *:folddoopen*
		在所有不在关闭折叠中的行上执行 {cmd}。当给出 [range]
		时，只使用这些行。每次执行 {cmd} 时，光标定位在执行
		该命令的行上。
		工作方式类似 ":global" 命令：首先标记所有不在关闭折叠
		中的行。然后对所有标记的行执行 {cmd}。因此当 {cmd}
		改变了折叠时，这不影响执行位置（除非删除了行）。
		示例： >
			:folddoopen s/end/loop_end/ge
<		注意使用了 "e" 标志以避免在 "end" 不匹配时得到错误
		消息。

:[range]folddoc[losed] {cmd}			*:folddoc* *:folddoclosed*
		在所有在关闭折叠中的行上执行 {cmd}。
		其他方面与 ":folddoopen" 相同。

3. 折叠选项					*fold-options*

颜色							*fold-colors*

关闭折叠的颜色用 Folded 组设置 |hl-Folded|。折叠列的颜色用
FoldColumn 组设置 |hl-FoldColumn|。设置颜色的示例： >

	:highlight Folded guibg=grey guifg=blue
	:highlight FoldColumn guibg=darkgrey guifg=white


FOLDLEVEL						*fold-foldlevel*

'foldlevel' 是一个数字选项：值越高，打开的折叠区域越多。
当 'foldlevel' 为 0 时，所有折叠关闭。
当 'foldlevel' 为正数时，一些折叠关闭。
当 'foldlevel' 很高时，所有折叠打开。
更改 'foldlevel' 时会应用它。之后可以手动打开和关闭折叠。
增加时，新级别以上的折叠打开。不会关闭手动打开的折叠。
减少时，新级别以上的折叠关闭。不会打开手动关闭的折叠。


FOLDTEXT						*fold-foldtext*

'foldtext' 是指定表达式的字符串选项。此表达式被评估以获取
关闭折叠显示的文本。示例： >

    :set foldtext=v:folddashes.substitute(getline(v:foldstart),'/\\*\\\|\\*/\\\|{{{\\d\\=','','g')

这显示折叠的第一行，去掉了 "/*"、"*/" 和 "{{{"。注意使用反斜杠
避免某些字符被 ":set" 命令解释。定义函数并调用它要简单得多： >

    :set foldtext=MyFoldText()
    :function MyFoldText()
    :  let line = getline(v:foldstart)
    :  let sub = substitute(line, '/\*\|\*/\|{{{\d\=', '', 'g')
    :  return v:folddashes .. sub
    :endfunction

'foldtext' 在 |sandbox| 中评估。当前窗口设置为显示该行的窗口。

错误被忽略。为了调试，将 'debug' 选项设置为 "throw"。

默认值是 |foldtext()|。这为大多数类型的折叠返回合理的文本。
如果你不喜欢它，可以指定自己的 'foldtext' 表达式。它可以使用
这些特殊 Vim 变量：
	v:foldstart	折叠第一行的行号
	v:foldend	折叠最后一行的行号
	v:folddashes	包含破折号的字符串，表示折叠级别
	v:foldlevel	折叠的折叠级别

如果结果是 |List|，它被解析和绘制为 "overlay" 虚拟文本
（参见 |nvim_buf_set_extmark()|），否则结果被转换为字符串，
其中 TAB 被替换为空格，不可打印字符变为可打印字符。

结果行被截断以适合窗口，它永远不会折行。当文本后有空间时，
用 'fillchars' 指定的字符填充。

如果 'foldtext' 表达式以 s: 或 |<SID>| 开头，则会被替换为
脚本 ID（|local-function|）。示例： >
		set foldtext=s:MyFoldText()
		set foldtext=<SID>SomeFoldText()
<
注意需要使用反斜杠处理 ":set" 命令以不同方式处理的字符：
空格、反斜杠和双引号。|option-backslash|


FOLDCOLUMN						*fold-foldcolumn*

'foldcolumn' 是一个数字，设置窗口侧面用于指示折叠的列宽。
当为零时，没有折叠列。正常值为 auto:9。最大值为 9。

打开的折叠用顶部的 '-' 和下面的 '|' 字符组成的列表示。此列
在打开的折叠停止处结束。当折叠嵌套时，嵌套折叠在其包含折叠
的右边一个字符。

关闭的折叠用 '+' 表示。

这些字符可以通过 'fillchars' 选项更改。

当折叠列太窄无法显示所有嵌套折叠时，显示数字来指示嵌套级别。
要覆盖此行为，可以使用 'fillchars' 选项的 "foldinner" 字符。

鼠标也可以用来在折叠列中打开和关闭折叠：
- 点击 '+' 打开该行的关闭折叠。
- 点击其他非空白字符关闭该行的打开折叠。


其他选项

'foldenable'  'fen':	未设置时打开所有折叠。
'foldexpr'    'fde':	用于 "expr" 折叠的表达式。
'foldignore'  'fdi':	用于 "indent" 折叠的字符。
'foldmarker'  'fmr':	用于 "marker" 折叠的已定义标记。
'foldmethod'  'fdm':	当前折叠方法的名称。
'foldminlines' 'fml':	折叠显示为关闭的最小屏幕行数。
'foldnestmax' 'fdn':	"indent" 和 "syntax" 折叠的最大嵌套层数。
'foldopen'    'fdo':	哪些类型的命令打开关闭的折叠。
'foldclose'   'fcl':	何时关闭不在光标下的折叠。

4. 折叠的行为						*fold-behavior*

当上下移动光标和滚动时，光标会移动到一系列折叠行的第一行。
当光标已在折叠行上时，它移动到下一个未折叠行或下一个关闭的折叠。

当光标在折叠行上时，光标总是显示在第一列。标尺确实显示实际的
光标位置，但由于行被折叠，无法在那里显示。

许多移动命令将一系列折叠行视为空行。例如，"w" 命令在第一列
停止一次。

在关闭的折叠中开始搜索不会在当前折叠中找到匹配。就像正向搜索
总是从关闭折叠的末尾开始，而反向搜索从关闭折叠的开头开始。

在插入模式下，光标行永远不会被折叠。这样你就可以看到你输入的
内容！

使用操作符时，关闭的折叠作为整体被包含。因此 "dl" 删除光标下
的整个关闭折叠。

对于在缓冲区行上操作的 Ex 命令，范围总是调整为从关闭折叠的
第一行开始并在关闭折叠的最后一行结束。因此，此命令： >
	:s/foo/bar/g
当光标在关闭折叠上使用时，将在折叠的所有行中替换 "foo" 为 "bar"。
这不适用于 |:folddoopen| 和 |:folddoclosed|。

注意对于某些 Ex 命令（如 |:source|），只有使用两行说明符
[range] 时才调整范围。

当编辑之前编辑过的缓冲区时，使用上次使用的折叠设置。对于手动
折叠，恢复已定义的折叠。对于所有折叠方法，恢复手动打开和关闭
的折叠。如果此缓冲区在此窗口中编辑过，使用那时的值。否则使用
该缓冲区最后编辑时所在窗口的值。
