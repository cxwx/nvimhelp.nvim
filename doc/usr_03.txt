*03.1*	按单词移动

要将光标向前移动一个单词，使用 "w" 命令。与大多数 Vim 命令一样，你可以使用数字
前缀来跨越多个单词移动。例如，"3w" 移动三个单词。下图展示了它的工作方式（从
标记为 "x" 的位置开始）:

	This is a line with example text ~
	  x-->-->->----------------->
	   w  w  w    3w

注意如果光标已经在一个单词的开头，"w" 会移动到下一个单词的开头。
   "b" 命令向后移动到前一个单词的开头:

	This is a line with example text ~
	<----<--<-<---------<--x
	   b   b b    2b      b

还有 "e" 命令移动到下一个单词的末尾，以及 "ge" 命令移动到前一个单词的末尾:

	This is a line with example text ~
	   <----<----x---->------------>
	   2ge   ge     e       2e

如果你在一行的最后一个单词上，"w" 命令会将你带到下一行的第一个单词。因此你可以
用它来在段落中移动，这比使用 "l" 快得多。"b" 在相反方向做同样的事情。

一个单词在非单词字符处结束，例如 "."、"-" 或 ")"。要更改 Vim 认为哪些是单词
字符，参见 'iskeyword' 选项。如果你直接在帮助中尝试这些，需要重置 'iskeyword'
才能使示例正常工作: >
	:set iskeyword&
也可以按空白分隔的字串 (WORD) 来移动。这不是通常意义上的单词，所以使用大写。
按字串移动的命令也是大写的，如下图所示:

	       ge      b	  w				e
	       <-     <-	 --->			       --->
	This is-a line, with special/separated/words (and some more). ~
	   <----- <-----	 -------------------->	       ----->
	     gE      B			 W			 E

结合小写和大写命令，你可以在段落中快速前后移动。

*03.2*	移动到行首或行尾

"$" 命令将光标移动到行尾。如果你的键盘有 <End> 键，它的作用相同。

"^" 命令移动到行的第一个非空白字符。"0" 命令（零）移动到行的第一个字符，
<Home> 键也做同样的事情。图示如下（"." 表示空格）:

		  ^
	     <-----------x
	.....This is a line with example text ~
	<----------------x   x-------------->
		0		   $

（这里 "....." 表示空格）

   "$" 命令接受计数，像大多数移动命令一样。但是多次移动到行尾没有意义。因此它
会使编辑器移动到另一行的行尾。例如，"1$" 移到第一行（你所在的行）的行尾，"2$"
移到下一行的行尾，依此类推。
   "0" 命令不接受计数参数，因为 "0" 本身会成为计数的一部分。出乎意料的是，对
"^" 使用计数没有任何效果。

*03.3*	移动到指定字符

最有用的移动命令之一是单字符搜索命令。命令 "fx" 在行内向前搜索单个字符 x。
提示: "f" 代表 "Find"（查找）。
   例如，你在下面一行的开头。假设你想移动到 human 的 h 上。只需执行命令 "fh"，
光标就会定位在 h 上:

	To err is human.  To really foul up you need a computer. ~
	---------->--------------->
	    fh		 fy

这也展示了命令 "fy" 移动到了 really 这个单词的末尾。
   你可以指定计数; 因此，你可以用 "3fl" 移动到 "foul" 的 "l" 上:

	To err is human.  To really foul up you need a computer. ~
		  --------------------->
			   3fl

"F" 命令向左搜索:

	To err is human.  To really foul up you need a computer. ~
		  <---------------------
			    Fh

"tx" 命令与 "fx" 命令类似，但它停在被搜索字符的前一个字符上。提示: "t" 代表
"To"（到）。这个命令的反向版本是 "Tx"。

	To err is human.  To really foul up you need a computer. ~
		   <------------  ------------->
			Th		tn

这四个命令可以用 ";" 重复。"," 反方向重复。光标永远不会移动到另一行。即使
句子是连续的也不行。

有时你会开始一个搜索，然后才意识到你输入了错误的命令。比如你输入 "f" 想向后
搜索，然后才意识到你其实想用 "F"。要中止搜索，按 <Esc>。所以 "f<Esc>" 是一个
中止的正向搜索，什么也不做。注意: <Esc> 取消大多数操作，不仅仅是搜索。

*03.4*	匹配括号

当编写程序时，你经常会遇到嵌套的 () 结构。此时 "%" 命令非常方便: 它移动到匹配
的括号上。如果光标在 "(" 上，它会移动到匹配的 ")"。如果在 ")" 上，它会移动到
匹配的 "("。

			    %
			 <----->
		if (a == (b * c) / d) ~
		   <---------------->
			    %

这对 [] 和 {} 对也同样有效。（可以通过 'matchpairs' 选项来定义。）

当光标不在有用的字符上时，"%" 会向前搜索以找到一个。因此如果光标在上一个示例
行的开头，"%" 会向前搜索并找到第一个 "("。然后移动到它的匹配:

		if (a == (b * c) / d) ~
		---+---------------->
			   %

其他在代码中移动的方式可以在 |usr_29.txt| 中找到。

*03.5*	移动到指定行

如果你是 C 或 C++ 程序员，你一定熟悉如下的错误信息:

	prog.c:33: j   undeclared (first use in this function) ~

这告诉你可能需要修复第 33 行的某些问题。那么如何找到第 33 行？一种方法是执行
"9999k" 回到文件顶部，然后 "32j" 向下走三十二行。这不是个好方法，但能用。一个
更好的方法是使用 "G" 命令。带上计数，这个命令将你定位到指定的行号。例如，"33G"
将你置于第 33 行。（要了解更好的遍历编译器错误列表的方法，参见 |usr_30.txt|，
关于 :make 命令的信息。）
   不带参数时，"G" 将你定位到文件末尾。快速跳到文件开头的方法是使用 "gg"。
"1G" 也能做同样的事，但多打了一点字。

	    |	first line of a file   ^
	    |	text text text text    |
	    |	text text text text    |  gg
	7G  |	text text text text    |
	    |	text text text text
	    |	text text text text
	    V	text text text text    |
		text text text text    |  G
		text text text text    |
		last line of a file    V

另一种移动到某行的方法是使用带计数的 "%" 命令。例如，"50%" 将你移到文件的一半
处，"90%" 到接近末尾。

前面假设你想移动到文件中的某一行，不管它当前是否可见。如果你想移动到屏幕上
可见的行呢？下图展示了你可以使用的三个命令:

			+---------------------------+
		H -->	| text sample text	    |
			| sample text		    |
			| text sample text	    |
			| sample text		    |
		M -->	| text sample text	    |
			| sample text		    |
			| text sample text	    |
			| sample text		    |
		L -->	| text sample text	    |
			+---------------------------+

提示: "H" 代表 Home（首行），"M" 代表 Middle（中间），"L" 代表 Last（末行）。
或者，"H" 代表 High（高），"M" 代表 Middle（中），"L" 代表 Low（低）。

*03.6*	确定当前位置

要查看你在文件中的位置，有三种方法:

1.  使用 CTRL-G 命令。你会看到这样的消息（假设 'ruler' 选项已关闭）:

	"usr_03.txt" line 233 of 650 --35%-- col 45-52 ~

    这显示了你正在编辑的文件名、光标所在的行号、总行数、文件中的百分比位置
    以及光标所在的列。
       有时你会看到分列的列号。例如，"col 2-9"。这表示光标位于第二个字符上，
    但因为第一个字符是制表符，占据了八个空格宽度的列，所以屏幕列是 9。

2.  设置 'number' 选项。这会在每一行前面显示行号: >

	:set number
<
    要再次关闭: >

	:set nonumber
<
    因为 'number' 是一个布尔选项，在名称前加 "no" 就可以关闭它。布尔选项
    只有这两个值，要么开要么关。
       Vim 有很多选项。除了布尔选项外，还有数值选项和字符串选项。在用到它们
    的地方你会看到示例。

3.  设置 'ruler' 选项。这会在 Vim 窗口的右下角显示光标位置: >

	:set ruler

使用 'ruler' 选项的好处是它不占用太多空间，因此有更多空间给你的文本。

*03.7*	滚动

CTRL-U 命令向下滚动半屏文本。想象一下通过一个窗口看文本，然后将这个窗口向上
移动半个窗口高度。这样窗口在文本上向上移动，即在文件中向后。如果你对哪个方向
是上有点困惑，不用担心。大多数用户都有同样的问题。
   CTRL-D 命令将视窗在文件中向下移动半屏，因此文本向上滚动半屏。

				       +----------------+
				       | some text	|
				       | some text	|
				       | some text	|
	+---------------+	       | some text	|
	| some text	|  CTRL-U  --> |		|
	|		|	       | 123456		|
	| 123456	|	       +----------------+
	| 7890		|
	|		|	       +----------------+
	| example	|  CTRL-D -->  | 7890		|
	+---------------+	       |		|
				       | example	|
				       | example	|
				       | example	|
				       | example	|
				       +----------------+

要一次滚动一行，使用 CTRL-E（向上滚动）和 CTRL-Y（向下滚动）。
可以把 CTRL-E 理解为多给你一行 (Extra)。（如果你使用 MS-Windows 兼容的键映射，
CTRL-Y 会重做修改而不是滚动。）

要向前滚动一整屏（保留两行重叠），使用 CTRL-F。向后滚动使用 CTRL-B。这些应该
很容易记住: F 代表 Forwards（前进），B 代表 Backwards（后退）。

一个常见的情况是在用 "j" 向下移动很多行后，你的光标处于屏幕底部。你想看到
光标所在行的上下文。可以用 "zz" 命令:

	+------------------+		 +------------------+
	| earlier text	   |		 | earlier text	    |
	| earlier text	   |		 | earlier text	    |
	| earlier text	   |		 | earlier text	    |
	| earlier text	   |   zz  -->	 | line with cursor |
	| earlier text	   |		 | later text	    |
	| earlier text	   |		 | later text	    |
	| line with cursor |		 | later text	    |
	+------------------+		 +------------------+

"zt" 命令将光标行放在顶部，"zb" 放在底部。还有一些其他的滚动命令，参见
|Q_sc|。要始终在光标周围保留几行上下文，使用 'scrolloff' 选项。

*03.8*	简单搜索

要搜索一个字符串，使用 "/string" 命令。例如，要查找 include 这个单词，使用
命令: >

	/include

你会注意到当你输入 "/" 时，光标会跳到 Vim 窗口的最后一行，就像冒号命令一样。
你在那里输入要搜索的单词。你可以按退格键（后退箭头或 <BS>）进行修正。必要时
使用 <Left> 和 <Right> 光标键。
   按 <Enter> 执行命令。

	注意:
	字符 `.*[]^%/\?~$` 有特殊含义。如果你想在搜索中使用它们，必须在前面
	加一个 \。参见下文。

要查找同一字符串的下一个出现，使用 "n" 命令。用这个来查找光标之后的第一个
#include: >

	/#include

然后多次输入 "n"。你会移动到文本中每一个 #include 的位置。如果你知道要找第
几个匹配，也可以使用计数。因此 "3n" 查找第三个匹配。你也可以对 "/" 使用计数:
"4/the" 跳到 "the" 的第四个匹配。

"?" 命令与 "/" 类似，但向后搜索: >

	?word

"N" 命令按相反方向重复上次搜索。因此在 "/" 命令之后使用 "N" 会向后搜索，在
"?" 之后使用 "N" 会向前搜索。


忽略大小写

通常你必须精确输入要查找的内容。如果你不关心单词的大小写，设置 'ignorecase'
选项: >

	:set ignorecase

如果你现在搜索 "word"，它也会匹配 "Word" 和 "WORD"。要重新区分大小写: >

	:set noignorecase


历史记录

假设你做了三次搜索: >

	/one
	/two
	/three

现在让我们输入一个简单的 "/"（不按 <Enter>）来开始搜索。如果你按 <Up>
（光标向上键），Vim 会在命令行上显示 "/three"。此时按 <Enter> 就搜索 three。
如果你不按 <Enter>，而是按 <Up>，Vim 会将提示改为 "/two"。再按一次 <Up> 就
到 "/one"。
   你也可以使用 <Down> 光标键在搜索命令的历史记录中反向移动。

如果你知道之前用过的模式以什么开头，并且想重新使用它，在按 <Up> 之前先输入
那个字符。以前面的例子为例，你可以输入 "/o<Up>"，Vim 会在命令行上显示
"/one"。

以 ":" 开头的命令也有自己的历史记录。它允许你调出以前的命令并重新执行。这两个
历史记录是分开的。


搜索文本中的单词

假设你在文本中看到了 "TheLongFunctionName" 这个单词，你想找到它的下一次出现。
你可以输入 "/TheLongFunctionName"，但那要打很多字。而且如果打错了 Vim 就找
不到它。
   有一个更简单的方法: 将光标定位在该单词上，然后使用 "*" 命令。Vim 会抓取
光标下的单词并将其作为搜索字符串。
   "#" 命令在相反方向做同样的事。你可以加计数: "3*" 搜索光标下单词的第三次
出现。


搜索完整单词

如果你输入 "/the"，它也会匹配 "there"。要只查找以 "the" 结尾的单词，使用: >

	/the\>

"\>" 项是一个特殊标记，只在单词末尾匹配。类似地，"\<" 只在单词开头匹配。因此
要只搜索完整的单词 "the": >

	/\<the\>

这不会匹配 "there" 或 "soothe"。注意 "*" 和 "#" 命令使用这些词首和词尾标记
来只查找完整的单词（你可以使用 "g*" 和 "g#" 来匹配部分单词）。


高亮匹配

当你编辑程序时看到一个叫 "nr" 的变量。你想查看它在哪里被使用。你可以将光标移到
"nr" 上，使用 "*" 命令，然后按 "n" 逐个访问所有匹配。

Vim 会高亮显示所有匹配。这是一个很好的方式来查看变量在哪里被使用，而不需要
输入命令。
   要关闭高亮: >

	:set nohlsearch

然后当你想在下一次搜索中使用高亮时需要重新打开: >

	:set hlsearch

如果你只想移除当前的高亮，使用这个命令: >

	:nohlsearch

这不会重置选项。相反，它只是禁用高亮。一旦你执行搜索命令，高亮会再次生效。
"n" 和 "N" 命令也会重新激活高亮。


调整搜索

有一些选项可以改变搜索的工作方式。以下是基本的:
>
	:set nowrapscan

这会在文件末尾停止搜索。或者，当你向后搜索时，在文件开头停止搜索。'wrapscan'
选项默认是开启的，因此搜索会在文件末尾处回绕。
>
	:set noincsearch

这会禁用在你输入搜索时就显示匹配的功能。


插曲

如果你喜欢前面提到的某个选项，并且每次使用 Vim 时都设置它，你可以将命令写入你
的 Vim 启动文件中。编辑该文件，例如: >

	:edit ~/.config/nvim/init.vim

然后添加一行设置选项的命令，就像你在 Vim 中输入的那样。例如: >

	Go:set hlsearch<Esc>

"G" 移到文件末尾。"o" 开始一个新行，你在那里输入 ":set" 命令。你用 <Esc> 结束
插入模式。然后保存并关闭文件: >

	ZZ

如果你现在重新启动 Vim，'hlsearch' 选项就已经设置好了。

*03.9*	简单搜索模式

Vim 编辑器使用正则表达式来指定要搜索的内容。正则表达式是一种极其强大和紧凑的
方式来指定搜索模式。不幸的是，这种强大也有代价，因为正则表达式的编写有点
棘手。
   在本节中我们只提到一些基本的。关于搜索模式和命令的更多内容可以在第 27 章
|usr_27.txt| 中找到。完整的解释在这里: |pattern|。


行首和行尾

^ 字符匹配行的开头。在英语 US 键盘上你可以在 6 的上方找到它。模式 "include"
匹配行中任何位置的 include 这个词。但模式 "^include" 只匹配位于行首的
include。
   $ 字符匹配行的末尾。因此，"was$" 只匹配位于行尾的 was。

让我们用 "x" 来标记 "/the" 在这个示例行中匹配的位置:

	the solder holding one of the chips melted and the ~
	xxx			  xxx		       xxx

使用 "/the$" 我们找到这个匹配:

	the solder holding one of the chips melted and the ~
						       xxx

使用 "/^the" 我们找到这个:
	the solder holding one of the chips melted and the ~
	xxx

你可以尝试搜索 "/^the$"; 它只会匹配仅由 "the" 组成的单独一行。这里空白是有
影响的，因此如果一行在该词后面包含一个空格，如 "the "，模式将不会匹配。


匹配任意单个字符

.（点）字符匹配任何现有字符。例如，模式 "c.m" 匹配第一个字符是 c、第二个字符
是任意字符、第三个字符是 m 的字符串。例如:

	We use a computer that became the cummin winter. ~
		 xxx		 xxx	  xxx


匹配特殊字符

如果你确实想匹配一个点号，你必须在前面加一个反斜杠来消除它的特殊含义。
   如果你搜索 "ter."，你会找到这些匹配:

	We use a computer that became the cummin winter. ~
		      xxxx			    xxxx

搜索 "ter\." 只会找到第二个匹配。

*03.10*	使用标记

当你用 "G" 命令跳转到某个位置时，Vim 会记住跳转前的位置。这个位置称为标记。
要回到你来的地方，使用这个命令: >

	``

这个 ` 是反引号字符。
   如果你再次使用相同的命令，你会跳回去。这是因为 "`" 命令本身就是一个跳转，
跳转前的位置也会被记住。

一般来说，每次你执行一个可以将光标移动到同一行之外的命令时，这就叫做跳转。
这包括搜索命令 "/" 和 "n"（不管匹配有多远）。但不包括字符搜索 "fx" 和 "tx"
或者单词移动 "w" 和 "e"。
   另外，"j" 和 "k" 不被视为跳转，即使你使用计数让它们移动光标很远。

"``" 命令在两个点之间来回跳转。CTRL-O 命令跳转到更早的位置（提示: O 代表
older，更旧）。CTRL-I 则跳回到更新的位置（提示: 在大多数常见键盘布局中，
I 就在 O 旁边）。考虑这个命令序列: >

	33G
	/^The
	CTRL-O

你首先跳到第 33 行，然后搜索以 "The" 开头的行。然后用 CTRL-O 跳回第 33 行。
再一次 CTRL-O 带你回到起始位置。如果你现在使用 CTRL-I，你又跳到第 33 行。
再来一次 CTRL-I 到 "The" 的匹配处。


	     |	example text   ^	     |
	33G  |	example text   |  CTRL-O     | CTRL-I
	     |	example text   |	     |
	     V	line 33 text   ^	     V
	     |	example text   |	     |
       /^The |	example text   |  CTRL-O     | CTRL-I
	     V	There you are  |	     V
		example text

	注意:
	CTRL-I 与 <Tab> 相同。

":jumps" 命令给出你跳转过的位置列表。你最后使用的条目用 ">" 标记。


命名标记							*bookmark*

Vim 允许你在文本中放置自己的标记。命令 "ma" 将光标所在位置标记为标记 a。你
可以在文本中放置 26 个标记（a 到 z）。你看不到它们，这只是 Vim 记住的位置。
   要跳到一个标记，使用命令 `{mark}，其中 {mark} 是标记字母。因此要移动到
标记 a:
>
	`a

命令 "'mark"（单引号或撇号）将你移到包含标记的行的行首。这与 "`mark" 命令
不同，后者也会移到标记所在的列。

标记在处理文件中两个相关部分时非常有用。假设你有一些文本在文件开头附近需要
查看，同时你在文件末尾附近工作。
   移到开头的文本，放置 s（start，起始）标记: >

	ms

然后移到你要工作的文本，放置 e（end，结束）标记: >

	me

现在你可以到处移动，当你想查看文件开头时，用这个命令跳过去: >

	's

然后你可以用 '' 跳回原来的位置，或者用 'e 跳到你在末尾工作的文本。
   用 s 代表 start 和 e 代表 end 没有什么特别的，它们只是容易记。

你可以用这个命令获得标记列表: >

	:marks

你会注意到一些特殊标记。包括:

	'	做跳转之前的光标位置
	"	最后编辑文件时的光标位置
	[	最后修改的开始处
	]	最后修改的结束处
