光标移动					*cursor-motions* *navigation*

这些命令移动光标位置。如果新位置在屏幕之外，屏幕会滚动以显示光标（另参见
'scrolljump' 和 'scrolloff' 选项）。

一般说明：

如果你想知道自己在文件中的位置，使用 "CTRL-G" 命令 |CTRL-G| 或 "g CTRL-G"
命令 |g_CTRL-G|。如果设置了 'ruler' 选项，光标位置会持续显示在状态行中
（这会使 Vim 稍微变慢）。

有经验的用户更喜欢 hjkl 键，因为它们就在手指下面。初学者通常更喜欢方向键，
因为他们不知道 hjkl 键的作用。从键盘上看 hjkl 的助记意义很明显。把 j 想象
成一个指向下方的箭头。

'virtualedit' 选项可设为使光标能移到没有字符或多列字符（如 tab）内部的位置。

                                      输入 |gO| 查看目录。

==============================================================================
1. 移动和操作符				*operator*

移动命令可在操作符命令之后使用，让命令对移动经过的文本进行操作。即光标位置
移动前后之间的文本。操作符通常用于删除或更改文本。以下操作符可用：

	|c|	c	更改
	|d|	d	删除
	|y|	y	复制到寄存器（不改变文本）
	|~|	~	切换大小写（仅当 'tildeop' 设置时）
	|g~|	g~	切换大小写
	|gu|	gu	转为小写
	|gU|	gU	转为大写
	|!|	!	通过外部程序过滤
	|=|	=	通过 'equalprg' 过滤或 C 缩进（如果为空）
	|gq|	gq	文本格式化
	|gw|	gw	文本格式化（不移动光标）
	|g?|	g?	ROT13 编码
	|>|	>	右移
	|<|	<	左移
	|zf|	zf	定义折叠
	|g@|	g@	调用 'operatorfunc' 选项设置的函数
						*motion-count-multiplied*
如果移动包含计数且操作符前也有计数，两个计数相乘。例如："2d3w" 删除六个单词。
						*operator-doubled*
双写操作符时对一行操作。使用计数时对那么多行操作。因此 `3dd` 删除三行。
						*operator-resulting-pos*
应用操作符后光标大多留在被操作文本的起始处。

						*linewise* *charwise* *characterwise*
操作符要么影响整行，要么影响起始和结束位置之间的字符。通常在行间移动的
移动影响行（按行的），在行内移动的影响字符（按字符的）。但有些例外。

						*exclusive* *inclusive*
字符移动要么是包含的要么是排除的。包含时起始和结束位置都包含在操作中。
排除时靠近缓冲区末尾的最后一个字符不包含。按行的移动始终包含起始和结束位置。

命令中会提到哪些移动是按行的、包含的或排除的。有两个一般例外：
1. 如果移动是排除的且移动结束在第 1 列，移动结束移到上一行末尾且移动变为
   包含的。
						*exclusive-linewise*
2. 如果移动是排除的，结束在第 1 列，且起始在行的第一个非空白处或之前，
   移动变为按行的。

注意当操作符待定时，可以使用一组特殊的映射。参见 |:omap|。

你可以使用可视模式代替先给操作符再给移动。参见 |Visual-mode|。

你可以用 ":" 命令作为移动。例如 "d:call FindEnd()"。

					*inclusive-motion-selection-exclusive*
当 'selection' 为 "exclusive"，|Visual| 模式激活且使用了包含移动时，
光标位置会向右再调一个字符。

								*forced-motion*
强制移动为按行、按字符或按块

当移动不是你想要的类型时，可以在操作符之后用 "v"、"V" 或 CTRL-V 强制另一种
类型。

							*o_v*
v		在操作符之后使用时：强制操作符按字符工作。

							*o_V*
V		在操作符之后使用时：强制操作符按行工作。

							*o_CTRL-V*
CTRL-V		在操作符之后使用时：强制操作符按块工作。

4. 单词移动					*word-motions*

<S-Right>	或					*<S-Right>* *w*
w			向前 [count] 个单词。|exclusive| 移动。

<C-Right>	或					*<C-Right>* *W*
W			向前 [count] 个字串。|exclusive| 移动。

							*e*
e			向前到第 [count] 个单词末尾 |inclusive|。

							*E*
E			向前到第 [count] 个字串末尾 |inclusive|。

<S-Left>	或					*<S-Left>* *b*
b			向后 [count] 个单词。|exclusive| 移动。

<C-Left>	或					*<C-Left>* *B*
B			向后 [count] 个字串。|exclusive| 移动。

							*ge*
ge			向后到第 [count] 个单词末尾 |inclusive|。

							*gE*
gE			向后到第 [count] 个字串末尾 |inclusive|。

这些命令在单词或字串上移动。
							*word*
单词由字母、数字和下划线序列，或其他非空白字符序列组成，以空白分隔。
可通过 'iskeyword' 选项更改。空行也被视为一个单词。
							*WORD*
字串由非空白字符序列组成，以空白分隔。空行也被视为一个字串。

特殊情况："cw" 和 "cW" 当光标在非空白上时被当作 "ce" 和 "cE" 处理。

5. 文本对象移动				*object-motions*

							*(*
(			向后 [count] 个 |sentence|。|exclusive| 移动。

							*)*
)			向前 [count] 个 |sentence|。|exclusive| 移动。

							*{*
{			向后 [count] 个 |paragraph|。|exclusive| 移动。

							*}*
}			向前 [count] 个 |paragraph|。|exclusive| 移动。

							*]]*
]]			向前 [count] 个 |section| 或到第一列的下一个 "{"。

							*][*
][			向前 [count] 个 |section| 或到第一列的下一个 '}'。

							*[[*
[[			向后 [count] 个 |section| 或到第一列的上一个 "{"。

							*[]*
[]			向后 [count] 个 |section| 或到第一列的上一个 "}"。

这些命令在三种文本对象上移动。

							*sentence*
句子定义为以 '.'、'!' 或 '?' 结尾，后跟行尾、空格或制表符。

							*paragraph*
段落在每个空行之后开始，也在 'paragraphs' 选项指定的段落宏处开始。
注意空白行（只含空白）不是段落边界。

							*section*
节在第一列的换页符 (<C-L>) 之后开始，以及在 'sections' 选项指定的节宏处开始。

7. 标记					*mark-motions* *E20* *E78*

跳转到标记有两种方式：
1. 用 `（反引号）：光标定位在指定位置，移动是 |exclusive|。
2. 用 '（单引号）：光标定位在行的第一个非空白字符上，移动是按行的。
						*mark-view*
3. 如果 'jumpoptions' 包含 "view"，还会尝试恢复标记视图。

						*m* *mark* *Mark*
m{a-zA-Z}		在光标位置设置标记 {a-zA-Z}。

						*m'* *m`*
m'  或  m`		设置上一个上下文标记。

						*m[* *m]*
m[  或  m]		设置 |'[| 或 |']| 标记。

						*m<* *m>*
m<  或  m>		设置 |'<| 或 |'>| 标记。

						*:ma* *:mark* *E191*
:[range]ma[rk] {a-zA-Z'}
			在 [range] 最后一个行号处设置标记，列 0。

						*:k*
:[range]k{a-zA-Z'}	与 :mark 相同。

						*'* *'a* *`* *`a*
'{a-z}  `{a-z}		跳到当前缓冲区中的标记 {a-z}。

						*'A* *'0* *`A* *`0*
'{A-Z0-9}  `{A-Z0-9}	跳到标记 {A-Z0-9} 所在的文件中。

						*g'* *g'a* *g`* *g`a*
g'{mark}  g`{mark}
			跳到 {mark}，但在当前缓冲区内跳转时不改变跳转列表。

						*:marks*
:marks			列出所有当前标记。

						*:delm* *:delmarks*
:delm[arks] {marks}	删除指定标记。

:delm[arks]!		删除当前缓冲区的所有标记（A-Z 和 0-9 除外）。

标记不以任何方式可见。它只是文件中记住的一个位置。不要将标记与命名寄存器
混淆，它们完全无关。

'a - 'z		小写标记，在一个文件内有效
'A - 'Z		大写标记（也称文件标记），在文件间有效
'0 - '9		编号标记，从 |shada| 文件设置

特殊标记：

							*'[* *`[*
'[  `[			到之前更改或复制文本的第一个字符。

							*']* *`]*
']  `]			到之前更改或复制文本的最后一个字符。

							*'<* *`<*
'<  `<			到上次可视区域的第一行或字符。

							*'>* *`>*
'>  `>			到上次可视区域的最后一行或字符。

							*''* *``*
''  ``			到最近跳转前的位置。

							*'quote* *`quote*
'"  `"			到上次退出当前缓冲区时的光标位置。

							*'^* *`^*
'^  `^			到上次停止插入模式时的光标位置。

							*'.* *`.*
'.  `.			到上次更改的位置。

							*':* *`:*
':			在提示缓冲区中，当前用户输入的开始。

							*'(* *`(*
'(  `(			到当前句子的开头。

							*')* *`)*
')  `)			到当前句子的结尾。

							*'{* *`{*
'{  `{			到当前段落的开头。

							*'}* *`}*
'}  `}			到当前段落的结尾。

							*]'*
]'			到下一个有小写标记的行。

							*]`*
]`			到光标后的下一个小写标记。

							*['*
['			到上一个有小写标记的行。

							*[`*
[`			到光标前的上一个小写标记。


:loc[kmarks] {command}				*:loc* *:lock* *:lockmarks*
			执行 {command} 但不调整标记。

:kee[pmarks] {command}				*:kee* *:keep* *:keepmarks*
			当前仅对过滤命令 |:range!| 有效。

							*:keepj* *:keepjumps*
:keepj[umps] {command}
			{command} 中的移动不改变 |''|、|'.| 和 |'^| 标记、
			|jumplist| 或 |changelist|。

"跳转"是通常将光标移动几行的命令。跳转前的位置会被记住。

							*CTRL-O*

							*:ju* *:jumps*

							*:cle* *:clearjumps*

							*jumplist*

9. 各种移动				*various-motions*

							*%*
%			查找此行中光标处或光标后的下一个项目并跳到其匹配。
			|inclusive| 移动。项目可以是：
			([{}])		括号或（花/方）括号
			`/* */`		C 风格注释的开始或结束
			#if, #ifdef, #else, #elif, #endif
					C 预处理器条件

						*[(*
[(			跳到第 [count] 个之前未匹配的 '('。|exclusive| 移动。

						*[{*
[{			跳到第 [count] 个之前未匹配的 '{'。|exclusive| 移动。

						*])*
])			跳到第 [count] 个之后未匹配的 ')'。|exclusive| 移动。

						*]}*
]}			跳到第 [count] 个之后未匹配的 '}'。|exclusive| 移动。

						*]m*
]m			跳到第 [count] 个方法的下一个开始处。|exclusive| 移动。
						*]M*
]M			跳到第 [count] 个方法的下一个结束处。|exclusive| 移动。
						*[m*
[m			跳到第 [count] 个方法的上一个开始处。|exclusive| 移动。
						*[M*
[M			跳到第 [count] 个方法的上一个结束处。|exclusive| 移动。

						*[#*
[#			跳到第 [count] 个之前未匹配的 "#if" 或 "#else"。

						*]#*
]#			跳到第 [count] 个之后未匹配的 "#else" 或 "#endif"。

						*[star* *[/*
[*  或  [/		跳到第 [count] 个之前的 C 注释 "/*" 开始处。

						*]star* *]/*
]*  或  ]/		跳到第 [count] 个之后的 C 注释 "*/" 结束处。


						*H*
H			到窗口顶部第 [count] 行（Home），在第一个非空白字符
			上 |linewise|。另参见 'startofline' 选项。

						*M*
M			到窗口中间行，在第一个非空白字符上 |linewise|。

						*L*
L			到窗口底部第 [count] 行（Last），在第一个非空白字符
			上 |linewise|。另参见 'startofline' 选项。

<LeftMouse>		移到屏幕上鼠标点击的位置 |exclusive|。另参见 |<LeftMouse>|。
