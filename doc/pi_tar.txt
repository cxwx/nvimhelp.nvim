2. 用法					*tar-usage* *tar-manual*

   当编辑 `*.tar` 文件时，此插件会处理显示内容页面。将光标移到所需的文件上，
   然后按 <return> 键来选择要编辑的文件。编辑后，也可以写入文件。目前，不能
   通过插件在 tar 归档中创建新文件。

						*:TarDiff*
   差异比较支持~

   :TarDiff [filename]

	此命令会尝试显示 tar 包中文件版本与系统上关联文件之间的差异。为了
	在系统上找到该文件，脚本使用 tar 包中提及的文件的路径。如果当前目录
	对于该路径不正确，:TarDiff 将无法找到关联的文件。

	如果给出了 [filename]，将使用该文件名 (和路径) 来指定关联的文件。


   阻止加载~

   如果由于某种原因你不希望使用 vim 来检查 tar 文件，可以在 <.vimrc> 中
   设置以下两个变量来阻止 tar 插件加载: >

	let g:loaded_tarPlugin= 1
	let g:loaded_tar      = 1
<
							*tar-mappings*
   映射~

   以下 (缓冲区局部) 映射在 tar 缓冲区中可用:

	<CR>		打开选定的文件进行编辑，任何更改将被写回归档。
	<LeftMouse>	与 <CR> 相同
	x		提取选定的文件。

==============================================================================
3. 选项						*tar-options*

   这些选项是变量，通常在 <.vimrc> 文件中更改。
			 默认值
   变量			  值      说明
   *g:tar_browseoptions*    "Ptf"   用于获取内容列表
   *g:tar_readoptions*	  "OPxf"  用于从 tar 包中提取文件
   *g:tar_cmd*		  "tar"   tar 程序的名称
   *g:tar_nomax*	    0	  如果为真，文件窗口不会被最大化
   *g:tar_writeoptions*	  "uf"    用于更新/替换文件
