命令							*python-commands*

					*:python* *:py* *E263* *E264* *E887*
:[range]py[thon] {stmt}
			执行 Python 语句 {stmt}。检测 `:python` 命令
			是否正常工作的简单方法: >vim
				:python print("Hello")

:[range]py[thon] << [trim] [{endmarker}]
{script}
{endmarker}
			执行 Python 脚本 {script}。适用于在 Vim 脚本
			中包含 python 代码。需要 Python，参阅
			|script-here|。

如果 "<<" 后面省略了 [endmarker]，则必须在 {script} 后面使用点号
'.'，与 |:append| 和 |:insert| 命令一样。参阅 |:let-heredoc| 获取
更多信息。

示例: >vim
	function! IcecreamInitialize()
	python << EOF
	class StrawberryIcecream:
		def __call__(self):
			print('EAT ME')
	EOF
	endfunction

查看你使用的 Python 版本: >vim
	:python print(sys.version)

不需要 "import sys"，这已经默认完成了。

							*python-environment*
在 Vim 中设置的环境变量不一定在 Python 中可用。这取决于 Vim 和
Python 的编译方式。另见
https://docs.python.org/3/library/os.html#os.environ

注意: Python 对缩进非常敏感。确保 "class" 行和 "EOF" 没有任何
缩进。

							*:pydo*
:[range]pydo {body}	对 [range] 内的每一行执行 Python 函数
			"def _vim_pydo(line, linenr): {body}"，其中
			函数参数分别设为每行的文本（不含尾部的
			<EOL>）和当前行号。函数应返回一个字符串或
			None。如果返回字符串，它将成为当前轮次中
			该行的文本。[range] 的默认值是整个文件:
			"1,$"。

示例:
>vim
	:pydo return "%s\t%d" % (line[::-1], len(line))
	:pydo if line: return "%4d: %s" % (linenr, line)
<
可以将 `:pydo` 与 `:py` 配合使用，通过 python 过滤某个范围。
例如: >vim

	:py3 << EOF
	needle = vim.eval('@a')
	replacement = vim.eval('@b')

	def py_vim_string_replace(str):
		return str.replace(needle, replacement)
	EOF
	:'<,'>py3do return py_vim_string_replace(line)
<
							*:pyfile* *:pyf*
:[range]pyf[ile] {file}
			执行 {file} 中的 Python 脚本。整个参数被用
			作单个文件名。

这两个命令本质上做同样的事情——执行一段 Python 代码，并将"当前范围"
|python-range| 设为给定的行范围。

对于 :python，要执行的代码在命令行中。
对于 :pyfile，要执行的代码是给定文件的内容。

Python 命令不能在 |sandbox| 中使用。

要传递参数，需要显式设置 sys.argv[]。示例: >vim

	:python sys.argv = ["foo", "bar"]
	:pyfile myscript.py

这里有一些示例						*python-examples*
>vim
	:python from vim import *
	:python current.line = str.upper(current.line)
	:python print("Hello")
	:python str = current.buffer[42]

注意更改（如 "import" 语句）会从一个命令持续到下一个命令，
就像 Python REPL 一样。

							*script-here*
当使用内联脚本语言时，你可能想要在该语言不受支持时跳过它。
>vim
   if has('python')
     python << EOF
       print("python works")
   EOF
   endif
<
注意 "EOF" 必须在行首，前面不能有空白字符。

vim 模块						*python-vim*

Python 代码通过 "vim" 模块访问 vim 的所有功能（有一个例外——参阅
下面的 |python-output|）。vim 模块实现了两个方法、三个常量和一个
错误对象。你需要先导入 vim 模块才能使用它: >vim
	:python import vim

概览 >vim
	:py print("Hello")		# 显示一条消息
	:py vim.command(cmd)		# 执行一个 Ex 命令
	:py w = vim.windows[n]		# 获取窗口 "n"
	:py cw = vim.current.window	# 获取当前窗口
	:py b = vim.buffers[n]		# 获取缓冲区 "n"
	:py cb = vim.current.buffer	# 获取当前缓冲区
	:py w.height = lines		# 设置窗口高度
	:py w.cursor = (row, col)	# 设置窗口光标位置
	:py pos = w.cursor		# 获取 (row, col) 元组
	:py name = b.name		# 获取缓冲区文件名
	:py line = b[n]			# 从缓冲区获取一行
	:py lines = b[n:m]		# 获取行列表
	:py num = len(b)		# 获取行数
	:py b[n] = str			# 设置缓冲区中的一行
	:py b[n:m] = [str1, str2, str3]	# 一次设置多行
	:py del b[n]			# 删除一行
	:py del b[n:m]			# 删除多行


"vim" 模块的方法

vim.command(str)					*python-command*
	执行 vim (ex 模式) 命令 str。返回 None。
	示例: >vim
	    :py vim.command("set tw=72")
	    :py vim.command("%s/aaa/bbb/g")
<	以下定义执行 Normal 模式命令: >python
		def normal(str):
			vim.command("normal "+str)
		# 注意使用单引号来分隔包含双引号的字符串
		normal('"a2dd"aP')

vim.eval(str)						*python-eval*
	使用 vim 内部表达式求值器对表达式 str 求值
	（参阅 |expression|）。以下列形式返回表达式结果:
	- 如果 Vim 表达式求值为字符串或数字，返回字符串
	- 如果 Vim 表达式求值为 Vim |list|，返回列表
	- 如果 Vim 表达式求值为 Vim |dict|，返回字典
	- 如果 Vim 表达式求值为 |v:true| 或 |v:false|，返回布尔值
	- 如果 Vim 表达式求值为 |v:null|，返回 `None`
	字典和列表会被递归展开。
	示例: >vim
	    :py text_width = vim.eval("&tw")
	    :py str = vim.eval("12+12")		# 注意结果是字符串！使用
						# int() 来转换为数字。

vim.strwidth(str)					*python-strwidth*
	类似 |strwidth()|: 返回 str 占用的显示单元格数，制表符算作
	一个单元格。

vim.foreach_rtp(callable)				*python-foreach_rtp*
	对 'runtimepath' 中的每个路径调用给定的 callable，直到
	callable 返回 None 以外的值、抛出异常或没有更多路径为止。
	如果因为 callable 返回了非 None 值而停止，vim.foreach_rtp
	函数返回 callable 返回的值。

`vim.chdir(*args, **kwargs)`				*python-chdir*
`vim.fchdir(*args, **kwargs)`				*python-fchdir*
	运行 os.chdir 或 os.fchdir，然后执行所有适当的 vim 操作。
	注意: 你不应该直接使用这些函数，而应使用 os.chdir 和
	      os.fchdir。如果 os.fchdir 不存在，vim.fchdir 的行为
	      未定义。

vim.current						*python-current*
	一个对象，通过特定属性提供对 vim 中各种"当前"对象的访问:
		vim.current.line	当前行 (RW)		String

	    try:
	        vim.current.buffer = vim.buffers[2] # 切换到缓冲区 2
	    finally:
	        vim.options['eventignore'] = saved_eventignore
	    EOF

Python 'runtimepath' 处理				*python-special-path*

在 python 中，vim.VIM_SPECIAL_PATH 特殊目录被用作 'runtimepath' 中
路径列表的替代: 当 sys.path 中包含此目录且 sys.path_hooks 中包含
vim.path_hooks 时，python 会尝试从 'runtimepath' 中每个 {rtp} 的
{rtp}/python3 和 {rtp}/pythonx 目录加载模块。

实现类似于以下代码: >python

    from imp import find_module, load_module
    import vim
    import sys

    class VimModuleLoader(object):
        def __init__(self, module):
            self.module = module

        def load_module(self, fullname, path=None):
            return self.module

    def _find_module(fullname, oldtail, path):
        idx = oldtail.find('.')
        if idx > 0:
            name = oldtail[:idx]
            tail = oldtail[idx+1:]
            fmr = find_module(name, path)
            module = load_module(fullname[:-len(oldtail)] + name, *fmr)
            return _find_module(fullname, tail, module.__path__)
        else:
            fmr = find_module(fullname, path)
            return load_module(fullname, *fmr)

    # 它使用 vim 模块本身代替 VimPathFinder 类: 对于 python 来说
    # 哪个对象附加了 find_module 函数作为属性并不重要。
    class VimPathFinder(object):
        @classmethod
        def find_module(cls, fullname, path=None):
            try:
                return VimModuleLoader(_find_module(fullname, fullname, path or vim._get_paths()))
            except ImportError:
                return None

        @classmethod
        def load_module(cls, fullname, path=None):
            return _find_module(fullname, fullname, path or vim._get_paths())

    def hook(path):
        if path == vim.VIM_SPECIAL_PATH:
            return VimPathFinder
        else:
            raise ImportError

    sys.path_hooks.append(hook)

vim.VIM_SPECIAL_PATH				*python-VIM_SPECIAL_PATH*
	与 vim 路径钩子配合使用的字符串常量。如果 vim 安装的路径钩子
	被要求处理不等于 vim.VIM_SPECIAL_PATH 常量的路径，它会抛出
	ImportError。在唯一的另一种情况下，它使用特殊加载器。

	注意: 你不能直接使用此常量的值，始终使用
	      vim.VIM_SPECIAL_PATH 对象。

vim.find_module(...)					*python-find_module*
vim.path_hook(path)					*python-path_hook*
	用于实现上述路径加载的方法或对象。除了在需要对 sys.meta_path
	进行操作的情况下使用 vim.path_hook 外，你不应该直接使用这些。
	不保证这些对象在未来的 vim 版本中仍然存在。

vim._get_paths						*python-_get_paths*
	返回路径钩子将搜索的路径列表的方法。你不应该依赖此方法在
	未来版本中存在，但可以用它进行调试。

	它返回 'runtimepath' 中每个 {rtp} 的 {rtp}/python3 和
	{rtp}/pythonx 目录列表。

Buffer 对象						*python-buffer*

Buffer 对象代表 vim 缓冲区。你可以通过多种方式获取它们:
	- 通过 vim.current.buffer (|python-current|)
	- 通过 vim.buffers 的索引 (|python-buffers|)
	- 通过窗口的 "buffer" 属性 (|python-window|)

Buffer 对象有两个只读属性 - name（缓冲区的完整文件名）和
number（缓冲区编号）。它们还有三个方法（append、mark 和 range;
见下文）。

你也可以将 buffer 对象当作序列对象来处理。在这种情况下，它们就像
字符串列表（是的，它们是可变的），每个元素是缓冲区的一行。所有
常见的序列操作，包括索引、索引赋值、切片和切片赋值，都按预期工作。
注意，索引（切片）缓冲区的结果是一个字符串（字符串列表）。这有一个
不寻常的结果——b[:] 与 b 不同。特别是，"b[:] = None" 会删除整个
缓冲区，而 "b = None" 只是更新变量 b，对缓冲区没有影响。

Buffer 索引从零开始，这是 Python 的正常做法。这与从 1 开始的 vim
行号不同。在处理标记（见下文）时尤其需要注意，因为标记使用 vim
行号。

buffer 对象的属性:
	b.vars		类字典对象，用于访问 |buffer-variable|。
	b.options	映射对象（支持获取、设置和删除项），提供对
			缓冲区局部选项和 |global-local| 选项的缓冲区
			局部值的访问。如果选项是窗口局部的，请使用
			|python-window|.options，此对象会抛出
			KeyError。如果选项是 |global-local| 且缺少
			局部值，获取它将返回 None。
	b.name		字符串，RW。包含缓冲区名称（完整路径）。
			注意: 赋值给 b.name 会触发 |BufFilePre| 和
			|BufFilePost| 自动命令。
	b.number	缓冲区编号。可用作 |python-buffers| 的键。
			只读。
	b.valid		True 或 False。当对应的缓冲区被清除后，
			Buffer 对象变为无效。

buffer 对象的方法:
	b.append(str)	向缓冲区追加一行
	b.append(str, nr)  同上，在第 "nr" 行之后
	b.append(list)	向缓冲区追加一组行
			注意，向 append 方法提供字符串列表的方式
			与 Python 内置 list 对象的对应方法不同。
	b.append(list, nr)  同上，在第 "nr" 行之后
	b.mark(name)	返回一个 (row,col) 元组，表示命名标记的位置
			（也可以获取 []"<> 标记）
	b.range(s,e)	返回一个范围对象（参阅 |python-range|），表示
			给定缓冲区中行号 s 和 e 之间的部分（|inclusive|）。

注意，添加一行时不能包含换行符 '\n'。允许尾部的 '\n' 并会被忽略，
因此你可以这样做: >vim
	:py b.append(f.readlines())

Buffer 对象类型可通过 vim 模块的 "Buffer" 属性获取。

示例（假设 b 是当前缓冲区） >vim
	:py print(b.name)		# 输出缓冲区文件名
	:py b[0] = "hello!!!"		# 替换第一行
	:py b[:] = None			# 删除整个缓冲区
	:py del b[:]			# 删除整个缓冲区
	:py b[0:0] = [ "a line" ]	# 在顶部添加一行
	:py del b[2]			# 删除一行（第三行）
	:py b.append("bottom")		# 在底部添加一行
	:py n = len(b)			# 行数
	:py (row,col) = b.mark('a')	# 命名标记
	:py r = b.range(1,5)		# 缓冲区的一个子范围
	:py b.vars["foo"] = "bar"	# 赋值 b:foo 变量
	:py b.options["ff"] = "dos"	# 设置 fileformat
	:py del b.options["ar"]		# 同 :set autoread<

Range 对象						*python-range*

Range 对象代表 vim 缓冲区的一部分。你可以通过多种方式获取它们:
	- 通过 vim.current.range (|python-current|)
	- 通过缓冲区的 range() 方法 (|python-buffer|)

Range 对象在操作上几乎与 buffer 对象相同。但是，所有操作都限制在
范围内的行（当然，由于切片赋值、行删除或 range.append() 方法，
此行范围可能会改变）。

range 对象的属性:
	r.start		缓冲区中第一行的索引
	r.end		缓冲区中最后一行的索引

range 对象的方法:
	r.append(str)	向范围追加一行
	r.append(str, nr)  同上，在第 "nr" 行之后
	r.append(list)	向范围追加一组行
			注意，向 append 方法提供字符串列表的方式
			与 Python 内置 list 对象的对应方法不同。
	r.append(list, nr)  同上，在第 "nr" 行之后

Range 对象类型可通过 vim 模块的 "Range" 属性获取。

示例（假设 r 是当前范围）:
	# 将范围内的所有行发送到默认打印机
	vim.command("%d,%dhardcopy!" % (r.start+1,r.end+1))

Window 对象						*python-window*

Window 对象代表 vim 窗口。你可以通过多种方式获取它们:
	- 通过 vim.current.window (|python-current|)
	- 通过 vim.windows 的索引 (|python-windows|)
	- 通过标签页的 "windows" 属性的索引 (|python-tabpage|)
	- 通过标签页的 "window" 属性 (|python-tabpage|)

你只能通过窗口对象的属性来操作它们。它们没有方法，也没有序列或
其他接口。

Window 的属性:
	buffer (只读)		此窗口中显示的缓冲区
	cursor (读写)		窗口中的当前光标位置
				这是一个 (row,col) 元组。
	height (读写)		窗口高度，以行数计
	width (读写)		窗口宽度，以列数计
	vars (只读)		窗口 |w:| 变量。属性不可赋值，但你
				可以通过这种方式修改窗口变量
	options (只读)		窗口局部选项。属性不可赋值，但你
				可以通过这种方式修改窗口选项。只提供
				对窗口局部选项的访问，缓冲区局部选项
				请使用 |python-buffer|，全局选项请使用
				|python-options|。如果选项是 |global-local|
				且缺少局部值，获取它将返回 None。
	number (只读)		窗口编号。第一个窗口编号为 1。
				如果无法确定（例如窗口对象属于其他
				标签页），则为零。
	row, col (只读)		窗口在屏幕上的位置，以显示单元格计。
				第一个位置为零。
	tabpage (只读)		窗口所属的标签页。
	valid (读写)		True 或 False。当对应的窗口关闭后，
				Window 对象变为无效。

height 属性仅在屏幕水平分割时可写。
width 属性仅在屏幕垂直分割时可写。

Window 对象类型可通过 vim 模块的 "Window" 属性获取。

==============================================================================
Tab page 对象						*python-tabpage*

Tab page 对象代表 vim 标签页。你可以通过多种方式获取它们:
	- 通过 vim.current.tabpage (|python-current|)
	- 通过 vim.tabpages 的索引 (|python-tabpages|)

你可以使用此对象来访问标签页的窗口。它们没有方法，也没有序列或
其他接口。

Tab page 的属性:
	number		标签页编号，与 |tabpagenr()| 返回的值相同。
	windows		类似 |python-windows|，但用于当前标签页。
	vars		标签页 |t:| 变量。
	window		当前标签页的窗口。
	valid		True 或 False。当对应的标签页关闭后，
			Tab page 对象变为无效。

TabPage 对象类型可通过 vim 模块的 "TabPage" 属性获取。

==============================================================================
pyeval() 和 py3eval() Vim 函数				*python-pyeval*

为了实现双向接口，你可以使用 |pyeval()| 和 |py3eval()| 函数来
对 Python 表达式求值并将其值传递给 Vim 脚本。|pyxeval()| 也可用。

==============================================================================
Python 3						*python3*

由于 Nvim 仅支持 Python 3，在当前版本中 "python" 与 "python3"
同义。然而，如果代码需要支持旧版本的 Nvim 以及 Vim，且需要
Python 3，则应优先显式使用 "python3" 变体。

							*:py3* *:python3*
:[range]py3 {stmt}
:[range]py3 << [trim] [{endmarker}]
{script}
{endmarker}

:[range]python3 {stmt}
:[range]python3 << [trim] [{endmarker}]
{script}
{endmarker}
	`:py3` 和 `:python3` 命令的工作方式与 `:python` 类似。
	检测 `:py3` 命令是否正常工作的简单方法: >vim
		:py3 print("Hello")
<
	查看你使用的 Python 版本: >vim
		:py3 import sys
		:py3 print(sys.version)
<							*:py3file*
:[range]py3f[ile] {file}
	`:py3file` 命令的工作方式与 `:pyfile` 类似。
							*:py3do*
:[range]py3do {body}
	`:py3do` 命令的工作方式与 `:pydo` 类似。

							*E880*
在 python 中抛出 SystemExit 异常不是退出 vim 的推荐方式，请使用:
>vim
	:py vim.command("qall!")
<
							*has-python*
你可以通过以下方式测试 Python 是否可用: >vim
	if has('pythonx')
	  echo 'there is Python'
	endif
	if has('python3')
	  echo 'there is Python 3.x'
	endif

Python 2 不再受支持。因此为了向后兼容，`has('python')` 始终返回零。

==============================================================================
Python X						*python_x* *pythonx*

"pythonx" 和 "pyx" 前缀最初是为同时适用于 Python 2.6+ 和 Python 3
的 python 代码引入的。由于 Nvim 仅支持 Python 3，这些命令现在都
等同于它们的 "python3" 对应命令。

							*:pyx* *:pythonx*
`:pyx` 和 `:pythonx` 的工作方式与 `:python3` 相同。检测 `:pyx`
是否正常工作: >vim
	:pyx print("Hello")

查看正在使用的 Python 版本: >vim
	:pyx import sys
	:pyx print(sys.version)
<
					*:pyxfile* *python_x-special-comments*
`:pyxfile` 的工作方式与 `:py3file` 相同。

							*:pyxdo*
`:pyxdo` 的工作方式与 `:py3do` 相同。

							*has-pythonx*
检测 `pyx*` 函数和命令是否可用: >vim
	if has('pythonx')
	  echo 'pyx* commands are available. (Python ' .. &pyx .. ')'
	endif
<
