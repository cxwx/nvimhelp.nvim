在多个标签页中使用窗口进行编辑。			*tab-page* *tabpage*

这里介绍了为使用多个标签页而添加的命令。此外，还有一些命令在与多个
标签页配合使用时工作方式不同的说明。

                                      输入 |gO| 查看目录。

==============================================================================
1. 介绍							*tab-page-intro*

一个标签页容纳一个或多个窗口。你可以轻松地在标签页之间切换，这样你
就可以有多组窗口来处理不同的事情。

通常你会在 Vim 窗口顶部看到一个标签列表，每个标签页一个标签。用
鼠标点击标签就可以跳转到该标签页。还有其他方式在标签页之间移动，
见下文。

大多数命令只在当前标签页中工作。这包括 |CTRL-W| 命令、|:windo|、|:all|
和 |:ball|（不使用 |:tab| 修饰符时）。下面会提到那些能感知当前标签页之外
的其他标签页的命令。

标签页也是临时编辑缓冲区而不改变当前窗口布局的好方法。打开一个新标签页，
做你想做的事情，然后关闭标签页。

							*tab-ID* *tabid* *tabpageid*
每个标签页都有一个称为标签 ID 的唯一标识符。此标识符在 Vim 会话内不会
改变——即使在重新排列标签时也是如此。|nvim_get_current_tabpage()| 返回
标签 ID，|nvim_list_tabpages()| 按显示顺序列出标签 ID。此外，标签从左
到右从 1 开始编号：这是 |tabpagenr()| 返回的标签编号。但是，当打开、
关闭或重新排列标签时，标签编号可能会改变。|nvim_tabpage_get_number()|
将标签 ID 转换为标签编号。


==============================================================================
2. 命令							*tab-page-commands*

打开新标签页：

当以 "vim -p filename ..." 启动 Vim 时，每个文件参数在单独的标签页中
打开（最多 'tabpagemax' 个）。参见 |-p|

在非 GUI 标签页行中双击鼠标会打开一个新的空标签页。它被放置在点击
位置的左边。第一次点击可能会先选择另一个标签页，导致额外的屏幕更新。

这在一些 GUI 版本中也有效，特别是 Win32。但只有在标签右侧点击时才行。

在 GUI 标签页行中，你可以使用鼠标右键打开菜单。|tabline-menu|。

相关的自动命令见 |tabnew-autocmd|。

:[count]tabe[dit]				*:tabe* *:tabedit* *:tabnew*
:[count]tabnew
		在当前标签页之后打开一个带空窗口的新标签页。如果给出
		[count]，新标签页出现在第 [count] 个标签页之后，否则
		出现在当前标签页之后。 >
		    :tabnew     " 在当前标签页之后打开新标签页
		    :.tabnew    " 同上
		    :+tabnew    " 在下一个标签页之后打开新标签页
				" 注意：比 :tabnew 多一个
		    :-tabnew    " 在当前标签页之前打开新标签页
		    :0tabnew    " 在第一个标签页之前打开新标签页
		    :$tabnew    " 在最后一个标签页之后打开新标签页

:[count]tabe[dit] [++opt] [+cmd] {file}
:[count]tabnew [++opt] [+cmd] {file}
		打开一个新标签页并编辑 {file}，类似于 |:edit|。
		关于 [count] 参见上面的 |:tabnew|。

:[count]tabf[ind] [++opt] [+cmd] {file}			*:tabf* *:tabfind*
		打开一个新标签页并在 'path' 中编辑 {file}，类似于
		|:find|。关于 [count] 参见上面的 |:tabnew|。

:[count]tab {cmd}					*:tab*
		执行 {cmd}，当它打开新窗口时，改为打开新标签页。对
		|:diffsplit|、|:diffpatch|、|:execute| 和 |:normal| 不起
		作用。
		如果给出 [count]，新标签页出现在第 [count] 个标签页之后，
		否则出现在当前标签页之后。
		示例： >
		    :tab split	    " 在新标签页中打开当前缓冲区
		    :tab help gt    " 打开包含 "gt" 帮助的标签页
		    :.tab help gt   " 同上
		    :+tab help	    " 在下一个标签页之后打开帮助标签页
		    :-tab help	    " 在当前标签页之前打开帮助标签页
		    :0tab help	    " 在第一个标签页之前打开帮助标签页
		    :$tab help	    " 在最后一个标签页之后打开帮助标签页

CTRL-W gf	打开一个新标签页并编辑光标下的文件名。参见 |CTRL-W_gf|。

CTRL-W gF	打开一个新标签页并编辑光标下的文件名，并跳转到文件名后面
		的行号。参见 |CTRL-W_gF|。

关闭标签页：

关闭标签页的最后一个窗口也会关闭该标签页，除非只有一个标签页。

使用鼠标：如果显示了标签页行，你可以点击右上角的 "X" 来关闭当前标签页。
自定义 'tabline' 可能显示其他内容。

							*:tabc* *:tabclose*
:tabc[lose][!]	关闭当前标签页。
		此命令在以下情况下失败：
		- 屏幕上只有一个标签页。			*E784*
		- 'hidden' 未设置，未使用 [!]，缓冲区有更改，且此缓冲区
		  没有其他窗口。
		对缓冲区的更改不会被写入也不会丢失，因此这是一个
		"安全"命令。 >
                    :tabclose   " 关闭当前标签页

:{count}tabc[lose][!]
:tabc[lose][!] {count}
		关闭第 {count} 个标签页。失败条件与上面的 `:tabclose`
		相同。 >
		    :-tabclose	    " 关闭前一个标签页
		    :+tabclose	    " 关闭下一个标签页
		    :1tabclose	    " 关闭第一个标签页
		    :$tabclose	    " 关闭最后一个标签页
		    :tabclose -2    " 关闭前第 2 个标签页
		    :tabclose +	    " 关闭下一个标签页
		    :tabclose 3	    " 关闭第三个标签页
		    :tabclose $	    " 关闭最后一个标签页
		    :tabclose #     " 关闭上次访问的标签页

当标签页被关闭时，下一个标签页将成为当前标签页。可以使用 'tabclose' 选项
自定义此行为。

							*:tabo* *:tabonly*
:tabo[nly][!]	关闭所有其他标签页。
		当设置了 'hidden' 选项时，关闭窗口中的所有缓冲区
		变为隐藏。
		当 'hidden' 未设置且 'autowrite' 选项已设置时，修改过的
		缓冲区会被写入。否则，含有已修改缓冲区的窗口不会被
		移除，除非给出了 [!]，此时它们变为隐藏。但修改过的
		缓冲区永远不会被放弃，因此更改不会丢失。 >
		    :tabonly " 关闭除当前标签页以外的所有标签页

:tabo[nly][!] {count}
		关闭除第 {count} 个标签页以外的所有标签页。 >
		    :.tabonly	    " 同上
		    :-tabonly	    " 关闭除前一个标签页以外的所有标签页
		    :+tabonly	    " 关闭除下一个标签页以外的所有标签页
		    :1tabonly	    " 关闭除第一个标签页以外的所有标签页
		    :$tabonly	    " 关闭除最后一个标签页以外的所有标签页
		    :tabonly -	    " 关闭除前一个标签页以外的所有标签页
		    :tabonly +2     " 关闭除后第二个标签页以外的所有标签页
		    :tabonly 1	    " 关闭除第一个标签页以外的所有标签页
		    :tabonly $	    " 关闭除最后一个标签页以外的所有标签页
		    :tabonly #	    " 关闭除上次访问的标签页以外的所有标签页


切换到另一个标签页：

使用鼠标：如果显示了标签页行，你可以点击标签页标签来切换到该标签页。
在没有标签的位置点击则转到下一个标签页。'tabline'

:tabn[ext]				*:tabn* *:tabnext* *gt*
<C-PageDown>				*CTRL-<PageDown>* *<C-PageDown>*
gt					*i_CTRL-<PageDown>* *i_<C-PageDown>*
		转到下一个标签页。从最后一个标签页环绕到第一个。

:{count}tabn[ext]
:tabn[ext] {count}
		转到第 {count} 个标签页。第一个标签页编号为一。 >
		    :-tabnext	" 转到前一个标签页
		    :+tabnext	" 转到下一个标签页
		    :+2tabnext	" 转到后第二个标签页
		    :1tabnext	" 转到第一个标签页
		    :$tabnext	" 转到最后一个标签页
		    :tabnext $	" 同上
		    :tabnext #	" 转到上次访问的标签页
		    :tabnext -	" 转到前一个标签页
		    :tabnext -1	" 同上
		    :tabnext +	" 转到下一个标签页
		    :tabnext +1	" 同上

{count}<C-PageDown>
{count}gt	转到第 {count} 个标签页。第一个标签页编号为一。

:tabp[revious]				*:tabp* *:tabprevious* *gT* *:tabN*
:tabN[ext]				*:tabNext* *CTRL-<PageUp>*
<C-PageUp>			 *<C-PageUp>* *i_CTRL-<PageUp>* *i_<C-PageUp>*
gT		转到前一个标签页。从第一个标签页环绕到最后一个。

:tabp[revious] {count}
:tabN[ext] {count}
{count}<C-PageUp>

:tabr[ewind]			*:tabfir* *:tabfirst* *:tabr* *:tabrewind*

							*:tabl* *:tablast*

其他命令：

:tabs		列出标签页及其包含的窗口。
		当前窗口用 ">" 标记。

重新排列标签页：

:tabm[ove] [N]						*:tabm* *:tabmove*
:[N]tabm[ove]
		将当前标签页移动到第 N 个标签页之后。使用零使当前
		标签页成为第一个。N 在移动之前计数，因此如果第二个
		标签页是当前标签页，`:tabmove 1` 和 `:tabmove 2`
		没有效果。
		不带 N 时标签页移到最后。 >
		    :.tabmove	" 不做任何事
		    :-tabmove	" 将标签页向左移动
		    :+tabmove	" 将标签页向右移动
		    :0tabmove	" 将标签页移到第一个位置
		    :tabmove 0	" 同上
		    :tabmove	" 将标签页移到最后
		    :$tabmove	" 同上
		    :tabmove $	" 同上
		    :tabmove #	" 将标签页移到上次访问的标签页之后

:tabm[ove] +[N]
:tabm[ove] -[N]
		将当前标签页向右（+）或向左（-）移动 N 个位置。 >
		    :tabmove -	" 将标签页向左移动
		    :tabmove -1	" 同上
		    :tabmove +	" 将标签页向右移动
		    :tabmove +1	" 同上


注意，虽然可以使用 :Ntabmove 将标签页移到第 N 个之后。也可以使用
:+Ntabmove 移动 N 个位置。关于 +N 在此上下文中的含义，
参见 |[range]|。


循环遍历标签页：

							*:tabd* *:tabdo*
:[range]tabd[o] {cmd}
		在每个标签页中执行 {cmd}，或者如果给出了 [range]，
		只在标签页编号在 [range] 中的标签页中执行。它的工作
		方式类似于这样做： >
			:tabfirst
			:{cmd}
			:tabnext
			:{cmd}
			etc.
<		这只在每个标签页的当前窗口中操作。当在一个标签页上
		检测到错误时，不会继续访问后面的标签页。
		最后一个标签页（或发生错误的地方）成为当前标签页。
		{cmd} 可以包含 '|' 来连接多个命令。
		{cmd} 不能打开或关闭标签页或重新排列它们。
		另见 |:windo|、|:argdo|、|:bufdo|、|:cdo|、|:ldo|、|:cfdo|
		和 |:lfdo|。

3. 其他事项						*tab-page-other*

							*tabline-menu*
GUI 标签页行有一个弹出菜单。通过右键点击访问。条目有：
	Close		关闭鼠标指针下的标签页。如果鼠标指针下没有标签，
			则关闭当前标签页。
	New Tab		打开一个标签页，编辑空缓冲区。出现在鼠标指针
			的左边。
	Open Tab...	与 "New Tab" 类似，另外使用文件选择器来选择
			要编辑的文件。

差异模式按标签页工作。你可以在一个标签页中查看几个文件之间的差异。
其他标签页可以显示其他文件之间的差异。

以 "t:" 开头的变量是标签页局部变量。|tabpage-variable|

目前只有一个标签页局部选项：'cmdheight'。

						*tabnew-autocmd*
TabLeave 和 TabEnter 自动命令事件可用于在从一个标签页切换到另一个
标签页时做一些事情。确切的顺序取决于你在做什么。创建新标签页时，
这就像你在同一缓冲区上创建新窗口然后编辑另一个缓冲区一样。因此
":tabnew" 触发：
	WinLeave		离开当前窗口
	TabLeave		离开当前标签页
	WinEnter		进入新标签页中的窗口
	TabEnter		进入新标签页
	BufLeave		离开当前缓冲区
	BufEnter		进入新的空缓冲区

切换到另一个标签页时，顺序是：
	BufLeave
	WinLeave
	TabLeave
	WinEnter
	TabEnter
	BufEnter

进入新标签页时（|:tabnew|），TabNew 在 TabEnter 之前和 WinEnter 之后触发。

4. 设置 'tabline'					*setting-tabline*

'tabline' 选项指定标签页标签行的外观。仅在没有 GUI 标签行时使用。

你可以使用 'showtabline' 选项来指定何时显示标签页标签行：从不、当有
多个标签页时、或总是显示。

标签页行的高亮通过 TabLine、TabLineSel 和 TabLineFill 组设置。
|hl-TabLine| |hl-TabLineSel| |hl-TabLineFill|

如果标签页包含修改过的窗口，则显示 "+"。标签页中的窗口数量也会显示。
因此 "3+" 表示三个窗口，其中一个有修改过的缓冲区。

'tabline' 选项允许你定义你喜欢的标签页标签方式。这不容易，因此这里
给出一个示例。

基础知识请参见 'statusline' 选项。'tabline' 选项中可以使用相同的项。
此外，|tabpagebuflist()|、|tabpagenr()| 和 |tabpagewinnr()| 函数也
很有用。

由于标签标签的数量会变化，你需要对整个选项使用表达式。类似于： >
	:set tabline=%!MyTabLine()

然后定义 MyTabLine() 函数来列出所有标签页标签。方便的方法是将其分为
两部分：首先遍历所有标签页并为它们定义标签。然后获取每个标签页的
标签。 >

	function MyTabLine()
	  let s = ''
	  for i in range(tabpagenr('$'))
	    " select the highlighting
	    if i + 1 == tabpagenr()
	      let s ..= '%#TabLineSel#'
	    else
	      let s ..= '%#TabLine#'
	    endif

	    " set the tab page number (for mouse clicks)
	    let s ..= '%' .. (i + 1) .. 'T'

	    " the label is made by MyTabLabel()
	    let s ..= ' %{MyTabLabel(' .. (i + 1) .. ')} '
	  endfor

	  " after the last tab page fill with TabLineFill and reset tab page nr
	  let s ..= '%#TabLineFill#%T'

	  " right-align the label to close the current tab page
	  if tabpagenr('$') > 1
	    let s ..= '%=%#TabLine#%999Xclose'
	  endif

	  return s
	endfunction

现在为每个标签页调用 MyTabLabel() 函数来获取其标签。 >

	function MyTabLabel(n)
	  let buflist = tabpagebuflist(a:n)
	  let winnr = tabpagewinnr(a:n)
	  return bufname(buflist[winnr - 1])
	endfunction

这只是一个简化的示例，生成的标签页行类似于默认的，但没有为修改过的
缓冲区添加 + 或截断名称。当没有足够空间时，你需要以巧妙的方式减少
标签的宽度。查看 'columns' 选项了解可用空间。

5. 设置 'guitablabel'				*setting-guitablabel*

当显示 GUI 标签页行时，'guitablabel' 可用于指定每个标签页显示的
标签。与 'tabline' 一次性指定整个标签页行不同，'guitablabel' 分别
用于每个标签。

'guitabtooltip' 非常类似，用于同一标签的工具提示。这只在鼠标指针
悬停在标签上时出现，因此通常更长。但只有一些系统支持。

值的格式参见 'statusline' 选项。

"%N" 项可用于当前标签页编号。评估选项时 |v:lnum| 变量也设置为此
编号。使用文件名的项引用标签页的当前窗口。

注意语法高亮不用于此选项。%T 和 %X 项也被忽略。

一个简单的示例，将标签页编号和缓冲区名称放在标签中： >
	:set guitablabel=%N\ %f

一个类似默认 'guitablabel' 的示例：显示标签页中的窗口数量，如果有
修改过的缓冲区则显示 '+'： >

	function GuiTabLabel()
	  let label = ''
	  let bufnrlist = tabpagebuflist(v:lnum)

	  " Add '+' if one of the buffers in the tab page is modified
	  for bufnr in bufnrlist
	    if getbufvar(bufnr, "&modified")
	      let label = '+'
	      break
	    endif
	  endfor

	  " Append the number of windows in the tab page if more than one
	  let wincount = tabpagewinnr(v:lnum, '$')
	  if wincount > 1
	    let label ..= wincount
	  endif
	  if label != ''
	    let label ..= ' '
	  endif

	  " Append the buffer name
	  return label .. bufname(bufnrlist[tabpagewinnr(v:lnum) - 1])
	endfunction

	set guitablabel=%{GuiTabLabel()}

注意函数必须在设置选项之前定义，否则你会得到函数未知的错误消息。

如果你想回退到默认标签，返回空字符串。

如果你想为标签页显示特定内容，你可能想使用标签页局部变量。|t:var|
