				      添加新菜单


现在你已经知道 Vim 非常灵活。这也包括 GUI 中使用的菜单。你可以定义自己的菜单
项，使某些命令易于访问。这只适合喜欢使用鼠标的用户。

*42.1*	简介

Vim 使用的菜单定义在文件 "$VIMRUNTIME/menu.vim" 中。如果你想编写自己的菜单，
可能需要先浏览一下这个文件。
   要定义一个菜单项，使用 ":menu" 命令。该命令的基本形式如下: >

	:menu {menu-item} {keys}

{menu-item} 描述了菜单项放在菜单的什么位置。一个典型的 {menu-item} 是
"File.Save"，表示 "File" 菜单下的 "Save" 项。用点来分隔名称。例如: >

	:menu File.Save  :update<CR>

":update" 命令在文件被修改时写入文件。
   你可以增加一个层级: "Edit.Settings.Shiftwidth" 定义了 "Edit" 菜单下的
"Settings" 子菜单，其中包含 "Shiftwidth" 项。你可以使用更深的层级。但不要用
太多，否则需要移动很多鼠标才能使用。
   ":menu" 命令与 ":map" 命令非常相似: 左边指定如何触发该项，右边定义要执行
的字符。{keys} 是字符，它们的使用方式就像你自己输入的一样。因此在插入模式下，
如果 {keys} 是纯文本，那个文本就会被插入。


加速键

& 字符用于指示加速键。例如，你可以用 Alt-F 选择 "File"，用 S 选择 "Save"。
（不过 'winaltkeys' 选项可能会禁用此功能！）因此 {menu-item} 看起来像
"&File.&Save"。加速键字符将在菜单中被加上下划线。
   你必须确保每个菜单中每个键只使用一次。否则你无法知道两个中哪一个会被实际
使用。Vim 不会对此给出警告。


优先级

File.Save 菜单项的实际定义如下: >

	:menu 10.340 &File.&Save<Tab>:w  :confirm w<CR>

数字 10.340 被称为优先级号。编辑器用它来决定菜单项的放置位置。第一个数字 (10)
表示在菜单栏上的位置。数字较小的菜单在左边，较大的在右边。
   以下是标准菜单使用的优先级:

	  10	20     40     50      60       70		9999

	+------------------------------------------------------------+
	| File	Edit  Tools  Syntax  Buffers  Window		Help |
	+------------------------------------------------------------+

注意 Help 菜单的数字非常大，使它出现在最右边。
   第二个数字 (340) 决定了菜单项在下拉菜单中的位置。数字较小的在上面，较大
的在下面。以下是 File 菜单中的优先级:
>
			+-----------------+
	    10.310	|Open...	  |
	    10.320	|Split-Open...	  |
	    10.325	|New		  |
	    10.330	|Close		  |
	    10.335	|---------------- |
	    10.340	|Save		  |
	    10.350	|Save As...	  |
	    10.400	|---------------- |
	    10.410	|Split Diff with  |
	    10.420	|Split Patched By |
	    10.500	|---------------- |
	    10.510	|Print		  |
	    10.600	|---------------- |
	    10.610	|Save-Exit	  |
	    10.620	|Exit		  |
			+-----------------+
<
注意数字之间留有间隔。这就是你可以插入自己的菜单项的地方（通常最好不要修改
标准菜单，而是添加一个新菜单来放你自己的项目）。
   当你创建子菜单时，可以在优先级中添加另一个 ".数字"。因此 {menu-item} 中的
每个名称都有其优先级号。


特殊字符

这个例子中的 {menu-item} 是 "&File.&Save<Tab>:w"。这带出了一个重要的要点:
{menu-item} 必须是一个单词。如果你想在名称中放入点、空格或制表符，要么使用
<> 表示法（如 <Space> 和 <Tab>），要么使用反斜杠 (\) 转义。>

	:menu 10.305 &File.&Do\ It\.\.\. :exit<CR>

在这个例子中，菜单项名称 "Do It..." 包含一个空格，命令是 ":exit<CR>"。

菜单名称中的 <Tab> 字符用于分隔定义菜单名称的部分和给用户的提示。<Tab> 之后
的部分在菜单中右对齐显示。在 File.Save 菜单中使用的名称是
"&File.&Save<Tab>:w"。因此菜单名称是 "File.Save"，提示是 ":w"。


分隔线

分隔线用于将相关的菜单项分组，可以使用以 '-' 开始和结束的名称来定义。例如
"-sep-"。当使用多个分隔线时，名称必须不同。否则名称无关紧要。
   分隔线的命令永远不会被执行，但你仍然需要定义一个。用单个冒号即可。例如: >

	:amenu 20.510 Edit.-sep3- :

*42.2*	菜单命令

你可以定义只在特定模式下存在的菜单项。这和 ":map" 命令的变体一样:

	:menu		普通、可视和操作符等待模式
	:nmenu		普通模式
	:vmenu		可视模式
	:omenu		操作符等待模式
	:menu!		插入和命令行模式
	:imenu		插入模式
	:cmenu		命令行模式
	:tlmenu		终端模式
	:amenu		所有模式（终端模式除外）

为了避免菜单项的命令被映射，使用 ":noremenu"、":nnoremenu"、":anoremenu" 等
命令。


使用 :AMENU

":amenu" 命令略有不同。它假设你给出的 {keys} 是在普通模式下执行的。当使用菜单
时 Vim 处于可视或插入模式，Vim 首先要回到普通模式。":amenu" 会为你插入
CTRL-C 或 CTRL-O。例如，如果你使用这个命令:
>
	:amenu  90.100 Mine.Find\ Word  *

则生成的菜单命令将是:

	普通模式:		`*`
	可视模式:		CTRL-C `*`
	操作符等待模式:	CTRL-C `*`
	插入模式:		CTRL-O `*`
	命令行模式:		CTRL-C `*`

在命令行模式下，CTRL-C 将放弃已输入的命令。在可视和操作符等待模式下，CTRL-C
会停止该模式。插入模式下的 CTRL-O 会执行命令然后返回插入模式。
   CTRL-O 只对一个命令有效。如果你需要使用两个或更多命令，将它们放入一个函数
中并调用该函数。例如: >

	:amenu  Mine.Next\ File  :call <SID>NextFile()<CR>
	:function <SID>NextFile()
	:  next
	:  1/^Code
	:endfunction

这个菜单项使用 ":next" 转到参数列表中的下一个文件。然后搜索以 "Code" 开头的
行。
   函数名前的 <SID> 是脚本 ID。这使函数局限于当前的 Vim 脚本文件。这避免了
在其他脚本文件中定义同名函数时出现问题。参见 |<SID>|。


静默菜单

菜单像你自己输入一样执行 {keys}。对于 ":" 命令，这意味着你会看到命令被回显在
命令行上。如果命令很长，会出现按回车继续的提示。这可能非常烦人！
   为了避免这个问题，使菜单静默。这通过 <silent> 参数实现。例如，以前例中的
NextFile() 调用为例。当你使用这个菜单时，你会在命令行上看到:

	:call <SNR>34_NextFile() ~

为了避免这些文本出现在命令行上，将 "<silent>" 作为第一个参数插入: >

	:amenu <silent> Mine.Next\ File :call <SID>NextFile()<CR>

不要过度使用 "<silent>"。对于简短的命令它不是必需的。如果你为别人制作菜单，
能看到执行的命令会给他们一个提示，告诉他们可以输入什么来替代使用鼠标。


列出菜单

当菜单命令没有 {keys} 部分时，它会列出已定义的菜单。你可以指定一个 {menu-item}
或其一部分来列出特定的菜单。例如: >

	:amenu

这列出所有菜单。列表会很长！最好指定菜单名称来获得更短的列表: >

	:amenu Edit

这只列出所有模式的 "Edit" 菜单项。只列出插入模式下的一个特定菜单项: >

	:imenu Edit.Undo

要注意输入正确的名称。大小写在这里很重要。但加速键的 '&' 可以省略。<Tab> 及
其后面的内容也可以省略。


删除菜单

要删除菜单，使用与列出相同的命令，但将 "menu" 改为 "unmenu"。因此 ":menu"
变成 ":unmenu"，":nmenu" 变成 ":nunmenu"，等等。要删除插入模式下的
"Tools.Make" 项: >

	:iunmenu Tools.Make

你可以使用菜单名称删除整个菜单及其所有项。例如: >

	:aunmenu Syntax

这删除 Syntax 菜单及其中的所有项。

*42.3*	杂项

你可以通过 'guioptions' 中的标志来改变菜单的外观。默认值中包含了所有标志，
但 "M" 除外。你可以用以下命令来移除一个标志: >

	:set guioptions-=m
<
	m		移除后菜单栏不显示。

	M		添加后不加载默认菜单。

	g		移除后非活动的菜单项不会变灰，
			而是完全移除。（不是所有系统都有效。）

关于翻译菜单项，参见 |:menutrans|。

由于需要使用鼠标来选择菜单项，使用 ":browse" 命令来选择文件是个好主意。使用
":confirm" 获得一个对话框而不是错误消息，例如当前缓冲区有修改时。这两者可以
结合使用: >

	:amenu File.Open  :browse confirm edit<CR>

":browse" 会弹出文件浏览器来选择要编辑的文件。":confirm" 会在当前缓冲区有
改动时弹出对话框。你可以选择保存改动、丢弃改动或取消命令。
   对于更复杂的项目，可以使用 confirm() 和 inputdialog() 函数。默认菜单中包含
了一些例子。

*42.4*	工具栏和弹出菜单

有两个特殊的菜单: ToolBar 和 PopUp。以这些名称开头的项目不会出现在普通的菜单
栏中。


工具栏

只有当 'guioptions' 选项中包含 "T" 标志时，工具栏才会显示。
   工具栏使用图标而不是文字来表示命令。例如，名为 "ToolBar.New" 的 {menu-item}
会在工具栏上显示 "New" 图标。
   Vim 编辑器有 28 个内建图标。你可以在这里找到一个表格: |builtin-tools|。
大多数在默认工具栏中使用。你可以重定义这些项目的功能（在默认菜单设置之后）。
   你可以为工具栏项目添加另一个位图。或者用位图定义一个新的工具栏项目。例如，
定义一个新的工具栏项目: >

	:tmenu ToolBar.Compile  Compile the current file
	:amenu ToolBar.Compile  :!cc %:S -o %:r:S<CR>

现在你需要创建图标。对于 MS-Windows 它必须是位图格式，文件名为 "Compile.bmp"。
对于 Unix 使用 XPM 格式，文件名为 "Compile.xpm"。尺寸必须是 18x18 像素。在
MS-Windows 上也可以使用其他尺寸，但看起来会不好。
   将位图放在 'runtimepath' 中某个目录的 "bitmaps" 目录中。例如，在 Unix 上
是 "~/.config/nvim/bitmaps/Compile.xpm"。

你可以为工具栏中的项目定义工具提示。工具提示是解释工具栏项目功能的简短文本。
例如 "Open file"。当鼠标指针停留在项目上不动片刻时就会出现。当图片的含义不够
明显时，这非常有用。例如: >

	:tmenu ToolBar.Make  Run make in the current directory
<
	备注:
	注意大小写。"Toolbar" 和 "toolbar" 与 "ToolBar" 是不同的！

要移除工具提示，使用 |:tunmenu| 命令。

'toolbar' 选项可以用来显示文字而不是位图，或者同时显示文字和位图。大多数人
只使用位图，因为文字占用相当大的空间。


弹出菜单

弹出菜单出现在鼠标指针所在位置。在 MS-Windows 上通过单击右键激活。然后用左键
选择项目。在 Unix 上，通过按住右键来使用弹出菜单。
   弹出菜单只有在 'mousemodel' 被设置为 "popup" 或 "popup_setpos" 时才会出现。
两者的区别是 "popup_setpos" 会将光标移到鼠标指针位置。当在选区内单击时，选区
不受影响。当在选区外单击时，选区被取消。
   每种模式都有单独的弹出菜单。因此不会有像普通菜单中那样的灰色项目。
