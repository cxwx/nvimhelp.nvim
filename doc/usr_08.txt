*08.1*	分割窗口

打开新窗口最简单的方法是使用以下命令: >

	:split

这个命令将屏幕分成两个窗口，光标留在上面的窗口中:
>
	+----------------------------------+
	|/* file one.c */		   |
	|~				   |
	|~				   |
	|one.c=============================|
	|/* file one.c */		   |
	|~				   |
	|one.c=============================|
	|				   |
	+----------------------------------+
<
你在这里看到的是同一个文件的两个窗口。带有 "====" 的行是状态行。它显示了上方
窗口的信息。（实际上状态行会以反色显示。）
   这两个窗口允许你查看同一个文件的两个部分。例如，你可以让上面的窗口显示程序
的变量声明，下面的窗口显示使用这些变量的代码。

CTRL-W w 命令可以用来在窗口之间跳转。如果你在上面的窗口中，CTRL-W w 跳到下面
的窗口。如果你在下面的窗口中，它会跳到第一个窗口。（CTRL-W CTRL-W 做同样的
事，以防你稍晚一点松开 CTRL 键。）


关闭窗口

要关闭一个窗口，使用命令: >

	:close

实际上，任何退出文件编辑的命令都可以，比如 ":quit" 和 "ZZ"。但 ":close" 可以
防止你在关闭最后一个窗口时意外退出 Vim。


关闭所有其他窗口

如果你打开了一大堆窗口，但现在想集中在其中一个上，这个命令会很有用: >

	:only

这会关闭所有窗口，除了当前的那个。如果其他窗口中有更改，你会收到错误信息，
那个窗口不会被关闭。

*08.2*	在另一个文件上分割窗口

以下命令打开第二个窗口并开始编辑给定的文件:
>
	:split two.c

如果你正在编辑 one.c，那么结果看起来像这样:
>
	+----------------------------------+
	|/* file two.c */		   |
	|~				   |
	|~				   |
	|two.c=============================|
	|/* file one.c */		   |
	|~				   |
	|one.c=============================|
	|				   |
	+----------------------------------+
<
要在一个新的空文件上打开窗口，使用: >

	:new

你可以重复 ":split" 和 ":new" 命令来创建任意多个窗口。

*08.3*	窗口大小

":split" 命令可以接受一个数字参数。如果指定了，这将是新窗口的高度。例如，
以下命令打开一个三行高的新窗口并开始编辑文件 alpha.c: >

	:3split alpha.c

对于已有的窗口，你可以用几种方式改变大小。当你有一个可用的鼠标时很简单: 将
鼠标指针移到分隔两个窗口的状态行上，然后上下拖动。

要增加窗口的大小: >

	CTRL-W +

要减小它: >

	CTRL-W -

这两个命令都接受计数，按指定的行数增加或减少窗口大小。因此 "4 CTRL-W +" 使
窗口增高四行。

要将窗口高度设为指定的行数: >

	{height}CTRL-W _

即: 一个数字 {height}，CTRL-W 然后一个下划线（在英语 US 键盘上是 Shift 加 -
键）。
   要使窗口尽可能高，不带计数使用 CTRL-W _ 命令。


使用鼠标

在 Vim 中你可以通过键盘非常快速地做很多事情。不幸的是，窗口调整大小的命令
需要输入不少。在这种情况下，使用鼠标更快。将鼠标指针定位在状态行上。然后
按左键并拖动。状态行会移动，从而使一侧的窗口更高，另一侧更小。


选项

'winheight' 选项可以设为窗口的最小期望高度，'winminheight' 设为硬最小高度。
   类似地，'winwidth' 用于最小期望宽度，'winminwidth' 用于硬最小宽度。
   'equalalways' 选项在设置时，使 Vim 在窗口关闭或打开时均等化窗口大小。

*08.4*	垂直分割

":split" 命令在当前窗口上方创建新窗口。要使窗口出现在左边，使用: >

	:vsplit

或: >
	:vsplit two.c

结果看起来像这样:
>
	+--------------------------------------+
	|/* file two.c */   |/* file one.c */  |
	|~		    |~		       |
	|~		    |~		       |
	|~		    |~		       |
	|two.c===============one.c=============|
	|				       |
	+--------------------------------------+
<
实际上，中间的 | 线会以反色显示。这称为垂直分隔符。它分隔了左右两个窗口。

还有 ":vnew" 命令，在一个新的空文件上打开垂直分割窗口。另一种方法: >

	:vertical new

":vertical" 命令可以插入到另一个分割窗口的命令之前。这会使该命令垂直分割窗口
而不是水平分割。（如果该命令不分割窗口，它照常工作。）


在窗口间移动

因为你可以随意水平和垂直分割窗口，你几乎可以创建任何窗口布局。然后你可以使用
这些命令在它们之间移动:

	CTRL-W h	移到左边的窗口
	CTRL-W j	移到下面的窗口
	CTRL-W k	移到上面的窗口
	CTRL-W l	移到右边的窗口

	CTRL-W t	移到最顶部的窗口
	CTRL-W b	移到最底部的窗口

你会注意到使用的字母与移动光标相同。如果你喜欢，也可以使用光标键。
   更多移动到其他窗口的命令: |Q_wi|。

*08.5*	移动窗口

你分割了几个窗口，但它们在错误的位置。那么你需要一个命令来把窗口移到别处。
例如，你有三个这样的窗口:
>
	+----------------------------------+
	|/* file two.c */		   |
	|~				   |
	|~				   |
	|two.c=============================|
	|/* file three.c */		   |
	|~				   |
	|~				   |
	|three.c===========================|
	|/* file one.c */		   |
	|~				   |
	|one.c=============================|
	|				   |
	+----------------------------------+
<
显然最后一个应该在最上面。移到那个窗口（使用 CTRL-W w）然后输入这个命令: >

	CTRL-W K

这使用大写字母 K。效果是窗口被移到最顶部。你会注意到 K 再次被用于向上移动。
   当你有垂直分割时，CTRL-W K 会将当前窗口移到顶部并使其占满 Vim 窗口的全
宽。如果你的布局是这样的:
>
	+-------------------------------------------+
	|/* two.c */  |/* three.c */  |/* one.c */  |
	|~	      |~	      |~	    |
	|~	      |~	      |~	    |
	|~	      |~	      |~	    |
	|~	      |~	      |~	    |
	|~	      |~	      |~	    |
	|two.c=========three.c=========one.c========|
	|					    |
	+-------------------------------------------+
<
那么在中间的窗口（three.c）中使用 CTRL-W K 会导致:
>
	+-------------------------------------------+
	|/* three.c */				    |
	|~					    |
	|~					    |
	|three.c====================================|
	|/* two.c */	       |/* one.c */	    |
	|~		       |~		    |
	|two.c==================one.c===============|
	|					    |
	+-------------------------------------------+
<
另外三个类似的命令（你可能已经猜到了）:

	CTRL-W H	将窗口移到最左边
	CTRL-W J	将窗口移到底部
	CTRL-W L	将窗口移到最右边

*08.6*	对所有窗口的命令

当你打开了多个窗口想退出 Vim 时，你可以分别关闭每个窗口。一个更快的方法是
使用这个命令: >

	:qall

这代表 "quit all"（全部退出）。如果任何窗口包含更改，Vim 不会退出。光标会
自动定位到有更改的窗口。你可以使用 ":write" 保存更改，或者 ":quit!" 丢弃
更改。

如果你知道有窗口有更改，并且你想保存所有这些更改，使用这个命令: >

	:wall

这代表 "write all"（全部写入）。但实际上，它只写入有更改的文件。Vim 知道写入
没有更改的文件没有意义。
   然后还有 ":qall" 和 ":wall" 的组合: "write and quit all"（全部写入并退出）
命令: >

	:wqall

这写入所有修改过的文件并退出 Vim。
   最后，有一个退出 Vim 并丢弃所有更改的命令: >

	:qall!

小心，这个命令无法撤销！


为所有参数打开窗口

要让 Vim 为每个文件打开一个窗口，使用 "-o" 参数启动: >

	vim -o one.txt two.txt three.txt

结果是:
>
	+-------------------------------+
	|file one.txt			|
	|~				|
	|one.txt========================|
	|file two.txt			|
	|~				|
	|two.txt========================|
	|file three.txt			|
	|~				|
	|three.txt======================|
	|				|
	+-------------------------------+
<
"-O" 参数用于获得垂直分割的窗口。
   当 Vim 已经在运行时，":all" 命令为参数列表中的每个文件打开一个窗口。
":vertical all" 使用垂直分割。

*08.7*	用 diff 模式查看差异

有一种特殊的方式来启动 Nvim，显示两个文件之间的差异。让我们取一个文件
"main.c" 并在其中一行中插入一些字符。在设置了 'backup' 选项的情况下保存这个
文件，这样备份文件 "main.c~" 将包含文件的上一个版本。
在 shell 中输入这个命令以 diff 模式启动 Nvim: >

	nvim -d main.c~ main.c

Vim 将启动，两个窗口并排显示。你只会看到你添加了字符的那一行，以及它上下的
几行。
>
	 VV		      VV
	+-----------------------------------------+
	|+ +--123 lines: /* a|+ +--123 lines: /* a|  <- 折叠
	|  text		     |	text		  |
	|  text		     |	text		  |
	|  text		     |	text		  |
	|  text		     |	changed text	  |  <- 修改的行
	|  text		     |	text		  |
	|  text		     |	------------------|  <- 删除的行
	|  text		     |	text		  |
	|  text		     |	text		  |
	|  text		     |	text		  |
	|+ +--432 lines: text|+ +--432 lines: text|  <- 折叠
	|  ~		     |	~		  |
	|  ~		     |	~		  |
	|main.c~==============main.c==============|
	|					  |
	+-----------------------------------------+
<
（此图未显示高亮，使用 "nvim -d" 可以看到。）

未修改的行被折叠成一行。这称为关闭的折叠。在图中用 "<- 折叠" 标示。因此顶部
的单个折叠行代表 123 行文本。这些行在两个文件中是相同的。
   标记为 "<- 修改的行" 的行被高亮显示，插入的文本用另一种颜色显示。这清楚地
展示了两个文件之间的区别。
   被删除的行在 main.c 窗口中用 "---" 显示。参见图中的 "<- 删除的行" 标记。
这些字符实际上并不在那里。它们只是填充 main.c，使其显示与另一个窗口相同数量
的行。


折叠列

每个窗口左边有一个背景略有不同的列。在上面的图中用 "VV" 标示。你注意到在每个
关闭的折叠前面有一个加号。将鼠标指针移到那个加号上并点击左键。折叠会打开，
你可以看到它包含的文本。
   折叠列中打开的折叠前有一个减号。如果你点击这个 -，折叠会关闭。
   显然，这只在你有可用的鼠标时才有效。你也可以使用 "zo" 打开折叠，"zc"
关闭它。


在 VIM 中进行 DIFF

另一种启动 diff 模式的方法是在 Vim 内部。编辑 "main.c" 文件，然后分割并显示
差异: >

	:edit main.c
	:vertical diffsplit main.c~

":vertical" 命令用于使窗口垂直分割。如果你省略它，你会得到水平分割。

如果你有补丁或 diff 文件，你可以使用第三种方式启动 diff 模式。首先编辑补丁
所应用的文件。然后告诉 Vim 补丁文件的名称: >

	:edit main.c
	:vertical diffpatch main.c.diff

警告: 补丁文件必须只包含一个补丁，针对你正在编辑的文件。否则你会得到很多错误
信息，一些文件可能被意外打补丁。
   打补丁只会对 Vim 中的文件副本进行。你硬盘上的文件将保持不变（直到你决定
写入文件）。


滚动绑定

当文件有更多更改时，你可以像平常一样滚动。Vim 会尝试保持两个窗口从相同的
位置开始，这样你可以方便地并排查看差异。
   当你暂时不想这样时，使用这个命令: >

	:set noscrollbind


跳转到更改处

当你以某种方式禁用了折叠时，可能很难找到更改。使用这个命令跳转到下一个
更改处: >

	]c

反方向使用: >

	[c

加上计数可以跳得更远。例如 "4]c" 跳到第四个下一个更改处，"3[c" 跳到第三个
上一个更改处。


消除差异

你可以将文本从一个窗口移到另一个窗口。这要么消除差异，要么添加新的差异。Vim
不会在所有情况下保持高亮更新。要更新它，使用这个命令: >

	:diffupdate

要消除一个差异，你可以将高亮块中的文本从一个窗口移到另一个。以上面的 "main.c"
和 "main.c~" 为例。将光标移到左窗口，在另一个窗口中被删除的那一行上。现在
输入这个命令: >

	dp

更改将通过将当前窗口的文本放到另一个窗口中来消除。"dp" 代表 "diff put"
（diff 放置）。
   你也可以反过来做。将光标移到右窗口，在 "changed" 被插入的那一行上。现在
输入这个命令: >

	do

更改现在通过从另一个窗口获取文本来消除。由于现在没有更改了，Vim 把所有文本
放入一个关闭的折叠中。"do" 代表 "diff obtain"（diff 获取）。"dg" 本来更好，
但它已经有不同的含义了（"dgg" 从光标删除到第一行）。

关于 diff 模式的详情，参见 |diff-mode|。

*08.8*	杂项

'laststatus' 选项可以用来指定最后一个窗口何时有状态行:

	0	从不
	1	只在有分割窗口时（默认）
	2	始终
	3	在底部使用全局状态行而不是每个窗口一个

很多编辑另一个文件的命令都有一个分割窗口的变体。对于命令行命令，这通过在前面
加 "s" 来完成。例如: ":tag" 跳转到一个标签，":stag" 分割窗口并跳转到一个
标签。
   对于普通模式命令，在前面加 CTRL-W。CTRL-^ 跳转到轮换文件，CTRL-W CTRL-^
分割窗口并编辑轮换文件。

'splitbelow' 选项可以设为让新窗口出现在当前窗口下方。'splitright' 选项可以
设为让垂直分割的窗口出现在当前窗口右边。

分割窗口时你可以在前面加一个修饰符命令来指定窗口出现在哪里:

	:leftabove {cmd}	在当前窗口的左边或上面
	:aboveleft {cmd}	同上
	:rightbelow {cmd}	在当前窗口的右边或下面
	:belowright {cmd}	同上
	:topleft {cmd}		在 Vim 窗口的顶部或左边
	:botright {cmd}		在 Vim 窗口的底部或右边

*08.9*	标签页

你会注意到窗口永远不会重叠。这意味着你很快就会用完屏幕空间。解决方案叫做
标签页。

假设你正在编辑 "thisfile"。要创建一个新标签页，使用这个命令: >

	:tabedit thatfile

这将在一个占据整个 Vim 窗口的窗口中编辑文件 "thatfile"。你会注意到顶部有一个
栏，显示两个文件名:
>
	+----------------------------------+
	| thisfile | /thatfile/ __________X|    (thatfile 是粗体)
	|/* thatfile */			   |
	|that				   |
	|that				   |
	|~				   |
	|~				   |
	|~				   |
	|				   |
	+----------------------------------+
<
你现在有两个标签页。第一个有一个显示 "thisfile" 的窗口，第二个有一个显示
"thatfile" 的窗口。就像两页纸叠在一起，每页上都有一个标签伸出来显示文件名。

现在用鼠标点击顶行的 "thisfile"。结果是
>
	+----------------------------------+
	| /thisfile/ | thatfile __________X|    (thisfile 是粗体)
	|/* thisfile */			   |
	|this				   |
	|this				   |
	|~				   |
	|~				   |
	|~				   |
	|				   |
	+----------------------------------+
<
因此你可以通过点击顶行的标签来切换标签页。如果你没有鼠标或不想使用它，你可以
使用 "gt" 命令。助记: Goto Tab（转到标签）。

现在让我们用这个命令创建另一个标签页: >

	:tab split

这会创建一个新标签页，其中有一个窗口正在编辑与我们之前所在窗口相同的缓冲区:
>
	+-------------------------------------+
	| thisfile | /thisfile/ | thatfile __X|   (thisfile 是粗体)
	|/* thisfile */			      |
	|this				      |
	|this				      |
	|~				      |
	|~				      |
	|~				      |
	|				      |
	+-------------------------------------+
<
你可以在任何打开窗口的 Ex 命令前放 ":tab"。窗口将在新标签页中打开。另一个
例子: >

	:tab help gt

将在新标签页中显示 "gt" 的帮助文本。

你可以对标签页做更多事情:

- 在最后一个标签之后的空白处点击鼠标
	将选择下一个标签页，就像使用 "gt" 一样。

- 点击右上角的 "X"
	当前标签页将被关闭。除非当前标签页中有未保存的更改。

- 在顶行双击鼠标
	将创建一个新标签页。

- "tabonly" 命令
	关闭除当前标签页之外的所有标签页。除非其他标签页中有未保存的更改。

关于标签页的更多信息请参见 |tab-page|。
