				      折叠


结构化的文本可以分成多个小节。小节又可以分成子节。折叠允许你将一个小节显示为
一行，从而提供概览。本章介绍实现这一功能的各种方式。

*28.1*	什么是折叠？

折叠用于将缓冲区中的一系列行在屏幕上显示为一行。就像把一张纸折叠起来使它变
短一样：

	+------------------------+
	| line 1		 |
	| line 2		 |
	| line 3		 |
	|_______________________ |
	\			 \
	 \________________________\
	 / folded lines		  /
	/________________________/
	| line 12		 |
	| line 13		 |
	| line 14		 |
	+------------------------+

文本仍然在缓冲区中，没有改变。折叠只影响行的显示方式。

折叠的好处是，你可以折叠一个小节的行并用一行来替代它，从而更好地了解文本的
结构。

*28.2*	手动折叠

试一试：将光标定位在一个段落上，然后输入: >

	zfap

你会看到这个段落被一行高亮行替代了。你创建了一个折叠。|zf| 是一个操作符，
|ap| 是一个文本对象选择。你可以将 |zf| 操作符与任何移动命令组合使用，为它移
过的文本创建折叠。|zf| 在可视模式下也能工作。

要再次查看文本，通过输入以下命令打开折叠: >

	zo

你也可以再次关闭折叠: >

	zc

所有的折叠命令都以 "z" 开头。发挥想象力的话，这看起来像从侧面看的一张折叠
纸。"z" 之后的字母有助记含义，便于记住这些命令：

	zf	F-old 创建折叠
	zo	O-pen 打开折叠
	zc	C-lose 关闭折叠

折叠可以嵌套：一个包含折叠的文本区域可以被再次折叠。例如，你可以折叠本节中
的每个段落，然后折叠本章的所有小节。试试看。你会注意到，打开整章的折叠会恢
复嵌套折叠原来的状态，有些是打开的，有些是关闭的。

假设你创建了多个折叠，现在想查看所有文本。你可以到每个折叠处输入 "zo"。要更
快地完成这个操作，使用以下命令: >

	zr

这将减少（R-educe）折叠。相反的操作是: >

	zm

这会增加（M-ore）折叠。你可以重复 "zr" 和 "zm" 来打开和关闭多层嵌套折叠。

如果你有多层嵌套的折叠，可以用以下命令打开所有折叠: >

	zR

这将减少折叠直到没有折叠剩下。你也可以用以下命令关闭所有折叠: >

	zM

这会折叠更多再更多（M-ore and M-ore）。

你可以用 |zn| 命令快速禁用折叠。然后 |zN| 恢复之前的折叠状态。|zi| 在两者
之间切换。这是一种很实用的工作方式：
- 创建折叠以获得文件的概览
- 移动到你想要工作的地方
- 用 |zi| 查看文本并编辑
- 再次用 |zi| 回到移动浏览状态

关于手动折叠的更多信息参见参考手册: |fold-manual|

*28.3*	折叠操作

当一些折叠处于关闭状态时，像 "j" 和 "k" 这样的移动命令会把折叠当作一个空行
来跳过。这样你就可以在折叠的文本上快速移动。

你可以像操作一行一样来复制、删除和粘贴折叠。这在你想重新排列程序中的函数时
非常有用。首先通过选择正确的 'foldmethod' 确保每个折叠包含一个完整的函数
（或差不多）。然后用 "dd" 删除函数，移动光标并用 "p" 粘贴。如果函数的某些行
在折叠之上或之下，你可以使用可视选择：
- 将光标放在要移动的第一行上
- 按 "V" 开始可视模式
- 将光标放在要移动的最后一行上
- 按 "d" 删除选中的行
- 将光标移到新位置并用 "p" 粘贴

有时很难看到或记住折叠的位置，因此不知道 |zo| 命令在哪里起作用。要查看已定
义的折叠: >

	:set foldcolumn=4

这将在窗口左边显示一小列来指示折叠。关闭的折叠显示 "+"。每个打开的折叠的起
始处显示 "-"，后续行显示 "|"。

你可以用鼠标点击 foldcolumn 中的 "+" 来打开折叠。点击 "-" 或其下方的 "|" 会
关闭一个打开的折叠。

要打开光标行的所有折叠，使用 |zO|。
要关闭光标行的所有折叠，使用 |zC|。
要删除光标行的一个折叠，使用 |zd|。
要删除光标行的所有折叠，使用 |zD|。

在插入模式下，光标所在行的折叠永远不会被关闭。这样你就能看到你输入的内容！

当跳转或向左右移动光标时，折叠会自动打开。例如，"0" 命令会打开光标下方的折
叠（如果 'foldopen' 包含 "hor"，这是默认值）。可以修改 'foldopen' 选项来指
定哪些命令会打开折叠。如果你想让光标所在行总是打开的，这样做: >

	:set foldopen=all

警告: 这样你就无法移到关闭的折叠上了。你可能只想临时使用这个设置，然后恢复
为默认值: >

	:set foldopen&

你可以让折叠在你移出时自动关闭: >

	:set foldclose=all

这将对所有不包含光标的折叠重新应用 'foldlevel'。你需要试试看是否喜欢这种效
果。使用 |zm| 增加折叠，使用 |zr| 减少折叠。

折叠是窗口局部的。这允许你为同一个缓冲区打开两个窗口，一个有折叠一个没有。
或者一个所有折叠都关闭，另一个所有折叠都打开。

*28.4*	保存和恢复折叠

当你放弃一个文件（开始编辑另一个文件）时，折叠的状态就丢失了。如果你稍后回
到同一个文件，所有手动打开和关闭的折叠都会恢复为默认状态。如果折叠是手动创
建的，所有折叠都会消失！要保存折叠，使用 |:mkview| 命令: >

	:mkview

这将保存影响文件视图的设置和其他内容。你可以通过 'viewoptions' 选项来更改保
存的内容。当你稍后回到同一个文件时，可以再次加载视图: >

	:loadview

你可以为一个文件保存最多十个视图。例如，将当前设置保存为第三个视图并加载第
二个视图: >

	:mkview 3
	:loadview 2

注意，当你插入或删除行时，视图可能会变得无效。还可以查看 'viewdir' 选项，
它指定了视图的保存位置。你可能需要不时删除旧的视图。

*28.5*	按缩进折叠

用 |zf| 定义折叠需要大量的工作。如果你的文本通过给低层级项更大的缩进来组织
结构，你可以使用缩进折叠方法。这会为每组相同缩进的连续行创建折叠。缩进更大
的行会成为嵌套折叠。这在许多编程语言中效果很好。

通过设置 'foldmethod' 选项来尝试: >

	:set foldmethod=indent

然后你可以使用 |zm| 和 |zr| 命令来增加和减少折叠。在以下示例文本上很容易看
出效果：

This line is not indented
	This line is indented once
		This line is indented twice
		This line is indented twice
	This line is indented once
This line is not indented
	This line is indented once
	This line is indented once

注意缩进量和折叠深度之间的关系取决于 'shiftwidth' 选项。每个 'shiftwidth'
的缩进量增加一层折叠深度。这被称为折叠级别。

当你使用 |zr| 和 |zm| 命令时，实际上是在增加或减少 'foldlevel' 选项的值。你
也可以直接设置它: >

	:set foldlevel=3

这意味着所有缩进达到 'shiftwidth' 三倍或更多的折叠都会被关闭。foldlevel 越
低，关闭的折叠越多。当 'foldlevel' 为零时，所有折叠都被关闭。|zM| 将
'foldlevel' 设为零。相反的命令 |zR| 将 'foldlevel' 设为文件中存在的最深折叠
级别。

因此有两种方式来打开和关闭折叠：
(A) 通过设置折叠级别。
    这提供了一种非常快速的方式来 "缩小" 查看文本结构，移动光标，然后再
    "放大" 文本。

(B) 通过使用 |zo| 和 |zc| 命令来打开或关闭特定折叠。
    这允许只打开你想打开的折叠，而其他折叠保持关闭。

两者可以组合使用：你可以先用 |zm| 几次关闭大部分折叠，然后用 |zo| 打开特定
折叠。或者用 |zR| 打开所有折叠，然后用 |zc| 关闭特定折叠。

但当 'foldmethod' 为 "indent" 时，你不能手动定义折叠，因为这会与缩进和折叠
级别之间的关系冲突。

关于按缩进折叠的更多信息参见参考手册: |fold-indent|

*28.6*	按标记折叠

文本中的标记用于指定折叠区域的开始和结束。这可以精确控制哪些行包含在折叠中。
缺点是需要修改文本。

试试看: >

	:set foldmethod=marker

示例文本，如同在 C 程序中出现的一样: >

	/* foobar () {{{ */
	int foobar()
	{
		/* return a value {{{ */
		return 42;
		/* }}} */
	}
	/* }}} */

注意折叠行会显示标记之前的文本。这对于说明折叠包含什么内容非常有用。

当移动一些行后标记不配对时会很烦人。使用编号标记可以避免这个问题。例如: >

	/* global variables {{{1 */
	int varA, varB;

	/* functions {{{1 */
	/* funcA() {{{2 */
	void funcA() {}

	/* funcB() {{{2 */
	void funcB() {}
	/* }}}1 */

在每个编号标记处，指定级别的折叠开始。这会使任何更高级别的折叠在此停止。你
只需使用编号开始标记就可以定义所有折叠。只有当你想在另一个折叠开始之前显式
停止一个折叠时，才需要添加结束标记。

关于按标记折叠的更多信息参见参考手册: |fold-marker|

==============================================================================
*28.7*	按语法折叠

对于每种语言，Vim 使用不同的语法文件。这定义了文件中各种元素的颜色。如果你
在支持颜色的终端中用 Vim 阅读本文，你看到的颜色就是由 "help" 语法文件定义
的。
   在语法文件中可以添加带有 "fold" 参数的语法项。这些定义了折叠区域。这需要
编写语法文件并在其中添加这些项。这不太容易做到。但一旦完成，所有折叠都会自
动进行。
   这里我们假设你使用的是现有的语法文件。那就没有更多需要解释的了。你可以像
上面解释的那样打开和关闭折叠。折叠会在你编辑文件时自动创建和删除。

关于按语法折叠的更多信息参见参考手册: |fold-syntax|

*28.8*	按表达式折叠

这类似于按缩进折叠，但使用用户函数来计算行的折叠级别，而不是使用行的缩进。
你可以将此用于文本中有某些内容指示哪些行属于一组的情况。一个例子是电子邮件
消息，其中引用的文本在行前用 ">" 表示。要折叠这些引用，使用以下命令: >

	:set foldmethod=expr
	:set foldexpr=strlen(substitute(substitute(getline(v:lnum),'\\s','',\"g\"),'[^>].*','',''))

你可以在以下文本上尝试：

> quoted text he wrote
> quoted text he wrote
> > double quoted text I wrote
> > double quoted text I wrote

示例中使用的 'foldexpr' 的解释（从内到外）：
   getline(v:lnum)			获取当前行
   substitute(...,'\\s','','g')		移除行中所有空白字符
   substitute(...,'[^>].*','','')	移除前导 '>' 之后的所有内容
   strlen(...)				计算字符串长度，即找到的 '>'
					的数量

注意在 ":set" 命令中，每个空格、双引号和反斜杠之前都必须插入一个反斜杠。如
果这让你困惑，可以这样做 >

	:set foldexpr

来检查实际的结果值。要修正复杂的表达式，可以使用命令行补全: >

	:set foldexpr=<Tab>

其中 <Tab> 是一个真正的 Tab 键。Vim 会填入之前的值，然后你可以编辑它。

当表达式变得更复杂时，你应该把它放在一个函数中，然后设置 'foldexpr' 来调用
该函数。

关于按表达式折叠的更多信息参见参考手册: |fold-expr|

==============================================================================
*28.9*	折叠未改变的行

当你在同一个窗口中设置 'diff' 选项时，这很有用。|-d| 选项会为你自动设置。
例如: >

	:setlocal diff foldmethod=diff scrollbind nowrap foldlevel=1

在每个显示同一文件不同版本的窗口中执行此操作。你将清楚地看到文件之间的差
异，而未更改的文本会被折叠。

更多细节参见 |fold-diff|。

*28.10* 选择哪种折叠方式？

所有这些可能性让你不知该选择哪种方法。遗憾的是，没有黄金法则。这里有一些提
示。

如果你正在编辑的语言有带折叠功能的语法文件，那可能是最好的选择。如果没有，
你可以尝试自己编写一个。这需要对搜索模式有很好的了解。这并不容易，但一旦完
成，你就不需要手动定义折叠了。

手动输入命令来折叠区域可以用于非结构化文本。然后使用 |:mkview| 命令来保存和
恢复你的折叠。

标记方法需要修改文件。如果你与其他人共享文件或必须遵守公司标准，你可能不被
允许添加标记。
   标记的主要优点是你可以精确地放置它们。这避免了在剪切和粘贴折叠时遗漏几
行。而且你可以添加关于折叠内容的注释。

按缩进折叠在许多文件中有效，但并不总是很好用。当你无法使用其他方法时可以使
用它。不过，它对于大纲编辑非常有用。那时你可以为每个嵌套级别专门使用一个
'shiftwidth'。

按表达式折叠几乎可以在任何结构化文本中创建折叠。指定起来相当简单，特别是当
折叠的开始和结束容易识别时。
   如果你使用 "expr" 方法定义折叠，但它们不完全符合你的要求，你可以切换到
"manual" 方法。这不会删除已定义的折叠。然后你可以手动删除或添加折叠。
