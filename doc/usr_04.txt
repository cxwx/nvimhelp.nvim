*04.1*	操作符和动作

在第 2 章你学了用 "x" 命令删除单个字符。并且使用计数: "4x" 删除四个字符。
   "dw" 命令删除一个单词。你可能认出了 "w" 命令是移动一个单词的命令。事实上，
"d" 命令后面可以跟任何动作命令，它会从当前位置删除到光标移动到的位置。
   例如，"4w" 命令将光标移过四个单词。"d4w" 命令删除四个单词。

	To err is human. To really foul up you need a computer. ~
			 ------------------>
				 d4w

	To err is human. you need a computer. ~

Vim 只删除到动作将光标移到的位置。这是因为 Vim 知道你可能不想删除单词的第一个
字符。如果你使用 "e" 命令移到单词末尾，Vim 会认为你想包括最后一个字符:

	To err is human. you need a computer. ~
			-------->
			   d2e

	To err is human. a computer. ~

光标下的字符是否包括在内取决于你用来移动到该字符的命令。参考手册称此为
"exclusive"（不包括）和 "inclusive"（包括）。

"$" 命令移到行尾。"d$" 命令从光标删除到行尾。这是一个 inclusive 动作，因此
行的最后一个字符包括在删除操作中:

	To err is human. a computer. ~
		       ------------>
			    d$

	To err is human ~

这里有一个模式: 操作符-动作。你先输入一个操作符命令。例如，"d" 是删除操作符。
然后你输入一个动作命令，如 "4l" 或 "w"。这样你就可以对任何你能移过的文本进行
操作。

*04.2*	修改文本

另一个操作符是 "c"，修改（change）。它的行为与 "d" 操作符类似，但会让你进入
插入模式。例如，"cw" 修改一个单词。或者更确切地说，它删除一个单词然后让你进入
插入模式。

	To err is human ~
	   ------->
	     c2wbe<Esc>

	To be human ~

这个 "c2wbe<Esc>" 包含以下部分:

	c	修改操作符
	2w	移动两个单词（它们被删除并开始插入模式）
	be	插入这段文本
	<Esc>	回到普通模式

你会注意到一些奇怪的地方: "human" 前面的空格没有被删除。有句话说对每个问题
都有一个简单、清楚但错误的答案。这里用 "cw" 命令的例子就是这种情况。c 操作符
的工作方式与 d 操作符完全一样，有一个例外: "cw"。它实际上的工作方式像 "ce"，
修改到单词末尾。因此单词后面的空格不被包括。这是一个追溯到旧 Vi 的例外。由于
很多人已经习惯了，这个不一致性在 Vim 中保留了下来。


更多修改

与 "dd" 删除整行一样，"cc" 修改整行。但它保留现有的缩进（前导空白）。

与 "d$" 删除到行尾一样，"c$" 修改到行尾。就像先用 "d$" 删除文本，然后用 "a"
开始插入模式并追加新文本。


快捷方式

一些操作符-动作命令因为用得太频繁，被赋予了单字母命令:

	x  代表  dl  （删除光标下的字符）
	X  代表  dh  （删除光标左边的字符）
	D  代表  d$  （删除到行尾）
	C  代表  c$  （修改到行尾）
	s  代表  cl  （修改一个字符）
	S  代表  cc  （修改整行）


计数放在哪里

命令 "3dw" 和 "d3w" 都是删除三个单词。如果你要严格区分，第一个命令 "3dw" 是
删除一个单词三次; 命令 "d3w" 是一次删除三个单词。这是一个没有区别的差异。你
实际上可以放两个计数。例如，"3d2w" 删除两个单词，重复三次，总共六个单词。


替换单个字符

"r" 命令不是一个操作符。它等待你输入一个字符，然后用它替换光标下的字符。你可以
用 "cl" 或 "s" 命令做同样的事，但用 "r" 你不需要按 <Esc> 来退出插入模式。

	there is somerhing grong here ~
	rT	     rt    rw

	There is something wrong here ~

对 "r" 使用计数会使多个字符被替换为同一个字符。例如:

	There is something wrong here ~
			   5rx

	There is something xxxxx here ~

要用换行符替换一个字符，使用 "r<Enter>"。这会删除一个字符并插入一个换行。在
这里使用计数只适用于被删除的字符数: "4r<Enter>" 用一个换行替换四个字符。

==============================================================================
*04.3*	重复修改

"." 命令是 Vim 中最简单却最强大的命令之一。它重复上一次修改。例如，假设你在
编辑一个 HTML 文件，想删除所有的 <B> 标签。你将光标定位在第一个 < 上，用命令
"df>" 删除 <B>。然后移到下一个 </B> 的 <，用 "." 命令删除它。"." 命令执行
上一个修改命令（在这种情况下是 "df>"）。要删除另一个标签，将光标定位在 < 上
并使用 "." 命令。

			      To <B>generate</B> a table of <B>contents ~
	f<   找到第一个 <     --->
	df>  删除到 >	       -->
	f<   找到下一个 <	   --------->
	.    重复 df>			    --->
	f<   找到下一个 <		       ------------->
	.    重复 df>					    -->

"." 命令适用于你做的所有修改，除了 "u"（撤销）、CTRL-R（重做）和以冒号（:）
开头的命令。

另一个例子: 你想把 "four" 这个词改成 "five"。它在你的文本中出现了多次。你可以
用下面的命令序列快速完成:

	/four<Enter>	找到第一个字符串 "four"
	cwfive<Esc>	将单词改为 "five"
	n		找到下一个 "four"
	.		重复修改为 "five"
	n		找到下一个 "four"
	.		重复修改
			等等。

*04.4*	可视模式

要删除简单的项目，操作符-动作的方式工作得很好。但通常不那么容易判断哪个命令能
移过你想改变的文本。这时你可以使用可视模式。

你通过按 "v" 启动可视模式。你将光标移到你要操作的文本上。在此过程中，文本会被
高亮显示。最后输入操作符命令。
   例如，要从一个单词的中间删除到另一个单词的中间:

		This is an examination sample of visual mode ~
				       ---------->
				 velllld

		This is an example of visual mode ~

这样做的时候你不需要精确计算要按多少次 "l" 才能到达正确的位置。当你按 "d" 时
可以立即看到什么文本会被删除。

如果在任何时候你决定不想对高亮的文本做任何操作，只需按 <Esc>，可视模式就会
停止而不做任何事情。


选择行

如果你想处理整行，使用 "V" 来启动可视模式。你会立即看到整行被高亮，而不需要
移动。当你左右移动时什么也不会改变。当你上下移动时，选择会以整行为单位扩展。
   例如，用 "Vjj" 选择三行:

			  +------------------------+
			  | text more text	   |
		       >> | more text more text    | |
	选中的行    >> | text text text	   | | Vjj
		       >> | text more		   | V
			  | more text more	   |
			  +------------------------+


选择块

如果你想操作一个矩形的字符块，使用 CTRL-V 来启动可视模式。这在处理表格时
非常有用。

		name		Q1	Q2	Q3
		pierre		123	455	234
		john		0	90	39
		steve		392	63	334

要删除中间的 "Q2" 列，将光标移到 "Q2" 的 "Q" 上。按 CTRL-V 启动块可视模式。
现在用 "3j" 将光标向下移三行，再用 "w" 移到下一个单词。你可以看到最后一列的
第一个字符也被包括了。要排除它，使用 "h"。现在按 "d"，中间的列就消失了。


到另一端

如果你在可视模式中选择了一些文本，然后发现你需要改变选择的另一端，使用 "o"
命令（提示: o 代表 other end，另一端）。光标会移到另一端，你可以移动光标来改变
选择的起点。再次按 "o" 带你回到另一端。

使用块选择时，你有四个角。"o" 只带你到对角线的另一个角。使用 "O" 移到同一行
的另一个角。

注意可视模式中的 "o" 和 "O" 与普通模式中的功能非常不同，普通模式中它们在光标
下方或上方打开一个新行。

*04.5*	移动文本

当你用 "d"、"x" 或其他命令删除内容时，文本会被保存。你可以用 "p" 命令把它
粘贴回来。（Vim 中称之为 put，放置。）
   看看这是怎么工作的。首先你删除整行，将光标放在要删除的行上，输入 "dd"。
然后将光标移到要放置该行的位置，使用 "p"（put）命令。该行被插入到光标下方的
行。

	a line		a line	      a line
	line 2	  dd	line 3	  p   line 3
	line 3			      line 2

因为你删除了整行，"p" 命令将文本行放在光标下方。如果你删除的是行的一部分（例如
一个单词），"p" 命令会把它放在光标之后。

	Some more boring try text to out commands. ~
			 ---->
			  dw

	Some more boring text to out commands. ~
			 ------->
			    welp

	Some more boring text to try out commands. ~


关于放置的更多内容

"P" 命令与 "p" 类似地放置文本，但在光标之前。当你用 "dd" 删除了整行时，"P"
会将它放回光标上方。当你用 "dw" 删除了单词时，"P" 会将它放回光标之前。

你可以重复放置任意多次。相同的文本会被使用。

你可以对 "p" 和 "P" 使用计数。文本会按指定的次数重复。因此 "dd" 然后 "3p"
会放三份同样被删除的行。


交换两个字符

经常在你打字时，你的手指比你的大脑快（或者反过来？）。结果是像把 "the" 打成
"teh" 这样的错误。Vim 使得纠正这类问题很容易。只需将光标放在 "teh" 的 e 上，
然后执行命令 "xp"。原理如下: "x" 删除字符 e 并将其放入寄存器。"p" 将文本放在
光标之后，即 h 的后面。

	teh     th     the ~
	 x       p

*04.6*	复制文本

要从一个地方复制文本到另一个地方，你可以先删除它，用 "u" 撤销删除，然后用 "p"
把它放到其他地方。有一个更简单的方法: 复制（yank）。"y" 操作符将文本复制到
寄存器中。然后可以用 "p" 命令粘贴它。
   Yank 只是 Vim 对复制的叫法。"c" 字母已经被修改操作符使用了，而 "y" 还可用。
把这个操作符叫做 "yank" 使得记住使用 "y" 键更容易。

因为 "y" 是一个操作符，你可以用 "yw" 来复制一个单词。计数照常可用。要复制两个
单词使用 "y2w"。例如:

	let sqr = LongVariable * ~
		 -------------->
		       y2w

	let sqr = LongVariable * ~
			       p

	let sqr = LongVariable * LongVariable ~

注意 "yw" 包括单词后面的空格。如果你不想要这个，使用 "ye"。

"yy" 命令复制整行，就像 "dd" 删除整行一样。

	a text line   yy	a text line	       a text line
	line 2			line 2		p      line 2
	last line		last line	       a text line
						       last line

"Y" 原本等同于 "复制整行"，与 "D" 是 "删除到行尾" 相对应。因此 "Y" 已被重新
映射为 "复制到行尾"，使其与 "D" 的行为保持一致。映射将在后续章节中介绍。

*04.7*	使用剪贴板

如果你使用的是 GUI 版本的 Vim（gvim），你可以在 "Edit" 菜单中找到 "Copy" 项。
先用可视模式选择一些文本，然后使用 Edit/Copy 菜单项。选中的文本现在被复制到
剪贴板。你可以在其他程序中粘贴这段文本。在 Vim 自身中也可以。

如果你已经从另一个应用程序复制了文本到剪贴板，你可以用 Edit/Paste 菜单项在
Vim 中粘贴它。这在普通模式和插入模式中都有效。在可视模式中，选中的文本会被
粘贴的文本替换。

"Cut" 菜单项在将文本放到剪贴板之前先删除它。"Copy"、"Cut" 和 "Paste" 项也
可以在弹出菜单中使用（当然，前提是有弹出菜单）。如果你的 Vim 有工具栏，你
也可以在那里找到这些项。

如果你不使用 GUI，或者你不喜欢使用菜单，你需要用另一种方式。你使用普通的
"y"（yank）和 "p"（put）命令，但在前面加上 "* （双引号星号）。要将一行复制到
剪贴板: >

	"*yy

要将剪贴板中的文本粘贴回来: >

	"*p

这只在支持剪贴板的 Vim 版本上有效。关于剪贴板的更多内容可以在 |09.3| 节和
这里找到: |clipboard|。

*04.8*	文本对象

如果光标在一个单词的中间，你想删除那个单词，你需要先移回单词开头才能执行
"dw"。有一个更简单的方式: "daw"。

	this is some example text. ~
		       daw

	this is some text. ~

"daw" 中的 "d" 是删除操作符。"aw" 是一个文本对象。提示: "aw" 代表
"A Word"（一个单词）。因此 "daw" 就是 "Delete A Word"（删除一个单词）。准确地
说，单词后面的空格也被删除了（或者如果在行尾则是单词前面的空格）。

使用文本对象是 Vim 中进行修改的第三种方式。我们已经有了操作符-动作和可视模式。
现在我们加上操作符-文本对象。
   它与操作符-动作非常相似，但不是操作光标移动前后之间的文本，而是将文本对象
作为一个整体来操作。不管光标在对象中的哪个位置。

要修改整个句子，使用 "cis"。看这段文本:

	Hello there.  This ~
	is an example.  Just ~
	some text. ~

移到第二行的开头，在 "is an" 上。现在使用 "cis":

	Hello there.    Just ~
	some text. ~

光标在第一行的空格之间。现在你输入新的句子 "Another line.":

	Hello there.  Another line.  Just ~
	some text. ~

"cis" 由 "c"（修改）操作符和 "is" 文本对象组成。"is" 代表 "Inner Sentence"
（内部句子）。还有 "as"（"A Sentence"，一个句子）对象。区别在于 "as" 包括句子
后面的空格而 "is" 不包括。如果你要删除一个句子，你同时也想删除空格，因此使用
"das"。如果你想输入新文本则空格可以保留，因此使用 "cis"。

你也可以在可视模式中使用文本对象。它会将文本对象包括在可视选择中。可视模式
继续，因此你可以多次执行。例如，用 "v" 开始可视模式并用 "as" 选择一个句子。
现在你可以重复 "as" 来包括更多句子。最后你用一个操作符对选中的句子做一些
操作。

你可以在这里找到文本对象的详细列表: |text-objects|。

*04.9*	替换模式

"R" 命令使 Vim 进入替换模式。在这个模式中，你输入的每个字符都会替换光标下的
字符。这一直持续到你输入 <Esc>。
   在这个例子中你在 "text" 的第一个 "t" 上开始替换模式:

	This is text. ~
		Rinteresting.<Esc>

	This is interesting. ~

你可能注意到这个命令用十二个字符替换了行中的 5 个字符。"R" 命令会在需要替换
的字符用完时自动扩展行。它不会继续到下一行。

你可以用 <Insert> 键在插入模式和替换模式之间切换。

当你使用 <BS>（退格）进行修正时，你会注意到旧的文本被恢复了。因此它的作用
就像撤销前一个输入的字符。

==============================================================================
*04.10*	总结

操作符、移动命令和文本对象给了你做大量组合的可能性。现在你知道了它们的工作
方式，你可以使用 N 个操作符配合 M 个移动命令来产生 N * M 个命令！

你可以在这里找到操作符列表: |operator|。

例如，还有很多其他方式来删除文本片段。以下是一些常见的:

x	删除光标下的字符（"dl" 的缩写）
X	删除光标前的字符（"dh" 的缩写）
D	从光标删除到行尾（"d$" 的缩写）
dw	从光标删除到下一个单词开头
db	从光标删除到前一个单词开头
diw	删除光标下的单词（不包括空格）
daw	删除光标下的单词（包括空格）
dG	删除到文件末尾
dgg	删除到文件开头

如果你用 "c" 代替 "d"，它们就变成修改命令。用 "y" 则是复制文本。依此类推。


还有一些不适合放在其他地方的常见修改命令:

	~	改变光标下字符的大小写，并将光标移到下一个字符。这不是一个
		操作符（除非设置了 'tildeop'），因此你不能将它与动作命令
		配合使用。它在可视模式中有效，会改变所有选中文本的大小写。

	I	将光标移到行的第一个非空白字符后开始插入模式。

	A	将光标移到行尾后开始插入模式。
