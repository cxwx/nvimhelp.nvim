Vim 中的俄语本地化和支持	   *russian* *Russian*

                                      输入 |gO| 查看目录。

==============================================================================
1. 简介							*russian-intro*

Vim 完美地支持俄语。你可以像输入和查看其他文本一样输入和查看俄语文本，
无需调整设置。

==============================================================================
2. 俄语键盘映射					       *russian-keymap*

要在语言之间切换，你可以使用系统自带的键盘切换器，或使用 Vim 发行版中
包含的俄语键盘映射之一。例如，
>
    :set keymap=russian-jcukenwin
<
在后一种情况下，即使没有系统俄语键盘或独立于系统级键盘设置，你也可以在
语言之间切换。参见 'keymap'。如果你选择后一种方式，也可以映射一个键来
切换键盘。参见 |:map|。

为了方便起见，在需要输入普通模式命令时避免切换键盘，你还可以设置
'langmap' 选项:
>
    :set langmap=ФИСВУАПРШОЛДЬТЩЗЙКЫЕГМЦЧНЯ;ABCDEFGHIJKLMNOPQRSTUVWXYZ,
    фисвуапршолдьтщзйкыегмцчня;abcdefghijklmnopqrstuvwxyz

你必须在一行中输入此命令，这里为了可读性进行了换行。

==============================================================================
3. 本地化							 *russian-l18n*

如果你希望使用翻译为俄语的消息、帮助文件、菜单和其他项目，你需要安装
RuVim 语言包，可从以下地址获取不同代码页的版本:

    https://www.sourceforge.net/projects/ruvim/

从 RuVim 项目下载存档后，将其解压到你的 $VIMRUNTIME 目录。我们建议使用
UTF-8 存档。

为了使用俄语文档，确保你已将 'helplang' 选项设置为 "ru"。

==============================================================================
4. 已知问题						       *russian-issues*

-- 如果你在 Win32 控制台中使用俄语消息翻译，那么 "vim --help"、
   "vim --version" 命令产生的输出以及 Win32 控制台窗口标题可能显示在
   错误的代码页中。此问题与 GNU gettext 库中的错误有关，可能在 gettext
   的未来版本中修复。
