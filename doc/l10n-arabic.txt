阿拉伯语支持 (选项和映射)		*Arabic*

这些功能由 Nadim Shaikli <nadim-at-arabeyes.org> 创建

最好在 VIM 的 GUI 中使用以下设置来查看此文件: >

	:set encoding=utf-8
	:set arabicshape


------------------------------------------------------------------------------
简介

阿拉伯语是一种要求较高的语言，需要许多特殊功能。字符是从右到左方向的，
应在屏幕上以这种方式显示 (即从右到左)。阿拉伯语还需要字符的形状变化
(shaping)，这意味着同一个字符根据其在单词中的相对位置 (词首、词中、词尾
或独立) 有不同的视觉形式。阿拉伯语还需要两种不同形式的组合，在某些情况下，
可以将最多两个字符叠加在另一个字符之上 (组合) 或将两个字符实际替换为一个
(合并)。最后，要正确显示阿拉伯语，不仅需要 ISO-8859-6 (U+0600-U+06FF)
字体，还需要表示形式 B (U+FE70-U+FEFF) 字体，这两者都是所谓的 ISO-10646-1
字体的子集。

命令、提示和帮助文件不是阿拉伯语的，因此用户界面保持标准的 Vi 界面。


------------------------------------------------------------------------------
亮点

o  编辑从左到右的文件与原始 Vim 中一样，没有变化。

o  在从右到左的窗口中查看和编辑文件。文件方向是按窗口设置的，因此可以
   同时在从右到左和从左到右模式下查看同一文件。

o  不需要具有从右到左功能的特殊终端。从右到左的变化完全独立于硬件。
   只需要阿拉伯语字体。

o  与原始 Vim 兼容。几乎所有功能都在从右到左模式下工作
   (可能存在错误)。

o  使用单个命令切换键盘映射和反向插入模式。

o  通过单个命令切换完整的阿拉伯语支持。

o  在阿拉伯语模式下，数字从左到右输入。输入非数字字符后，该字符将插入
   到最后一个数字的左侧。

o  在反向插入模式下的命令行上使用阿拉伯语键映射。

o  如果在支持双向 (Bidi) 的终端模拟器中启动 Vim，则可以实现正确的双向
   功能。


------------------------------------------------------------------------------
阿拉伯语字体						*arabicfonts*

Vim 需要等宽字体，有很多可用的。阿拉伯语需要 ISO-8859-6 以及表示形式 B
字体 (没有形式 B，阿拉伯语将 _无法_ 使用)。强烈建议用户搜索所谓的
'ISO-10646-1' 字体。在互联网上搜索或查看 www.arabeyes.org 以获取有关
在哪里获取必要阿拉伯语字体的更多信息。


------------------------------------------------------------------------------
字体安装

o  在 X Window 系统 (Unix/Linux) 上安装字体

   根据你的系统，将 your_ARABIC_FONT 文件复制到你选择的目录。切换到
   包含阿拉伯语字体的目录并执行以下命令:

     %	mkfontdir
     %	xset +fp path_name_of_arabic_fonts_directory


------------------------------------------------------------------------------
用法

在实际使用 Vim 中的阿拉伯语之前，需要考虑和调用一些设置。

o  设置阿拉伯语字体

   +  对于 Vim GUI，将 'guifont' 设置为你的阿拉伯语字体。这通过在 Vim
      窗口中输入以下命令完成。
>
		:set guifont=your_ARABIC_FONT
<
      注意: 字符串 'your_ARABIC_FONT' 用于表示完整的字体名称，
	    类似于 Linux/Unix 系统中使用的名称。
	    (例如 -misc-fixed-medium-r-normal--20-200-75-75-c-100-iso10646-1)

      你可以将 'guifont' 设置命令附加到 vimrc 文件中以获得相同的效果。
      换句话说，你可以将 ':set guifont=your_ARABIC_FONT' 加入 vimrc 文件。

   +  在 X Window 环境下，你也可以使用 '-fn your_ARABIC_FONT' 选项
      启动 Vim。

o  设置适当的字符编码
   要启用正确的阿拉伯语编码，需要添加以下命令,
>
		:set encoding=utf-8
<
   到你的 vimrc 文件 (强烈不建议在 Vim 窗口中手动输入此命令)。简而言之，
   将 ':set encoding=utf-8' 加入你的 vimrc 文件。

   尝试不使用 UTF-8 来使用阿拉伯语将导致以下警告消息,

								*W17*  >
     Arabic requires UTF-8, do ':set encoding=utf-8'

o  启用阿拉伯语设置 [快捷方式]

   为了简化和精简操作，你可以使用命令行选项调用 Vim,

     % vim -A my_utf8_arabic_file ...

   或在 Vim 中通过以下命令启用 'arabic'
>
		:set arabic
<
   上述两种可能的调用方式是建议用户使用的首选方式。除非启用了 'termbidi'
   设置，两个命令选项都会:

     1. 设置适当的键盘映射
     2. 启用删除单个组合配对字符
     3. 启用 rightleft    模式
     4. 启用 rightleftcmd 模式 (影响命令行)
     5. 启用 arabicshape  模式 (执行视觉字符变化)

   你也可以将命令附加到 vimrc 文件，只需加入 ':set arabic' 即可。

   你也可以通过以下方式禁用阿拉伯语支持
>
		:set noarabic
<
   这会重置命令启用的所有内容，而不触及全局设置，因为它们可能影响其他
   可能打开的缓冲区。简而言之，'noarabic' 命令:

     1. 重置为替代键盘映射
     2. 禁用删除单个组合配对字符
     3. 禁用 rightleft 模式

   注意: 'arabic' 命令考虑了 'termbidi' 以支持可能的外部双向 (bidi)
	 终端支持 ("mlterm" 即提供此类支持)。'termbidi' (如果可用) 优于
	 rightleft 支持，由于其提供的功能更丰富，因此首选。当 'termbidi'
	 启用时 'arabic' 只设置键盘映射。

	 在设置 'termbidi' 时为了窗口垂直隔离，可以使用 LTR 垂直分隔符
	 如 "l" 或 "\u{1d5a8}"。也可以通过将其颜色更改为前景色来隐藏它: >
		:set fillchars=vert:l
		:hi WinSeparator ctermbg=White
<	注意这是一个变通方法，不是正确的解决方案。

   另一方面，如果你想要更详细和明确，并且选择不使用 'arabic' 快捷命令，
   以下是所需的设置 (即如果你使用 ':set arabic' 可以跳过此部分) -

   +  阿拉伯语键盘映射激活

      要激活阿拉伯语键盘映射 (即将你的英语/拉丁键盘重新映射为看起来
      像标准阿拉伯语键盘)，将 'keymap' 选项设置为 "arabic"。这通过输入
>
		:set keymap=arabic
<
      在 VIM 窗口中完成。你也可以将 'keymap' 设置命令附加到 vimrc 文件。
      换句话说，你可以将 ':set keymap=arabic' 加入你的 vimrc 文件。

      要在阿拉伯语和默认映射 (英语) 之间切换键盘映射，建议用户在插入
      (或添加/替换) 模式下使用 'CTRL-^' 键。命令行会通过在插入模式旁
      显示 "Arabic" 字符串 (例如 -- INSERT Arabic --) 来显示你当前的
      映射。

   +  阿拉伯语组合配对字符的删除

      默认情况下 Vim 禁用了 'delcombine' 选项。此选项允许删除
      LAM_ALEF (LAA) 组合字符中的 ALEF 并保留 LAM (即恢复为将组合字符
      视为其自然的两个字符形式 -- 这也适用于 harakat 及其组合形式)。
      你可以通过输入以下命令启用此选项
>
		:set delcombine
<
      在 VIM 窗口中。你也可以将 'delcombine' 设置命令附加到 vimrc 文件。
      换句话说，你可以将 ':set delcombine' 加入你的 vimrc 文件。

   +  阿拉伯语从右到左模式

      默认情况下 VIM 以从左到右模式启动。'rightleft' 是允许更改窗口
      方向的命令 - 可以通过以下方式完成:

      - 在从左到右和从右到左模式之间切换通过 ':set rightleft' 和
	':set norightleft' 完成。

      - 在从左到右模式下，在命令行中输入 ':set rl'
	('rl' 是 rightleft 的缩写)。

      - 在 vimrc 文件中放置 ':set rl' 行以永久以从右到左模式启动 Vim。

   +  阿拉伯语从右到左命令行模式

      对于某些命令，编辑可以在从右到左模式下进行。目前这仅适用于搜索
      命令。

      这由 'rightleftcmd' 选项控制。默认值是 "search"，这意味着设置了
      'rightleft' 的窗口将在从右到左模式下编辑搜索命令。要禁用此行为,
>
		:set rightleftcmd=
<
      要重新启用搜索命令的从右到左编辑,
>
		:set rightleftcmd&
<
   +  阿拉伯语字符变形模式

      要激活阿拉伯语所需的视觉字符变化 (变形、组合、合并)，启用
      'arabicshape' 命令。这通过输入以下命令完成
>
		:set arabicshape
<
      在 VIM 窗口中。你也可以将 'arabicshape' 设置命令附加到 vimrc
      文件。换句话说，你可以将 ':set arabicshape' 加入你的 vimrc 文件。


------------------------------------------------------------------------------
键盘映射/键盘						*arabickeymap*

Vim 中使用的字符/字母编码是标准的 UTF-8。强烈不建议使用或尝试任何其他编码。

注意: UTF-8 是一种全面的编码，因此是唯一受支持 (和鼓励) 的阿拉伯语编码
      (所有其他专有编码都应被反对和不鼓励)。

o  键盘

   +  在插入/替换模式下 CTRL-^ 在阿拉伯语/拉丁模式之间切换

   +  键盘映射基于微软的阿拉伯语键盘布局 (阿拉伯世界的事实标准): >

  +---------------------------------------------------------------------+
  |!   |@   |#   |$   |%   |^   |&   |*   |(   |)   |_   |+   ||   |~  ّ |
  |1 ١ |2 ٢ |3 ٣ |4 ٤ |5 ٥ |6 ٦ |7 ٧ |8 ٨ |9 ٩ |0 ٠ |-   |=   |\   |` ذ |
  +---------------------------------------------------------------------+
       |Q  َ |W  ً |E  ُ |R  ٌ |T لإ |Y إ |U ` |I ÷ |O x |P ؛ |{ < |} > |
       |q ض |w ص |e ث |r ق |t ف |y غ |u ع |i ه |o خ |p ح |[ ج |] د |
       +-----------------------------------------------------------+
	 |A  ِ |S  ٍ |D [ |F ] |G لأ |H أ |J ـ |K ، |L / |:   |"   |
	 |a ش |s س |d ي |f ب |g ل |h ا |j ت |k ن |l م |; ك |' ط |
	 +------------------------------------------------------+
	   |Z ~ |X  ْ |C { |V } |B لآ |N آ |M ' |< , |> . |? ؟ |
	   |z ئ |x ء |c ؤ |v ر |b لا |n ى |m ة |, و |. ز |/ ظ |
	   +-------------------------------------------------+
<

------------------------------------------------------------------------------
限制

o  Vim 的 GUI 形式目前不支持双向性 (即在同一行中同时看到阿拉伯语和拉丁
   文字混合的能力)。


------------------------------------------------------------------------------
已知错误

有一个已知的小错误，

 1. 如果在 LAM (U+0644) 后插入 haraka (例如 Fatha (U+064E))，然后插入
    ALEF (U+0627)，由于夹在中间的 haraka，适当的组合不会发生，导致
    显示不正确。

    解决方法: 不要在 LAM 和 ALEF 组合之间包含 harakat。
	     一般来说，不要期望看到 harakat 和 LAM+ALEF 组合字符
	     (包括在两个字符之后输入的) 的正确视觉表示。需要注意的是
	     这个问题严格来说是视觉上的，意味着保存这样的文件将包含
	     所有适当的信息/编码 - 没有任何丢失。

没有其他已知的错误。
