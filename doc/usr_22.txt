				   找到要编辑的文件


文件可能在任何地方。那么如何找到它们？Vim 提供了多种方式来浏览目录树。有些命令
可以跳转到另一个文件中提到的文件。Vim 还会记住哪些文件曾经被编辑过。

*22.1*	文件浏览器

Vim 有一个插件，可以用来编辑目录。试试这个: >

	:edit .

通过自动命令和 Vim 脚本的魔力，窗口会被填入目录的内容。它看起来像这样（稍作
整理以适应 78 个字符宽度）: >

  " ==========================================================================
  " Netrw Directory Listing                                       (netrw v184)
  "   /path/to/vim/runtime/doc
  "   Sorted by      name
  "   Sort sequence: [\/]$,*,\(\.bak\|\~\|\.o\|\.h\|\.info\|\.swp\)[*@]\=$
  "   Quick Help: <F1>:help -:go up dir D:delete R:rename s:sort-by x:special
  " ==========================================================================
  ../
  ./
  check/
  Makefile
  autocmd.txt
  change.txt
  eval.txt
  filetype.txt
  help.txt.info
<

你可以看到这些内容:

1. 浏览工具的名称和版本号
2. 浏览目录的名称
3. 排序方式（可以按名称、时间或大小）
4. 名称的排序规则（目录优先，然后按扩展名等）
5. 如何获取帮助（<F1> 键），以及可用命令的简要列表
6. 文件列表，包括 "../"（列出父目录）。

如果你启用了语法高亮，不同部分会被高亮显示，使得更容易辨认。

你可以使用普通模式的 Vim 命令在文本中移动。例如，将光标移到一个文件名上并按
<Enter>；你就会编辑那个文件。要回到浏览器，再次使用 ":edit ." 或使用
":Explore"。CTRL-O 也可以。

试试在光标位于目录名上时按 <Enter>。结果是文件浏览器进入那个目录并显示其中的
项目。在第一个目录 "../" 上按 <Enter> 会上移一级。按 "-" 也一样，不需要先移到
"../" 项目上。

你可以按 <F1> 获取 netrw 文件浏览器中可以做的事情的帮助。你会看到:
>
 QUICK HELP						netrw-quickhelp
                       (Use ctrl-] to select a topic)
	Intro to Browsing...............................netrw-intro-browse
	  Quick Reference: Maps.........................netrw-quickmap
	  Quick Reference: Commands.....................netrw-browse-cmds
<
<F1> 键将你带到 netrw 目录浏览内容帮助页面。它是一个普通的帮助页面；使用通常的
|CTRL-]| 跳转到标签帮助项目，用 |CTRL-O| 跳回。所以，如果你在 |netrw-quickmap|
上按 CTRL-]，你会跳转到:
>
				netrw-quickmap  netrw-quickmaps
 QUICK REFERENCE: MAPS				netrw-browse-maps

	  ---			-----------------			----
	  Map			Quick Explanation			Link
	  ---			-----------------			----
	 <F1>	Causes Netrw to issue help
	 <cr>	Netrw will enter the directory or read the file      netrw-cr
	 <del>	Netrw will attempt to remove the file/directory      netrw-del
<	 (etc.)

要选择文件进行显示和编辑（光标在文件名上）:
>
	   o	在新浏览器窗口中打开光标下的文件/目录。    netrw-o
		使用水平分割。
	   O	获取光标指定的文件                          netrw-O
	   p	预览文件                                     netrw-p
	   P	在之前使用的窗口中浏览                       netrw-P
	   v	在新浏览器窗口中打开光标下的文件/目录。    netrw-v
		使用垂直分割。
<
以下普通模式命令可用于控制浏览器显示:
>
	   i	在简洁、详细、宽和树形列表之间循环           netrw-i
	   r	反转排序顺序                                 netrw-r
	   s	选择排序方式: 按名称、时间或文件大小         netrw-s
<
额外普通模式命令示例:
>
	   cd	将浏览目录设为当前目录                       netrw-cd
	   D	尝试删除文件/目录                            netrw-D
	   gb	转到之前的书签目录                           netrw-gb
	   mb	将当前目录加入书签                           netrw-mb
	   R	重命名指定的文件/目录                        netrw-R
<
也可以使用命令模式；同样只是示例:
>
     :Explore[!]  [dir] 浏览当前文件所在目录.........netrw-explore
     :Hexplore[!] [dir] 水平分割并浏览...............netrw-explore
<
netrw 浏览器不仅限于本地机器；你可以使用 URL，如: >

	:Explore ftp://somehost/path/to/dir/
	:e scp://somehost/path/to/dir/
<
	备注: 末尾的 "/" 很重要。

更多信息请参见 |netrw-browse|。

*22.2*	当前目录

就像 shell 一样，Vim 有当前目录的概念。假设你在主目录中，想编辑
"VeryLongFileName" 目录中的几个文件。你可以这样做: >

	:edit VeryLongFileName/file1.txt
	:edit VeryLongFileName/file2.txt
	:edit VeryLongFileName/file3.txt

为了减少输入，可以这样做: >

	:cd VeryLongFileName
	:edit file1.txt
	:edit file2.txt
	:edit file3.txt

":cd" 命令改变当前目录。你可以用 ":pwd" 命令查看当前目录: >

	:pwd
	/home/Bram/VeryLongFileName

Vim 记住你上次使用的目录。用 "cd -" 回到那里。例如: >

	:pwd
	/home/Bram/VeryLongFileName
	:cd /etc
	:pwd
	/etc
	:cd -
	:pwd
	/home/Bram/VeryLongFileName
	:cd -
	:pwd
	/etc


窗口局部目录

当你分割一个窗口时，两个窗口使用相同的当前目录。如果你想在新窗口中编辑其他地方
的文件，你可以让它使用不同的目录，而不改变另一个窗口的当前目录。这叫做局部目
录。 >

	:pwd
	/home/Bram/VeryLongFileName
	:split
	:lcd /etc
	:pwd
	/etc
	CTRL-W w
	:pwd
	/home/Bram/VeryLongFileName

只要没有使用 `:lcd` 命令，所有窗口共享同一个当前目录。在一个窗口中执行 `:cd`
命令也会改变另一个窗口的当前目录。
   对于使用过 `:lcd` 的窗口，会记住一个不同的当前目录。在其他窗口中使用 `:cd`
或 `:lcd` 不会改变它。
   在使用不同当前目录的窗口中使用 `:cd` 命令时，它会回到使用共享目录。


标签页局部目录

当你打开一个新的标签页时，它使用之前标签页中窗口的目录（即新标签页从哪里打开
的）。你可以使用 `:tcd` 命令改变当前标签页的目录。标签页中的所有窗口共享这个目
录，但设置了窗口局部目录的窗口除外。在这个标签页中打开的任何新窗口都会使用这个
目录作为当前工作目录。在一个标签页中使用 `:cd` 命令不会改变有标签页局部目录的标
签页的工作目录。当使用 `:cd` 命令在一个标签页中改变全局工作目录时，它也会改变当
前标签页的工作目录。

*22.3*	查找文件

你正在编辑一个 C 程序，其中包含这一行:

	#include "inits.h" ~

你想看看 "inits.h" 文件里有什么。将光标移到文件名上并输入: >

	gf

Vim 会找到该文件并编辑它。
   如果文件不在当前目录怎么办？Vim 会使用 'path' 选项来查找文件。这个选项是一个
目录名称列表，指定在哪里查找你的文件。
   假设你的头文件在 "c:/prog/include" 中。这个命令会将它添加到 'path' 选项: >

	:set path+=c:/prog/include

这个目录是绝对路径。无论你在哪里，它都是同一个位置。如果你的文件在当前文件下方
的子目录中呢？那你可以指定相对路径名。这以一个点开头:
>
	:set path+=./proto

这告诉 Vim 在使用 "gf" 的文件所在目录下面的 "proto" 目录中查找。因此在
"inits.h" 上使用 "gf" 会让 Vim 从该文件所在目录开始查找 "proto/inits.h"。
   不带 "./"，即 "proto"，Vim 会在当前目录下的 "proto" 目录中查找。而当前目录
可能不是你正在编辑的文件所在的目录。

'path' 选项允许以更多方式指定在哪些目录中搜索文件。请参见 'path' 选项的帮助。
   'isfname' 选项用于决定哪些字符包含在文件名中，哪些不包含（例如上面例子中的
" 字符）。

当你知道文件名，但文件中找不到时，你可以输入: >

	:find inits.h

Vim 会使用 'path' 选项来尝试定位文件。这和 ":edit" 命令一样，只是多了对 'path'
的使用。

要在新窗口中打开找到的文件，使用 CTRL-W f 而不是 "gf"，或者用 ":sfind" 而不是
":find"。


直接启动 Vim 编辑 'path' 中某个文件的好方法: >

	vim "+find stdio.h"

这会在你的 'path' 值中查找文件 "stdio.h"。引号是必需的，以确保它是一个参数
|-+c|。

*22.4*	缓冲区列表

Vim 编辑器使用术语 "缓冲区" 来描述正在编辑的文件。实际上，缓冲区是你编辑的文件
的副本。当你完成对缓冲区的修改后，你将缓冲区的内容写入文件。缓冲区不仅包含文件
内容，还包含所有的标记、设置和其他相关信息。


隐藏缓冲区

假设你正在编辑文件 one.txt，需要编辑文件 two.txt。你可以简单地使用
":edit two.txt"，但因为你对 one.txt 做了修改，这不行。你也不想现在就写入
one.txt。Vim 有一个解决方案: >

	:hide edit two.txt

缓冲区 "one.txt" 从屏幕上消失，但 Vim 仍然知道你在编辑这个缓冲区，所以它保持
修改过的文本。这叫做隐藏缓冲区: 缓冲区包含文本，但你看不到它。
   ":hide" 的参数是另一个命令。":hide" 使那个命令表现得好像 'hidden' 选项被设置
了一样。你也可以自己设置这个选项。效果是当任何缓冲区被放弃时，它变成隐藏的。
   小心！当你有包含修改的隐藏缓冲区时，不要在没有确保所有缓冲区都已保存的情况
下退出 Vim。


非活动缓冲区

当一个缓冲区被使用过一次后，Vim 会记住它的一些信息。当它不在任何窗口中显示也不
是隐藏的时，它仍然在缓冲区列表中。这叫做非活动缓冲区。概览:

	活动		在窗口中显示，文本已加载。
	隐藏		不在窗口中，文本已加载。
	非活动		不在窗口中，没有加载文本。

非活动缓冲区被记住，因为 Vim 保留了关于它们的信息，如标记。记住文件名也很有用，
这样你可以看到编辑过哪些文件，并再次编辑它们。


列出缓冲区

用这个命令查看缓冲区列表: >

	:buffers

有一个功能相同的命令，名字不那么明显，但输入起来要短得多: >

	:ls

输出可能像这样:

  1 #h   "help.txt"			line 62 ~
  2 %a + "usr_21.txt"			line 1 ~
  3      "usr_toc.txt"			line 1 ~

第一列是缓冲区编号。你可以用它来编辑缓冲区而不必输入名字，见下文。
   在缓冲区编号之后是标志。然后是文件名和光标上次所在的行号。
   可能出现的标志是（从左到右）:

	u	缓冲区是未列出的 |unlisted-buffer|。
	 %	当前缓冲区。
	 #	备选缓冲区。
	  a	缓冲区已加载并显示。
	  h	缓冲区已加载但隐藏。
	   =	缓冲区是只读的。
	   -	缓冲区不可修改，'modifiable' 选项关闭。
	    +	缓冲区已被修改。


编辑缓冲区

你可以通过编号来编辑缓冲区。这避免了输入文件名: >

	:buffer 2

但知道编号的唯一方法是查看缓冲区列表。你也可以使用名称或名称的一部分: >

	:buffer help

Vim 会为你输入的名称找到最佳匹配。如果只有一个缓冲区匹配该名称，它就会被使用。
在这个例子中就是 "help.txt"。
   要在新窗口中打开一个缓冲区: >

	:sbuffer 3

这也适用于名称。


使用缓冲区列表

你可以用这些命令在缓冲区列表中移动:

	:bnext		转到下一个缓冲区
	:bprevious	转到上一个缓冲区
	:bfirst		转到第一个缓冲区
	:blast		转到最后一个缓冲区

要从列表中删除一个缓冲区，使用这个命令: >

	:bdelete 3

同样，这也适用于名称。
   如果你删除的是活动缓冲区（在窗口中可见），那个窗口将被关闭。如果你删除的是
当前缓冲区，当前窗口将被关闭。如果它是最后一个窗口，Vim 会找另一个缓冲区来编
辑。你不能什么都不编辑！

	备注: 即使用 ":bdelete" 删除缓冲区后，Vim 仍然记得它。它实际上变成了
	"未列出" 的，不再出现在 ":buffers" 的列表中。":buffers!" 命令会列出未
	列出的缓冲区（是的，Vim 可以做到不可能的事）。要让 Vim 真正忘记一个
	缓冲区，使用 ":bwipe"。另请参见 'buflisted' 选项。
