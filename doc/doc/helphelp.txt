帮助标签约定					*help-context*

获取特定帮助：可以通过给 |:help| 命令一个参数来直接跳转到你想要帮助的内容。
在前面添加前缀以指定上下文： >

	  什么			前缀    示例
      普通模式命令		   :help x
      可视模式命令	  v_	   :help v_u
      插入模式命令	  i_	   :help i_<Esc>
      命令行命令	  :	   :help :quit
      命令行编辑	  c_	   :help c_<Del>
      Vim 命令参数	  -	   :help -r
      选项		  '	   :help 'textwidth'
      正则表达式	  /	   :help /[

更多上下文和解释见 |help-summary|。
帮助语法的解释见 |notation|。

搜索帮助

输入 ":help word"，然后按 CTRL-D 查看匹配 "word" 的帮助条目。或者
使用 ":helpgrep word"。|:helpgrep|

表示法						*notation*

当使用语法高亮阅读本文时，非字面输入的文本通常用 Special 组高亮显示。
这些是 []、{} 和 <> 中的项目，以及 CTRL-X。

请注意 Vim 在命令中使用所有可能的字符。有时 []、{} 和 <> 是你输入内容的
一部分，上下文会说清楚这一点。


- []            方括号中的字符是可选的。

                                                    *count* *[count]*
- [count]       一个可选的数字，可以放在命令前面以倍增
                或迭代该命令。如果没有给出数字，则使用计数 1，
                除非另有说明。请注意，在本手册中，[count] 不在
                命令描述中提及，而仅在解释中提及。这样做是为了
                使命令更容易查找。如果 'showcmd' 选项打开，
                （部分）输入的计数会显示在窗口底部。你可以使用
                <Del> 来擦除最后一位数字 (|N<Del>|)。

                                                        *[quotex]*
- ["x]          一个可选的寄存器指定，用于存放文本。
                见 |registers|。x 是 'a' 到 'z' 或 'A' 到 'Z'
                之间的单个字符，在某些情况下（对于放置命令）
                是 '0' 到 '9'、'%'、'#' 或其他字符。大写和
                小写字母指定相同的寄存器，但小写字母用于覆盖
                先前的寄存器内容，而大写字母用于追加到先前的
                寄存器内容。不带 ""x" 或带 """" 时，存储的文本
                放入无名寄存器。

                                                        *{}*
- {}            花括号表示命令中必须出现但可以取不同值的部分。
                Vim 和 Vi 之间的差异也用花括号给出
                （从上下文可以看出）。

                                                        *{char1-char2}*
- {char1-char2} 从 char1 到 char2 范围内的单个字符。
                例如：{a-z} 是一个小写字母。可以连接多个范围。
                例如，{a-zA-Z0-9} 是任何字母数字字符。

                                                *{motion}* *movement*
- {motion}      一个移动光标的命令。这些在 |motion.txt| 中解释。
                - 示例：
                  - `w`           到下一个单词的开头
                  - `b`           到当前单词的开头
                  - `4j`          向下四行
                  - `/The<CR>`    到下一个 "The" 出现的地方
                - 这在 |operator| 命令后使用，以移过要操作的文本。
                  - 如果移动包含计数且操作符也有计数，则两个
                    计数相乘。例如："2d3w" 删除六个单词。
                  - 移动可以是向后的，例如 "db" 删除到单词开头。
                  - 移动也可以是鼠标点击。但不是每个终端都
                    支持鼠标。
                  - 可以使用 ":omap" 命令在操作符等待时映射字符。
                  - Ex 命令可以用来移动光标。这可以用来调用
                    执行复杂移动的函数。移动始终是逐字符排他的，
                    无论使用什么 ":" 命令。这意味着不可能在不
                    包含换行符的情况下包含行的最后一个字符
                    （除非设置了 'virtualedit'）。如果 Ex 命令
                    在操作符起始位置之前更改文本或跳转到另一个
                    缓冲区，则结果不可预测。可以更改后面的文本。
                    如果当前缓冲区未卸载，则可以跳转到另一个
                    缓冲区。

                                                        *{Visual}*
- {Visual}      一个选定的文本区域。它由 "v"、"V" 或 CTRL-V 命令
                启动，然后可以使用任何光标移动命令来更改选定
                文本的末端。
                这在 |operator| 命令之前使用，以高亮要操作的文本。
                见 |Visual-mode|。

                                                        *<character>*
- <character>   下表中的特殊字符，可选带修饰符，或带修饰符的
                单个 ASCII 字符。

                                                        *'character'*
- 'c'           单个 ASCII 字符。

                                                        *CTRL-{char}*
- CTRL-{char}   作为控制字符输入的 {char}；即按住 CTRL 键的同时
                输入 {char}。{char} 的大小写被忽略；因此 CTRL-A
                和 CTRL-a 是等价的。但在某些终端和环境中，使用
                SHIFT 键会产生不同的代码（例如 CTRL-SHIFT-a）；
                在这些环境中使用 SHIFT 键将不会触发如 CTRL-A
                之类的命令。

                                                        *'option'*
- 'option'      一个可以设置值的选项或参数，用单引号括起来。
                见 |options|。

                                                        *quotecommandquote*
- "command"     你可以输入的命令引用在双引号中。
- `command`     新式命令，用以区别于其他引用的文本和字符串。

帮助命令						*online-help*

			*help* *<Help>* *:h* *:help* *<F1>* *i_<F1>* *i_<Help>*
<Help>		或
:h[elp]			打开一个窗口并以只读模式显示帮助文件。
			如果已经有一个帮助窗口打开，则使用那个窗口。
			否则，如果当前窗口使用全屏宽度或至少 80 个
			字符宽，帮助窗口将出现在当前窗口的正上方。
			否则新窗口放在最顶部。
			'helplang' 选项用于选择语言，如果主帮助文件
			有多种语言可用。

			输入 |gO| 查看目录。

							*:help!*
:h[elp]!		以 DWIM（"按我的意思做"）方式从光标处的 |WORD|
			猜测帮助标签：使用各种启发式方法修剪标点符号，
			直到找到有效的帮助标签。

			例如，将光标移动到此代码中的任何位置，
			然后运行 `:help!`： >

				local v = vim.version.parse(vim.system({'foo'}):wait().stdout)
<
			然后与 `:exe 'help' expand('<cword>')` 比较。

						*{subject}* *E149* *E661*
:h[elp] {subject}	类似 ":help"，另外跳转到标签 {subject}。
			例如： >
				:help options

<			{subject} 可以包含通配符如 "*"、"?" 和
			"[a-z]"：
			   :help z?	跳转到任何 "z" 命令的帮助
			   :help z.	跳转到 "z." 的帮助
			但当标签存在时会按字面意思处理：
			   :help :?	跳转到 ":?" 的帮助

			如果没有模式的完全匹配，或者有多个匹配，
			则使用"最佳"匹配。使用复杂的算法来决定
			哪个匹配比另一个更好。计算中考虑以下因素：
			- 大小写相同的匹配比大小写不同的匹配好得多。
			- 在非字母数字字符之后开始的匹配比在单词
			  中间的匹配好。
			- 在标签开头或附近的匹配比更后面的匹配好。
			- 匹配的字母数字字符越多越好。
			- 匹配长度越短越好。

			'helplang' 选项用于选择语言，如果 {subject}
			有多种语言可用。
			要在特定语言中查找标签，附加 "@ab"，
			其中 "ab" 是两个字母的语言代码。见
			|help-translated|。

			请注意，你给出的 {subject} 越长，找到的匹配
			就越少。你可以使用命令行补全来了解这一切
			如何工作（在 ":help subject" 之后输入 CTRL-D
			|c_CTRL-D|）。
			如果有多个匹配，你可以通过按 CTRL-D 列出它们。
			示例： >
				:help cont<Ctrl-D>

<			你可以输入以下内容来代替输入 ":help CTRL-V"
			来搜索 CTRL-V 的帮助： >
				:help ^V
<			这也适用于其他字符的组合，例如在插入模式下
			查找 CTRL-V 的帮助： >
				:help i^V
<
			也可以先执行 ":help"，然后在帮助窗口中
			使用 ":tag {pattern}"。然后可以使用
			":tnext" 命令跳转到其他匹配，
			"tselect" 列出匹配并选择一个。 >
				:help index
				:tselect /.*mode

<			当没有参数时，你将看到 "help" 的匹配，
			以避免列出所有可能的匹配（那会非常慢）。
			显示的匹配数限制为 300 个。

			`:help` 命令后面可以跟 '|' 和另一个命令，
			但你不需要在帮助命令中转义 '|'。所以这两个
			都有效： >
				:help |
				:help k| only
<			请注意 '|' 前面的空格被视为 ":help" 参数的
			一部分。
			你也可以使用 <NL> 或 <CR> 将帮助命令与后续
			命令分开。你需要先输入 CTRL-V 来插入 <NL>
			或 <CR>。示例： >
				:help so<C-V><CR>only
<

:h[elp]! {subject}	类似 ":help"，但优先选择与当前文件相同的
			|help-translated| 语言的标签。

			与没有 {subject} 的 |:help!| 无关。

							*:helpc* *:helpclose*
:helpc[lose]		关闭一个帮助窗口（如果有的话）。
			Vim 将尝试恢复窗口布局（包括光标位置）
			到最初打开帮助窗口之前的相同布局。
			这可能会触发多个自动命令。

							*:helpg* *:helpgrep*
:helpg[rep] {pattern}[@xx]
			搜索所有帮助文本文件，并列出 {pattern} 匹配
			的行。跳转到第一个匹配。
			可选的 [@xx] 指定只查找 "xx" 语言的匹配。
			你可以使用 |quickfix| 命令在匹配之间导航，
			例如 |:cnext| 跳转到下一个。或使用 |:cwindow|
			在快速修复窗口中获取匹配列表。
			{pattern} 用作 Vim 正则表达式 |pattern|。
			不使用 'ignorecase'，添加 "\c" 以忽略大小写。
			区分大小写搜索的示例： >
				:helpgrep Uganda
<			忽略大小写搜索的示例： >
				:helpgrep uganda\c
<			搜索法语帮助的示例： >
				:helpgrep backspace@fr
<			模式不支持跨行匹配，必须在一行内匹配。
			你可以使用 |:grep| 代替，但那样你需要以
			复杂的方式获取帮助文件列表。
			不能跟其他命令，所有内容都用作模式的一部分。
			但你可以在需要时使用 |:execute|。
			压缩的帮助文件不会被搜索（Fedora 压缩了
			帮助文件）。

							*:lh* *:lhelpgrep*
:lh[elpgrep] {pattern}[@xx]
			与 ":helpgrep" 相同，但使用位置列表而不是
			快速修复列表。如果帮助窗口已打开，则使用
			该窗口的位置列表。否则，打开一个新的帮助
			窗口并设置该窗口的位置列表。当前窗口的
			位置列表不会被更改。

							*:exu* *:exusage*
:exu[sage]		显示 Ex 命令的帮助。添加以模拟 Nvi 命令。

							*:viu* *:viusage*
:viu[sage]		显示普通模式命令的帮助。添加以模拟 Nvi 命令。

当没有给 |:help| 参数时，将打开 'helpfile' 选项给出的文件。
否则在 'runtimepath' 选项指定的目录中的所有 "doc/tags" 文件中
搜索指定的标签。

如果你想在当前窗口中打开帮助，请参阅此技巧：
|help-curwin|。

帮助窗口的初始高度可以用 'helpheight' 选项设置（默认 20）。
						*help-buffer-options*
创建帮助缓冲区时，会设置多个本地选项以确保帮助文本按预期显示：
    'iskeyword'		几乎所有 ASCII 字符，除了 ' '、"*"、'"' 和 '|'
    'foldmethod'	"manual"
    'tabstop'		8
    'arabic'		关闭
    'binary'		关闭
    'buflisted'		关闭
    'cursorbind'	关闭
    'diff'		关闭
    'foldenable'	关闭
    'list'		关闭
    'modifiable'	关闭
    'number'		关闭
    'relativenumber'	关闭
    'rightleft'		关闭
    'scrollbind'	关闭
    'spell'		关闭

使用标签跳转到特定主题。这可以通过两种方式完成：
- 在命令或选项名称上使用 "CTRL-]" 命令。
  这仅在标签是关键字时有效。"<C-Leftmouse>" 和
  "g<LeftMouse>" 的工作方式与 "CTRL-]" 相同。
- 使用 ":ta {subject}" 命令。这也适用于非关键字字符。

使用 CTRL-T 或 CTRL-O 跳回。
使用 ":q" 关闭帮助窗口。
使用 `g==` 执行当前 Lua/Vimscript 代码块。

如果你查找的项有多个匹配，以下是跳转到每个匹配的方法：
1. 打开帮助窗口
2. 使用 ":tag" 命令，在标签前加斜杠。例如： >
	:tag /min
3. 使用 ":tnext" 跳转到下一个匹配标签。

可以为插件和其他项目添加帮助文件。你不需要为此更改分发的帮助文件。
见 |add-local-help|。

要编写本地帮助文件，见 |write-local-help|。

请注意，本地帮助文件的标题行会自动添加到 "help.txt" 帮助文件的
"LOCAL ADDITIONS" 部分 |local-additions|。这是在 Vim 中查看文件时完成的，
文件本身不会被更改。这是通过遍历所有帮助文件并获取每个文件的第一行来完成的。
$VIMRUNTIME/doc 中的文件被跳过。

					*:helpt* *:helptags*
			*E150* *E151* *E152* *E153* *E154* *E670* *E856*
:helpt[ags] [++t] {dir}
			为目录 {dir} 生成帮助标签文件。
			当 {dir} 是 ALL 时，将使用 'runtimepath' 中
			所有的 "doc" 目录。

			扫描目录和子目录中所有 "*.txt" 和 "*.??x" 文件
			的星号之间的帮助标签定义。"*.??x" 文件用于
			翻译文档，它们生成 "tags-??" 文件，见
			|help-translated|。生成的标签文件是排序的。
			有重复时会给出错误消息。
			已有的标签文件会被静默覆盖。

			可选的 "++t" 参数强制添加 "help-tags" 标签。
			当 {dir} 等于 $VIMRUNTIME/doc 时也会这样做。

			要重建运行时目录中的帮助标签
			（需要那里的写权限）： >
				:helptags $VIMRUNTIME/doc
<

翻译的帮助文件					*help-translated*

可以在原始英文帮助文件旁边添加翻译的帮助文件。Vim 将在
'runtimepath' 中的 "doc" 目录中搜索所有帮助。

目前可用的翻译有：
	中文   - 多位作者
	法语   - 由 David Blanchet 翻译
	意大利语 - 由 Antonio Colombo 翻译
	日语   - 多位作者
	波兰语 - 由 Mikolaj Machowski 翻译
	俄语   - 由 Vassily Ragosin 翻译
见 Vim 网站查找它们：https://www.vim.org/translations.php

一套翻译的帮助文件包含这些文件：

	help.abx
	howto.abx
	...
	tags-ab

"ab" 是两个字母的语言代码。因此对于意大利语，名称是：

	help.itx
	howto.itx
	...
	tags-it

'helplang' 选项可以设置为首选语言。默认值根据环境设置。
Vim 将首先尝试在首选语言中查找匹配的标签。找不到时使用英语。

要在特定语言中查找标签，在标签后附加 "@ab"，其中 "ab" 是两个
字母的语言代码。示例： >
	:he user-manual@it
	:he user-manual@en
第一个找到意大利语用户手册，即使 'helplang' 为空。
第二个找到英语用户手册，即使 'helplang' 设置为 "it"。

使用 ":help" 命令的命令行补全时，"@en" 扩展仅在标签存在多种
语言时显示。当标签仅存在英语时省略 "@en"。当第一个候选有
"@ab" 扩展并且它匹配 'helplang' 中的第一种语言时，也省略 "@ab"。

在非英语帮助文件中使用 |CTRL-]| 或 ":help!" 时，Vim 将尝试在
相同语言中查找标签。如果找不到，则使用 'helplang' 来选择语言。

帮助文件必须使用 latin1 或 utf-8 编码。当在第一行发现非 ASCII 字符
时，Vim 假定编码为 utf-8。因此你必须翻译带有 "For Vim version" 的
标题。

同一目录中同一语言的帮助文件必须使用相同的编码。你可以对不同
语言使用不同的编码，也可以对同一语言但在不同目录中的帮助文件
使用不同的编码。

给翻译者的提示：
- 不要翻译标签。这使得可以使用 'helplang' 来指定首选语言。
  你可以添加你的语言的新标签。
- 当你不翻译文件的一部分时，使用 "tag@en" 表示法向英语版本添加标签。
- 将所有文件和标签文件打包以供下载。
  用户可以将其放入 "doc" 目录之一并开始使用。
  向开发团队报告，这样他们可以在 www.vim.org 上添加链接。
- 使用 |:helptags| 命令生成标签文件。它会找到指定目录中的
  所有语言。

编写帮助文件					*help-writing*

为了使用方便，插件的 Vim 帮助文件应遵循标准 Vim 帮助文件的格式，
第一行除外。如果你正在编写新的帮助文件，最好复制一个现有文件
并将其用作模板。

帮助文件的第一行应具有以下格式： >

	*plugin_name.txt*	{插件的简短描述}

第一个字段是帮助标签，":help plugin_name" 将跳转到那里。行的
其余部分，在 Tab 之后，简要描述插件用途。这将显示在主帮助文件
的 "LOCAL ADDITIONS" 部分。在那里检查它是否正确显示：|local-additions|。

如果你想添加版本号或最后修改日期，将其放在第二行，右对齐。

在帮助文件底部，放置一个 Vim 模式行来设置 'textwidth' 和
'tabstop' 选项以及 'filetype' 为 "help"。永远不要在这种模式行
中设置全局选项，那可能会产生不良后果。


标签

要定义帮助标签，将名称放在星号之间（"*tag-name*"）。标签名称
应与所有 Vim 帮助标签名称不同，最好以 Vim 插件的名称开头。
标签名称通常在行上右对齐。

引用现有帮助标签并创建热链接时，将名称放在两个竖线（"|"）之间，
例如 |help-writing|。

在帮助文件中引用 Vim 选项时，将选项名称放在两个单引号之间，
例如 'statusline'

引用任何其他技术术语或符号（如文件名或函数参数）时，用反引号
括起来，例如 `~/.path/to/init.vim`。这将其渲染为 "行内" 代码
（与 "代码块" |help-codeblock| 相对）。


高亮

要定义列标题，在行尾使用波浪字符，前面带空格。这将以不同颜色
高亮列标题。例如

列标题 ~

要在帮助文件中分隔各节，在从第一列开始的行中放置一系列 '='
字符。节分隔线以不同方式高亮。

							      *help-codeblock*
要逐字引用 ex 命令块，在块之前的行尾放置大于号 (>) 字符，
在块之后的行的第一个非空白处放置小于号 (<) 字符。从第 1 列
开始的任何行也会隐式停止 ex 命令块。例如 >
	function Example_Func()
	  echo "Example"
	endfunction
<
要为代码块启用语法高亮，在大于号 (>) 字符后放置语言名称注释
（例如 "vim"）。例如 >vim
	function Example_Func()
	  echo "Example"
	endfunction
<
						*help-notation*
以下内容在 Vim 帮助文件中以不同方式高亮：
  - 以 <> 表示法表示的特殊键名，如 <PageDown>，或
    Ctrl 字符如 CTRL-X
  - {大括号} 之间的任何内容，例如 {lhs} 和 {rhs}

"Note"、"Notes" 及类似单词会自动获得独特的高亮。还有这些：
	Todo	待办事项
	Error	错误内容

你可以在 $VIMRUNTIME/syntax/help.vim 中找到详细信息


文件类型补全					*ft-help-omni*

编写标签引用时，要获得帮助标签的补全，可以使用
|i_CTRL-X_CTRL-O| 命令。
