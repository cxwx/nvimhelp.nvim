可视模式				*Visual* *Visual-mode* *visual-mode*

可视模式是一种灵活且简单的方式来选择一段文本以便进行操作。
它是选择文本块的唯一方式。

这在用户手册的 |04.4| 节中介绍。

                                      输入 |gO| 查看目录。

==============================================================================
1. 使用可视模式					*visual-use*

使用可视模式包含三个部分：
1. 用 "v"、"V" 或 CTRL-V 标记文本的起点。
   光标下的字符将用作起点。
2. 移动到文本的末尾。
   从可视模式起点到光标下字符（包括该字符）的文本被高亮。
3. 输入操作符命令。
   高亮的字符将被操作。

|hl-Visual| 组决定可视选区的高亮方式。
'virtualedit' 选项可用于允许将光标定位在没有实际字符的位置。

高亮文本通常包含光标下的字符。
但是，当 'selection' 选项设置为 "exclusive" 且光标在可视区域
之后时，光标下的字符不包含在内。

使用 "v" 时，起始位置之前和结束位置之后的文本不会被高亮。
然而，所有大写和非字母操作符（"~" 和 "U" 除外）仍然对
整行操作。见下面的操作符列表。

							*visual-block*
使用 CTRL-V（块状可视模式）时，高亮文本将是起始位置和光标
之间的矩形。然而，某些操作符仍然对整行操作（见下面的列表）。
更改和替换操作符将删除高亮文本，然后在左上角位置开始插入。

2. 启动和停止可视模式				*visual-start*

						*v* *charwise-visual*
[count]v		按字符启动可视模式。
			使用 [count] 选择与上次可视操作相同数量的
			字符或行，但在当前光标位置，乘以 [count]。
			当上次可视操作是块模式时，块的宽度和高度
			都乘以 [count]。
			当没有上次可视操作时，选择 [count] 个字符。
			这相当于将光标向右移动 N * [count] 个字符。
			当 'selection' 不是 "exclusive" 时少一个。

						*V* *linewise-visual*
[count]V		按行启动可视模式。
			使用 [count] 选择与上次可视操作相同数量的
			行，但在当前光标位置，乘以 [count]。当没有
			上次可视操作时，选择 [count] 行。

						*CTRL-V* *blockwise-visual*
[count]CTRL-V		按块启动可视模式。

如果你在可视模式中使用 <Esc>、点击鼠标左键或使用任何跳转到
另一个缓冲区的命令，高亮停止且没有文本被影响。在字符可视
模式中按 "v"、在块状可视模式中按 "CTRL-V" 或在行可视模式中
按 "V" 也是如此。如果你按 CTRL-Z，高亮停止，编辑器被挂起
或启动新的 shell |CTRL-Z|。

	      输入后的新模式：			*v_v* *v_CTRL-V* *v_V*
旧模式		     "v"	      "CTRL-V"		     "V"	~

普通		    可视	   块状可视	  行可视
可视		    普通	   块状可视	  行可视
块状可视	    可视	   普通		  行可视
行可视		    可视	   块状可视	  普通

						*gv* *v_gv* *reselect-Visual*
gv			用与上次区域相同的区域和相同的模式启动
			可视模式。
			在可视模式中，当前和上次可视区域互换。
			在可视模式中使用 "p" 或 "P" 后，将选中
			被放置的文本。

								*gn* *v_gn*
gn			向前搜索上次使用的搜索模式（类似 `n`），
			并启动可视模式来选择匹配。如果光标在匹配
			上，则可视选择该匹配。如果操作符等待中，
			则对匹配操作。例如 "dgn" 删除下一个匹配的
			文本。
			如果可视模式已激活，则扩展选区直到下一个
			匹配的末尾。
			'wrapscan' 适用。
			注意：与 `n` 不同，搜索方向不依赖于上次
			搜索命令。

								*gN* *v_gN*
gN			类似 |gn| 但向后搜索，类似 `N`。

							*<LeftMouse>*
<LeftMouse>		设置当前光标位置。如果可视模式激活则停止。
			仅当 'mouse' 选项包含 'n' 或 'a' 时。
			如果位置在距屏幕最后一行 'so' 行以内，
			文本向上滚动。如果位置在距屏幕第一行
			'so' 行以内，文本向下滚动。

							*<RightMouse>*
<RightMouse>		如果可视模式未激活则启动可视模式。从光标
			位置到点击位置的文本被高亮。如果可视模式
			已激活，则移动高亮文本的起点或终点
			（取较近的那个）到点击位置。仅当 'mouse'
			选项包含 'n' 或 'a' 时。

			注意：当 'mousemodel' 设置为 "popup" 时，
			必须用 <S-LeftMouse> 代替 <RightMouse>。

							*<LeftRelease>*
<LeftRelease>		这类似 <LeftMouse>，如果不在与 <LeftMouse>
			相同的位置。在旧版本的 xterm 中，除非可以
			访问 xterm 运行的显示器（通过 DISPLAY 环境
			变量或 -display 参数），否则看不到选定区域
			直到按钮释放。仅当 'mouse' 选项包含 'n'
			或 'a' 时。

如果可视模式未激活且 "v"、"V" 或 CTRL-V 前面有计数，则使用
上次高亮区域的大小作为起点。然后你可以移动高亮区域的末端
并给出操作符。使用旧区域的类型（字符、行或块）。
- 行可视模式：行数乘以计数。
- 块状可视模式：行数和列数乘以计数。
- 普通可视模式在一行内：字符数乘以计数。
- 普通可视模式跨多行：行数乘以计数，最后一行使用与上次
  高亮区域最后一行相同的字符数。
文本的起点是光标位置。如果 "$" 命令是用于扩展高亮文本的
最后一个命令之一，区域将扩展到最长行的最右列。

如果你想高亮与上次完全相同的区域，可以使用 "gv" |gv| |v_gv|。

							*v_<Esc>*
<Esc>			在可视模式中：停止可视模式。
						*v_META* *v_ALT*
		如果组合键没有映射，ALT (|META|) 可能像 <Esc> 一样。
		例如，如果 <A-x> 没有可视模式映射，则 <A-x> 像
		<Esc>x 一样。

							*v_CTRL-C*
CTRL-C			在可视模式中：停止可视模式。当插入模式
			待处理时（模式消息显示
			"-- (insert) VISUAL --"），也停止。
			在 MS-Windows 上，你可能需要按 CTRL-Break。

==============================================================================
3. 更改可视区域					*visual-change*

							*v_o*
o			跳到高亮文本的另一端：当前光标位置变成
			高亮文本的起点，光标移到高亮文本的另一端。
			高亮区域保持不变。

							*v_O*
O			跳到高亮文本的另一端。这类似 "o"，但在
			块状可视模式中，光标移到同一行的另一个角。
			当角在占用多个屏幕位置的字符上（例如
			<Tab>）时，高亮文本可能会改变。

							*v_$*
当 "$" 命令与块状可视模式一起使用时，高亮文本的右端由最长的
高亮行决定。当使用不直接上下移动的移动命令时停止。

对于移动块的末端可以使用很多命令，但你不能使用 Ex 命令、
做更改的命令或放弃文件的命令。以 "."、"&"、CTRL-^、"Z"、
CTRL-]、CTRL-T、CTRL-R、CTRL-I 和 CTRL-O 开头的命令会
发出蜂鸣声，可视模式继续。

当在同一缓冲区的另一个窗口切换时，该窗口中的光标位置被
调整，使得相同的可视区域仍被选中。这对于在一个窗口查看
可视区域的起点、在另一个窗口查看终点特别有用。然后你可以
用 <RightMouse>（或当 'mousemodel' 为 "popup" 时用
<S-LeftMouse>）来拖动可视区域的任一端。

4. 对可视区域操作					*visual-operators*

可以使用的操作符有：
	~	切换大小写				|v_~|
	d	删除					|v_d|
	c	修改 (4)				|v_c|
	y	复制					|v_y|
	>	右移 (4)				|v_>|
	<	左移 (4)				|v_<|
	!	通过外部命令过滤 (1)			|v_!|
	=	通过 'equalprg' 选项命令过滤 (1)	|v_=|
	gq	将行格式化为 'textwidth' 长度 (1)	|v_gq|

可以使用的对象有：
	aw	一个单词（含空白）			|v_aw|
	iw	内部单词				|v_iw|
	aW	一个字串（含空白）			|v_aW|
	iW	内部字串				|v_iW|
	as	一个句子（含空白）			|v_as|
	is	内部句子				|v_is|
	ap	一个段落（含空白）			|v_ap|
	ip	内部段落				|v_ip|
	ab	一个 () 块（含括号）			|v_ab|
	ib	内部 () 块				|v_ib|
	aB	一个 {} 块（含花括号）			|v_aB|
	iB	内部 {} 块				|v_iB|
	at	一个 <tag> </tag> 块（含标签）		|v_at|
	it	内部 <tag> </tag> 块			|v_it|
	a<	一个 <> 块（含 <>）			|v_a<|
	i<	内部 <> 块				|v_i<|
	a[	一个 [] 块（含 []）			|v_a[|
	i[	内部 [] 块				|v_i[|
	a"	一个双引号字符串（含引号）		|v_aquote|
	i"	内部双引号字符串			|v_iquote|
	a'	一个单引号字符串（含引号）		|v_a'|
	i'	内部单引号字符串			|v_i'|
	a`	一个反引号字符串（含反引号）		|v_a`|
	i`	内部反引号字符串			|v_i`|

此外还可以使用以下命令：
	:	为高亮行启动 Ex 命令 (1)		|v_:|
	r	修改 (4)				|v_r|
	s	修改					|v_s|
	C	修改 (2)(4)				|v_C|
	S	修改 (2)				|v_S|
	R	修改 (2)				|v_R|
	x	删除					|v_x|
	D	删除 (3)				|v_D|
	X	删除 (2)				|v_X|
	Y	复制 (2)				|v_Y|
	p	粘贴					|v_p|
	P	粘贴但不覆盖寄存器			|v_P|
	J	合并 (1)				|v_J|
	U	转大写					|v_U|
	u	转小写					|v_u|
	^]	查找标签				|v_CTRL-]|
	I	块插入					|v_b_I|
	A	块追加					|v_b_A|

(1): 总是整行，见 |:visual_example|。
(2): 不使用 CTRL-V 时为整行。
(3): 不使用 CTRL-V 时为整行，使用 CTRL-V 时删除到行尾。
(4): 使用 CTRL-V 时只对块操作。

注意可以使用 ":vmap" 命令来专门在可视模式中映射键。例如，
如果你想让 "/" 命令不扩展可视区域，而是取高亮文本并搜索： >
	:vmap / y/<C-R>"<CR>
（在 <> 表示法 |<>| 中，输入时应按字面输入；你需要从
'cpoptions' 中删除 'B' 标志。）

如果你想用 """ 命令指定寄存器名称，在输入操作符字符之前
这样做："v{move-around}"xd"。

如果你想给命令一个计数，在输入操作符字符之前这样做：
"v{move-around}3>"（将行向右移动 3 个缩进）。

							*{move-around}*
{move-around} 是任何移动命令序列。注意与 {motion} 的区别，
{motion} 只是一个移动命令。

另一种对可视区域操作的方式是在模式中使用 |/\%V|。例如，
要将可视区域中所有 '(' 替换为 '#'： >

	:'<,'>s/\%V(/#/g

注意在可视模式中按 ":" 时会自动出现 "'<,'>"。

5. 块状操作符					*blockwise-operators*

提醒：使用 'virtualedit' 可以选择在行尾之后或制表符中间
开始或结束的块。

块状可视插入						*v_b_I*
使用块状选区，I{string}<ESC> 将在块的每一行的块起始处插入
{string}，前提是该行延伸到块中。因此短行不受影响。TAB 被
分割以保持视觉列。仅适用于向行中添加文本，不适用于删除。
见 |v_b_I_example|。

块状可视追加						*v_b_A*
使用块状选区，A{string}<ESC> 将在块的每一行的块末尾追加
{string}。由于不同行长度，块右边界不对齐时有些不同行为：

1. 块是用 <C-v>$ 创建的
    此时字符串追加到每行的末尾。
2. 块是用 <C-v>{move-around} 创建的
    此时字符串追加到每行的块末尾，并插入空白来填充到
    块末尾列。
见 |v_b_A_example|。
注意："I" 和 "A" 对不延伸到选定块的行行为不同。
这是有意为之，这样你可以按你想要的方式做。
仅适用于向行中添加文本，不适用于删除。

块状可视修改						*v_b_c*
块中所有选定的文本将被替换为相同的文本字符串。使用 "c" 时，
选定文本被删除并开始插入模式。然后你可以输入文本（不带换行）。
当你按 <Esc> 时，相同的字符串被插入到所有先前选定的行中。

块状可视修改						*v_b_C*
类似使用 "c"，但选区扩展到所有行的行尾。

								*v_b_<*
块状可视移位						*v_b_>*
块按 'shiftwidth' 移位。块的右边界无关。块的左边界决定
应用右移的起点，填充包括根据 'ts' 和 'et' 优化使用的 TAB。
块的左边界决定左移的终点。
见 |v_b_>_example|。
见 |v_b_<_example|。

块状可视替换						*v_b_r*
高亮区域中的每个屏幕字符都被替换为相同的字符，即 TAB 被
分割，虚拟空白被替换，保持屏幕布局。
见 |v_b_r_example|。

6. 重复						*visual-repeat*

重复可视模式操作符时，操作符将应用于与上次相同数量的文本：
- 行可视模式：相同的行数。
- 块状可视模式：相同的行数和列数。
- 普通可视模式在一行内：相同的字符数。
- 普通可视模式跨多行：相同的行数，最后一行使用与上次
  最后一行相同的字符数。
文本的起点是光标位置。如果 "$" 命令是用于扩展高亮文本的
最后一个命令之一，重复将应用到最长行的最右列。传递给 `.`
命令的任何计数不被使用。

可视模式 |default-mappings| "@" 和 "Q" 如果选区是按行的，
则为所有选定行重复寄存器。详见 |v_@-default| 和 |v_Q-default|。
例如，给定文本：

	123(hello)321
	456(world)654
	456(NOT THIS)654

寄存器 "x" 包含命令 `yi(VP`，可视选择前两行并输入 `@x`
产生：

	hello
	world
	456(NOT THIS)654

7. 示例						*visual-examples*

							*:visual_example*
目前 ":" 命令仅对整行操作。当你选择行的一部分时，做类似
":!date" 的操作会替换整行。如果你只想替换行的一部分，你
需要为此创建映射。在未来的版本中 ":" 可能支持部分行。

以下是用 "date" 的输出替换选定文本的示例： >
	:vmap _a <Esc>`>a<CR><Esc>`<i<CR><Esc>!!date<CR>kgJgJ

（在 <> 表示法 |<>| 中，输入时应按字面输入；你需要从
'cpoptions' 中删除 'B' 标志）

这做了什么：
<Esc>		停止可视模式
`>		去到可视区域的末尾
a<CR><Esc>	在可视区域后断行
`<		跳到可视区域的起点
i<CR><Esc>	在可视区域前断行
!!date<CR>	通过 date 过滤可视文本
kJJ		将行重新合并

							*visual-search*
以下是一个映射的想法，使得可以搜索选定的文本： >
	:vmap X y/<C-R>"<CR>

（在 <> 表示法 |<>| 中，输入时应按字面输入；你需要从
'cpoptions' 中删除 'B' 标志）

注意特殊字符（如 '.' 和 "*"）会导致问题。

8. 选择模式					*Select* *Select-mode*

选择模式看起来像可视模式，但接受的命令截然不同。
这类似于 Microsoft Windows 的选择模式。
当 'showmode' 选项打开时，最后一行显示 "-- SELECT --"。

进入选择模式：
- 使用鼠标选择区域，且 'selectmode' 包含 "mouse"。
  'mouse' 也必须包含当前模式的标志。
- 使用不可打印的移动命令，按住 Shift 键，且 'selectmode'
  包含 "key"。例如：<S-Left> 和 <S-End>。'keymodel' 也
  必须包含 "startsel"。
- 使用 "v"、"V" 或 CTRL-V 命令，且 'selectmode' 包含 "cmd"。
- 在普通模式中使用 "gh"、"gH" 或 "g_CTRL-H" 命令。
- 在可视模式中按 CTRL-G。			*v_CTRL-G*

选择模式中的命令：
- 可打印字符、<NL> 和 <CR> 导致选区被删除，Vim 进入
  插入模式。输入的字符被插入。
- 不可打印的移动命令，按住 Shift 键，扩展选区。
  'keymodel' 必须包含 "startsel"。
- 不可打印的移动命令，未按 Shift 键，停止选择模式。
  'keymodel' 必须包含 "stopsel"。
- ESC 停止选择模式。
- CTRL-O 切换到可视模式执行一个命令。 *v_CTRL-O*
- CTRL-G 切换到可视模式。
- CTRL-R {register} 选择用于删除文本时使用的寄存器。
							  *v_CTRL-R*
  除非你指定 "_"（黑洞）寄存器，否则无名寄存器也会被覆盖。

否则，输入的字符按可视模式处理。

在选择模式中使用操作符时，如果选区是按行的，则选定行像
按字符选区一样被操作。例如，当一整行被删除时，稍后可以
粘贴到行的中间。


选择模式中的映射和菜单。			*Select-mode-mapping*

当映射和菜单是用 |:vmap| 或 |:vmenu| 命令定义时，它们
在可视模式和选择模式中都有效。当在选择模式中使用时，Vim
自动切换到可视模式，以便有与可视模式相同的行为。如果你
不想这样，使用 |:xmap| 或 |:smap|。

一个特殊的边界情况： >
	:vnoremap <C-K> <Esc>
这在可视模式中结束可视模式，但在选择模式中不起作用，因为
执行映射键后选择模式被恢复。你需要使用： >
	:snoremap <C-K> <Esc>
<
用户期望可打印字符替换选定区域。因此避免在选择模式中映射
可打印字符。或者在 |:map| 和 |:vmap| 之后使用 |:sunmap|
来为选择模式删除它。

映射或菜单完成后，选区重新启用并进入选择模式，除非选定
区域被删除、另一个缓冲区成为当前缓冲区或窗口布局被更改。

当输入一个字符导致选区被删除并开始插入模式时，插入模式映射
应用于此字符。这可能导致一些混淆，因为这意味着插入模式映射
应用于在选择模式中输入的字符。语言映射也适用。

							*gV* *v_gV*
gV			避免在选择模式映射或菜单完成后自动重选
			可视区域。将其放在映射或菜单末尾之前。
			至少应在对选区的任何操作之后。

							*gh*
gh			启动选择模式，按字符。这类似 "v"，但启动
			选择模式而不是可视模式。
			助记："get highlighted"（获取高亮）。

							*gH*
gH			启动选择模式，按行。这类似 "V"，但启动
			选择模式而不是可视模式。
			助记："get Highlighted"（获取高亮）。

							*g_CTRL-H*
g CTRL-H		启动选择模式，按块。这类似 CTRL-V，但启动
			选择模式而不是可视模式。
			助记："get Highlighted"（获取高亮）。
