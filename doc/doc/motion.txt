光标移动					*cursor-motions* *navigation*

这些命令移动光标位置。如果新位置不在屏幕上，屏幕将滚动以
显示光标（另见 'scrolljump' 和 'scrolloff' 选项）。

一般说明：

如果你想知道你在文件中的位置，使用 "CTRL-G" 命令 |CTRL-G|
或 "g CTRL-G" 命令 |g_CTRL-G|。如果你设置了 'ruler' 选项，
光标位置会连续显示在状态行中（这会稍微减慢 Vim 速度）。

有经验的用户喜欢 hjkl 键，因为它们总是在手指下面。初学者
通常喜欢方向键，因为他们不知道 hjkl 键做什么。hjkl 的
助记价值从看键盘就能清楚。把 j 想象成一个向下的箭头。

'virtualedit' 选项可以设为使光标可以移动到没有字符或多列
字符（如制表符）内的位置。

                                      输入 |gO| 查看目录。

==============================================================================
1. 移动和操作符				*operator*

移动命令可以在操作符命令之后使用，使命令对被移过的文本操作。
即光标位置在移动前后之间的文本。操作符通常用于删除或修改
文本。以下操作符可用：

	|c|	c	修改
	|d|	d	删除
	|y|	y	复制到寄存器（不改变文本）
	|~|	~	切换大小写（仅当 'tildeop' 设置时）
	|g~|	g~	切换大小写
	|gu|	gu	转小写
	|gU|	gU	转大写
	|!|	!	通过外部程序过滤
	|=|	=	通过 'equalprg' 或 C 缩进（如果为空）过滤
	|gq|	gq	文本格式化
	|gw|	gw	文本格式化（不移动光标）
	|g?|	g?	ROT13 编码
	|>|	>	右移
	|<|	<	左移
	|zf|	zf	定义折叠
	|g@|	g@	调用 'operatorfunc' 选项设置的函数
						*motion-count-multiplied*
如果移动包含计数且操作符在它之前也有计数，两个计数相乘。
例如："2d3w" 删除六个单词。
						*operator-doubled*
当操作符双写时，它对一行操作。在第一个字符前后使用计数，
则对那么多行操作。因此 `3dd` 删除三行。第一个字符前后的
计数相乘，因此 `2y3y` 复制六行。
						*operator-resulting-pos*
应用操作符后，光标通常留在被操作文本的开头。例如，"yfe"
不移动光标，但 "yFe" 将光标向左移到复制开始的 "e" 处。
'startofline' 选项仅适用于 "d"、"<<"、"==" 和 ">>" 按行
操作。

					*linewise* *charwise* *characterwise*
操作符要么影响整行，要么影响起始和结束位置之间的字符。
通常，在行之间移动的移动影响行（是按行的），在行内移动的
移动影响字符（是按字符的）。但有些例外。

					*exclusive* *inclusive*
按字符的移动要么是包含的，要么是排他的。当包含时，移动的
起始和结束位置都包含在操作中。当排他时，朝缓冲区末尾方向
的最后一个字符不包含在内。按行的移动总是包含起始和结束位置。
插件可以检查 |TextYankPost| 事件的 v:event.inclusive 标志。

哪些移动是按行的、包含的或排他的在命令中提到。但有两个
一般例外：
1. 如果移动是排他的且移动的末尾在第 1 列，移动的末尾被
   移到前一行的末尾，移动变为包含的。示例："}" 移到段落
   后的第一行，但 "d}" 不包括那一行。
						*exclusive-linewise*
2. 如果移动是排他的，移动的末尾在第 1 列且移动的起点在
   行的第一个非空白处或之前，移动变为按行的。示例：如果
   一个段落以一些空白开头且你在第一个非空白处执行 "d}"，
   段落的所有行都被删除，包括空白。如果你现在粘贴，
   删除的行将被插入到光标位置下方。

注意当操作符等待时（操作符命令已输入但移动还没有），
可以使用一组特殊映射。见 |:omap|。

你可以使用可视模式代替先给操作符再给移动：用 "v" 标记文本
的开始，移光标到要影响的文本末尾，然后按操作符。起始和
光标位置之间的文本被高亮，这样你可以看到将被操作的文本。
这允许更多自由，但需要更多按键且重做功能有限。见可视模式
章节 |Visual-mode|。

你可以使用 ":" 命令作为移动。例如 "d:call FindEnd()"。
但如果命令超过一行则不能用 "." 重复。
这可以重复： >
	d:call search("f")<CR>
这不能重复： >
	d:if 1<CR>
	   call search("f")<CR>
	endif<CR>
注意使用 ":" 时任何移动都变为按字符排他的。

					*inclusive-motion-selection-exclusive*
当 'selection' 为 "exclusive"、|Visual| 模式激活且使用了
包含移动时，光标位置将向右调整一个字符，使可视选区包含
预期文本并可以被操作。

								*forced-motion*
强制移动为按行、按字符或按块

当移动不是你想使用的类型时，你可以在操作符之后使用 "v"、
"V" 或 CTRL-V 强制另一种类型。
示例： >
	dj
删除两行 >
	dvj
从光标位置删除到光标下方的字符 >
	d<C-V>j
删除光标下的字符和光标下方的字符。 >

强制按行移动为按字符或按块使用时要小心，列可能不总是定义的。

							*o_v*
v		在操作符之后、移动命令之前使用：强制操作符
		按字符工作，即使移动是按行的。如果移动是按行的，
		它变为 |exclusive|。
		如果移动已经是按字符的，切换包含/排他。
		这可以用来使排他移动变为包含的，包含移动变为排他的。

							*o_V*
V		在操作符之后、移动命令之前使用：强制操作符
		按行工作，即使移动是按字符的。

							*o_CTRL-V*
CTRL-V		在操作符之后、移动命令之前使用：强制操作符
		按块工作。这类似可视块模式选区，角由移动前后
		的光标位置定义。

2. 左右移动					*left-right-motions*

这些命令将光标移到当前行中指定的列。它们停在第一列和行尾，
"$" 除外，它可能移到下面的行之一。见 'whichwrap' 选项使
某些命令跨越行边界移动。

h		或					*h*
<Left>		或					*<Left>*
CTRL-H		或					*CTRL-H* *<BS>*
<BS>			向左 [count] 个字符。|exclusive| 移动。
			注意：如果你想用 <BS> 删除字符，使用
			映射： >
				:map CTRL-V<BS>		X
<			（要输入 "CTRL-V<BS>" 按 CTRL-V 键，
			然后按 <BS> 键）

l		或					*l*
<Right>		或					*<Right>* *<Space>*
<Space>			向右 [count] 个字符。|exclusive| 移动。
			行尾行为调整见 'whichwrap' 选项

							*0*
0			到行的第一个字符。|exclusive| 移动。

							*<Home>* *<kHome>*
<Home>			到行的第一个字符。|exclusive| 移动。
			上下移动时，停留在相同的文本列（如果可能）。
			大多数其他命令停留在相同的屏幕列。<Home>
			类似 "1|"，当行以 <Tab> 开头时与 "0" 不同。

							*^*
^			到行的第一个非空白字符。
			|exclusive| 移动。任何计数被忽略。

							*$* *<End>* *<kEnd>*
$  或 <End>		到行尾。给出计数时也向下移 [count - 1] 行，
			或尽可能远。|inclusive| 移动。如果给出 2 或
			更大的计数且光标在最后一行，这是错误且
			光标不移动。
			在可视模式中光标移到行中最后一个字符之后。
			'virtualedit' 激活时，"$" 可能将光标从行尾
			之后移回到行中最后一个字符。

							*g_*
g_			到行的最后一个非空白字符并向下
			[count - 1] 行 |inclusive|。

							*g0* *g<Home>*
g0 或 g<Home>		当行换行时（'wrap' 打开）：到屏幕行的
			第一个字符。|exclusive| 移动。当行比屏幕
			宽时与 "0" 不同。
			当行不换行时（'wrap' 关闭）：到当前行在
			屏幕上的最左字符。当行的第一个字符不在
			屏幕上时与 "0" 不同。

							*g^*
g^			当行换行时（'wrap' 打开）：到屏幕行的
			第一个非空白字符。|exclusive| 移动。
			当行比屏幕宽时与 "^" 不同。
			当行不换行时（'wrap' 关闭）：到当前行在
			屏幕上的最左非空白字符。当行的第一个非空白
			字符不在屏幕上时与 "^" 不同。

							*gm*
gm			类似 "g0"，但向右移半个屏幕宽度（或尽可能远）。

							*gM*
gM			类似 "g0"，但到行文本的中间。
			使用计数时：到行文本的此百分比。
			因此 "10gM" 在文本起点附近，"90gM" 在文本
			终点附近。

							*g$*
g$			当行换行时（'wrap' 打开）：到屏幕行的
			最后一个字符并向下 [count - 1] 屏幕行
			|inclusive|。当行比屏幕宽时与 "$" 不同。
			当行不换行时（'wrap' 关闭）：到当前行在
			屏幕上可见的最右字符。当行的最后一个字符
			不在屏幕上或使用计数时与 "$" 不同。
			此外，垂直移动保持列，而不是到行尾。
			'virtualedit' 启用时移到屏幕行末尾。

							*g<End>* *g<kEnd>*
g<End>			类似 |g$| 但到最后一个非空白字符而不是
			最后一个字符。

							*bar*
|			到当前行中的第 [count] 屏幕列。
			|exclusive| 移动。Ceci n'est pas une pipe.

							*f*
f{char}			到右边第 [count] 次出现的 {char}。光标
			放在 {char} 上 |inclusive|。
			{char} 可以作为二合字母输入 |digraph-arg|。
			当 'encoding' 设为 Unicode 时可以使用组合
			字符，见 |utf-8-char-arg|。
			|:lmap| 映射应用于 {char}。插入模式中的
			CTRL-^ 命令可用于开关此功能 |i_CTRL-^|。

							*F*
F{char}			到左边第 [count] 次出现的 {char}。光标
			放在 {char} 上 |exclusive|。
			{char} 可以像 |f| 命令一样输入。

							*t*
t{char}			到右边第 [count] 次出现的 {char} 之前。
			光标放在 {char} 左边的字符上 |inclusive|。
			{char} 可以像 |f| 命令一样输入。

							*T*
T{char}			到左边第 [count] 次出现的 {char} 之后。
			光标放在 {char} 右边的字符上 |exclusive|。
			{char} 可以像 |f| 命令一样输入。

							*;*
;			重复最近的 f、t、F 或 T [count] 次。见 |cpo-;|

							*,*
,			以相反方向重复最近的 f、t、F 或 T
			[count] 次。另见 |cpo-;|

3. 上下移动					*up-down-motions*

k		或					*k*
<Up>		或					*<Up>* *CTRL-P*
CTRL-P			向上 [count] 行 |linewise|。

j		或					*j*
<Down>		或					*<Down>*
CTRL-J		或					*CTRL-J*
<NL>		或					*<NL>* *CTRL-N*
CTRL-N			向下 [count] 行 |linewise|。

gk		或					*gk* *g<Up>*
g<Up>			向上 [count] 显示行。|exclusive| 移动。
			当行换行时与 'k' 不同，用于操作符时
			也不同因为它不是按行的。

gj		或					*gj* *g<Down>*
g<Down>			向下 [count] 显示行。|exclusive| 移动。
			当行换行时与 'j' 不同，用于操作符时
			也不同因为它不是按行的。

							*-*
`-`  <minus>		向上 [count] 行，到第一个非空白字符
			|linewise|。

`+`		或					*+*
CTRL-M		或					*CTRL-M* *<CR>*
<CR>			向下 [count] 行，到第一个非空白字符
			|linewise|。

							*_*
_  <underscore>		向下 [count] - 1 行，到第一个非空白字符
			|linewise|。

							*G*
G			到第 [count] 行，默认最后一行，到第一个
			非空白字符 |linewise|。如果未设置 'startofline'，
			保持相同列。
			G 是 |jump-motions| 之一。

							*<C-End>*
<C-End>			到第 [count] 行，默认最后一行，到最后一个
			字符 |inclusive|。

<C-Home>	或					*gg* *<C-Home>*
gg			到第 [count] 行，默认第一行，到第一个
			非空白字符 |linewise|。如果未设置 'startofline'，
			保持相同列。

							*:[range]*
:[range]		将光标设在 [range] 中的最后一行号上。
			在 Ex 模式中，打印 [range] 中的行。
			[range] 也可以是单个行号，例如 ":1"
			或 ":'m"。
			与 |G| 不同，此命令不修改 |jumplist|。
							*N%*
{count}%		到文件的 {count} 百分比处，到行中第一个
			非空白 |linewise|。计算新行号的公式：
			    ({count} * number-of-lines + 99) / 100
			另见 'startofline' 选项。

:[range]go[to] [count]					*:go* *:goto* *go*
[count]go		到缓冲区中第 [count] 个字节。|exclusive| 移动。
			默认 [count] 为一，文件开头。给 [range] 时，
			其中最后一个数字用作字节计数。行尾字符
			根据当前 'fileformat' 设置计数。
			另见 |line2byte()| 函数和 'statusline' 中
			的 'o' 选项。

这些命令移到指定行。它们在到达第一行或最后一行时停止。
前两个命令将光标放在与最后一个改变列的命令之后相同的列
（如果可能），"$" 命令之后除外，那时光标将放在行的
最后一个字符上。

4. 单词移动					*word-motions*

<S-Right>	或					*<S-Right>* *w*
w			向前 [count] 个单词。|exclusive| 移动。

<C-Right>	或					*<C-Right>* *W*
W			向前 [count] 个字串。|exclusive| 移动。

							*e*
e			向前到第 [count] 个单词末尾 |inclusive|。
			不在空行停止。

							*E*
E			向前到第 [count] 个字串末尾 |inclusive|。
			不在空行停止。

<S-Left>	或					*<S-Left>* *b*
b			向后 [count] 个单词。|exclusive| 移动。

<C-Left>	或					*<C-Left>* *B*
B			向后 [count] 个字串。|exclusive| 移动。

							*ge*
ge			向后到第 [count] 个单词末尾 |inclusive|。

							*gE*
gE			向后到第 [count] 个字串末尾 |inclusive|。

这些命令在单词或字串上移动。
							*word*
单词由字母、数字和下划线的序列，或其他非空白字符的序列
组成，以空白（空格、制表符、<EOL>）分隔。这可以用
'iskeyword' 选项更改。对于 255 以上的字符，当 Unicode 字符
类别改变时单词结束（例如在字母、下标、表情等之间）。
空行也被视为单词。
							*WORD*
字串由非空白字符的序列组成，以空白分隔。空行也被视为字串。

折叠行的序列对单个单词的单个字符计数。
"w" 和 "W"、"e" 和 "E" 移到折叠行范围后第一个单词或字串的
开始/结束。"b" 和 "B" 移到折叠之前第一个单词或字串的开始。

特殊情况："cw" 和 "cW" 在光标在非空白上时被视为 "ce" 和
"cE"。这是 Vi 兼容的，见 |cpo-_| 来改变行为。

另一个特殊情况：当使用 "w" 移动与操作符结合且移过的最后
一个单词在行尾时，被操作文本的末尾变为该单词的末尾，
而不是下一行的第一个单词。

Vi 原始实现的 "e" 有缺陷。例如，如果前一行为空，"e" 命令
将停在行的第一个字符上。但使用 "2e" 时不会发生。在 Vim 中
"ee" 和 "2e" 相同，更符合逻辑。但这导致 Vi 和 Vim 之间有
小的不兼容。

5. 文本对象移动				*object-motions*

							*(*
(			向后 [count] 个 |sentence|。|exclusive| 移动。

							*)*
)			向前 [count] 个 |sentence|。|exclusive| 移动。

							*{*
{			向后 [count] 个 |paragraph|。|exclusive| 移动。

							*}*
}			向前 [count] 个 |paragraph|。|exclusive| 移动。

							*]]*
]]			向前 [count] 个 |section| 或到第一列的下一个
			"{"。当在操作符后使用时，也在第一列的 "}"
			下方停止。|exclusive|
			注意 |exclusive-linewise| 经常适用。
			在 :terminal 缓冲区中每个 shell 提示符被
			视为一个节。|terminal_]]|

							*][*
][			向前 [count] 个 |section| 或到第一列的下一个
			'}'。|exclusive|
			注意 |exclusive-linewise| 经常适用。

							*[[*
[[			向后 [count] 个 |section| 或到第一列的前一个
			"{"。|exclusive|
			注意 |exclusive-linewise| 经常适用。
			在 :terminal 缓冲区中每个 shell 提示符被
			视为一个节。|terminal_]]|

							*[]*
[]			向后 [count] 个 |section| 或到第一列的前一个
			"}"。|exclusive|
			注意 |exclusive-linewise| 经常适用。

这些命令在三种文本对象上移动。

							*sentence*
句子定义为以 '.'、'!' 或 '?' 结尾，后跟行尾或空格或制表符。
'.'、'!' 或 '?' 后和空格、制表符或行尾前可以有任意数量的
')'、']'、'"' 和 ''' 字符。段落和节边界也是句子边界。
如果 'cpoptions' 中有 'J' 标志，标点后至少要跟两个空格；
<Tab> 不被识别为空白。句子的定义不能更改。

							*paragraph*
段落在每个空行之后开始，也在 'paragraphs' 选项中成对字符
指定的段落宏之后开始。默认是 "IPLPPPQPP TPHPLIPpLpItpplpipbp"，
对应宏 ".IP"、".LP" 等。（这些是 nroff 宏，所以点必须在
第一列。）节边界也是段落边界。
注意空白行（只包含空白）不是段落边界。
注意：这不包括第一列的 '{' 或 '}'。

							*section*
节在第一列的换页符 (<C-L>) 之后和 'sections' 选项中成对
字符指定的节宏之后开始。默认是 "SHNHH HUnhsh"，定义节
从 nroff 宏 ".SH"、".NH"、".H"、".HU"、".nh" 和 ".sh" 开始。
在 :terminal 缓冲区中每个 shell 提示符被视为一个节。|terminal_]]|

"]]" 和 "[[" 命令在第一列的 '{' 处停止。这对在 C 程序中
查找函数的开头很有用。要搜索第一列的 '}'（C 函数的结尾），
使用 "]["（向前）或 "[]"（向后）。注意命令的第一个字符
决定搜索方向。

			到行的第一个非空白字符。

							*[`*
[`			[count] 次到光标前的小写标记。


:loc[kmarks] {command}				*:loc* *:lock* *:lockmarks*
			执行 {command} 而不调整标记。当以更改完成时
			行数相同的方式更改文本时很有用。
			警告：当行数确实改变时，更改以下的标记将
			保持其行号，因此移到另一文本行。
			以下项目不会为删除/插入行调整：
			- 小写字母标记 'a - 'z
			- 大写字母标记 'A - 'Z
			- 编号标记 '0 - '9
			- 上次插入位置 '^
			- 上次更改位置 '.
			- 上次影响文本区域 '[ 和 ']
			- 可视区域 '< 和 '>
			- 放置标记中的行号
			- 快速修复位置中的行号
			- |jumplist| 中的位置
			- |tagstack| 中的位置
			以下项目仍将被调整：
			- 前一个上下文标记 ''
			- 光标位置
			- 窗口在缓冲区上的视图
			- 折叠
			- 差异

:kee[pmarks] {command}				*:kee* *:keep* *:keepmarks*
			目前只对过滤命令 |:range!| 有效：
			- 当过滤后的行数等于或大于之前时，所有
			  标记保持在相同行号。
			- 当行数减少时，消失行中的标记被删除。
			无论如何，过滤文本下方的标记会调整行号，
			因此粘附于文本，像往常一样。
			当 'cpoptions' 中缺少 'R' 标志时，与使用
			":keepmarks" 效果相同。

							*:keepj* *:keepjumps*
:keepj[umps] {command}
			在 {command} 中的移动不改变 |''|、|'.|
			和 |'^| 标记、|jumplist| 或 |changelist|。
			当自动进行更改或插入文本且用户不想去此
			位置时很有用。例如，更新第一行的
			"Last change" 时间戳时： >

				:let lnum = line(".")
				:keepjumps normal gg
				:call SetLastChange()
				:keepjumps exe "normal " .. lnum .. "G"
<
			注意 ":keepjumps" 必须用于每个命令。
			调用函数时函数中的命令仍然可以改变
			跳转列表。此外，对于
			`:keepjumps exe 'command '`，"command"
			不会保持跳转。改用：`:exe 'keepjumps command'`

8. 跳转					*jump-motions*

"跳转"是通常将光标移动到多行之外的命令。如果你使光标"跳转"，
跳转前的光标位置被记住。你可以用 "''" 和 "``" 命令返回该
位置，除非包含该位置的行被更改或删除。以下命令是"跳转"命令：
"'"、"`"、"G"、"/"、"?"、"n"、"N"、"%"、"("、")"、"[["、
"]]"、"{"、"}"、":s"、":tag"、"L"、"M"、"H" 以及开始编辑
新文件的命令。

							*CTRL-O*
CTRL-O			到跳转列表中第 [count] 个更旧的光标位置
			（不是移动命令）。

<Tab>		或					*CTRL-I* *<Tab>*
CTRL-I			到跳转列表中第 [count] 个更新的光标位置
			（不是移动命令）。

			注意：在 GUI 和支持 |tui-modifyOtherKeys|
			或 |tui-csiu| 的终端中，CTRL-I 可以与
			<Tab> 分别映射，条件是两个键都被映射，
			否则映射对两者都适用。在 tmux 中除外：
			https://github.com/tmux/tmux/issues/2705

							*:ju* *:jumps*
:ju[mps]		打印跳转列表（不是移动命令）。

							*:cle* *:clearjumps*
:cle[arjumps]		清除当前窗口的跳转列表。

							*jumplist*
跳转记在跳转列表中。使用 CTRL-O 和 CTRL-I 命令你可以到
旧跳转之前的光标位置，然后再回来。因此你可以在列表中
上下移动。每个窗口有单独的跳转列表。最大条目数固定为 100。

例如，三次跳转命令后你有此跳转列表： >

    jump line  col file/text
      3     1    0 some text
      2    70    0 another line
      1  1154   23 end.
   >
<
"file/text" 列显示文件名，或如果在当前文件中则显示跳转处
的文本（删除缩进，长行截断以适合窗口）。

">" 标记表示跳转列表中的当前位置。使用 |:filter| 过滤
|:jumps| 命令时可能不显示

你当前在第 1167 行。如果你然后使用 CTRL-O 命令，光标放在
第 1154 行。结果为： >

    jump line  col file/text
      2     1    0 some text
      1    70    0 another line
   >  0  1154   23 end.
      1  1167    0 foo bar
<
指针将设在最后使用的跳转位置。下一个 CTRL-O 命令使用它
上面的条目，下一个 CTRL-I 命令使用它下面的条目。如果
指针在最后一个条目下面，这表示你之前没有使用 CTRL-I
或 CTRL-O。此时 CTRL-O 命令将使光标位置被添加到跳转列表，
这样你可以回到 CTRL-O 之前的位置。此时这是第 1167 行。

更多 CTRL-O 命令将带你到第 70 行和第 1 行。如果你使用
CTRL-I 你可以再回到 1154 和 1167。注意 "jump" 列中的数字
表示带你到此位置的 CTRL-O 或 CTRL-I 命令的计数。

如果你使用跳转命令，当前行号被插入到跳转列表末尾。如果
同一行已在跳转列表中，它被删除。结果是重复 CTRL-O 时
你只回到旧位置一次。

当使用 |:keepjumps| 命令修饰符时，跳转不存储在跳转列表中。
在其他情况下跳转也不存储，例如在 |:global| 命令中。你可以
通过用 "m'" 设置 ' 标记来显式添加跳转。注意调用 setpos()
不会这样做。

在让你进入第 1154 行的 CTRL-O 命令后你可以给出另一个
跳转命令（例如 "G"）。跳转列表将变为： >

    jump line  col file/text
      4     1    0 some text
      3    70    0 another line
      2  1167    0 foo bar
      1  1154   23 end.
   >
<
行号将为删除和插入行调整。如果你不写就停止编辑文件（如
":n!"），这会失败。

当你分割窗口时，跳转列表将复制到新窗口。

如果你在 'shada' 选项中包含了 ' 项目，跳转列表将存储在
ShaDa 文件中，启动 Vim 时恢复。

							*jumplist-stack*
当 'jumpoptions' 选项包含 "stack" 时，跳转列表的行为类似
标签栈。从跳转列表中间跳转到新位置时，当前位置之后的
位置将被丢弃。设置此选项后你可以在跳转位置树中移动。
回到一个分支然后进入另一个分支时，CTRL-O 仍然带你进一步
上升树。

给定一个跳转列表，其中 CTRL-O 已被使用向后移动三次到
位置 X： >

     jump line  col file/text
       2  1260    8 mark.c		<-- 位置 X-2
       1   685    0 eval.c		<-- 位置 X-1
    >  0   462   36 eval.c		<-- 位置 X
       1   479   39 eval.c
       2   213    2 mark.c
       3   181    0 mark.c
<
跳转到（新的）位置 Y 导致当前位置之后的位置被删除： >

     jump line  col file/text
       3  1260    8 mark.c		<-- 位置 X-2
       2   685    0 eval.c		<-- 位置 X-1
       1   462   36 eval.c		<-- 位置 X
    >
<
然后，当又跳转到另一个位置 Z 时，新位置 Y 直接出现在
跳转列表中位置 X 之后，位置 X 相对于之前在它前面的位置
（X-1、X-2 等）保持相同位置： >

     jump line  col file/text
       4  1260    8 mark.c		<-- 位置 X-2
       3   685    0 eval.c		<-- 位置 X-1
       2   462   36 eval.c		<-- 位置 X
       1   100    0 buffer.c		<-- 位置 Y
    >
<
更改列表跳转		*changelist* *change-list-jumps* *E664*

做更改时记住光标位置。对每个可以撤销的更改记住一个位置，
除非它接近之前的更改。可以使用两个命令跳转到更改的位置，
包括已撤销的：

							*g;* *E662*
g;			到更改列表中第 [count] 个更旧的位置。
			如果 [count] 大于更旧更改位置的数量，
			去到最旧的更改。
			如果没有更旧的更改则给出错误消息。
			（不是移动命令）

							*g,* *E663*
g,			到更改列表中第 [count] 个更新的位置。
			与 |g;| 相同但方向相反。
			（不是移动命令）

使用计数时尽可能向前或向后跳转。因此你可以使用 "999g;"
到仍然记住位置的第一个更改。更改列表中的条目数固定且
与 |jumplist| 相同。

当两个可撤销的更改在同一行且列位置之差少于 'textwidth'
时，只记住最后一个。这避免了一行中的小更改序列
（例如 "xxxxx"）向更改列表添加很多位置。当 'textwidth'
为零时使用 'wrapmargin'。当它也未设置时使用固定数 79。
细节：计算使用字节而非字符，以避免速度惩罚
（这仅对多字节编码有影响）。

注意当文本被插入或删除时，光标位置可能与更改位置略有
不同。特别是当行被删除时。

当使用 `:keepjumps` 命令修饰符时，更改的位置不被记住。

							*:changes*
:changes		打印更改列表。">" 字符表示当前位置。
			更改之后它在最新条目下方，表示 `g;` 将
			带你到最新条目位置。第一列表示带你到此
			位置的计数。示例：

				change line  col text ~
				    3     9    8 bla bla bla
				    2    11   57 foo is a bar
				    1    14   54 the latest changed line
				>

			`3g;` 命令带你到第 9 行。然后 `:changes`
			的输出是：

				change line  col text ~
				>   0     9    8 bla bla bla
				    1    11   57 foo is a bar
				    2    14   54 the latest changed line

			现在你可以用 "g," 去第 11 行，用 "2g,"
			去第 14 行。

9. 各种移动				*various-motions*

							*%*
%			在此行中找到光标处或之后的下一个项目并
			跳转到其匹配。|inclusive| 移动。
			项目可以是：
			([{}])		圆括号或（花/方）括号
					（可以用 'matchpairs' 选项更改）
			`/* */`		C 风格注释的开头或结尾
			#if, #ifdef, #else, #elif, #endif
					C 预处理器条件（当光标在 #
					上或后面没有 ([{ 时）
			对于其他项目可以使用 matchit 插件，见
			|matchit|。此插件也帮助跳过注释中的匹配。

			当 'cpoptions' 包含 "M" |cpo-M| 时忽略
			括号前的反斜杠。没有 "M" 时反斜杠数量
			有关：偶数不与奇数匹配。因此在
			"( \) )" 和 "\( ( \)" 中第一个和最后一个
			括号匹配。

			当 'cpoptions' 中没有 '%' 字符 |cpo-%| 时，
			双引号内的括号和花括号被忽略，除非一行中
			括号/花括号的数量是奇数且此行和前一行不
			以反斜杠结尾。'('、'{'、'['、']'、'}' 和 ')'
			也被忽略（单引号内的括号和花括号）。注意
			这对 C 有效，但对 Perl 无效，因为 Perl
			使用单引号作字符串。

			对注释中的匹配不做特殊处理。你可以使用
			|matchit| 插件或在匹配周围放引号。

			不允许计数，{count}% 跳转到文件的 {count}
			百分比 |N%|。在 #if/#else/#endif 上使用 '%'
			使移动变为按行。

						*[(*
[(			到第 [count] 个前面未匹配的 '('。
			|exclusive| 移动。

						*[{*
[{			到第 [count] 个前面未匹配的 '{'。
			|exclusive| 移动。

						*])*
])			到第 [count] 个后面未匹配的 ')'。
			|exclusive| 移动。

						*]}*
]}			到第 [count] 个后面未匹配的 '}'。
			|exclusive| 移动。

上面四个命令可以用来到当前代码块的开头或结尾。就像在
代码块另一端的 "("、")"、"{" 或 "}" 上使用 "%"，但你
可以从代码块中的任何位置这样做。
对 C 程序非常有用。示例：当站在 "case x:" 上，`[{` 将
带你回到 switch 语句。

						*]m*
]m			到第 [count] 个下一个方法开始（用于 Java
			或类似结构化语言）。当不在方法开始之前时，
			跳到类的开始或结束。|exclusive| 移动。
						*]M*
]M			到第 [count] 个下一个方法结束（用于 Java
			或类似结构化语言）。当不在方法结束之前时，
			跳到类的开始或结束。|exclusive| 移动。
						*[m*
[m			到第 [count] 个前一个方法开始（用于 Java
			或类似结构化语言）。当不在方法开始之后时，
			跳到类的开始或结束。当光标前没有找到 '{'
			时这是错误。|exclusive| 移动。
						*[M*
[M			到第 [count] 个前一个方法结束（用于 Java
			或类似结构化语言）。当不在方法结束之后时，
			跳到类的开始或结束。当光标前没有找到 '}'
			时这是错误。|exclusive| 移动。

上面四个命令假定文件包含一个带方法的类。类定义用 '{' 和
'}' 围起来。类中的每个方法也用 '{' 和 '}' 围起来。
这适用于 Java 语言。文件看起来像这样： >

	// comment
	class foo {
		int method_one() {
			body_one();
		}
		int method_two() {
			body_two();
		}
	}

[要试验这个，复制文本并放入新缓冲区，上面的帮助文本会
混淆跳转命令]

从光标在 "body_two()" 开始，使用 "[m" 将跳到 "method_two()"
开始的 '{'（显然当方法较长时这更有用！）。使用 "2[m" 将
跳到 "method_one()" 的开始。使用 "3[m" 将跳到类的开始。

						*[#*
[#			到第 [count] 个前面未匹配的 "#if" 或 "#else"。
			|exclusive| 移动。

						*]#*
]#			到第 [count] 个后面未匹配的 "#else" 或 "#endif"。
			|exclusive| 移动。

这两个命令在包含 #if/#else/#endif 构造的 C 程序中使用。
它将你带到包含当前行的 #if/#else/#endif 的开始或结束。
然后你可以用 "%" 到匹配行。

						*[star* *[/*
[*  或  [/		到第 [count] 个前一个 C 注释 "/*" 的开始。
			|exclusive| 移动。

						*]star* *]/*
]*  或  ]/		到第 [count] 个下一个 C 注释 "*/" 的结束。
			|exclusive| 移动。


						*H*
H			到距窗口顶部第 [count] 行（Home）（默认：
			窗口的第一行），到第一个非空白字符
			|linewise|。另见 'startofline' 选项。
			为 'scrolloff' 选项调整光标，除非操作符
			等待中，此时文本可能滚动。例如 "yH" 复制
			从第一个可见行到光标行（包含）。

						*M*
M			到窗口中间行，到第一个非空白字符
			|linewise|。另见 'startofline' 选项。

						*L*
L			到距窗口底部第 [count] 行（默认：窗口的
			最后一行），到第一个非空白字符 |linewise|。
			另见 'startofline' 选项。
			为 'scrolloff' 选项调整光标，除非操作符
			等待中，此时文本可能滚动。例如 "yL" 复制
			从光标到最后一个可见行。

<LeftMouse>		移到屏幕上鼠标点击的位置 |exclusive|。
			另见 |<LeftMouse>|。如果位置在状态行中，
			该窗口成为活动窗口且光标不移动。
