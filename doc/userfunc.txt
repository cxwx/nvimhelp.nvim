				      输入 |gO| 查看目录。

1. 定义函数 ~
						*define-function*
可以定义新的函数。这些函数可以像内置函数一样调用。函数执行一系列 Ex 命令。
普通模式命令可以通过 |:normal| 命令执行。

函数名必须以大写字母开头，以避免与内置函数混淆。为了防止在不同脚本中使用
相同的名称，应将其设为脚本局部函数。如果使用全局函数，则应避免使用显而易见
的短名称。一个好的习惯是用脚本名作为函数名的前缀，例如 "HTMLcolor()"。

也可以使用花括号，参见 |curly-braces-names|。

|autoload| 功能用于仅在函数被调用时才定义该函数，这很有用。

							*local-function*
脚本局部函数必须以 "s:" 开头。脚本局部函数只能从脚本内部以及在脚本中定义的
函数、用户命令和自动命令中调用。也可以从脚本中定义的映射调用该函数，但当映射
在脚本外部展开时，必须使用 |<SID>| 代替 "s:"。
只有脚本局部函数，没有缓冲区局部或窗口局部函数。

					*:fu* *:function* *E128* *E129* *E123*
:fu[nction]		列出所有函数及其参数。

:fu[nction][!] {name}	列出函数 {name}，除非给出 "!" 否则带有行号标注。
			{name} 可以是 |Dictionary| |Funcref| 条目: >
				:function dict.init
<			注意 {name} 不是表达式，不能使用作为函数引用的变量。
			可以用以下技巧列出变量 "Funcref" 所引用的函数: >
				let g:MyFuncref = Funcref
				func g:MyFuncref
				unlet g:MyFuncref

:fu[nction] /{pattern}	列出名称匹配 {pattern} 的函数。
			列出所有以 "File" 结尾的函数的示例: >
				:function /File$
<
							*:function-verbose*
当 'verbose' 非零时，列出函数时也会显示其最后定义的位置。示例: >

    :verbose function SetFileTypeSH
	function SetFileTypeSH(name)
	    Last set from /usr/share/vim/vim-7.0/filetype.vim
<
详见 |:verbose-cmd|。

						*E124* *E125* *E853* *E884*
:fu[nction][!] {name}([arguments]) [range] [abort] [dict] [closure]
			定义一个名为 {name} 的新函数。函数体在接下来的行中，
			直到匹配的 |:endfunction|。

			名称必须由字母数字字符和 '_' 组成，且必须以大写字母
			或 "s:" 开头（参见上文）。
			注意不允许使用 "b:"、"l:" 等（自补丁 7.4.260 起，
			如果函数名包含冒号，例如 "foo:bar()"，会给出 E884
			错误），而前导 "g:" 会被跳过但仍要求后跟大写字母。

			{name} 可以是 |Dictionary| |Funcref| 条目: >
				:function dict.init(arg)
<			"dict" 必须是已存在的字典。如果 "init" 条目不存在
			则会被添加。否则需要 [!] 来覆盖已存在的函数。
			结果是指向编号函数的 |Funcref|。该函数只能通过
			|Funcref| 使用，当没有更多引用时会被删除。
								*E127* *E122*
			当同名函数已存在且未使用 [!] 时会给出错误消息。有一个
			例外：当重新加载脚本时，之前在该脚本中定义的函数会被
			静默替换。
			使用 [!] 时，已存在的函数会被静默替换。除非该函数
			正在执行，那样会报错。
			注意：请谨慎使用 !。如果不小心使用可能导致已有函数
			被意外替换，这很难调试。

			{arguments} 参见 |function-argument|。

					*:func-range* *a:firstline* *a:lastline*
			添加 [range] 参数时，函数需要自己处理范围。范围通过
			"a:firstline" 和 "a:lastline" 传递。如果不包含
			[range]，":{range}call" 会对范围内的每一行调用函数，
			光标位于每行的起始位置。参见 |function-range-example|。
			光标仍会移动到范围的第一行，这与所有 Ex 命令一样。
								*:func-abort*
			添加 [abort] 参数时，函数会在检测到错误时立即中止。
								*:func-dict*
			添加 [dict] 参数时，函数必须通过 |Dictionary| 中的
			条目来调用。局部变量 "self" 将被设置为该字典。
			参见 |Dictionary-function|。
						*:func-closure* *E932*
			添加 [closure] 参数时，函数可以访问外部作用域的变量
			和参数。这通常称为闭包。在此示例中 Bar() 使用了
			Foo() 作用域中的 "x"。即使 Foo() 返回后它仍然被
			引用: >
				:function! Foo()
				:  let x = 0
				:  function! Bar() closure
				:    let x += 1
				:    return x
				:  endfunction
				:  return funcref('Bar')
				:endfunction

				:let F = Foo()
				:echo F()
<			1 >
				:echo F()
<			2 >
				:echo F()
<			3

						*function-search-undo*
			最后使用的搜索模式和重做命令 "." 不会被函数改变。
			这也意味着 |:nohlsearch| 的效果会在函数返回时撤销。

				*:endf* *:endfunction* *E126* *E193* *W22*
:endf[unction] [argument]
			函数定义的结束。最好单独放在一行上，不带 [argument]。

			[argument] 可以是:
				| command	接下来要执行的命令
				\n command	接下来要执行的命令
				" comment	始终被忽略
				anything else	被忽略，'verbose' 非零时会给出警告
			对后续命令的支持在 Vim 8.0.0654 中添加，在此之前任何
			参数都会被静默忽略。

			要在 `:execute` 命令中定义函数，请使用换行符代替
			|:bar|: >
				:exe "func Foo()\necho 'foo'\nendfunc"
<
				*:delf* *:delfunction* *E131* *E933*
:delf[unction][!] {name}
			删除函数 {name}。
			{name} 也可以是 |Funcref| 的 |Dictionary| 条目: >
				:delfunc dict.init
<			这将从 "dict" 中移除 "init" 条目。如果没有更多引用
			则函数会被删除。
			使用 ! 时，如果函数不存在不会报错。
							*:retu* *:return* *E133*
:retu[rn] [expr]	从函数返回。当给出 [expr] 时，它会被求值并作为函数
			的结果返回。如果没有给出 [expr]，则返回数字 0。
			当函数在没有显式 ":return" 的情况下结束时，返回数字
			0。
			注意不会检查不可达的行，因此如果命令跟在 ":return"
			后面不会有警告。
			也不会检查后续行是否包含有效命令。忘记行续接
			反斜杠可能不会被注意到: >
				return 'some text'
				       .. ' some more text'
<			会愉快地返回 "some text" 而不报错。应该写成: >
				return 'some text'
				       \ .. ' some more text'
<
			如果 ":return" 在 |:try| 之后但在匹配的 |:finally|
			（如果有的话）之前使用，则会先执行 ":finally" 到
			匹配 |:endtry| 之间的命令。这个过程适用于函数内所有
			嵌套的 ":try"。函数在最外层的 ":endtry" 处返回。

						*function-argument* *a:var*
参数可以通过给出名称来定义。在函数中可以用 "a:name" 来使用它（"a:" 代表
argument）。
					*a:0* *a:1* *a:000* *E740* *...*
最多可以给出 20 个参数，用逗号分隔。在命名参数之后可以指定参数 "..."，这意味着
可以有更多的可选参数。在函数中，额外的参数可以用 "a:1"、"a:2" 等来使用。"a:0"
被设为额外参数的数量（可以是 0）。"a:000" 被设为包含这些参数的 |List|。注意
"a:1" 与 "a:000[0]" 相同。
								*E742*
a: 作用域及其中的变量不能被更改，它们是固定的。但是，如果使用复合类型，如
|List| 或 |Dictionary|，你可以更改它们的内容。因此你可以将 |List| 传递给函数，
让函数向其中添加项目。如果你想确保函数不能更改 |List| 或 |Dictionary|，请使用
|:lockvar|。

也可以定义没有任何参数的函数。但仍然必须提供 ()。

允许在函数体内定义另一个函数。

						*optional-function-argument*
你可以为位置命名参数提供默认值。这使得它们在函数调用时成为可选的。当位置参数
在调用时未指定，则使用默认表达式来初始化它。这仅适用于用 `:function` 声明的
函数，不适用于 lambda 表达式 |expr-lambda|。

示例: >
  function Something(key, value = 10)
     echo a:key .. ": " .. a:value
  endfunction
  call Something('empty')	"empty: 10"
  call Something('key', 20)	"key: 20"

参数默认表达式在函数调用时求值，而不是在函数定义时。因此可以使用在函数定义
时无效的表达式。这些表达式也仅在调用时未指定参数时才求值。

								*E989*
带默认表达式的可选参数必须出现在所有必需参数之后。你可以在所有可选命名参数
之后使用 "..."。

后面的参数默认值可以引用前面的参数，但反之则不行。它们必须像所有参数一样加上
"a:" 前缀。

可行的示例: >
  :function Okay(mandatory, optional = a:mandatory)
  :endfunction
不可行的示例: >
  :function NoGood(first = a:second, second = 10)
  :endfunction
<
不使用 "..." 时，函数调用中的参数数量必须至少等于必需命名参数的数量。使用
"..." 时，参数数量可以大于必需和可选参数的总数。

							*local-variables*
在函数内部可以使用局部变量。这些变量在函数返回时消失。全局变量需要用 "g:" 来
访问。在函数内部，局部变量不需要加任何前缀即可访问。但如果你愿意也可以加上
"l:" 前缀。对于某些保留名称（如 "version"）这是必需的。

示例: >
  :function Table(title, ...)
  :  echohl Title
  :  echo a:title
  :  echohl None
  :  echo a:0 .. " items:"
  :  for s in a:000
  :    echon ' ' .. s
  :  endfor
  :endfunction

然后可以这样调用此函数: >
  call Table("Table", "line1", "line2")
  call Table("Empty Table")

要返回多个值，返回一个 |List|: >
  :function Compute(n1, n2)
  :  if a:n2 == 0
  :    return ["fail", 0]
  :  endif
  :  return ["ok", a:n1 / a:n2]
  :endfunction

然后可以这样调用此函数: >
  :let [success, div] = Compute(102, 6)
  :if success == "ok"
  :  echo div
  :endif
<

2. 调用函数 ~
						*:cal* *:call* *E107* *E117*
:[range]cal[l] {name}([arguments])
		调用函数。函数的名称和参数如 `:function` 中所指定。最多可以
		使用 20 个参数。返回值被丢弃。
		没有范围且函数接受范围时，函数被调用一次。当给出范围时，光标
		在执行函数前定位到第一行的起始位置。
		当给出范围且函数不自己处理范围时，函数会对范围内的每一行执行，
		光标位于该行的第一列。光标停留在最后一行（可能被最后一次函数
		调用移动）。参数在每一行都会重新求值。因此以下代码可以工作:
						*function-range-example*  >
	:function Mynumber(arg)
	:  echo line(".") .. " " .. a:arg
	:endfunction
	:1,5call Mynumber(getline("."))
<
		"a:firstline" 和 "a:lastline" 始终会被定义，它们可以用来在
		范围的开始或结束处做一些不同的事情。

		处理范围的函数示例: >

	:function Cont() range
	:  execute (a:firstline + 1) .. "," .. a:lastline .. 's/^/\t\\ '
	:endfunction
	:4,8call Cont()
<
		此函数在范围内所有行（第一行除外）的前面插入续行字符 "\"。

		当函数返回复合值时可以进一步解引用，但范围不会被使用。示例: >
	:4,8call GetDict().method()
<		这里 GetDict() 获得范围但 method() 不会。

								*E132*
用户函数的递归深度受 'maxfuncdepth' 选项限制。

也可以使用 `:eval`。它不支持范围，但允许方法链式调用，例如: >
	eval GetList()->Filter()->append('$')

函数也可以作为表达式求值的一部分或作为方法使用时被调用: >
	let x = GetList()
	let y = GetList()->Filter()
<

3. 函数中的清理 ~
							*:defe* *:defer*
:defe[r] {func}({args})	在当前函数完成时调用 {func}。
			{args} 在此处求值。

通常函数中的命令有全局效果，在函数结束时必须撤销。在各种情况下处理这些问题
可能很麻烦，特别是遇到意外错误时。这可以用 `try` / `finally` 块来完成，但当
有多个这样的情况时会变得复杂。

一个更简单的解决方案是使用 `defer`。它会在函数返回时调度一个函数调用，无论
是否有错误。示例: >
	func Filter(text) abort
	  call writefile(a:text, 'Tempfile')
	  call system('filter < Tempfile > Outfile')
	  call Handle('Outfile')
	  call delete('Tempfile')
	  call delete('Outfile')
	endfunc

这里如果某些原因导致函数中止，'Tempfile' 和 'Outfile' 将不会被删除。`:defer`
可以用来避免这个问题: >
	func Filter(text) abort
	  call writefile(a:text, 'Tempfile')
	  defer delete('Tempfile')
	  defer delete('Outfile')
	  call system('filter < Tempfile > Outfile')
	  call Handle('Outfile')
	endfunc

注意删除 "Outfile" 是在调用 `system()` 之前调度的，因为即使 `system()` 失败
它也可能已被创建。

延迟函数以相反的顺序调用，最后添加的最先执行。一个无用的示例: >
	func Useless() abort
	  for s in range(3)
	    defer execute('echomsg "number ' .. s .. '"')
	  endfor
	endfunc

现在 `:messages` 显示:
	number 2
	number 1
	number 0

延迟函数的任何返回值都会被丢弃。函数后面不能跟任何东西，如 "->func" 或
".member"。目前 `:defer GetArg()->TheFunc()` 不起作用，可能在以后的版本中
可以工作。

错误会被报告但不会导致中止延迟函数的执行或改变延迟函数之外的执行。

不接受范围。函数可以是带额外参数的 partial，但不能带字典。 *E1300*

4. 自动加载函数 ~
							*autoload-functions*
当使用许多或大型函数时，可以仅在使用时才自动定义它们。有两种方法：使用自动命令
和使用 'runtimepath' 中的 "autoload" 目录。


使用自动命令 ~

这在用户手册的 |41.14| 节中有介绍。

当你有一个很长的 Vim 脚本文件作为插件时，自动命令很有用。你可以定义自动命令
并用 `:finish` 快速退出脚本。这使得 Vim 启动更快。自动命令应该再次加载同一个
文件，设置一个变量来跳过 `:finish` 命令。

使用 FuncUndefined 自动命令事件和匹配要定义的函数的模式。示例: >

	:au FuncUndefined BufNet* source ~/vim/bufnetfuncs.vim

文件 "~/vim/bufnetfuncs.vim" 应该定义以 "BufNet" 开头的函数。另见
|FuncUndefined|。


使用 autoload 脚本 ~
							*autoload* *E746*
这在用户手册的 |41.15| 节中有介绍。

使用 "autoload" 目录中的脚本更简单，但需要使用精确正确的文件名。可以自动加载
的函数的名称如下: >

	:call filename#funcname()

当这样的函数被调用且尚未定义时，Vim 会在 'runtimepath' 的 "autoload" 目录中
搜索名为 "filename.vim" 的脚本文件。例如
"~/.config/nvim/autoload/filename.vim"。该文件应这样定义函数: >

	function filename#funcname()
	   echo "Done!"
	endfunction

如果文件不存在，Vim 也会在 'packpath'（"start" 下）中搜索，以允许在包尚未
添加到 'runtimepath' 时从 |vimrc| 调用包的函数（参见 |packages|）。

文件名和函数名中 # 之前使用的名称必须完全匹配，定义的函数必须与调用时的名称
完全一致。

可以使用子目录。函数名中的每个 # 都相当于路径分隔符。因此调用函数时: >

	:call foo#bar#func()

Vim 会在 'runtimepath' 中查找文件 "autoload/foo/bar.vim"。

当读取尚未设置的变量时也可以使用: >

	:let l = foo#bar#lvar

但是，当 autoload 脚本已被加载时，不会因未知变量而再次加载。

给这样的变量赋值时不会发生什么特殊的事情。这可以用来在 autoload 脚本加载前
向其传递设置: >

	:let foo#bar#toggle = 1
	:call foo#bar#func()

注意如果你犯了错误，调用了一个本应在 autoload 脚本中定义的函数，但脚本实际上
没有定义该函数，你将收到缺少函数的错误消息。如果你修复了 autoload 脚本，它
不会自动重新加载。要么重启 Vim，要么手动加载该脚本。

还要注意，如果你有两个脚本文件，一个调用另一个中的函数，反之亦然，在使用的
函数定义之前，这将不起作用。避免在顶层使用 autoload 功能。

提示：如果你要分发一组脚本，请参见 |distribute-script|。
