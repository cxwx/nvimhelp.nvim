使用多窗口和缓冲区进行编辑。			*windows* *buffers*

这里解释了为使用多窗口和缓冲区而添加的命令。此外，还解释了在与多个窗口组合
使用时工作方式不同的命令。

基础知识在用户手册的第 7 章和第 8 章中进行了解释 |usr_07.txt|
|usr_08.txt|。

                                      输入 |gO| 查看目录。

==============================================================================
1. 简介						*windows-intro* *window*

概要：
   缓冲区是文件在内存中的文本。
   窗口是缓冲区的视口。
   标签页是窗口的集合。

窗口是缓冲区的视口。你可以在一个缓冲区上使用多个窗口，或者在不同的缓冲区上
使用多个窗口。

缓冲区是加载到内存中进行编辑的文件。原始文件保持不变，直到你将缓冲区写入
文件。

缓冲区可以处于以下三种状态之一：

							*active-buffer*
活动:   缓冲区显示在窗口中。如果此缓冲区有对应的文件，该文件已被读入缓冲区。
	缓冲区可能在那之后被修改过，因此可能与文件不同。
							*hidden-buffer*
隐藏:   缓冲区未显示。如果此缓冲区有对应的文件，该文件已被读入缓冲区。否则
	它与活动缓冲区相同，只是你看不到它。
							*inactive-buffer*
非活动: 缓冲区未显示且不包含任何内容。如果文件曾经被加载过，缓冲区的选项会被
	记住。它可以包含来自 |shada| 文件的标记。但缓冲区不包含文本。

表格形式：

state		displayed	loaded		":buffers"  ~
		in window			shows	    ~
active		  yes		 yes		  'a'
hidden		  no		 yes		  'h'
inactive	  no		 no		  ' '

							*buffer-reuse*
每个缓冲区有一个唯一编号，该编号在一次 Vim 会话中不会改变。可以使用
|bufnr()| 和 |bufname()| 函数在缓冲区名称和缓冲区编号之间进行转换。有一个
例外：如果创建了一个新的空缓冲区且未被修改，当将另一个文件加载到该缓冲区时，
该缓冲区将被重用。这也意味着缓冲区编号不会改变。

主 Vim 窗口可以容纳多个分割窗口。还有标签页 |tab-page|，每个标签页可以容纳
多个窗口。

							*focusable*
如果窗口是可聚焦的，它就是"导航栈"的一部分，也就是说，编辑器命令如 :windo、
|CTRL-W| 等，会将该窗口视为可以成为"当前窗口"的窗口。不可聚焦的窗口会被此类
命令跳过，因为它没有被分配窗口编号。可以通过 |nvim_set_current_win()| 显式
聚焦它，因为它仍然被分配了一个 |window-ID|。如果它被聚焦，它也会有一个窗口
编号。不可聚焦的窗口不会被 |:tabs| 列出，也不会被默认的 'tabline' 计数。它们
的缓冲区内容不包含在 'complete' "w" 补全中。

窗口（特别是浮动窗口）可以有许多其他 |api-win_config| 属性，如 "hide" 和
"fixed"，它们也会影响行为。

					*window-ID* *winid* *windowid*
每个窗口有一个唯一的标识符，称为窗口 ID。此标识符在一次 Vim 会话中不会改变。
可以使用 |win_getid()| 和 |win_id2tabwin()| 函数在窗口/标签编号和标识符之间
进行转换。还有窗口编号，每当窗口被打开或关闭时可能会改变，参见 |winnr()|。
窗口编号仅在一个特定的标签页中有效。窗口 ID 在所有标签页中有效。对于大多数
接受窗口 ID 或窗口编号的函数，窗口编号仅适用于当前标签页，而窗口 ID 可以引用
任何标签页中的窗口。

2. 启动 Vim						*windows-starting*

默认情况下，Vim 以一个窗口启动，就像 Vi 一样。

Vim 的 "-o" 和 "-O" 参数可用于为参数列表中的每个文件打开一个窗口。"-o" 参数
将水平分割窗口；"-O" 参数将垂直分割窗口。如果同时给出 "-o" 和 "-O"，最后
遇到的那个将用于决定分割方向。例如，这将打开三个水平分割的窗口: >
	vim -o file1 file2 file3

"-oN"（N 为十进制数字）打开 N 个水平分割的窗口。如果文件名多于窗口数，只会
打开 N 个窗口，一些文件不会获得窗口。如果窗口多于文件名，最后几个窗口将编辑
空缓冲区。类似地，"-ON" 打开 N 个垂直分割的窗口，具有相同的限制。

如果文件名很多，窗口会变得非常小。你可能想要设置 'winheight' 和/或 'winwidth'
选项来创建可工作的状况。

在打开新窗口和读取文件时不会执行 Buf/Win Enter/Leave |autocommand|，只有在
真正进入窗口时才会执行。

							*status-line*
状态行将用于分隔窗口。'laststatus' 选项指定最后一个窗口是否也有状态行：
	'laststatus' = 0	从不显示状态行
	'laststatus' = 1	当有多个窗口时显示状态行
	'laststatus' = 2	总是显示状态行
	'laststatus' = 3	在底部使用全局状态行，而不是每个窗口一个

你可以使用 'statusline' 选项更改状态行的内容。此选项可以是窗口局部的，这样
你可以在每个窗口中使用不同的状态行。

通常使用反色来显示状态行。这可以通过 |hl-StatusLine| 高亮组来更改。如果状态
行没有使用高亮，当前窗口使用 '^' 字符，其他窗口使用 '='。如果启用了 'mouse'，
可以拖动状态行来调整窗口大小。

							*filler-lines*
窗口中最后一个缓冲区行之后的行称为填充行。默认情况下，这些行以波浪号 (~)
字符开头。可以使用 'fillchars' 选项中的 "eob" 项来更改此字符。默认情况下，
这些字符以 NonText (|hl-NonText|) 高亮显示。可以使用 EndOfBuffer 高亮组
(|hl-EndOfBuffer|) 来更改填充字符的高亮。

3. 打开和关闭窗口					*opening-window*

CTRL-W s						*CTRL-W_s*
CTRL-W S						*CTRL-W_S*
CTRL-W CTRL-S						*CTRL-W_CTRL-S*
:[N]sp[lit] [++opt] [+cmd]				*:sp* *:split*
		将当前窗口一分为二。结果是同一文件的两个视口。

		使新窗口高度为 N 行（默认使用当前窗口高度的一半）。减少当前
		窗口的高度以腾出空间（如果设置了 'equalalways' 选项、
		'eadirection' 不是 "hor"、且其中一个窗口高于当前窗口或新窗口，
		则其他窗口也会调整）。

		注意：CTRL-S 在所有终端上不一定有效，可能会阻止进一步输入，
		使用 CTRL-Q 恢复。
		另见 |++opt| 和 |+cmd|。
							*E242* *E1159*
		在自动命令中分割窗口时要小心，如果在进行其他窗口布局更改时
		发生分割，可能会弄乱窗口布局。

:[N]sp[lit] [++opt] [+cmd] {file}			*:split_f*
		类似 |:split|，但创建一个新窗口并在其中开始编辑文件 {file}。
		这几乎等同于先执行 ":split"，然后执行 ":edit" 命令，但原始
		窗口中的备选文件名会被设置为 {file}。
		如果给出了 [+cmd]，当文件加载后执行该命令 |+cmd|。
		另见 |++opt|。
		使新窗口高度为 N 行（默认使用现有高度的一半）。减少当前窗口
		高度以腾出空间（如果设置了 'equalalways' 选项，其他窗口也会
		调整）。

CTRL-W CTRL-V						*CTRL-W_CTRL-V*
CTRL-W v						*CTRL-W_v*
:[N]vs[plit] [++opt] [+cmd] [file]			*:vs* *:vsplit*
		类似 |:split|，但垂直分割。在以下情况下窗口将水平展开：
		1. 未指定宽度，
		2. 设置了 'equalalways'，
		3. 'eadirection' 不是 "ver"，且
		4. 其他窗口之一比当前窗口或新窗口更宽。
		如果给出了 N，使新窗口宽 N 列（如果可能的话）。
		注意：在其他地方 CTRL-Q 与 CTRL-V 相同，但在这里不是！

CTRL-W n						*CTRL-W_n*
CTRL-W CTRL-N						*CTRL-W_CTRL-N*
:[N]new [++opt] [+cmd]					*:new*
		创建一个新窗口并在其中开始编辑一个空文件。使新窗口高度为 N
		行（默认使用现有高度的一半）。减少当前窗口高度以腾出空间
		（如果设置了 'equalalways' 选项且 'eadirection' 不是 "hor"，
		其他窗口也会调整）。
		另见 |++opt| 和 |+cmd|。
		如果 'fileformats' 不为空，第一个指定的格式将用于新缓冲区。
		如果 'fileformats' 为空，将使用当前缓冲区的 'fileformat'。
		这可以用 |++opt| 参数覆盖。
		自动命令按以下顺序执行：
		1. 当前窗口的 WinLeave
		2. 新窗口的 WinEnter
		3. 当前缓冲区的 BufLeave
		4. 新缓冲区的 BufEnter
		这相当于先执行 ":split"，然后执行 ":enew" 命令。

:[N]new [++opt] [+cmd] {file}
		类似 |:split_f|，创建一个新窗口并开始编辑 {file}。

:[N]vne[w] [++opt] [+cmd] [file]			*:vne* *:vnew*
		类似 |:new|，但垂直分割。如果设置了 'equalalways' 且
		'eadirection' 不是 "ver"，窗口将水平展开，除非指定了宽度。

:[N]sv[iew] [++opt] [+cmd] [file]		*:sv* *:sview* *splitview*
		与 ":split" 相同，但为此缓冲区设置 'readonly' 选项。

:[N]sf[ind] [++opt] [+cmd] {file}	     *:sf* *:sfi* *:sfind* *splitfind*
		与 ":split" 相同，但像 |:find| 一样在 'path' 中搜索 {file}。
		如果找不到 {file}，则不分割。

CTRL-W CTRL-^					*CTRL-W_CTRL-^* *CTRL-W_^*
CTRL-W ^	将当前窗口一分为二并编辑备选文件。当给出计数 N 时，分割当前
		窗口并编辑缓冲区 N。类似于 ":sp #" 和 ":sp #N"，但它允许
		另一个缓冲区是未命名的。此命令的行为与 |CTRL-^| 相同，只是
		它先分割窗口。

CTRL-W ge						*CTRL-W_ge*
		将当前窗口分离为外部窗口。
		仅在使用支持 |ui-multigrid| 的 UI 时可用。

注意 'splitbelow' 和 'splitright' 选项会影响新窗口出现的位置。
								*E36*
如果没有足够的空间，创建窗口将失败。每个窗口至少需要一个屏幕行和列，有时
更多。选项 'winminheight' 和 'winminwidth' 是相关的。

						*:vert* *:vertical*
:vert[ical] {cmd}
		执行 {cmd}。如果它包含分割窗口的命令，将垂直分割。对于
		`vertical wincmd =`，窗口将仅在垂直方向上均衡化。
		不适用于 |:execute| 和 |:normal|。

						*:hor* *:horizontal*
:hor[izontal] {cmd}
		在水平分割窗口中执行 {cmd}。支持以下命令：
		- `:wincmd =`：仅水平均衡化窗口。
		- |:terminal|：在分割窗口中打开 |terminal| 缓冲区。
		- |:checkhealth|：在分割窗口中打开健康检查缓冲区。

:lefta[bove] {cmd}				*:lefta* *:leftabove*
:abo[veleft] {cmd}				*:abo* *:aboveleft*
		执行 {cmd}。如果它包含分割窗口的命令，窗口将打开在当前窗口
		的左边（垂直分割）或上方（水平分割）。覆盖 'splitbelow' 和
		'splitright'。
		不适用于 |:execute| 和 |:normal|。

:rightb[elow] {cmd}				*:rightb* *:rightbelow*
:bel[owright] {cmd}				*:bel* *:belowright*
		执行 {cmd}。如果它包含分割窗口的命令，窗口将打开在当前窗口
		的右边（垂直分割）或下方（水平分割）。覆盖 'splitbelow' 和
		'splitright'。
		不适用于 |:execute| 和 |:normal|。

						*:topleft* *E442*
:to[pleft] {cmd}
		执行 {cmd}。如果它包含分割窗口的命令，窗口将出现在顶部并
		占据 Vim 窗口的全部宽度。当分割是垂直的时，窗口出现在最
		左边并占据 Vim 窗口的全部高度。
		不适用于 |:execute| 和 |:normal|。

						*:bo* *:botright*
:bo[tright] {cmd}
		执行 {cmd}。如果它包含分割窗口的命令，窗口将出现在底部并
		占据 Vim 窗口的全部宽度。当分割是垂直的时，窗口出现在最
		右边并占据 Vim 窗口的全部高度。
		不适用于 |:execute| 和 |:normal|。

这些命令修饰符可以组合使用，使垂直分割的窗口占据全部高度。例如: >
	:vertical topleft split tags
在 Vim 窗口的最左边打开一个垂直分割、全高度的窗口来编辑 "tags" 文件。

关闭窗口

:q[uit]
:{count}q[uit]						*:count_quit*
CTRL-W q						*CTRL-W_q*
CTRL-W CTRL-Q						*CTRL-W_CTRL-Q*
		不带 {count}：退出当前窗口。如果给出了 {count}，退出第
		{count} 个窗口。
							*edit-window*
		当退出最后一个编辑窗口（不计帮助或预览窗口）时，退出 Vim。

		当设置了 'hidden'，且当前缓冲区只有一个窗口时，缓冲区变为
		隐藏。当未设置 'hidden'，且当前缓冲区只有一个窗口，且缓冲区
		已被修改时，命令失败。
		（注意：CTRL-Q 在所有终端上不一定有效）。
		如果 [count] 大于最后一个窗口编号，最后一个窗口将被关闭: >
		    :1quit  " 退出第一个窗口
		    :$quit  " 退出最后一个窗口
		    :9quit  " 退出最后一个窗口
			    " 如果打开的窗口少于 9 个
		    :-quit  " 退出上一个窗口
		    :+quit  " 退出下一个窗口
		    :+2quit " 退出下下一个窗口
<
		关闭帮助窗口时，如果这不是唯一的窗口，Vim 将尝试恢复之前的
		窗口布局，参见 |:helpclose|。

:q[uit]!
:{count}q[uit]!
		不带 {count}：退出当前窗口。如果给出了 {count}，退出第
		{count} 个窗口。
		如果这是某个缓冲区的最后一个窗口，该缓冲区的任何更改将丢失。
		当退出最后一个窗口（不计帮助窗口）时，退出 Vim。缓冲区的
		内容将丢失，即使设置了 'hidden' 也是如此。

:clo[se][!]
:{count}clo[se][!]
CTRL-W c					*CTRL-W_c* *:clo* *:close*
		不带 {count}：关闭当前窗口。如果给出了 {count}，关闭第
		{count} 个窗口。

		当设置了 'hidden'，或者缓冲区已被修改且使用了 [!] 时，缓冲区
		变为隐藏（除非有另一个窗口正在编辑它）。

		当当前标签页中只有一个 |edit-window| 且存在另一个标签页时，
		这将关闭当前标签页。|tab-page|。

		此命令在以下情况下失败：			*E444*
		- 屏幕上只有一个窗口。
		- 未设置 'hidden'、未使用 [!]、缓冲区有更改、且没有其他窗口
		  在编辑此缓冲区。
		缓冲区的更改不会被写入也不会丢失，所以这是一个"安全"的命令。

CTRL-W CTRL-C						*CTRL-W_CTRL-C*
		你可能期望 CTRL-W CTRL-C 会关闭当前窗口，但这不起作用，因为
		CTRL-C 会取消命令。

							*:hide*
:hid[e]
:{count}hid[e]
		不带 {count}：退出当前窗口，除非它是屏幕上的最后一个窗口。
		如果给出了 {count}，退出第 {count} 个窗口。

		缓冲区变为隐藏（除非有另一个窗口正在编辑它，或者 'bufhidden'
		是 `unload`、`delete` 或 `wipe`）。如果该窗口是当前标签页中
		的最后一个窗口，标签页将被关闭。|tab-page|

		'hidden' 的值与此命令无关。
		缓冲区的更改不会被写入也不会丢失，所以这是一个"安全"的命令。

:hid[e] {cmd}	在 'hidden' 设置为开的情况下执行 {cmd}。{cmd} 执行完毕后将
		恢复 'hidden' 之前的值。
		示例: >
		    :hide edit Makefile
<		这将编辑 "Makefile"，如果当前缓冲区有任何更改则将其隐藏。

:on[ly][!]
:{count}on[ly][!]
CTRL-W o						*CTRL-W_o* *E445*
CTRL-W CTRL-O					*CTRL-W_CTRL-O* *:on* *:only*
		使当前窗口成为屏幕上唯一的窗口。所有其他窗口关闭。对于
		{count}，参见上面的 `:quit` 命令 |:count_quit|。

		当设置了 'hidden' 选项时，关闭窗口中的所有缓冲区变为隐藏。

		当未设置 'hidden' 且设置了 'autowrite' 选项时，已修改的缓冲区
		将被写入。否则，有已修改缓冲区的窗口不会被关闭，除非给出了
		[!]，此时它们变为隐藏。但已修改的缓冲区永远不会被放弃，所以
		更改不会丢失。

							*:fc* *:fclose*
:[count]fc[lose][!]
		关闭 [count] 个具有最高 zindex 值的浮动窗口。使用 '!' 关闭
		所有浮动窗口。

CTRL-W <Up>					*CTRL-W_<Up>*
CTRL-W CTRL-K					*CTRL-W_CTRL-K* *CTRL-W_k*
CTRL-W k	将光标移动到当前窗口上方第 N 个窗口。使用光标位置在备选方案

CTRL-W <Left>					*CTRL-W_<Left>*
CTRL-W CTRL-H					*CTRL-W_CTRL-H*
CTRL-W <BS>					*CTRL-W_<BS>* *CTRL-W_h*
CTRL-W h	将光标移动到当前窗口左边第 N 个窗口。使用光标位置在备选方案

CTRL-W <Right>					*CTRL-W_<Right>*

CTRL-W w					*CTRL-W_w* *CTRL-W_CTRL-W*
CTRL-W CTRL-W	不带计数：将光标移动到当前窗口下方/右方的 |focusable| 窗口。
		如果没有，则转到左上角的窗口。带计数：转到第 N 个窗口（从左

						*CTRL-W_W*
CTRL-W W	不带计数：将光标移动到当前窗口上方/左方的 |focusable| 窗口。
		如果没有，则转到右下角的窗口。带计数：转到第 N 个窗口，如
		CTRL-W w。

CTRL-W t					*CTRL-W_t* *CTRL-W_CTRL-T*
CTRL-W CTRL-T	将光标移动到左上角的窗口。

CTRL-W b					*CTRL-W_b* *CTRL-W_CTRL-B*
CTRL-W CTRL-B	将光标移动到右下角的窗口。

CTRL-W p					*CTRL-W_p* *CTRL-W_CTRL-P*
CTRL-W CTRL-P	转到上一个（最后访问的）窗口。

						*CTRL-W_P* *E441*
CTRL-W P	转到预览窗口。如果没有预览窗口，这是一个错误。

如果 Visual 模式处于活动状态且新窗口不是同一缓冲区的，Visual 模式将结束。
如果窗口在同一缓冲区上，光标位置将被设置以保持选择相同的 Visual 区域。

						*:winc* *:wincmd*
这些命令也可以用 ":wincmd" 执行：

:[count]winc[md] {arg}
:winc[md] [count] {arg}
		类似执行 CTRL-W [count] {arg}。示例: >
			:wincmd j
<		移动到当前窗口下方的窗口。
		当无法使用普通模式时（对于 |CursorHold| 自动命令事件），
		此命令很有用。或者当普通模式命令不方便时。
		计数也可以是窗口编号。示例: >
			:exe nr .. "wincmd w"
<		这将转到第 "nr" 个窗口。

注意：所有 CTRL-W 命令也可以用 |:wincmd| 执行，适用于无法使用普通模式命令
或不方便的场合（例如在基于浏览器的终端中）。

5. 移动窗口						*window-moving*

CTRL-W r				*CTRL-W_r* *CTRL-W_CTRL-R* *E443*
CTRL-W CTRL-R	向下/向右旋转窗口。第一个窗口变为第二个，第二个变为第三个，
		以此类推。最后一个窗口变为第一个。光标保持在同一窗口中。
		这仅在当前窗口所在的行或列内起作用。

						*CTRL-W_R*
CTRL-W R	向上/向左旋转窗口。第二个窗口变为第一个，第三个变为第二个，
		以此类推。第一个窗口变为最后一个。光标保持在同一窗口中。
		这仅在当前窗口所在的行或列内起作用。

CTRL-W x					*CTRL-W_x* *CTRL-W_CTRL-X*
CTRL-W CTRL-X	不带计数：将当前窗口与下一个窗口交换。如果没有下一个窗口，
		与上一个窗口交换。
		带计数：将当前窗口与第 N 个窗口交换（第一个窗口是 1）。光标
		被放在另一个窗口中。
		当垂直和水平窗口分割混合时，交换仅在当前窗口所在的行或列内
		进行。

以下命令可用于更改窗口布局。例如，当有两个垂直分割的窗口时，CTRL-W K 将
变为水平分割的窗口。CTRL-W H 则反向操作。

						*CTRL-W_K*
CTRL-W K	将当前窗口移到最顶部，使用屏幕的全部宽度。这类似于
		`:topleft split`，但应用于当前窗口且不创建新窗口。

						*CTRL-W_J*
CTRL-W J	将当前窗口移到最底部，使用屏幕的全部宽度。这类似于
		`:botright split`，但应用于当前窗口且不创建新窗口。

						*CTRL-W_H*
CTRL-W H	将当前窗口移到最左边，使用屏幕的全部高度。这类似于
		`:vert topleft split`，但应用于当前窗口且不创建新窗口。

						*CTRL-W_L*
CTRL-W L	将当前窗口移到最右边，使用屏幕的全部高度。这类似于
		`:vert botright split`，但应用于当前窗口且不创建新窗口。

						*CTRL-W_T*
CTRL-W T	将当前窗口移到新的标签页。如果当前标签页中只有一个窗口，
		此操作将失败。
		这类似于 `:tab split`，但之前的窗口会被关闭。
		当指定了计数时，新标签页将在此索引的标签页之前打开。否则
		它在当前标签页之后。

6. 窗口大小调整					*window-resize*

						*CTRL-W_=*
CTRL-W =	使所有窗口（几乎）等高等宽，但对当前窗口使用 'winheight'
		和 'winwidth'。
		设置了 'winfixheight' 的窗口保持其高度，设置了 'winfixwidth'
		的窗口保持其宽度。
		要仅垂直均衡化（使窗口等高），使用 `vertical wincmd =`。
		要仅水平均衡化（使窗口等宽），使用 `horizontal wincmd =`。

:res[ize] -N					*:res* *:resize* *CTRL-W_-*
CTRL-W -	将当前窗口高度减少 N（默认 1）。
		如果在 |:vertical| 之后使用：减少宽度 N。

:res[ize] +N					*CTRL-W_+*
CTRL-W +	将当前窗口高度增加 N（默认 1）。
		如果在 |:vertical| 之后使用：增加宽度 N。

:res[ize] [N]
CTRL-W CTRL-_					*CTRL-W_CTRL-_* *CTRL-W__*
CTRL-W _	将当前窗口高度设为 N（默认：尽可能高）。

:{winnr}res[ize] [+-]N
		类似上面的 `:resize`，但应用于窗口 {winnr} 而不是当前窗口。

z{nr}<CR>	将当前窗口高度设为 {nr}。

						*CTRL-W_<*
CTRL-W <	将当前窗口宽度减少 N（默认 1）。

						*CTRL-W_>*
CTRL-W >	将当前窗口宽度增加 N（默认 1）。

:vert[ical] res[ize] [N]			*:vertical-resize* *CTRL-W_bar*
CTRL-W |	将当前窗口宽度设为 N（默认：尽可能宽）。

你也可以通过用鼠标上下拖动状态行来调整窗口大小。或者左右拖动垂直分隔线。
这仅在使用的 Vim 版本支持鼠标且 'mouse' 选项已启用时有效。

选项 'winheight' ('wh') 用于设置当前窗口的最小窗口高度。每次另一个窗口成为
当前窗口时都会使用此选项。如果选项值为 '0'，则被禁用。将 'winheight' 设为
很大的值，例如 '9999'，可以使当前窗口始终填满所有可用空间。设为合理的值，
例如 '10'，可以使在当前窗口中编辑更舒适。

等价的 'winwidth' ('wiw') 选项用于设置当前窗口的最小宽度。

当选项 'equalalways' ('ea') 设置时，分割或关闭窗口后所有窗口会自动调整为
相同大小。如果不设置此选项，分割窗口将减小当前窗口的大小并保持其他窗口不变。
关闭窗口时，多余的行将给上方的窗口。

'eadirection' 选项限制 'equalalways' 选项应用的方向。默认值 "both" 在两个
方向上调整大小。当值为 "ver" 时只均衡化窗口的高度。在手动调整了垂直分割窗口
的大小并希望保持此宽度时使用此值。类似地，"hor" 只使窗口的宽度均衡化。

选项 'cmdheight' ('ch') 用于设置命令行的高度。如果你被长消息的 |hit-enter|
提示烦扰，可以将此选项设为 2 或 3。

如果只有一个窗口，调整该窗口大小也会改变命令行的高度。如果有多个窗口，调整
当前窗口大小也会改变下方窗口（有时是上方窗口）的高度。

窗口的最小高度和宽度通过 'winminheight' 和 'winminwidth' 设置。这些是硬性
值，窗口永远不会变得更小。


WinScrolled 和 WinResized 自动命令 ~
						*win-scrolled-resized*
如果你想在窗口大小发生变化时得到通知，可以使用 |WinResized| 自动命令事件。
如果你想在窗口中的文本垂直或水平滚动时得到通知，可以使用 |WinScrolled| 自动
命令事件。这也会在窗口大小变化时触发。
例外：当文本因 'incsearch' 而滚动时不会触发这些事件。
							*WinResized-event*
|WinResized| 事件在更新显示后触发，此时可能有多个窗口的大小已更改。自上次以来
发生变化的窗口 ID 列表在 v:event.windows 变量中提供，例如：
	[1003, 1006]
							*WinScrolled-event*
|WinScrolled| 事件在 |WinResized| 之后触发，并且在窗口被滚动时也会触发。
滚动可以是垂直的（窗口顶部的文本发生了变化）或水平的（当 'wrap' 关闭时或
第一行的首个显示部分发生了变化）。注意 |WinScrolled| 的触发次数比 |WinResized|
多得多，可能会稍微减慢编辑速度。

|WinScrolled| 提供的信息是一个字典，其中每个发生变化的窗口使用窗口 ID 作为
键，并使用键 "all" 表示所有变化的总计。|v:event| 的示例值: >
	{
	   all:  {width: 0, height:  2, leftcol: 0, skipcol: 0, topline: 1, topfill: 0},
	   1003: {width: 0, height: -1, leftcol: 0, skipcol: 0, topline: 0, topfill: 0},
	   1006: {width: 0, height:  1, leftcol: 0, skipcol: 0, topline: 1, topfill: 0},
	}

注意 "all" 条目是各个窗口绝对值的累加。

如果你需要更多关于变化内容的信息，或者你想"防抖"事件（不处理每个事件以避免
做太多工作），你可能想使用 `winlayout()` 和 `getwininfo()` 函数。

|WinScrolled| 和 |WinResized| 在添加第一个自动命令时不会触发，只在第一次
滚动或调整大小后触发。在切换到另一个标签页时可能会触发。

执行的命令预计不会导致窗口大小或滚动变化。如果确实发生了，事件将很快再次
触发。换句话说：在触发事件之前，当前的大小和滚动位置会被存储，并用于判断
是否发生了变化。

参数列表和多窗口

参数列表中的当前位置可以在每个窗口中不同。记住当执行 ":e file" 时，参数列表
中的位置保持不变，但你不是在编辑该位置的文件。为了指示这一点，文件消息
（和标题，如果你有的话）显示 "(file (N) of M)"，其中 "(N)" 是文件列表中的
当前位置，"M" 是文件列表中的文件数量。

参数列表中的所有条目都会添加到缓冲区列表中。因此，你也可以使用缓冲区列表
命令来访问它们，如 ":bnext"。

:[N]al[l][!] [N]				*:al* *:all* *:sal* *:sall*
:[N]sal[l][!] [N]
		重新排列屏幕，为每个参数打开一个窗口。所有其他窗口关闭。
		当给出计数时，这是要打开的最大窗口数。
		使用 |:tab| 修饰符时，为每个参数打开一个标签页。当参数多于
		'tabpagemax' 时，多余的参数在最后一个标签页中变为分割窗口。
		当设置了 'hidden' 选项时，关闭窗口中的所有缓冲区变为隐藏。
		当未设置 'hidden' 且设置了 'autowrite' 选项时，已修改的
		缓冲区将被写入。否则，有已修改缓冲区的窗口不会被关闭，除非
		给出了 [!]，此时它们变为隐藏。但已修改的缓冲区永远不会被
		放弃，所以更改不会丢失。
		[N] 是要打开的最大窗口数。'winheight' 也限制打开的窗口数
		（如果前面有 |:vertical|，则是 'winwidth'）。
		此处新窗口不会执行 Buf/Win Enter/Leave 自动命令，只有在
		真正进入时才会执行。
		如果自动命令在此命令忙碌时更改了窗口布局，将给出错误。 *E249*

:[N]sa[rgument][!] [++opt] [+cmd] [N]			*:sa* *:sargument*
		":split | argument [N]" 的简写：分割窗口并转到第 N 个参数。
		但当没有这样的参数时，窗口不会被分割。另见 |++opt| 和 |+cmd|。

:[N]sn[ext][!] [++opt] [+cmd] [file ..]			*:sn* *:snext*
		":split | [N]next" 的简写：分割窗口并转到下 N 个参数。但当
		没有下一个文件时，窗口不会被分割。另见 |++opt| 和 |+cmd|。

:[N]spr[evious][!] [++opt] [+cmd] [N]			*:spr* *:sprevious*
:[N]sN[ext][!] [++opt] [+cmd] [N]			*:sN* *:sNext*
		":split | [N]Next" 的简写：分割窗口并转到上 N 个参数。但当
		没有上一个文件时，窗口不会被分割。另见 |++opt| 和 |+cmd|。

						*:sre* *:srewind*
:sre[wind][!] [++opt] [+cmd]
		":split | rewind" 的简写：分割窗口并转到第一个参数。但当
		没有参数列表时，窗口不会被分割。另见 |++opt| 和 |+cmd|。

						*:sfir* *:sfirst*
:sfir[st] [++opt] [+cmd]
		与 ":srewind" 相同。

						*:sla* *:slast*
:sla[st][!] [++opt] [+cmd]
		":split | last" 的简写：分割窗口并转到最后一个参数。但当
		没有参数列表时，窗口不会被分割。另见 |++opt| 和 |+cmd|。

						*:dr* *:drop*
:dr[op] [++opt] [+cmd] {file} ..
		在窗口中编辑第一个 {file}。
		- 如果文件已在某个窗口中打开，切换到该窗口。
		- 如果文件未在窗口中打开，在当前窗口中编辑该文件。如果
		  当前缓冲区无法被 |abandon|，则先分割窗口。
		- 不在参数列表中或不是全宽的窗口将尽可能被关闭。
		|argument-list| 被设置，类似于 |:next| 命令。
		此命令的目的是可以从希望 Vim 编辑另一个文件的程序中使用，
		例如调试器。
		使用 |:tab| 修饰符时，每个参数在一个标签页中打开。如果最后
		一个窗口为空，则使用它。
		另见 |++opt| 和 |+cmd|。

8. 在所有缓冲区或窗口中执行命令			*list-repeat*

							*:windo*
:[range]windo {cmd}	在每个 |focusable| 窗口中执行 {cmd}，或者仅对给定
			窗口编号 [range] 内的窗口执行。其工作方式如下: >
				CTRL-W t
				:{cmd}
				CTRL-W w
				:{cmd}
				etc.
<			这仅在当前标签页中操作。
			在一个窗口上检测到错误时，不会继续访问更多窗口。
			最后一个窗口（或发生错误的窗口）成为当前窗口。
			{cmd} 可以包含 '|' 来连接多个命令。
			{cmd} 不能打开或关闭窗口或重新排序它们。

			另见 |:tabdo|、|:argdo|、|:bufdo|、|:cdo|、|:ldo|、
			|:cfdo| 和 |:lfdo|。

							*:bufdo*
:[range]bufdo[!] {cmd}	在缓冲区列表中的每个缓冲区中执行 {cmd}，或者如果
			给出了 [range]，则仅对缓冲区编号在 [range] 内的
			缓冲区执行。其工作方式如下: >
				:bfirst
				:{cmd}
				:bnext
				:{cmd}
				etc.
<			当当前文件无法被 |abandon| 且未使用 [!] 时，命令
			失败。
			在一个缓冲区上检测到错误时，不会继续访问更多
			缓冲区。
			未列出的缓冲区会被跳过。
			最后一个缓冲区（或发生错误的缓冲区）成为当前缓冲区。
			{cmd} 可以包含 '|' 来连接多个命令。
			{cmd} 不能删除缓冲区或向缓冲区列表添加缓冲区。
			注意：当此命令执行时，Syntax 自动命令事件通过添加到
			'eventignore' 来禁用。这大大加快了编辑每个缓冲区的
			速度。

			另见 |:tabdo|、|:argdo|、|:windo|、|:cdo|、|:ldo|、
			|:cfdo| 和 |:lfdo|。

示例: >

	:windo set nolist foldcolumn=0 | normal! zn

这将在所有窗口中重置 'list' 选项并禁用折叠。 >

	:bufdo set fileencoding= | update

这将在每个缓冲区中重置 'fileencoding' 并在发生更改时写入。结果是所有缓冲区
将使用 'encoding' 编码（如果转换成功的话）。

		"/path"。
		如果给出了计数，编辑第 count 个匹配的文件。

		将当前窗口一分为二。编辑光标下的文件名并跳转到文件名后面的
		行号。有关如何获取行号的详细信息，请参见 |gF|。

		打开新的标签页并编辑光标下的文件名。类似于 "tab split" 和

CTRL-W gF						*CTRL-W_gF*

CTRL-W gt						*CTRL-W_gt*

CTRL-W gT						*CTRL-W_gT*

10. 预览窗口					*preview-window*

预览窗口是用于显示（预览）另一个文件的特殊窗口。它通常是一个用于显示包含
文件或函数定义的小窗口。

每个标签页只能有一个预览窗口。它由下面的命令之一创建。'previewheight' 选项
可以设置预览窗口打开时的高度。在预览窗口中设置了 'previewwindow' 选项以便
识别它。设置了 'winfixheight' 选项以使其在打开/关闭其他窗口时保持相同的高度。

						*:pt* *:ptag*
:pt[ag][!] [tagname]
		执行 ":tag[!] [tagname]" 并在"预览"窗口中显示找到的标签，
		而不更改当前缓冲区或光标位置。如果"预览"窗口已存在，则重用
		它（像帮助窗口一样）。如果打开了新窗口，使用 'previewheight'
		作为窗口高度。另见 |:tag|。
		有关示例，请参见下文。|CursorHold-example|
		与 |:tag| 的小差异：当 [tagname] 等于已显示的标签时，匹配
		标签列表中的位置不会被重置。这使得 CursorHold 示例在
		|:ptnext| 之后也能工作。

CTRL-W z					*CTRL-W_z*
CTRL-W CTRL-Z					*CTRL-W_CTRL-Z* *:pc* *:pclose*
:pc[lose][!]	关闭当前打开的任何"预览"窗口。当设置了 'hidden' 选项，或者
		缓冲区已被修改且使用了 [!] 时，缓冲区变为隐藏（除非有另一个
		窗口正在编辑它）。如果任何"预览"缓冲区无法关闭，命令将失败。
		另见 |:close|。

							*:pp* *:ppop*
:[count]pp[op][!]
		在预览窗口中执行 ":[count]pop[!]"。参见 |:pop| 和 |:ptag|。

CTRL-W }						*CTRL-W_}*
		使用光标下的标识符作为标签并执行 :ptag。使新的预览窗口
		（如果需要）高度为 N 行。如果未给出 N，使用 'previewheight'。

CTRL-W g }						*CTRL-W_g}*
		使用光标下的标识符作为标签并执行 :ptjump。使新的预览窗口
		（如果需要）高度为 N 行。如果未给出 N，使用 'previewheight'。

							*:pb* *:pbuffer*
:[N]pb[uffer][!] [+cmd] [N]
		在预览窗口中从缓冲区列表编辑缓冲区 [N]。如果未给出 [N]，
		继续编辑当前缓冲区。有关 [!]，请参见 |:buffer-!|。这也会
		编辑不在缓冲区列表中的缓冲区，而不设置 'buflisted' 标志。
		另见 |+cmd|。

							*:ped* *:pedit*
:ped[it][!] [++opt] [+cmd] {file}
		在预览窗口中编辑 {file}。预览窗口的打开方式与 |:ptag| 相同。
		当前窗口和光标位置不会改变。有用的示例: >
			:pedit +/fputc /usr/include/stdio.h
<
		另见 |++opt| 和 |+cmd|。

							*:ps* *:psearch*
:[range]ps[earch][!] [count] [/]pattern[/]
		类似 |:ijump|，但在预览窗口中显示找到的匹配。预览窗口的
		打开方式与 |:ptag| 相同。当前窗口和光标位置不会改变。有用的
		示例: >
			:psearch popen
<		类似于 |:ptag| 命令，你可以使用这个来自动显示关于光标下单词
		的信息。这不如使用 |:ptag| 智能，但你不需要标签文件，它也会
		在系统包含文件中找到匹配。示例: >
  :au! CursorHold *.[ch] ++nested exe "silent! psearch " .. expand("<cword>")
<		警告：这可能很慢。

示例						*CursorHold-example*  >

  :au! CursorHold *.[ch] ++nested exe "silent! ptag " .. expand("<cword>")

这将在光标未移动的时间达到 'updatetime' 设定的时间时，对光标下的关键字执行
":ptag"。"++nested" 使其他自动命令得以执行，以便语法高亮在预览窗口中工作。
"silent!" 避免在找不到标签时出现错误消息。另见 |CursorHold|。要再次禁用: >

  :au! CursorHold

一个好的补充是高亮找到的标签、在光标下没有单词时避免 ":ptag"，以及一些其他
事项: >

  :au! CursorHold *.[ch] ++nested call PreviewWord()
  :func PreviewWord()
  :  if &previewwindow			" don't do this in the preview window
  :    return
  :  endif
  :  let w = expand("<cword>")		" get the word under cursor
  :  if w =~ '\a'			" if the word contains a letter
  :
  :    " Delete any existing highlight before showing another tag
  :    silent! wincmd P			" jump to preview window
  :    if &previewwindow		" if we really get there...
  :      match none			" delete existing highlight
  :      wincmd p			" back to old window
  :    endif
  :
  :    " Try displaying a matching tag for the word under the cursor
  :    try
  :       exe "ptag " .. w
  :    catch
  :      return
  :    endtry
  :
  :    silent! wincmd P			" jump to preview window
  :    if &previewwindow		" if we really get there...
  :	 if has("folding")
  :	   silent! .foldopen		" don't want a closed fold
  :	 endif
  :	 call search("$", "b")		" to end of previous line
  :	 let w = substitute(w, '\\', '\\\\', "")
  :	 call search('\<\V' .. w .. '\>')	" position cursor on match
  :	 " Add a match highlight to the word at this position
  :      hi previewWord term=bold ctermbg=green guibg=green
  :	 exe 'match previewWord "\%' .. line(".") .. 'l\%' .. col(".") .. 'c\k*"'
  :      wincmd p			" back to old window
  :    endif
  :  endif
  :endfun

11. 使用隐藏缓冲区					*buffer-hidden*

隐藏缓冲区不显示在窗口中，但仍然加载在内存中。这使得可以在文件之间跳转，
而不需要每次在窗口中获取另一个缓冲区时都读取或写入文件。

							*:buffer-!*
如果设置了选项 'hidden' ('hid')，对于所有开始编辑另一个文件的命令，被放弃的
缓冲区将被保留：":edit"、":next"、":tag" 等。在缓冲区列表中移动的命令有时
会使当前缓冲区变为隐藏，即使未设置 'hidden' 选项。当缓冲区已被修改但被强制
（使用 '!'）从窗口中移除，且 'autowrite' 关闭或缓冲区无法写入时，就会发生
这种情况。

你可以通过使用任何命令开始编辑隐藏缓冲区来使其不再隐藏，或者使用 ":bdelete"
命令删除它。

'hidden' 是全局的，它对所有缓冲区使用。'bufhidden' 选项可用于对特定缓冲区
作例外处理。它可以取以下值：
	<empty>		使用 'hidden' 的值。
	hide		隐藏此缓冲区，即使未设置 'hidden'。
	unload		不隐藏但卸载此缓冲区，即使设置了 'hidden'。
	delete		删除缓冲区。

							*hidden-quit*
当你尝试在有隐藏的、已修改的缓冲区时退出 Vim，你会得到一条错误消息，Vim
会使该缓冲区成为当前缓冲区。然后你可以决定写入此缓冲区 (":wq") 或不写入就
退出 (":q!")。小心：可能有更多隐藏的、已修改的缓冲区！

缓冲区也可以是未列出的。这意味着它存在，但不在缓冲区列表中。|unlisted-buffer|


:files[!] [flags]				*:files*
:buffers[!] [flags]				*:buffers* *:ls*
:ls[!] [flags]
		显示所有缓冲区。示例：

			1 #h   "/test/text"		line 1 ~
			2u     "asdf"			line 0 ~
			3 %a + "version.c"		line 1 ~

		在这里有点混淆...）。

		每个缓冲区有一个唯一编号。该编号不会改变，因此你始终可以
		使用 ":buffer N" 或 "N CTRL-^" 转到特定缓冲区，其中 N 是
		缓冲区编号。

		对于文件名使用以下特殊值：
			"[Prompt]"	|prompt-buffer|
			"[Scratch]"	'buftype' 为 "nofile"
			"[No Name]"	未指定文件名

		指示符（同一列中的字符互斥）：
		u	未列出的缓冲区（仅在使用 [!] 时显示）
			   |unlisted-buffer|
		 %	当前窗口中的缓冲区
		 #	用于 ":e #" 和 CTRL-^ 的备选缓冲区
		  a	活动缓冲区：已加载且可见
		  h	隐藏缓冲区：已加载，但当前未在窗口中显示
			   |hidden-buffer|
		   `-`	'modifiable' 关闭的缓冲区
		   =	只读缓冲区
		   R	正在运行作业的终端缓冲区
		   F	作业已完成的终端缓冲区
		   ?    没有作业的终端缓冲区：`:terminal NONE`
		    +	已修改的缓冲区
		    x   有读取错误的缓冲区

		[flags] 可以是以下字符的组合，用于限制要列出的缓冲区：
			+	已修改的缓冲区
			`-`	'modifiable' 关闭的缓冲区
			=	只读缓冲区
			a	活动缓冲区
			u	未列出的缓冲区（覆盖 "!"）
			h	隐藏缓冲区
			x	有读取错误的缓冲区
			%	当前缓冲区
			#	备选缓冲区
			R	正在运行作业的终端缓冲区
			F	作业已完成的终端缓冲区
			t	显示最后使用时间并按缓冲区排序
		组合标志意味着它们被"与"在一起，例如：
			h+	已修改的隐藏缓冲区
			a+	已修改的活动缓冲区

		使用 |:filter| 时，模式与显示的缓冲区名称匹配，例如: >
			filter /\.vim/ ls
<
						*:bad* *:badd*
:bad[d]	[+lnum] {fname}
		将文件名 {fname} 添加到缓冲区列表中而不加载它（如果尚未列出
		的话）。如果缓冲区之前被删除但未清除，它将重新变为已列出。

		+ 之后的其他命令将被忽略。

:[N]bd[elete][!]			*:bd* *:bdel* *:bdelete* *E516*
:bd[elete][!] [N]
		卸载缓冲区 [N]（默认：当前缓冲区）并从缓冲区列表中删除它。
		如果缓冲区已被修改，此操作将失败，除非指定了 [!]，在这种
		情况下更改将丢失。
		文件不受影响。此缓冲区的所有窗口都将关闭。如果缓冲区 [N]
		是当前缓冲区，将显示另一个缓冲区。这是跳转列表中指向已加载
		缓冲区的最近条目。

		实际上，缓冲区并未完全删除，它从缓冲区列表中移除
		|unlisted-buffer|，并且缓冲区的选项值、变量和映射/缩写将被
		清除。如果 [N] 是窗口中最后一个列出的缓冲区（即没有其他已列
		出的缓冲区可切换到），缓冲区将被清空而不是被卸载。窗口不会
		关闭，缓冲区可以作为新缓冲区重用 |buffer-reuse|。这确保每个
		窗口始终有一个有效的缓冲区。

		    :.,$-bdelete    " 从当前缓冲区删除到倒数第二个
				    " 缓冲区

		分割窗口并转到缓冲区列表中的第一个缓冲区。如果缓冲区列表

		遵守 'switchbuf' 选项。

								*]B*
]B		映射到 |:blast|。|default-mappings|

		分割窗口并转到缓冲区列表中的最后一个缓冲区。如果缓冲区列表
		为空，转到最后一个未列出的缓冲区。

		转到第 [N] 个下一个已修改的缓冲区。注意：此命令也会找到

12. 特殊类型的缓冲区				*special-buffers*

缓冲区除了包含文件的文本外，还可以用于其他目的。一些选项可以设置来更改缓冲区
的行为：
	'bufhidden'	当缓冲区不再显示在窗口中时会发生什么。
	'buftype'	这是什么类型的缓冲区
	'swapfile'	缓冲区是否有交换文件
	'buflisted'	缓冲区是否出现在缓冲区列表中

几种有用的缓冲区类型：

quickfix	用于包含错误列表或位置列表。参见 |:cwindow| 和 |:lwindow|。
		此命令将 'buftype' 选项设为 "quickfix"。你不应该更改这个！
		'swapfile' 关闭。

help		包含帮助文件。只能用 |:help| 命令创建。标识帮助缓冲区的标志
		是内部的，无法更改。帮助缓冲区的 'buflisted' 选项将被重置。

terminal	终端窗口缓冲区，参见 |terminal|。在作业结束前，内容不能被
		读取或更改。

directory	显示目录内容。可以被文件浏览器插件使用。缓冲区以这些设置
		创建: >
			:setlocal buftype=nowrite
			:setlocal bufhidden=delete
			:setlocal noswapfile
<		缓冲区名称是目录的名称，使用 |:cd| 命令时会调整。

						*scratch-buffer*
scratch		包含可以随时丢弃的文本。关闭窗口时保留，必须显式删除。
		设置: >
			:setlocal buftype=nofile
			:setlocal bufhidden=hide
			:setlocal noswapfile
<		如果给它一个有意义的名称，缓冲区名称可用于标识缓冲区。

						*unlisted-buffer*
unlisted	缓冲区不在缓冲区列表中。它不用于普通编辑，而是用于显示帮助
		文件、记住文件名或标记。":bdelete" 命令也会设置此选项，因此
		它不会完全删除缓冲区。设置: >
			:setlocal nobuflisted
<
