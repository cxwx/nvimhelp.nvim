*31.1*	文件浏览器

使用 File/Open... 菜单时你会得到一个文件浏览器。这使得找到你想要编辑的文件
更加容易。但如果你想要分割窗口来编辑另一个文件呢？没有对应的菜单项。你可以
先用 Window/Split 然后 File/Open...，但那更麻烦。
   既然你在 Vim 中大多数命令都是打字输入的，用打字的方式打开文件浏览器也是
可以的。要让 split 命令使用文件浏览器，在前面加上 "browse": >

	:browse split

选择一个文件，然后 ":split" 命令将用它来执行。如果你取消文件对话框，什么也不
会发生，窗口不会被分割。
   你也可以指定一个文件名参数。这用来告诉文件浏览器从哪里开始。例如: >

	:browse split /etc

文件浏览器将弹出，从目录 "/etc" 开始。

":browse" 命令几乎可以加在任何打开文件的命令前面。
   如果没有指定目录，Vim 将决定文件浏览器从哪里开始。默认情况下它使用和上次
相同的目录。因此当你使用 ":browse split" 并选择了 "/usr/local/share" 中的文件，
下次你使用 ":browse" 时它将再次从 "/usr/local/share" 开始。
   这可以通过 'browsedir' 选项改变。它可以有三个值之一:

	last		使用上次浏览的目录（默认）
	buffer		使用与当前缓冲区相同的目录
	current		使用当前目录

例如，当你在目录 "/usr" 中，编辑文件 "/usr/local/share/readme" 时，命令: >

	:set browsedir=buffer
	:browse edit

将在 "/usr/local/share" 中启动浏览器。另外: >

	:set browsedir=current
	:browse edit

将在 "/usr" 中启动浏览器。

	注意:
	为了避免使用鼠标，大多数文件浏览器都提供使用按键来导航。由于这在每个
	系统上都不同，这里不做解释。Vim 尽可能使用标准浏览器，你的系统文档
	应该在某处有关于键盘快捷键的解释。

当你不使用 GUI 版本时，你可以使用文件浏览器窗口来选择文件，就像在文件浏览器
中一样。但这对 ":browse" 命令不起作用。见 |netrw-browse|。

*31.2*	确认

Vim 保护你不会意外覆盖文件以及其他丢失修改的方式。如果你做了可能是坏事的操作，
Vim 产生一个错误信息，并建议加上 ! 如果你真的想这么做。
   为了避免重新输入带 ! 的命令，你可以让 Vim 给你一个对话框。然后你可以按
"OK" 或 "Cancel" 来告诉 Vim 你的选择。
   例如，你正在编辑一个文件并对它做了修改。你开始编辑另一个文件: >

	:confirm edit foo.txt

Vim 会弹出一个类似这样的对话框:

	+-----------------------------------+
	|				    |
	|   ?	Save changes to "bar.txt"?  |
	|				    |
	|   YES   NO		 CANCEL     |
	+-----------------------------------+

现在做你的选择。如果你想保存修改，选择 "YES"。如果你想永远丢弃修改: "NO"。
如果你忘了自己在做什么，想检查到底改了什么，选 "CANCEL"。你将回到同一个文件，
修改仍然在那里。

就像 ":browse" 一样，":confirm" 命令可以加在大多数编辑其他文件的命令前面。
它们也可以组合使用: >

	:confirm browse edit

这将在当前缓冲区被修改时产生一个对话框。然后它会弹出一个文件浏览器来选择
要编辑的文件。

	注意:
	在对话框中你可以使用键盘来选择。通常 <Tab> 键和光标键改变选项。
	按 <Enter> 选择当前选项。不过这取决于系统。

当你不使用 GUI 时，":confirm" 命令同样有效。它不会弹出对话框，而是 Vim 会在
窗口底部打印消息并要求你按一个键来做出选择。 >

	:confirm edit main.c
<	Save changes to "Untitled"? ~
	[Y]es, (N)o, (C)ancel:  ~

你现在可以按对应选项的单个键。你不需要像在命令行上的其他输入那样按 <Enter>。

*31.3*	菜单快捷键

键盘用于所有 Vim 命令。菜单提供了一种简单的方式来选择命令，而不需要知道它们
叫什么。但你必须把手从键盘上移开去拿鼠标。
   菜单通常也可以用按键来选择。这取决于你的系统，但最常见的方式是这样的。使用
<Alt> 键和菜单中带下划线的字母的组合。例如，<A-w>（<Alt> 和 w）弹出 Window
菜单。
   在 Window 菜单中，"split" 项的 p 带有下划线。要选择它，松开 <Alt> 键然后
按 p。

在用 <Alt> 键第一次选择了菜单后，你可以用光标键在菜单之间移动。<Right> 选择
子菜单，<Left> 关闭它。<Esc> 也关闭菜单。<Enter> 选择一个菜单项。

使用 <Alt> 键选择菜单项和使用 <Alt> 组合键做映射之间存在冲突。'winaltkeys'
选项告诉 Vim 应该如何处理 <Alt> 键。
   默认值 "menu" 是明智的选择: 如果该键组合是菜单快捷键，则不能被映射。所有
其他键可以用于映射。
   值 "no" 不使用任何 <Alt> 键用于菜单。因此你必须用鼠标来使用菜单，所有
<Alt> 键都可以被映射。
   值 "yes" 意味着 Vim 将使用所有 <Alt> 键用于菜单。一些 <Alt> 键组合可能
还有除选择菜单之外的其他功能。

*31.4*	Vim 窗口位置和大小

要查看当前 Vim 窗口在屏幕上的位置，使用: >

	:winpos

这只在 GUI 中有效。输出可能看起来像这样:

	Window position: X 272, Y 103 ~

位置以屏幕像素为单位给出。现在你可以用这些数字来将 Vim 移到其他地方。例如，
向左移动一百个像素: >

	:winpos 172 103
<
	注意:
	报告的位置和窗口实际移动的位置之间可能有一个小的偏差。这是因为窗口
	周围有边框。这是窗口管理器添加的。

你可以在启动脚本中使用这个命令将窗口定位在特定位置。

Vim 窗口的大小以字符为单位计算。因此这取决于所使用的字体大小。你可以用这个
命令查看当前大小: >

	:set lines columns

要改变大小，将 'lines' 和/或 'columns' 选项设为新值: >

	:set lines=50
	:set columns=80

获取大小在终端中和在 GUI 中一样工作。在大多数终端中不能设置大小。

你可以用一个参数启动 X-Windows 版本的 gvim 来指定窗口的大小和位置: >

	gvim -geometry {width}x{height}+{x-offset}+{y-offset}

{width} 和 {height} 以字符为单位，{x-offset} 和 {y-offset} 以像素为单位。
例如: >

	gvim -geometry 80x25+100+300

*31.5*	杂项

你可以使用 gvim 来编辑电子邮件消息。在你的邮件程序中你必须选择 gvim 作为
消息的编辑器。当你尝试时，你会发现它不能工作: 邮件程序认为编辑已经完成了，
而 gvim 还在运行！
   原因是 gvim 从启动它的 shell 断开了连接。当你在终端中启动 gvim 时这是好的，
这样你就可以在那个终端中做其他工作。但当你确实想要等待 gvim 完成时，你必须
阻止它断开连接。"-f" 参数做到了这一点: >

	gvim -f file.txt

"-f" 代表前台（foreground）。现在 Vim 将阻塞启动它的 shell，直到你完成编辑
并退出。


延迟启动 GUI

在 Unix 上可以先在终端中启动 Vim。当你在同一个 shell 中做各种工作时这很有用。
如果你正在编辑一个文件并决定想要使用 GUI，你可以用以下命令启动它: >

	:gui

Vim 将打开 GUI 窗口并不再使用终端。你可以继续使用终端做其他事情。"-f" 参数
在这里用于在前台运行 GUI。你也可以使用 ":gui -f"。
