*02.1*	第一次运行 Vim

要启动 Nvim,输入这个命令: >

	nvim file.txt

在 Unix 上,你可以在任何命令提示符下输入。如果你在 Microsoft Windows 上,打
开命令提示符窗口然后输入这个命令。无论哪种情况,Vim 都会开始编辑一个名为
file.txt 的文件。因为这是一个新文件,你会看到一个空白窗口。屏幕看起来会像这
样:
>
	+---------------------------------------+
	|#					|
	|~					|
	|~					|
	|~					|
	|~					|
	|"file.txt" [New]			|
	+---------------------------------------+
		('#' 是光标位置。)
<
波浪号 (~) 行表示不在文件中的行。换句话说,当 Vim 没有文件内容可显示时,就会
显示波浪号行。在屏幕底部,有一条消息行表明文件名为 file.txt,并且你正在创建
一个新文件。消息信息是临时的,其他信息会覆盖它。

*02.2*	插入文本

Vim 编辑器是一个模式编辑器。这意味着编辑器的行为会因你所处的模式而不同。两
种基本模式称为普通模式和插入模式。在普通模式下,你输入的字符是命令。在插入
模式下,字符被作为文本插入。
   因为你刚启动 Vim,它处于普通模式。要进入插入模式,输入 "i" 命令 (i 代表
Insert,插入)。然后你就可以输入文本了。文本会被插入到文件中。不用担心出
错;你可以稍后纠正。要输入以下程序员的打油诗,需要这样输入: >

	iA very intelligent turtle
	Found programming Unix a hurdle

输入 "turtle" 后按 <Enter> 键开始新的一行。最后按 <Esc> 键退出插入模式,回
到普通模式。你现在的 Vim 窗口中有两行文本:
>
	+---------------------------------------+
	|A very intelligent turtle		|
	|Found programming Unix a hurdle	|
	|~					|
	|~					|
	|					|
	+---------------------------------------+
<

当前是什么模式?

要能看到你处于什么模式,输入这个命令: >

	:set showmode

你会注意到输入冒号时 Vim 把光标移到了窗口的最后一行。那是你输入冒号命令 (以
冒号开头的命令) 的地方。按 <Enter> 键完成这个命令 (所有以冒号开头的命令都这
样结束)。
   现在,如果你输入 "i" 命令,Vim 会在窗口底部显示 --INSERT-- (插入)。这表示
你处于插入模式。
>
	+---------------------------------------+
	|A very intelligent turtle		|
	|Found programming Unix a hurdle	|
	|~					|
	|~					|
	|-- INSERT --				|
	+---------------------------------------+
<
如果按 <Esc> 回到普通模式,最后一行将变为空白。


摆脱麻烦

Vim 初学者的一个常见问题是模式混淆,这是由于忘记了你处于什么模式,或者意外
输入了切换模式的命令。要回到普通模式,无论你处于什么模式,按 <Esc> 键。有时
你需要按两次。如果 Vim 发出哔声,说明你已经在普通模式了。

*02.3*	移动光标

回到普通模式后,你可以使用以下按键移动光标:

	h   左						*hjkl*
	j   下
	k   上
	l   右

乍一看,这些命令似乎是随意选择的。毕竟,谁听说过用 l 表示右呢?但实际上,
选择这些键有一个非常好的理由: 移动光标是编辑器中最常做的事,而这些键在右手
的起始行上。换句话说,这些命令被放在你能最快输入的位置 (尤其是当你用十指打
字时)。

	备注:
	你也可以用方向键移动光标。但如果你这样做,编辑速度会大大降低,因为
	按方向键时必须把手从文本键移到方向键上。考虑到你可能每小时要这样做
	几百次,这会花费大量时间。
	   另外,有些键盘没有方向键,或者方向键位置不常见;因此,掌握 hjkl
	键在这些情况下会有帮助。

记住这些命令的一个方法是: h 在左边,l 在右边,j 指向下方。用图示表示: >

		       k
		   h     l
		     j

学习这些命令的最好方法就是使用它们。用 "i" 命令插入更多文本行。然后用 hjkl
键四处移动并在某处插入一个单词。别忘了按 <Esc> 回到普通模式。|:Tutor| 也是一
种很好的边做边学的方式。

对于日本用户,Hiroshi Iwatani 建议使用以下方式记忆:

			Komsomolsk
			    ^
			    |
	   Huan Ho	<--- --->  Los Angeles
	(Yellow river)	    |
			    v
			  Java (指岛屿,不是编程语言)

*02.4*	删除字符

要删除一个字符,将光标移到它上面然后输入 "x"。(这要追溯到打字机的旧时代,
那时你通过在上面打 xxxx 来删除东西。) 将光标移到第一行的开头,例如,输入
xxxxxxx (七个 x) 来删除 "A very "。结果应该是这样的:
>
	+---------------------------------------+
	|intelligent turtle			|
	|Found programming Unix a hurdle	|
	|~					|
	|~					|
	|					|
	+---------------------------------------+
<
现在你可以插入新文本,例如输入: >

	iA young <Esc>

这开始一次插入 (i),插入文字 "A young",然后退出插入模式 (最后的 <Esc>)。
结果:
>
	+---------------------------------------+
	|A young intelligent turtle		|
	|Found programming Unix a hurdle	|
	|~					|
	|~					|
	|					|
	+---------------------------------------+
<

删除整行

要删除整行,使用 "dd" 命令。下面的行会上移来填补空缺:
>
	+---------------------------------------+
	|Found programming Unix a hurdle	|
	|~					|
	|~					|
	|~					|
	|					|
	+---------------------------------------+
<

删除换行符

在 Vim 中你可以将两行合并在一起,这意味着它们之间的换行符被删除。"J" 命令可
以完成这个操作。
   拿这两行来说:

	A young intelligent ~
	turtle ~

将光标移到第一行然后按 "J":

	A young intelligent turtle ~

*02.5*	撤销和重做

假设你删多了。没关系,你可以重新输入,但有更简单的方法。"u" 命令撤销上一次
编辑。看看实际操作: 用 "dd" 删除第一行后,"u" 会把它恢复回来。
   再来一个: 将光标移到第一行的 A 上:

	A young intelligent turtle ~

现在输入 xxxxxxx 来删除 "A young"。结果如下:

	 intelligent turtle ~

输入 "u" 撤销上一次删除。那次删除去掉了 g,所以撤销恢复了这个字符。

	g intelligent turtle ~

下一个 "u" 命令恢复倒数第二个被删除的字符:

	ng intelligent turtle ~

下一个 "u" 命令给你 u,依此类推:

	ung intelligent turtle ~
	oung intelligent turtle ~
	young intelligent turtle ~
	 young intelligent turtle ~
	A young intelligent turtle ~

重做

如果你撤销得太多,你可以按 CTRL-R (重做) 来逆转上一个命令。换句话说,它撤销
了撤销。要看看实际效果,按 CTRL-R 两次。字符 A 和它后面的空格消失了:

	young intelligent turtle ~

有一个特殊版本的撤销命令,"U" (撤销行) 命令。撤销行命令撤销对最后编辑的行
所做的所有更改。输入此命令两次会取消之前的 "U"。

	A very intelligent turtle ~
	  xxxx				删除 very

	A intelligent turtle ~
		      xxxxxx		删除 turtle

	A intelligent ~
					用 "U" 恢复该行
	A very intelligent turtle ~
					用 "u" 撤销 "U"
	A intelligent ~

"U" 命令本身也是一个修改操作,"u" 命令可以撤销它,CTRL-R 可以重做它。这可能
有点令人困惑。别担心,用 "u" 和 CTRL-R 你可以回到任何一个之前的状态。更多相
关内容在 |32.2| 节。

==============================================================================
*02.6*	其他编辑命令

Vim 有大量修改文本的命令。参见 |Q_in| 和下文。这里列出一些常用的。


追加

"i" 命令在光标下的字符之前插入一个字符。这很好用;但如果你想在行尾添加内容
怎么办?为此你需要在光标之后插入文本。这是用 "a" (追加) 命令完成的。
   例如,要将这行

	and that's not saying much for the turtle. ~
改为
	and that's not saying much for the turtle!!! ~

将光标移到行尾的句点上。然后输入 "x" 删除句点。光标现在位于行尾 turtle 的 e
上。现在输入 >

	a!!!<Esc>

在 turtle 的 e 之后追加三个感叹号:

	and that's not saying much for the turtle!!! ~


开始新行

"o" 命令在光标下方创建一个新的空行,并将 Vim 置于插入模式。然后你可以输入新
行的文本。
   假设光标在以下两行中第一行的某处:

	A very intelligent turtle ~
	Found programming Unix a hurdle ~

如果你现在使用 "o" 命令并输入新文本: >

	oThat liked using Vim<Esc>

结果是:

	A very intelligent turtle ~
	That liked using Vim ~
	Found programming Unix a hurdle ~

"O" 命令 (大写) 在光标上方开始新行。


使用计数

假设你想向上移动九行。你可以输入 "kkkkkkkkk" 或者输入命令 "9k"。实际上,你
可以在许多命令前加一个数字。在本章前面,例如,你通过输入 "a!!!<Esc>" 在行尾
添加了三个感叹号。另一种方法是使用命令 "3a!<Esc>"。计数 3 告诉后面的命令将
其效果重复三倍。同样,要删除三个字符,使用命令 "3x"。计数总是在它所应用的命
令之前。

==============================================================================
*02.7*	退出

要退出,使用 "ZZ" 命令。这个命令保存文件并退出。

	备注:
	与许多其他编辑器不同,Vim 不会自动创建备份文件。如果你输入 "ZZ",
	你的修改就已提交,无法回头了。你可以配置 Vim 编辑器来产生备份文件;
	参见 |07.4|。


丢弃修改

有时你会做了一系列修改,然后突然意识到修改之前更好。不用担心;Vim 有一个
放弃一切退出的命令。它是: >

	:q!

别忘了按 <Enter> 来完成这个命令。

对于那些对细节感兴趣的人,这个命令的三个部分分别是: 冒号 (:),进入命令行模
式;q 命令,告诉编辑器退出;以及覆盖修饰符 (!)。
   需要覆盖修饰符是因为 Vim 不愿轻易丢弃修改。如果你只输入 ":q",Vim 会显
示错误消息并拒绝退出:

	E37: No write since last change (use ! to override) ~

通过指定覆盖,你实际上是在告诉 Vim,"我知道我做的看起来很蠢,但我确实要这么
做。"

如果你想继续用 Vim 编辑: ":e!" 命令重新加载文件的原始版本。

*02.8*	查找帮助

你想知道的一切都可以在 Vim 帮助文件中找到。别怕提问!

如果你知道你在找什么,使用帮助系统搜索通常比用 Google 更容易。因为主题遵循
一定的样式指南。

而且帮助的优势在于它属于你特定版本的 Vim。你不会看到后来添加的命令的帮助。
那些命令对你是不起作用的。

要获得通用帮助,使用这个命令: >

	:help

你也可以使用第一个功能键 <F1>。如果你的键盘有 <Help> 键,它可能也有效。
   如果你不提供主题,":help" 会显示通用帮助窗口。Vim 的创建者们对帮助系统做
了一件很聪明 (或者说很懒) 的事: 他们把帮助窗口做成了一个普通的编辑窗口。你
可以使用所有普通的 Vim 命令在帮助信息中移动。因此 h、j、k 和 l 分别向左、
下、上和右移动。
   要退出帮助窗口,使用与退出编辑器相同的命令: "ZZ"。这只会关闭帮助窗口,
不会退出 Vim。

在阅读帮助文本时,你会注意到一些文本被竖线包围 (例如 |help|)。这表示一个超
链接。如果你将光标定位在竖线之间的任何位置并按 CTRL-] (跳转到标签),帮助系
统会带你到所指的主题。(由于这里不讨论的原因,Vim 对超链接的术语是标签。所以
CTRL-] 跳转到光标下单词所给出的标签位置。)
   跳转几次后,你可能想回去。CTRL-T (弹出标签) 会带你回到之前的位置。CTRL-O
(跳到较旧的位置) 在这里也很好用。
   在帮助屏幕的顶部,有标记 "*help.txt*"。"*" 字符之间的名称被帮助系统用来
定义一个标签 (超链接目标)。
   关于使用标签的详细信息参见 |29.1|。

要获取给定主题的帮助,使用以下命令: >

	:help {subject}

要获取 "x" 命令的帮助,例如,输入以下命令: >

	:help x

要查找如何删除文本,使用这个命令: >

	:help deleting

要获取所有 Vim 命令的完整索引,使用以下命令: >

	:help index

当你需要获取控制字符命令的帮助时 (例如 CTRL-A),你需要用前缀 "CTRL-" 来拼
写它。 >

	:help CTRL-A

Vim 编辑器有许多不同的模式。默认情况下,帮助系统显示普通模式命令。例如,以
下命令显示普通模式 CTRL-H 命令的帮助: >

	:help CTRL-H

要识别其他模式,使用模式前缀。如果你想要插入模式版本的命令帮助,使用 "i_"。
对于 CTRL-H,这给你以下命令: >

	:help i_CTRL-H

当你启动 Vim 编辑器时,你可以使用几个命令行参数。这些都以短横线 (-) 开头。
要找出 -t 参数做什么,例如,使用命令: >

	:help -t

Vim 编辑器有许多选项,使你能够配置和自定义编辑器。如果你想获取选项的帮助,
需要用单引号将其括起来。要找出 'number' 选项做什么,例如,使用以下命令: >

	:help 'number'

所有模式前缀的表格可以在下面找到: |help-summary|。

特殊键用尖括号括起来。要找到插入模式下上箭头键的帮助,例如,使用这个命令: >

	:help i_<Up>

如果你看到一个不理解的错误消息,例如:

	E37: No write since last change (use ! to override) ~

你可以使用开头的错误 ID 来找到关于它的帮助: >

	:help E37


帮助摘要:					*help-summary*  >

1) 在输入主题后使用 Ctrl-D,让 Vim 显示所有可用的主题。
   或者按 Tab 来补全: >
	:help some<Tab>
<   关于如何使用帮助的更多信息: >
	:help helphelp

2) 跟随竖线中的链接到相关帮助。你可以从详细帮助跳转到用户文档,后者从用户
   角度描述某些命令,且不那么详细。例如,在: >
	:help pattern.txt
<   之后你可以在简介中看到用户指南主题 |03.9| 和 |usr_27.txt|。

3) 选项用单引号括起来。要跳转到 list 选项的帮助主题: >
	:help 'list'
<   如果你只知道你在找某个选项,你也可以这样做: >
	:help options.txt
<   打开描述所有选项处理的帮助页面,然后使用正则表达式搜索,例如 textwidth。
   某些选项有自己的命名空间,例如: >
	:help cpo-<letter>
<   是 'cpoptions' 设置的对应标志,将 <letter> 替换为具体的标志,例如: >
	:help cpo-;
<   对于 'guioptions' 标志: >
	:help go-<letter>

4) 普通模式命令没有前缀。要跳转到 "gt" 命令的帮助页面: >
	:help gt

5) 插入模式命令以 i_ 开头。删除一个单词的帮助: >
	:help i_CTRL-W

6) 可视模式命令以 v_ 开头。跳转到可视区域另一端的帮助: >
	:help v_o

7) 命令行编辑和参数以 c_ 开头。使用命令参数 % 的帮助: >
	:help c_%

8) Ex 命令总是以 ":" 开头,所以要跳转到 ":s" 命令的帮助: >
	:help :s

9) 专门用于调试的命令以 ">" 开头。要跳转到 "cont" 调试命令的帮助: >
	:help >cont

10) 组合键。它们通常以一个字母开头,表示可以使用的模式。例如: >
	:help i_CTRL-X
<    带你到插入模式下的 CTRL-X 命令族,这些命令可用于自动补全不同的内容。注
    意,某些键总是以相同方式书写,例如 Control 总是写为 CTRL。
    对于普通模式命令没有前缀,主题位于 :h CTRL-<Letter>。例如  >
	:help CTRL-W
<    相反 >
	:help c_CTRL-R
<    描述在命令行中输入命令时 CTRL-R 的作用,而 >
	:help v_CTRL-A
<    讨论在可视模式下增加数字,而 >
	:help g_CTRL-A
<    讨论 "g<C-A>" 命令 (即你必须先按 "g" 然后按 <CTRL-A>)。这里的 "g" 代
    表普通命令 "g",它总是期望第二个键然后才执行某些操作,类似于以 "z" 开头
    的命令。

11) 正则表达式项总是以 / 开头。所以要获取 Vim 正则表达式中 "\+" 量词的帮助: >
	:help /\+
<    如果你想了解关于正则表达式的所有内容,从这里开始阅读: >
	:help pattern.txt

12) 寄存器总是以 "quote" 开头。要了解特殊的 ":" 寄存器: >
	:help quote:

13) Vim 脚本位于 >
	:help vimeval.txt
<    语言的某些方面位于 :h expr-X,其中 "X" 是一个字母。例如  >
	:help expr-!
<    将带你到描述 Vim 脚本中 "!" (非) 运算符的主题。
    同样重要的是 >
	:help function-list
<    可以找到所有可用函数的简短描述。Vim 脚本函数的帮助主题总是包含 "()",
    所以: >
	:help append()
<    讨论的是 append Vim 脚本函数,而不是如何在当前缓冲区中追加文本。

14) 映射在帮助页面 :h |map.txt| 中讨论。使用 >
	:help mapmode-i
<    来了解 |:imap| 命令。也可以使用 :map-topic 来了解映射的某些特定子主
    题。例如: >
	:help :map-local
<    用于缓冲区局部映射,或 >
	:help map-bar
<    了解映射中如何处理 '|'。

15) 命令定义在 :h command-topic 中讨论,所以使用 >
	:help command-bang
<    来了解自定义命令的 '!' 参数。

16) 窗口管理命令总是以 CTRL-W 开头,所以你可以在 :h CTRL-W_letter 找到对应
    的帮助。例如 >
	:help CTRL-W_p
<    用于移动到之前访问的窗口。你也可以访问 >
	:help windows.txt
<    如果你正在寻找窗口操作命令,可以通读一遍。

17) 使用 |:helpgrep| 在所有帮助页面 (包括已安装的插件) 中搜索。参见
    |:helpgrep| 了解如何使用它。
    要搜索一个主题: >
	:helpgrep topic
<    这会带你到第一个匹配。要转到下一个: >
	:cnext
<    所有匹配都在快速修复窗口中,可以用以下命令打开: >
	:copen
<    移动到你想要的匹配处,然后按 Enter 跳转到该帮助。

18) 用户手册。它以相当友好的方式为初学者描述帮助主题。从 |usr_toc.txt| 开始
    查找目录 (你可能已经猜到了): >
	:help usr_toc.txt
<    浏览内容找到感兴趣的主题。"Digraphs" 和 "Entering special characters"
    项在第 24 章,所以要跳转到那个特定的帮助页面: >
	:help usr_24.txt
<    如果你想访问帮助中的某个章节,也可以直接像这样访问章节号: >
	:help 10.1
<    这将跳转到 |usr_10.txt| 的第 10.1 章,讲述录制宏。

19) 高亮组。总是以 hl-groupname 开头。例如 >
	:help hl-WarningMsg
<    讲述 WarningMsg 高亮组。

20) 语法高亮的命名空间为 :syn-topic。例如 >
	:help :syn-conceal
<    讲述 ":syn" 命令的 conceal 参数。

21) 快速修复命令通常以 :c 开头,而位置列表命令通常以 :l 开头

22) 自动命令事件可以通过名称找到: >
	:help BufWinLeave
<    要查看所有可能的事件: >
	:help events

23) 命令行开关总是以 "-" 开头。所以对于 Vim 的 -f 命令开关使用: >
	:help -f

24) Lua 语言和 Nvim 的 Lua 标准库位于 >vim
	:help lua.txt
<    在 Nvim 中使用 Lua 的指南位于 >vim
	:help lua-guide.txt
<    Lua 5.1 参考手册位于 >vim
	:help luaref.txt
<
25) 特定文件类型功能的文档通常以 ft-<filetype>-<functionality> 的形式提供。
    所以 >
	:help ft-c-syntax
<    讲述 C 语法文件及其提供的选项。有时还有 omni 补全的额外章节 >
	:help ft-php-omni
<    或文件类型插件 >
	:help ft-tex-plugin
<    可用。

26) 错误和警告代码可以直接在帮助中查找。所以 >
	:help E297
<    会直接带你到交换错误消息的描述,而 >
	:help W10
<    讲述 "Changing a readonly file" 警告。
    但有时这些错误代码没有描述,而是列在通常导致此错误的 Vim 命令处。所以: >
	:help E128
<    带你到 |:function| 命令

27) 随 Vim 分发的软件包的文档形式为 package-<name>。所以 >
	:help package-termdebug
<
    将带你到包含的 termdebug 插件的帮助部分以及如何启用它。
